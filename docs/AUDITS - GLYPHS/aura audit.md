**Findings & labels**
- Hover aura system: **not present** as a dedicated implementation (only hover glyph/scanline elsewhere). No mesh-based hover aura found in current codebase. (Flagged as the system to retire → currently absent).
- Selected aura system to elevate: `_UISelectedNodeHighlight3_2.js` is the only dedicated selected-node aura/highlight mesh system.
- Flame/linked aura isolation: `NodeLinkedAuraSystem.js` is self-contained, acts only on nodes with active links, uses its own meshes/materials, and doesn’t touch hover/selected meshes—removal/updates are confined to its internal `nodeAuras` map → **isolated from hover/selected flows**.

**Conflict map (material/scale writers)**
- `material.opacity`: NodeLinkedAuraSystem, AuraModulationSystem, GlobalAuraOpacityClamp, UIPrimaryNodeAura (pulse), UISelectedNodeHighlight (minor). Potential multi-writer combinations: LinkedAura ↔ Clamp; LinkedAura ↔ Modulation; Primary/Selected ↔ Clamp/Modulation.
- `mesh.scale`: NodeLinkedAuraSystem (scale pulse), AuraModulationSystem (scale_swell), UISelectedNodeHighlight (pulse), UIPrimaryNodeAura (bob/rotation).
- `material.color/emissive`: AuraModulationSystem; UISelectedNodeHighlight (emissiveIntensity), UIPrimaryNodeAura (emissive), NodeLinkedAuraSystem color mostly static.
