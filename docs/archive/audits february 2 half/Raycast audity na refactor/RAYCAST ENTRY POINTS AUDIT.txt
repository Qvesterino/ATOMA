SECTION 5 — Suspicious Patterns
CONFIRMED ANTI-PATTERNS
Pattern 1: scene.traverse() for Click Detection
Files: _NodeLinking2_3.js, NodeInspectOverlay3_0.js
Code:

scene.traverse((obj) => {
  if (obj.userData && obj.userData.isNode) {
    nodes.push(obj);
  }
});
const intersects = this.raycaster.intersectObjects(nodes);
Violation: Full scene traversal every raycast
Recommendation: Use hit-proxy system or registered target registry
Pattern 2: intersectObjects(scene.children, true) with Recursive Flag
Files: AINodes.js, SafeMobilityPack4.js
Code:

const intersects = raycaster.intersectObjects(scene.children, true);
Violation: Recursive traversal, hits visual artifacts
Recommendation: Use non-recursive + filtered targets
Pattern 3: Multiple Intersect Calls Per Frame
Files: NodeEditor.js
Code: Multiple sequential intersectObjects() calls per update
Violation: Inefficient batching
Recommendation: Consolidate raycasts or cache results
Pattern 4: Raycast Logic Inside Visual/VFX Systems
Files: SafeMobilityPack4.js (mobility VFX)
Code: Raycast for ground detection in VFX update loop
Violation: Visual system performing gameplay raycasts
Recommendation: Separate concerns (visual vs interaction)
