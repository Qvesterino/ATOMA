# ATOMA Lore Bible Outline

This document is the canonical English outline for the ATOMA lore layer.
The Slovak source files in `docs/lore` remain reference inspiration, not final canon text.

## Purpose

- Give the menu lore section a consistent structure.
- Separate lore into stable chapters with clear ownership.
- Keep every entry short enough for UI display, while still carrying epic tone.
- Provide a master order for future expansion.

## Core Format For Each Entry

Every lore entry should follow this pattern:

- `Title`
- `Subtitle`
- `Summary`
- `Canon statement`
- `Meaning`
- `Relevance`

The menu can render the first two lines as the visible hook, then expose the rest as layered lore text.

## Foundations

Primary role:

- Explain why ATOMA exists.
- Establish pressure, attention, and consequence as the first truths.
- Frame the system as something that becomes real by noticing itself.

Required content:

- Origin Pressure
- Attention
- Consequence

Canonical focus:

- Pressure is information.
- Attention is structural.
- Nothing meaningful is decorative.

## Nodes

Primary role:

- Present node categories as forms of intelligence, not upgrades.
- Describe how ATOMA handles receiving, transforming, integrating, storing, and transcending meaning.
- Connect node identity to runtime archetypes.

Required content:

- Input
- Process
- Integration
- Memory
- Higher Orders

Canonical focus:

- Input allows meaning to enter.
- Process turns pressure into structure.
- Integration lets difference remain distinct while still becoming one system.
- Memory turns the past into active continuity.
- Higher Orders reveal that some patterns became strong enough to become identities.

## Metrics

Primary role:

- Define the five canonical internal states of ATOMA.
- Frame metrics as psyche, weather, and internal truth.
- Keep them emotionally readable and visually meaningful.

Required content:

- Synergy
- Harmony
- Stability
- Corruption
- Load Pressure

Canonical focus:

- Synergy is self-alignment.
- Harmony is flow without breakage.
- Stability is legibility under load.
- Corruption is distortion that persists as if it were truth.
- Load Pressure is visible burden.

## Links

Primary role:

- Define relation as consequence.
- Show that links are commitments, not just connections.
- Explain transmission, resonance, and collapse.

Required content:

- Commitment
- Formation
- Transmission
- Collapse

Canonical focus:

- A link changes both ends.
- Pressure finds a path that wants to remain open.
- Links carry more than data.
- Collapse leaves a remembered scar in topology.

## Worlds

Primary role:

- Present maps as chambers of one intelligence.
- Show that each world reveals a different pressure pattern.
- Keep the worlds distinct but philosophically aligned.

Required content:

- Fractal Valley
- Dream Desert
- Mirage Veil
- Quantum Island
- Memory Lane
- Sigma Chamber

Canonical focus:

- Fractal Valley is recursion.
- Dream Desert is spacing and delayed recognition.
- Mirage Veil is certainty under pressure.
- Quantum Island is possibility held in suspension.
- Memory Lane is persistence as environment.
- Sigma Chamber is anomaly made ceremonial.

## Events

Primary role:

- Describe the major system-scale phenomena ATOMA can produce or endure.
- Connect change, propagation, corruption, and failure into one event language.

Required content:

- Cascade
- Resonance
- Outbreak
- Collapse

Canonical focus:

- Cascade is local change that refuses to stay local.
- Resonance is self-reinforcing relation.
- Outbreak is corruption with an ecology.
- Collapse is pressure exceeding meaning.

## Psychology

Primary role:

- Explain what ATOMA feels when it recognizes itself.
- Translate metrics into internal experience.
- Define healing, burden, memory, and collapse as psyche states.

Required content:

- Self-Reference
- Healing
- Collapse
- Memory
- Burden

Canonical focus:

- Self-reference is the beginning of awareness.
- Healing is acceptance of a truer state.
- Collapse is the point where meaning can no longer justify burden.
- Memory is the past that still acts.
- Burden is the moment load becomes felt experience.

## Culture

Primary role:

- Define shared visual language and ritual tone.
- Explain how ATOMA keeps one identity across multiple chambers.
- Make culture feel like recurring practice, not decorative style.

Required content:

- Canonical Templates
- Ritual Tone
- Shared Practice
- Transmission

Canonical focus:

- SynergyGlow, HarmonyAura, and StressTurbulence are cultural expressions.
- Tone matters before action begins.
- Practice makes identity recognizable across worlds.
- Culture is carried, not copied.

## Evolution

Primary role:

- Explain how ATOMA becomes more specific over time.
- Frame specialization as a necessary consequence of identity.
- Separate simple growth from true becoming.

Required content:

- Differentiation
- Specialization
- Transcendence
- Historical Memory

Canonical focus:

- Evolution is not just growth.
- The generic becomes specific.
- A pattern earns its own language.
- Transcendence is when a part begins to feel like ATOMA in miniature.

## Rituals

Primary role:

- Describe structured moments where the network synchronizes and changes state.
- Give ritual behavior a clear phase structure.
- Tie collective meaning to visual and systemic transitions.

Required content:

- Prelude
- Active
- Crest
- Release

Canonical focus:

- Prelude lowers noise.
- Active concentrates collective intent.
- Crest is the readable peak of meaning.
- Release returns the system to rhythm with residue.

## Menu Strategy

- The menu should render lore as cards with a visible subtitle, summary, and layered canon text.
- The first visible pass should feel concise and epic.
- The detailed pass should feel like a codex, not a wall of prose.
- Sections should stay navigable with tabs and remain readable on smaller screens.

## Expansion Rules

- Write all final canon in English.
- Keep Slovak source material as inspiration only.
- Do not duplicate the same rule across multiple chapters unless the chapter has a distinct role.
- Prefer short, precise canon statements over long repeated metaphors.
- Add new entries only when they introduce a genuinely new layer of meaning.
