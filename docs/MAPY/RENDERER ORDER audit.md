## CONFLICT ZONES
- **VisualAuthority (per-frame)** vs **VisualHierarchyRegistry v2**: forces CORE=0, SHELL=5, AURA=10, VFX=15 every frame; overrides registry node (<2) & link (2–20) scheme.
- **NodeSurfaceProtectionRule_v2** (core=100, aura=10) and **NodeSurfaceDominanceRule_v1** (core=10, aura=5) override registry values when invoked.
- **NodeDepthAndHoloPreservationFix**: scene-wide override links=10, auras=20, cores=30, holograms=40; conflicts with registry and new LINK stack orders.
- **CoreVisualAuthoritySystem**: spawn-time override core=1000, visual-only=-1000, rims=500; divergent from registry.
- **_VisualHierarchyCorrectionSystem_v1**: register sets core=100 (higher than registry); enforcement disabled but if toggled would recursively overwrite hierarchy.
- **Debug helper** (9999) temporarily forces top renderOrder; safe when off.
