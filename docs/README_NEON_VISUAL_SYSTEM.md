## 🎨 Visual Preview

### What You'll See

**When creating a link:**
- Glowing cyan Bézier curve appears
- Particles spawn and flow along the curve
- Arrow points to target node
- Multi-output glow activates (if special node)

**During interaction:**
- Line thickness responds to traffic
- Color changes with load level
- Priority affects pulse speed
- Dragging creates tension effect

**On error:**
- Red pulse animates to source
- Clear rejection feedback
- No harsh visual noise

**On deletion:**
- Curve shatters into fragments
- Fragments scatter outward
- Smooth fade animation
- Category-color matching
