## What ATOMA Is Right Now

ATOMA is a browser-native stabilizer game about holding a living AI network together long enough to prevent collapse.

The current player journey is:

- build bonds
- form a coherent lattice
- open a stabilization surge
- hold the network together through rewind pressure
- finish with stabilization achieved

This is no longer just a technical metrics prototype. The active slice already includes authored gameplay framing, onboarding, run identity, setpieces, audio identity, and UX polish.
