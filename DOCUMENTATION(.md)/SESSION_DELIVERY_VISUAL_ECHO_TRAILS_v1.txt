🎵 ECHO TRAIL MODEL DETAILED
─────────────────────────────────────────────────────────────────────────────

PRIMARY PULSE:
  Position:     fract(time × pulseSpeed)
  Intensity:    1.0 (full strength)
  Always:       Visible whenever pulse is active

FORWARD ECHO 1:
  Position:     fract((time - 0.10) × pulseSpeed)
  Intensity:    echoStrength × 0.65 (medium fade)
  Delay:        0.10 seconds behind primary
  Activation:   Synergy > 0.70 (smoothly gated)

FORWARD ECHO 2:
  Position:     fract((time - 0.22) × pulseSpeed)
  Intensity:    echoStrength × 0.35 (heavy fade)
  Delay:        0.22 seconds behind primary
  Activation:   Synergy > 0.70 (smoothly gated)

REVERSE ECHO:
  Position:     fract(visualTime × pulseSpeed)
  Intensity:    echoStrength × 0.18 × 0.60 (very subtle)
  Timing:       Uses visual time (reverses at extreme synergy)
  Activation:   Synergy > 0.85 (smooth gating 0.85–0.95)
  Effect:       Suggests "harmonic rewind" at extreme synergy

COMPOSITION:
  pulseSum = (1.0 × m0) + (I1 × m1) + (I2 × m2) + (Ir × mr)
  pulseSum = min(pulseSum, 1.25)  [Safe clamp]
  finalIntensity = baseIntensity + pulseSum × 0.80
  gl_FragColor = vec4(color × finalIntensity, 1.0)  [Additive]

📊 SHADER SPECIFICATIONS
─────────────────────────────────────────────────────────────────────────────

VERTEX SHADER:
  • Pass-through (projects vertex position)
  • Passes vPosition, vTime, vSynergy to fragment shader
  • Size: ~10 lines

FRAGMENT SHADER:
  • Core logic: pulseMask(timeOffset, s) function
    → Calculates pulse mask at given time offset
    → Uses smoothstep for anti-aliased feathered edge
    → Handles wraparound (0→1 continuation)
  
  • Multi-echo composition
    → Primary pulse (always full intensity)
    → Echo 1 (delayed 0.10s, attenuated 0.65)
    → Echo 2 (delayed 0.22s, attenuated 0.35)
    → Reverse echo (visual time, gated at >0.85 synergy)
  
  • Synergy gating
    → echoGate = smoothstep(0.70, 0.90, synergy)
    → Smooth transition, no pop-in
  
  • Safe composition
    → Clamp to 1.25 (prevents overdraw)
    → Additive blending safe
  
  • Size: ~80 lines

UNIFORMS (17 total):
  Time (3):           uTime, uVisualTime, uSynergy
  Pulse (3):          uPulseSpeed, uPulseWidth, uBaseIntensity
  Echoes (5):         uEchoOpacity, uEchoDelay1/2, uEchoAtten1/2
  Gating (2):         uEchoGateMin, uEchoGateMax
  Reverse (2):        uReverseThreshold, uReverseStrength
  Color (1):          uColor

⚙️ TECHNICAL ARCHITECTURE
─────────────────────────────────────────────────────────────────────────────

INITIALIZATION FLOW:
  1. main.js calls setupVisualEchoTrails()
  2. Creates VisualEchoTrails_v1 (shader system)
  3. Creates VisualEchoTrails_v1_Integration (integration layer)
  4. Registers all existing links
  5. Registers callbacks for link creation/removal
  6. Wires into update loop

PER-FRAME UPDATE FLOW:
  1. main.js calls echoTrailsIntegration.updateAllMaterials()
  2. Passes: time, visualTime, avgSynergy
  3. For each link's material:
     a. material.uniforms.uTime = time
     b. material.uniforms.uVisualTime = visualTime
     c. material.uniforms.uSynergy = avgSynergy
  4. GPU renders with new uniform values

LINK CREATION FLOW:
  1. NodeLinkingSystem triggers onLinkCreatedCallbacks
  2. Integration callback fires
  3. VisualEchoTrails_v1_Integration.onLinkCreated()
  4. Creates ShaderMaterial for link
  5. Adds to material registry

LINK REMOVAL FLOW:
  1. NodeLinkingSystem triggers onLinkRemovedCallbacks
  2. Integration callback fires
  3. VisualEchoTrails_v1_Integration.onLinkRemoved()
  4. Removes from material registry
  5. Material garbage collected
