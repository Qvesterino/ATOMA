🚀 INTEGRATION (3 MINUTES)
───────────────────────────────────────────────────────────────────────────────

1. Import:
   import { LinkDirectionalGradientPolish, setupLinkGradientPolishConsoleAPI } 
     from './LinkDirectionalGradientPolish.js';

2. Create instance:
   const gradientPolish = new LinkDirectionalGradientPolish(world.network);
   setupLinkGradientPolishConsoleAPI(gradientPolish);

3. Update each frame:
   gradientPolish.update(deltaTime);

4. Apply to links (in render loop):
   const brightness = gradientPolish.getBrightnessMultiplier(link.id, t);
   const saturation = gradientPolish.getSaturationMultiplier(link.id, t);
   linkMaterial.uniforms.uBrightnessMultiplier.value = brightness;
   linkMaterial.uniforms.uSaturationMultiplier.value = saturation;

📊 QUERY API
───────────────────────────────────────────────────────────────────────────────

Get brightness multiplier at position t:
  gradientPolish.getBrightnessMultiplier(linkId, t)      // Returns: 0.94-1.12

Get saturation multiplier at position t:
  gradientPolish.getSaturationMultiplier(linkId, t)      // Returns: 0.955-1.09

Get emissive boost at position t:
  gradientPolish.getEmissiveBoost(linkId, t)             // Returns: -0.1 to 0.2

Get complete gradient info at position t:
  gradientPolish.getGradientAtT(linkId, t)               // Returns: {brightness, saturation, emissiveBoost}

Get cached gradient data for link:
  gradientPolish.getGradientInfo(linkId)                 // Returns: {finalStrength, synergy, harmony, corruption, instability}


🎛️  TUNING PARAMETERS
───────────────────────────────────────────────────────────────────────────────

Gradient strength (5-15% typical):
  gradientPolish.baseGradientStrength = 0.08       // 8% baseline
  gradientPolish.maxGradientStrength = 0.12        // 12% with full synergy

Gradient shape:
  gradientPolish.gradientShape = 'smoothstep'      // 'linear' | 'smoothstep' | 'sine'
  // linear: straightforward fade
  // smoothstep: smooth curve (default, most elegant)
  // sine: bell curve (softest)

Corruption dampening (how much corruption flattens gradient):
  gradientPolish.corruptionFlatteningFactor = 0.5  // 0.3-0.7 typical

Instability reduction (how much instability reduces contrast):
  gradientPolish.instabilityReductionFactor = 0.3  // 0.2-0.4 typical

🚨 TROUBLESHOOTING
───────────────────────────────────────────────────────────────────────────────

Gradient not visible?
  → Check: gradientPolish.getDebugStats() should show linksProcessed > 0
  → Verify: gradient data is being read by link rendering code

Gradient too subtle?
  → LinkGradientAPI.setStrength(0.12, 0.18)    // Increase strength
  → LinkGradientAPI.setShape('linear')          // Use linear instead of smoothstep

Gradient too obvious?
  → LinkGradientAPI.setStrength(0.04, 0.07)    // Decrease strength
  → LinkGradientAPI.setShape('sine')            // Use sine for softer curve

Performance issue?
  → Verify: gradientPolish.update() is called once per frame (not per-link)
  → Check: Link material uniforms are batch-updated, not per-vertex
