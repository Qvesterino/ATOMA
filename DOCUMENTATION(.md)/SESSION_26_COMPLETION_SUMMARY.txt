KNOWN LIMITATIONS & EDGE CASES
================================================================================

HANDLED (Gracefully):
  ✓ Node without mesh → Skipped silently
  ✓ Node without material → Skipped silently
  ✓ Incompatible material type → Caught and ignored
  ✓ Material replaced externally → Restores automatically
  ✓ Rapid spawn/link cycles → Race conditions handled
  ✓ World reset → Auto-cleanup via WeakMap

NOT HANDLED (By Design):
  - Multiple materials on single core (edge case)
  - Custom shader material uniforms (use material properties)
  - Material cloned externally (re-register after cloning)

All edge cases fail gracefully (silent, non-breaking)
