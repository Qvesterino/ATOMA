EFFECT PROFILES SPECIFICATION
================================================================================

CLARITY BLOOM
─────────────
Input:       uClarity, uEnergy, uQuality (0–1)
Visual:      Bright, clean neon glow
Effect:      +40% emissive boost + rim lighting
Formula:     float clarityFactor = clamp(uClarity * 0.8 + uEnergy * 0.4 + 
             uQuality * 0.3, 0.0, 1.0);
Gameplay:    Healthy, coherent thinking nodes
Tuning:      clarityEmissiveMax (0.4 default)

CORRUPTION RIFT
───────────────
Input:       uCorruption, uEntropy, uTime
Visual:      Red/orange tint + animated noise
Effect:      25% color shift + noise breakup
Formula:     vec3 corruptTint = mix(baseColor, vec3(1.0, 0.3, 0.0), 
             uCorruption * 0.25);
Gameplay:    Corrupted, degraded AI nodes
Tuning:      corruptionTintMax (0.25 default)

RESONANCE WAVE
──────────────
Input:       uResonance, uEnergy, uTime
Visual:      Breathing harmonic pulse (~2 Hz)
Effect:      20% emissive oscillation
Formula:     float breathingWave = sin(uTime * 2.0 * pi) * 0.5 + 0.5;
             float wavePulse = mix(1.0, breathingWave, resonanceFactor * 0.2);
Gameplay:    Well-connected, synchronized nodes
Tuning:      resonancePulseFrequency (2.0 Hz default)

ENTROPY GLITCH
──────────────
Input:       uEntropy, uFocus, uTime
Visual:      Vertex wobble + distortion shimmer
Effect:      2% displacement + noise distortion
Formula:     wobbleAmount = uEntropy * 0.02;
             glitchOffset = glitchNoise * 0.02 * glitchStrength;
Gameplay:    Chaotic, unstable nodes
Tuning:      entropyWobbleStrength (0.02 default)

FOCUS DRIFT
───────────
Input:       uFocus, uEntropy, uTime
Visual:      Gentle rotation + position drift
Effect:      0.3 rad rotation + 2% position shift
Formula:     rotAngle = sin(uTime * 2.0) * uFocus * 0.3;
             driftPos += vec3(noise * 0.02, noise * 0.02, 0.0);
Gameplay:    Overloaded, stressed nodes
Tuning:      focusRotationAmount (0.3 default)

LINK RESONANCE WAVE (for links)
────────────────────────────────
Input:       uLinkGlow, uTime
Visual:      Pulsing connection lines
Effect:      ~2 Hz glow modulation
Gameplay:    High-resonance connections
Use:         Traces "highways" between synchronized nodes

LINK GLOW BOOST (for links)
────────────────────────────
Input:       uLinkGlow, uLinkQuality
Visual:      Brightness enhancement
Effect:      +50% glow boost, quality-modulated
Gameplay:    Link importance hierarchy
Use:         Shows which connections are most important
