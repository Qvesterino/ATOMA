===============================================================================
5-MINUTE INTEGRATION
===============================================================================

1. IMPORT:
  import {
    initializeGlobalWiringSystem,
    wireRenderable,
    updateAllVisualControllers,
    unwireRenderable,
    RENDERABLE_TYPE
  } from './VisualAutoWiringSystem.js';

2. SETUP (once):
  await initializeGlobalWiringSystem();

3. ON LINK CREATE:
  await wireRenderable(link, RENDERABLE_TYPE.LINK, linkMesh);

4. PER FRAME:
  updateAllVisualControllers(dt, timeSeconds);

5. ON LINK DESTROY:
  unwireRenderable(link);

ARCHITECTURE LAYERS
===============================================================================

Layer 1: VisualTemplateRegistry
  Role:    Static renderable type → canonical template mapping
  Input:   Renderable type (string)
  Output:  Template ID (string)
  Logic:   None (pure lookup)
  
Layer 2: VisualTemplateResolver
  Role:    Template ID → controller class + material factory
  Input:   Template ID (string)
  Output:  {ControllerClass, createMaterial}
  Logic:   Module resolution (deterministic)
  
Layer 3: VisualAutoWiringSystem
  Role:    Renderable → wired controller + material (orchestrator)
  Input:   Renderable + type + mesh
  Output:  {material, controller}
  Logic:   Coordination (no branching)

===============================================================================
GUIDING PRINCIPLES
===============================================================================

1. Registry is Law
   All valid wiring defined in one place.
   Adding mappings requires architectural review.

2. Templates Locked
   All templates from CanonicalVisualTemplateLibrary.md.
   No new templates without explicit lock.

3. Resolver is Dumb
   Pure ID → factory mapping.
   No branching, no intelligence.

4. Wiring is Atomic
   Each renderable gets exactly one template.
   No multiple templates per renderable.

5. Updates are Mechanical
   Forward time + delta only.
   No metrics, no conditionals, no gameplay logic.
