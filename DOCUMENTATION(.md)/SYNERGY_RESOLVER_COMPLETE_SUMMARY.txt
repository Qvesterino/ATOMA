SYNERGY STATE RESOLVER — ARCHITECTURE
═══════════════════════════════════════════════════════════════════════════════

DISCRETE STATES (semantic, zero ambiguity)
──────────────────────────────────────────

SynergyState.LOW       → synergy < 0.50
SynergyState.ACTIVE    → 0.50 ≤ synergy < 0.75
SynergyState.STRONG    → 0.75 ≤ synergy < 0.85
SynergyState.AWAKENED  → synergy ≥ 0.85

THRESHOLDS (single source of truth)
─────────────────────────────────────

activeThreshold:   0.50    (Link becomes connected)
strongThreshold:   0.75    (Glyph begins reveal)
awakenedThreshold: 0.85    (Full awakening)

CORE API METHODS
─────────────────

1. resolve(synergy) → SynergyState
   Convert numeric synergy (0–1) to discrete state
   O(1) time, < 0.01ms

2. isAtLeast(synergy, minState) → boolean
   Query if synergy meets or exceeds threshold
   Semantic: if (isAtLeast(syn, SynergyState.STRONG))

3. getStateInfo(synergy) → Object
   Detailed state transition information
   For animations, warnings, debug

4. setThresholds(config) → void
   Reconfigure thresholds at runtime
   Validated and clamped

5. getThresholds() → Object
   Query current threshold configuration

STATIC UTILITIES
─────────────────

getStateDescription(state) → string
  "Peak connection — Nodes fully synchronized"

getStats() → Object
  Usage statistics, performance metrics

PROBLEMS SOLVED
═══════════════════════════════════════════════════════════════════════════════

PROBLEM 1: Multiple Conflicting Thresholds
────────────────────────────────────────────
BEFORE:
  - NeonLinkVisuals.js uses 0.85
  - _AtomaGlyphSystem4_0.js uses 0.70, 0.75, 0.85
  - ComputeSynergyScore2_1.js uses 0.25, 0.50, 0.75
  - _ExtremeAINodeEvolution3.js uses stage1, stage2
  - 6+ different threshold systems total

AFTER:
  - SynergyStateResolver defines ONE threshold set
  - All systems use same thresholds
  - Change thresholds once, affects everywhere

PROBLEM 2: Hard-Coded Magic Numbers
─────────────────────────────────────
BEFORE:
  if (synergy >= 0.85) { ... }  // Line 970 NeonLinkVisuals
  if (linkedSynergy >= 0.85) { ... }  // Line 1390 AtomaGlyph
  if (synergy >= 0.75) { ... }  // Line 1393 AtomaGlyph
  const colorShift = (linkedSynergy - 0.85) * 2;  // Hard-coded 0.85

AFTER:
  const state = resolver.resolve(synergy);
  if (state === SynergyState.AWAKENED) { ... }
  if (state === SynergyState.STRONG || state === SynergyState.AWAKENED) { ... }

PROBLEM 3: No Single State Representation
──────────────────────────────────────────
BEFORE:
  - Boolean: isSynergyAwakened (yes/no, loses information)
  - Numeric: synergy = 0.73 (requires magic numbers)
  - Tier: "low"/"medium"/"high"/"critical" (confuses different systems)
  - Reveal Level: 0/1/2 (glyph-specific)

AFTER:
  - SynergyState: LOW | ACTIVE | STRONG | AWAKENED
  - Semantic, meaningful, reusable across all systems

PROBLEM 4: Scattered Logic Across 25+ Places
──────────────────────────────────────────────
BEFORE:
  if (synergy >= THRESHOLD1) { doThing1(); }
  if (synergy >= THRESHOLD2) { doThing2(); }
  if (synergy >= THRESHOLD3) { doThing3(); }
  // ... repeated in 25+ places

AFTER:
  const state = resolver.resolve(synergy);  // One place
  switch(state) {
    case SynergyState.LOW: break;
    case SynergyState.ACTIVE: doThing1(); break;
    case SynergyState.STRONG: doThing2(); break;
    case SynergyState.AWAKENED: doThing3(); break;
  }

DESIGN PRINCIPLES
═══════════════════════════════════════════════════════════════════════════════

✅ SINGLE RESPONSIBILITY
   Only converts numeric synergy → discrete state
   Nothing else, no side effects

✅ NO GLOBAL STATE
   Each system creates its own resolver instance
   Independent, composable

✅ PURE FUNCTION
   resolve(0.80) always returns SynergyState.STRONG
   Deterministic, testable

✅ CONFIGURABLE
   Thresholds can change at runtime
   No code modification needed

✅ SEMANTIC STATES
   LOW/ACTIVE/STRONG/AWAKENED are meaningful
   Not 0/1/2/3 or arbitrary numbers

✅ ZERO DEPENDENCIES
   Pure JavaScript, no external imports
   < 2KB minified

✅ PERFORMANCE FIRST
   O(1) time complexity
   < 0.01ms per resolve() call
   < 200 bytes memory per instance

═══════════════════════════════════════════════════════════════════════════════
HOW TO USE (BEFORE & AFTER)
═══════════════════════════════════════════════════════════════════════════════

EXAMPLE 1: Link Visual Effects
───────────────────────────────

BEFORE (Hard-coded, scattered):
  if (state.synergy >= 0.85) {
    child.material.opacity += 0.08;  // ← Magic number 0.85
  }

AFTER (Centralized, readable):
  const synergyState = resolver.resolve(state.synergy);
  if (synergyState === SynergyState.AWAKENED) {
    child.material.opacity += 0.08;  // ← Semantic state
  } else if (synergyState === SynergyState.STRONG) {
    child.material.opacity += 0.04;  // ← Can now distinguish STRONG
  }

EXAMPLE 2: Glyph Reveal Logic
──────────────────────────────

BEFORE (Multiple thresholds):
  if (linkedSynergy >= 0.85) {        // ← Three separate comparisons
    revealLevel = 2;
  } else if (linkedSynergy >= 0.75) {
    revealLevel = 1;
  } else if (linkedSynergy >= 0.70) {
    revealLevel = 0;
  }

AFTER (Single resolve):
  const state = resolver.resolve(linkedSynergy);
  switch(state) {
    case SynergyState.AWAKENED: revealLevel = 2; break;
    case SynergyState.STRONG: revealLevel = 1; break;
    case SynergyState.ACTIVE: revealLevel = 0; break;
    case SynergyState.LOW: revealLevel = 0; break;
  }
