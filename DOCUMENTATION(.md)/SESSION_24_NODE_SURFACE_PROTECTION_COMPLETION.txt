PROBLEM STATEMENT
================================================================================

ISSUE: Node cores become visually hidden after linking because link/evolution/
       emotional auras render with higher visual dominance.

ROOT CAUSES:
  • Aura opacity too high (0.4-0.5 vs 0.25 needed)
  • No renderOrder coordination between systems
  • Transparent nodes especially vulnerable
  • Multiple aura systems operate independently

EXPECTED RESULT:
  ✅ Nodes remain clearly visible
  ✅ Auras provide context without dominating
  ✅ Transparent nodes fully readable
  ✅ Professional visual hierarchy

================================================================================
SOLUTION: NODE SURFACE PROTECTION RULE v2.0
================================================================================

MECHANISM 1: Dynamic Opacity Attenuation
  • Aura opacity reduced based on node-aura overlap
  • Formula: effectiveOpacity = ceiling × (1 - overlap × 0.8)
  • At 100% overlap: 20% of ceiling opacity
  • Progressively fades aura as overlap increases

MECHANISM 2: RenderOrder Hierarchy (Enforced)
  • Node core: renderOrder = 100 (always on top)
  • Node internal: renderOrder = 50
  • Evolution overlays: renderOrder = 50
  • Auras: renderOrder = 10 (background)

MECHANISM 3: Opacity Floor Protection
  • Node cores: opacity ≥ 0.7 (always readable)
  • Auras: opacity ≤ 0.25 (background only)
  • Protects transparent nodes
  • Automatic enforcement on protection events

MECHANISM 4: Event-Driven Activation
  • Triggered on link creation
  • Triggered on node spawn
  • Triggered on evolution event
  • ZERO per-frame traversal

CHANGE 3: Initialization (Lines 1522-1550)

  // Initialize NodeSurfaceProtectionRule_v2
  this.nodeSurfaceProtection = new NodeSurfaceProtectionRule_v2({
      auraOpacityCeiling: 0.25,
      coreOpacityFloor: 0.7,
      debugEnabled: false
  });
  
  // Protect existing nodes
  if (this.aiNodes?.nodes) {
      this.nodeSurfaceProtection.protectNodes(this.aiNodes.nodes);
  }
  
  // Hook node spawn for automatic protection
  const originalSpawnNode = this.aiNodes?.spawnNode;
  if (originalSpawnNode) {
      this.aiNodes.spawnNode = function(...args) {
          const newNode = originalSpawnNode.apply(this, args);
          if (newNode) {
              this.game?.nodeSurfaceProtection?.registerNode(newNode);
          }
          return newNode;
      }.bind(this.aiNodes);
      this.aiNodes.game = this;
  }
  
  // Register observer for link creation events
  if (this.linkingSystem && this.linkingSystem.registerObserver) {
      this.linkingSystem.registerObserver({
          onLinkCreated: (link) => {
              this.nodeSurfaceProtection?.onLinkCreated(link);
              // Also apply defensive layering...
          }
      });
  }
