📊 ML SCORING FORMULA
═══════════════════════════════════════════════════════════════════════════════

Feature Vector Extraction:
  For each unlinked node pair (A, B):
  • Category pair synergy bonus
  • Current synergy score
  • Historical quality & trend
  • Distance decay (exponential)
  • Node degree balance
  • Highway membership bonus
  • Automation health context

Weighted Sum:
  score = Σ (weight_i * feature_i)
  • synergyWeight: 0.35 (highest)
  • highwayRouteBonus: 0.25
  • categoryBonus: 0.3
  • historyWeight: 0.2
  • + 4 more weights

Logistic Transformation:
  quality = 1 / (1 + e^(-2*score))
  output = clamp(quality, 0, 1)

Result:
  0.0 = Very poor prediction
  0.5 = Moderate prediction
  1.0 = Excellent prediction
