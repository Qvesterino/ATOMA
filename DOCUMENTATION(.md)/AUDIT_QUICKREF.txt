THE PIPELINE (How Everything Flows)
═══════════════════════════════════════════════════════════════════════════════════

AINodes.createNodes()
  ↓
EnhancedNodeModels.create()
  ├─ Creates static geometry
  ├─ Calls CoreHologramShader (materials)
  ├─ Queries VisualHierarchyRegistry (renderOrder)
  └─ Returns THREE.Group
  ↓
Node added to scene
  ├─ NodeVisualBootstrap validates
  └─ Optional: Personality systems applied
  ↓
User interacts
  ├─ Raycast via CanonicalInteractionFilter
  ├─ Hit proxy validates selection
  └─ Can select node or create link
  ↓
Link creation
  ├─ NodeLinkingSystem.createLink()
  ├─ Synergy calculated (ComputeSynergyScore2_1)
  ├─ NeonLinkVisuals renders curve
  ├─ Optional: Corruption spreading
  ├─ Optional: Harmony healing
  └─ FXRuntime displays effects
