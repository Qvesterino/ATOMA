STATE PERSISTENCE
═════════════════

localStorage Key: "atoma_hud_layout_v1"

Storage Format (JSON):
{
  "ui-category-legend": {
    "collapsed": false
  },
  "node-inspect-overlay": {
    "collapsed": false
  },
  "core-metrics-hud": {
    "collapsed": false
  },
  "ai-automation-hud": {
    "collapsed": false
  }
}

Behavior:
├─ On Startup: Load from localStorage (or use defaults)
├─ On Toggle: Update state, persist immediately
├─ On Error: Graceful fallback to defaults
└─ On Reset: Clear storage, reset all to expanded
