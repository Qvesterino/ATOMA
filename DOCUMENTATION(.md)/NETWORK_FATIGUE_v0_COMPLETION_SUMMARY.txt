KEY SPECIFICATIONS
================================================================================

CORE MECHANIC
  • Per-node fatigue scalar: fatigue ∈ [0.0, 1.0]
  • Accumulates when stressed (high load, instability, corruption, low harmony)
  • Recovers when healthy (low load, stable, high harmony, clean)
  • Applies soft multipliers to harmony, synergy, and corruption decay

ACCUMULATION TRIGGERS (Any One)
  • loadRatio > 0.75 (high load stress)
  • instability > 0.60 (unstable)
  • corruption > 0.40 (corrupted)
  • harmony < 0.20 (harmony starved)

RECOVERY CONDITIONS (All Required)  
  • loadRatio < 0.50 (unloaded)
  • instability < 0.30 (stable)
  • corruption < 0.30 (clean)
  • harmony > 0.40 (healthy harmony)

RATES
  • Accumulation: 0.015/s × stressComposite × categorySensitivity
  • Recovery: 0.005/s (constant, 3× slower than max accumulation)
  • Results: ~67s to max at max stress, ~200s to recover from max

MULTIPLIER EFFECTS (Soft Modulation)
  • Harmony Rate: 1 - (fatigue × 0.40) [range: 0.60-1.00]
  • Synergy: 1 - (fatigue × 0.35) [range: 0.65-1.00]
  • Corruption Decay: 1 - (fatigue × 0.30) [range: 0.70-1.00]

CATEGORY SENSITIVITIES (During Accumulation)
  • Storage: 0.75 (ages very well)
  • Analytics: 0.85 (ages well)
  • Integration: 0.90 (resilient)
  • Control: 0.95 (resilient)
  • Process: 1.00 (baseline)
  • Input: 1.15 (burns out fastest)

CONSOLE API
================================================================================

Available Commands:

  ATOMA_DEBUG.NetworkFatigue.printDiagnostics()
    → Print fatigue diagnostics for all nodes
    → Shows: fatigue, state, stress composite, metrics, multipliers

  ATOMA_DEBUG.NetworkFatigue.seedFatigue(nodeIndex, value)
    → Manually set a node's fatigue (0.0 to 1.0)
    → Example: ATOMA_DEBUG.NetworkFatigue.seedFatigue(0, 0.5)

  ATOMA_DEBUG.NetworkFatigue.diagnose(nodeIndex)
    → Get detailed diagnostics for single node
    → Shows full status with all metrics

  await ATOMA_DEBUG.NetworkFatigue.runStressTest(seconds)
    → Run accumulation test on first node for N seconds
    → Example: await ATOMA_DEBUG.NetworkFatigue.runStressTest(30)
    → Useful for measuring accumulation rates

FINAL NOTES
================================================================================

Network Fatigue v0 is a complete, self-contained Tier 5 gameplay system that
answers the question: "What happens if this continues?"

Without fatigue, players can indefinitely maintain max-stress networks.
With fatigue, long-running networks naturally feel alive—they age, tire,
and require player management to maintain effectiveness.

The system is invisible in v0 but creates emergent long-term gameplay that
can be progressively revealed in v1+ as player visibility features are added.

All code is production-ready, non-breaking, and fully reversible.
