WHAT IS IT?
───────────────────────────────────────────────────────────────────────────────
Cascade visual system that creates ripple & glow effects when synergy cascades
propagate through the ATOMA network.

STATUS: ✅ Complete & ready for integration


IN 30 SECONDS
───────────────────────────────────────────────────────────────────────────────
1. Import the module
2. Create instance in game.init()
3. Trigger cascades when they occur
4. Update each frame
5. Apply effects to materials

That's it. Cascades handle the rest.


IMPORT (1 LINE)
───────────────────────────────────────────────────────────────────────────────
import { CascadePropagationFX_v1 } from './CascadePropagationFX_v1.js';


INITIALIZE (5 LINES)
───────────────────────────────────────────────────────────────────────────────
this.cascadeFX = new CascadePropagationFX_v1(this);
this.cascadeFX.init();  // Pre-allocate object pool


TRIGGER CASCADE (1 LINE)
───────────────────────────────────────────────────────────────────────────────
this.cascadeFX.triggerCascade(node, 0.85);


UPDATE (1 LINE)
───────────────────────────────────────────────────────────────────────────────
this.cascadeFX.update(deltaTime);  // In animate() loop


APPLY EFFECTS (5 LINES)
───────────────────────────────────────────────────────────────────────────────
const linkState = this.cascadeFX.getLinkCascadeState(link);
if (linkState) {
    link.material.uniforms.uCascadeIntensity.value = linkState.smoothedIntensity;
    link.material.emissive.copy(linkState.effectiveColor);
}

COMMON PATTERN: APPLY TO LINK MATERIALS
───────────────────────────────────────────────────────────────────────────────
for (const link of game.links) {
    const state = this.cascadeFX.getLinkCascadeState(link);
    if (state?.totalIntensity > 0) {
        link.material.uniforms.uCascadeIntensity.value = state.smoothedIntensity;
        link.material.uniforms.uRippleAmplitude.value = state.rippleAmplitude;
        link.material.emissive.copy(state.effectiveColor);
    }
}


COMMON PATTERN: APPLY TO NODE MATERIALS
───────────────────────────────────────────────────────────────────────────────
for (const node of game.nodes) {
    const state = this.cascadeFX.getNodeCascadeState(node);
    if (state?.totalIntensity > 0) {
        node.material.emissive.copy(state.effectiveColor);
        node.material.emissiveIntensity = state.glowAmplification;
    }
}

TROUBLESHOOTING
───────────────────────────────────────────────────────────────────────────────
Cascades not propagating?
  → Check nodeLinkingSystem.getLinksForNode() exists

Visual effects weak?
  → Verify material uniforms receiving values
  → Check shader uses cascade uniforms

Memory growing?
  → Ensure nodes/links properly deleted
  → Check WeakMap keys still referenced

Performance slow?
  → Increase waveDuration (0.5 → 1.0)
  → Reduce maxHops (8 → 4)

WHAT'S DIFFERENT FROM TRAVELING WAVES?
───────────────────────────────────────────────────────────────────────────────
Traveling Waves (Week 23):    GPU-only wave visualization
Cascade Propagation (Week 25): Network propagation + CPU state tracking

They work together:
  CascadePropagationFX → Link/Node states → Material uniforms
                                              ↓
                                    SynergyTravelingWaveFX
                                              ↓
                                        GPU effects


COMPLETE MINIMAL EXAMPLE
───────────────────────────────────────────────────────────────────────────────
// In game.js
class MyGame {
    init() {
        this.cascadeFX = new CascadePropagationFX_v1(this);
        this.cascadeFX.init();
    }
    
    onCascadeEvent(node) {
        this.cascadeFX.triggerCascade(node, 0.85);
    }
    
    animate(deltaTime) {
        this.cascadeFX.update(deltaTime);
        
        // Apply to links
        for (const link of this.links) {
            const state = this.cascadeFX.getLinkCascadeState(link);
            if (state) {
                link.material.uniforms.uCascadeIntensity.value = 
                    state.smoothedIntensity;
            }
        }
        
        this.renderer.render(this.scene, this.camera);
    }
    
    dispose() {
        this.cascadeFX.dispose();
    }
}
