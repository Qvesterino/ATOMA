## 💡 Quick Tips

1. **Color indicates category** - Learn colors fast
2. **Shape indicates variant** - 4 per category
3. **Glow indicates activity** - Bright = active
4. **Animation shows function** - Rotation = processing
5. **Links connect compatible** - Rules enforced
6. **Special nodes rare** - 10% of nodes
7. **Right-click for menu** - Manage links easily
8. **Preview is instant** - Visual feedback fast
