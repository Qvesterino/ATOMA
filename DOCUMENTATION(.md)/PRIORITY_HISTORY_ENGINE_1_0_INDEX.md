## Key Concepts Explained

### Circular Buffer
A fixed-size array that wraps around. When full, new data overwrites oldest data.
```
Size: 60
Position 0: oldest data
Position 59: newest data
After writing 61 samples: Position 0 now has 2nd oldest
```

### Sample
A single recorded point in time with 4 values:
```javascript
{
  t: timestamp,     // When recorded
  score: 0-1,       // Priority value
  tier: 0-3,        // Priority level
  traffic: 0-1      // Activity intensity
}
```

### Aggregates
Running statistics calculated as samples arrive:
- Min/Max/Avg Score
- Rising/Falling/Stable counts
- Active/Idle counts

### Trend
Direction of priority change (rising/falling/stable)
- 'rising': avg score increasing
- 'falling': avg score decreasing
- 'stable': no significant change

## Data Flow Visualization

```
Timeline:
  t=0ms: Create link → no history yet
  t=500ms: 1st sample recorded
  t=1000ms: 2nd sample recorded
  ...
  t=30000ms: 60th sample recorded (buffer full)
  t=30500ms: New sample overwrites oldest (wrap around)

Per-Link State Over Time:
  buffer = [s1, s2, s3, ... s60]
  size = 60 (reaches max after 30 seconds)
  aggregates = { min, max, avg, risingTicks, ... }

Query at Any Time:
  getLinkHistory() → Array of all samples
  getLinkStats() → Aggregated stats
  getTrend() → 'rising'|'falling'|'stable'
  getTopBy() → Sorted by metric
```
