    harmonicSyncController  // Pass the harmonic hub controller

collapseController.update(
    harmony,      // Node harmony level
    corruption,   // Node corruption level
    synergy,      // Node synergy level
    instability,  // Node instability level
    deltaTime     // Frame delta in seconds
);

// In visual rendering (Directional Streaks):

================================================================================
KEY API
================================================================================

HarmonicHubCollapseController Methods:

  update(harmony, corruption, synergy, instability, deltaTime)
    └─ Update collapse state (call every frame)

  getPhaseCollapseEffect(linkIndex, linkCount, time)
    └─ Get phase deviation and noise for a link

  getShockwaveEffect(position, linkIndex, linkCount)
    └─ Get shockwave disturbance at position along link

  getHaloEffect()
    └─ Get halo oscillation effect for node visualization

  getDebugInfo()
    └─ Get detailed debug information

  getCollapseDescription()
    └─ Get state description ('Healthy', 'Strained', 'Overloading', 'Collapsed')

  setConfig(configOverrides)
    └─ Adjust configuration parameters

Properties:

  collapseFactor
    └─ Current collapse progression (0 = healthy, 1 = fully collapsed)

  phaseVariance
    └─ Current angular variance in radians

  isInOverload
    └─ Whether hub is in overload state

  shockwaveQueue
    └─ Array of active shockwaves

CONCLUSION
================================================================================

Resonance Overload & Phase Collapse is a complete visual-only system that
shows harmonic hub degradation through smooth, deterministic progression.

When corruption overwhelms harmony, harmonic hubs visibly break down through
four distinct stages:
  1. Healthy (organized energy flow)
  2. Strained (subtle uncertainty)
  3. Overloading (visible chaos, shockwaves)
  4. Collapsed (complete desynchronization)

The system communicates network failure to players through elegant visual
patterns without requiring UI elements or affecting gameplay. Recovery is
as visible as breakdown, creating a narrative of network health.

All effects are:
  ✅ Deterministic (corruption-driven, not random)
  ✅ Reversible (full recovery when corruption drops)
  ✅ Smooth (no jarring transitions)
  ✅ Non-intrusive (zero gameplay impact)
