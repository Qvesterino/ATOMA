## Settings You Can Tweak

**In NodeLinkingSystem.js, createLink() method:**

```javascript
// Make links thinner/thicker
linewidth: isSpecial ? 12 : 10  // Adjust these numbers (was 2-3)

// Adjust bloom intensity
const bloomBoost = 1.25;  // 1.0 = no boost, 2.0 = 2× boost

// Vein speed
link.veinAnimation.speed = 2.0;  // 1.0 = normal, 3.0 = fast
```
