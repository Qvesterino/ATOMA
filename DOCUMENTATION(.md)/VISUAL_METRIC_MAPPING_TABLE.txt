================================================================================
SCALE NORMALIZATION RULES
================================================================================

FOR ALL 0–100 METRICS (Legacy and New):
  Normalized form = metric / 100
  Example: stability (0–100) → normalized (0–1)
    const normalized = node.userData.metrics.stability / 100;

FOR ALL 0–1 METRICS (Legacy):
  Denormalized form = metric * 100
  Example: synergyScore (0–1) → percentage (0–100)
    const percent = link.synergyScore * 100;

FOR ALL PERSONALITY MODIFIERS (-1 to +1):
  Apply as delta:
    finalMetric = baseMetric + (modifier * scaleFactor)
    Example: scaleFactor = 10 for metrics that are 0–100
    finalStability = baseStability + (personality.harmony * 10)

FOR ALL ABSOLUTE UNITS (Energy 0–120):
  No normalization needed
  Normalize manually if needed: energyNorm = energy / 120

  const linkQualityNorm = linkQuality / 100;  // 0–1 range
