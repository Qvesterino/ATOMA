================================================================================
THE 5 GPU UNIFORMS
================================================================================

Material uniforms automatically created:

uArchetypeIntensity          Aura glow strength (0.5–2.5)
uArchetypeRadiusBoost        Sphere radius scale (0.5–2.0)
uArchetypeColorShift         RGB additive shift (vec3)
uArchetypeBloomBoost         Bloom/glow strength (0.5–2.5)
uArchetypeDistortionAmount   Shader distortion (0.0–1.0)

These are injected via material.onBeforeCompile (safe, non-invasive)

In shaders, you can use them:
  baseColor *= uArchetypeIntensity;
  baseColor += uArchetypeColorShift * 0.5;

================================================================================
COMMON ISSUES & FIXES
================================================================================

Issue: "Cannot read property 'auras' of undefined"
Fix:   NodeAuraSystem_v1 not initialized. Make sure it's passed correctly.

Issue: Auras not enhancing (no visible changes)
Fix:   1. Check archetypeCurves.update() is called BEFORE archetypeAuraFX.update()
       2. Check archetype evolution: game.aiNodes.nodes[0].userData.archetypeEvolution
       3. Enable debugEnabled: true to see logging

Issue: Performance is slow
Fix:   Check DevTools Performance tab - should be <0.5ms per 200 nodes

Issue: Color shifts not visible
Fix:   Color shifts are subtle (5–15%) by design. To see them better:
       - Watch nodes over time as ascension increases
       - Check console: console.log(enhancement.currentColorShift);

Issue: Uniforms "not defined" in shader
Fix:   Uniform injection happens at shader compile time. If you see errors:
       1. Ensure material.onBeforeCompile is supported (ShaderMaterial)
       2. Call archetypeAuraFX.update() a couple times to trigger injection
