KEY METRICS COMPUTED (11 Total)
═══════════════════════════════════════════════════════════════════════════════

STRUCTURAL (Fresh Each Frame):
  • linkCount - Total connections (in + out)
  • incomingLinks - Incoming connections
  • outgoingLinks - Outgoing connections  
  • loadMax - Maximum capacity (default 4)
  • loadRatio - Utilization 0-1 (linkCount / loadMax)

DYNAMIC (EMA Smoothed, 0-100 scale except energy):
  • energy - 0-120, increases with links, decays when idle
  • stability - 0-100, decreases under load
  • harmony - 0-100, balance indicator (70% stability + 30% low-load bonus)
  • clarity - 0-100, coherence (influenced by stability)
  • corruption - 0-100, sigma nodes +15/sec, others decay
  • instability - 0-100, inverse of stability (100 - stability)

TIME-BASED:
  • lastActiveSeconds - Idle time tracking
  • updatedAt - Last update timestamp (ms)

═══════════════════════════════════════════════════════════════════════════════
CORE FORMULAS
═══════════════════════════════════════════════════════════════════════════════

Energy: newEnergy += energyGainPerLink × linkCount × deltaTime
        Decays when idle (>2 sec), clamped 0-120

Stability: baseStability + (1-loadRatio)×40 - linkCount×2
          Clamped 0-100

Harmony: stability×0.7 + (1-loadRatio)×30
        Balance indicator

Clarity: 50 + (stability×0.5 - 30)
        Coherence metric

Corruption: Sigma nodes: +15 per second
           Regular nodes: -5% per second (decay)

EMA Smoothing: result = α×newValue + (1-α)×previousValue
              (prevents flicker, default α=0.2)
