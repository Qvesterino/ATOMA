## Safety & Design

### 🛡️ ABSOLUTE SAFETY GUARANTEES
- ✅ **Zero gameplay modifications** — Iba čítanie, žiadne zmeny
- ✅ **Žiadne zmeny metrik** — Synergy, harmony, instability nezmenené
- ✅ **Žiadny vplyv na spawning** — Spawn weights zachované
- ✅ **Žiadne shader zmeny** — Všetky vizuály bez zmeny
- ✅ **Pure linguistic layer** — Iba dva nové textové property na node
- ✅ **100% reverzibilné** — disable() odstraní všetko

### 🎯 Implementation Details
- Každý nod dostane pri vytváraní: `namingCode` a `namingMeaning`
- Automatické mapovanie podľa archetypu alebo kategórie
- Fallback pre neznáme archetypy (procedurálne vygenerované)
- Console API pre testovanie a debugging

## Console API

### Príkazy

```javascript
// Zobrazenie mena nodu
name.show(nodeId)               // Vypíše naming code + meaning

// Generovanie
name.random()                   // Náhodný naming code

// Referenčné tabuľky
name.archetypes()               // Všetky archetype → code mapovanie
name.reference()                // Úplná morfémová tabuľka

// Štatistika
name.stats()                    // Počet pomenovaných nodov, apod.

// Ovládanie
name.enable()                   // Zapnúť naming layer
name.disable()                  // Vypnúť naming layer
```

### Príklady Použitia

#### Zobrazenie mena nodu
```javascript
name.show(0)
// Output:
// Node 0:
//   Code: RSN-WVE-SYN
//   Meaning: Harmonically resonant signal in synchronized oscillation
//   Archetype: CORE-HARMONIC-RESONANT
```

```javascript
name.random()
// Output:
// Random Code: AET-CRW-PRM
// Meaning: Transcendent eternity ascending infinitely
```

#### Zobrazenie všetkých archetypy


#### Kompletná referenčná tabuľka

## Technical Details

### Dátové štruktúry
```javascript
node.userData = {
  namingCode: "QNT-KNT-CPL",           // Tri-morfémový kód
  namingMeaning: "Quantum probability...",  // Krátky popis
  // ... ostatné properties bez zmeny
}
```

### Mapping Priority
1. Úplný archetype ID (CORE-..., OUTER-..., EXTREME-...)
2. Kategória fallback (input, process, etc.)
3. Procedurálna generácia (pri neznámych)

### Performance
- Mapovanie pri vytváraní nodu: <1ms
- Žiadny per-frame overhead
- Memory: ~100 bajtov per nod
