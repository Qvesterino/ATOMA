STEP 3: INITIALIZE ENGINE
──────────────────────────
□ Open: main.js (or game initialization file)
□ Find: Where linkingSystem is created
  └─ Look for: window.game.linkingSystem = new NodeLinkingSystem(...)
  └─ Or: this.linkingSystem = new NodeLinkingSystem(...)

□ After linkingSystem creation, add:

        enabled: true,
        tickIntervalMs: 500,

□ SAVE file
□ VERIFY: No syntax errors


STEP 4: ADD TICK TO ANIMATION LOOP
──────────────────────────────────
□ Find: animate() function (or gameLoop, render, etc.)
  └─ Should contain: renderer.render(scene, camera)

□ At the START of animate function, add:

    // Tick Priority Decay Engine
    const deltaMs = typeof now !== 'undefined' ? (now - (window.lastFrameTime || 0)) : 16;
    if (typeof window.lastFrameTime !== 'number') window.lastFrameTime = now || Date.now();
    window.lastFrameTime = now || Date.now();
    
    if (window.game?.priorityDecayEngine) {
      window.game.priorityDecayEngine.tick(deltaMs);
    }

  ⚠️ IMPORTANT: Add BEFORE renderer.render() so changes are visible immediately

□ ALTERNATIVE (if deltaMs already tracked):
    If you already have deltaMs variable, just add:

    if (window.game?.priorityDecayEngine) {
      window.game.priorityDecayEngine.tick(deltaMs);
    }

TROUBLESHOOTING DURING DEPLOYMENT
==================================

PROBLEM: "Cannot find module PriorityDecayEngine1_0"
─────────────────────────────────────────────────────
CAUSE: File not in correct location
FIX:
  1. Check file copied to project root (same folder as NodeLinkingSystem.js)
  2. Verify filename: PriorityDecayEngine1_0.js (exact spelling, case-sensitive)
  3. Clear browser cache: Ctrl+Shift+Delete

PROBLEM: "window.game.linkingSystem is undefined"
──────────────────────────────────────────────────
CAUSE: Engine initialized before linkingSystem created
FIX:
  1. Move engine initialization AFTER linkingSystem creation
  2. Find where linkingSystem = new NodeLinkingSystem(...)
  3. Add engine init immediately after that line

PROBLEM: Engine enabled but "updatedLinks: 0"
──────────────────────────────────────────────
CAUSE: No links exist, or tick not being called
FIX:
  1. Create some nodes and links in ATOMA
  2. Verify tick() is in animation loop:
     if (window.game?.priorityDecayEngine) {
       window.game.priorityDecayEngine.tick(deltaMs);
     }
  3. Check: animate() is actually being called

PROBLEM: Visual effects not updating
────────────────────────────────────
CAUSE: NeonLinkVisuals not reading updated priorities
FIX:
  1. Check: NeonLinkVisuals.js exists
  2. Verify: applyPriorityEffects() called in animate
  3. Try: Manual call in console:
     window.game.linkingSystem.visuals.applyPriorityEffects()

PROBLEM: Extreme flickering or jitter
──────────────────────────────────────
CAUSE: jitterAmount too high or stabilizeAlpha too low
FIX:
  window.game.priorityDecayEngine.setConfig({
    jitterAmount: 0.005,      // Reduce from 0.01
    stabilizeAlpha: 0.10      // Increase from 0.15
  });

PROBLEM: Performance drops below 60 FPS
──────────────────────────────────────
CAUSE: Too many links or tickIntervalMs too small
FIX:
  window.game.priorityDecayEngine.setConfig({
    tickIntervalMs: 1000      // Increase from 500ms
  });
  
  OR: Check how many links exist (should be < 500)
