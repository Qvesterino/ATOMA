🐛 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Mouse feels sluggish?
→ Sensitivity too low (increase to 0.9-1.1)
→ Verify post-rotation smoothing ≤ 0.18
→ Check console for errors

Mouse feels twitchy?
→ Sensitivity too high (decrease to 0.7-0.8)
→ Reduce post-rotation smoothing
→ Verify no other systems interfering

Camera won't pitch?
→ Check rotationX is updating
→ Verify pitch clamping in valid range (-89° to +89°)
→ Ensure FirstPersonCameraController enabled

Sensitivity changes?
→ Should NOT change (constant 0.85)
→ Verify enforceInputNormalization() runs every frame
→ Check console for safe mode activation

Input feels delayed?
→ Pre-rotation smoothing should be 0 (not applied)
→ Check post-rotation smoothing value (0.10-0.18)
→ Verify frame rate consistency
