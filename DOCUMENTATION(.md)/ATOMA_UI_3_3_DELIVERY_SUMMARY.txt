FEATURE SUMMARY
================================================================================

SELECTED NODE VISUAL IDENTITY
=============================
1. Crosshair Badge (Under Cursor)
   - Size: 240×55px
   - Content: "SELECTED NODE" header + code + archetype + dot
   - Styling: Neon frame, cyan glow, magenta text
   - Animation: 120ms fade in/out

2. 3D Highlight (Around Node)
   - Outer ring: Pulsing neon outline (1.5s cycle)
   - Inner glow: Soft pulsing layer
   - Thickness: 30% thicker than UI 3.2
   - Scale: 0.98 → 1.25 pulse range

3. Floating Label (Above Node)
   - Text: [SELECTED] header + QNT code
   - Animation: Bob 2.5Hz cycle (±0.3m)
   - Rendering: Canvas texture on 3D sprite
   - Facing: Always faces camera

SELECTED-ONLY MODE (RMB TOGGLE)
===============================
- RMB on selected node: Toggle inspection mode
- In inspection mode: LMB different node = switch (no link)
- Exit inspection: RMB on current node
- Use case: Inspect multiple nodes without creating links
- Visual feedback: All three visuals remain active

SAFE UNLINKING SYSTEM
====================
- Bidirectional link removal (remove from both nodes)
- Runtime callbacks: node.runtime?.unlink(targetNode)
- Error-safe: Won't crash on missing runtime
- Non-destructive: Only removes from link arrays
- Multiple removal modes: outgoing, incoming, or all

INTERACTION FLOW ENHANCEMENTS
=============================
- LMB node: Select (show all 3 visuals)
- LMB same: Deselect (hide all)
- LMB different (linking): Link + switch selection
- LMB different (selected-only): Switch (no link)
- RMB selected: Toggle mode
- RMB empty: Cancel
- LMB empty: Deselect all
- E key: Context menu (existing)
- ESC: Close UI (existing)
