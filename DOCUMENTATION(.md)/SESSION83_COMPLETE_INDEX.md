## 🎓 Learning Resources

### Understanding Command/Decision Topology
- Control nodes use **command flow** principle - authority flows through structures
- DecisionFork: Commands diverge into decisions, then converge back
- AuthorityHelix: Command cascades downward through hierarchy
- CommandMatrix: Command distributed across network with unified convergence

### Geometry Implementation
- All use custom **BufferGeometry** (no Three.js primitives)
- All use **parametric curves** for topology preservation
- All use **asymmetric cross-sections** for visual richness
- All support **material variation** for depth

### Performance Optimization
- Static geometry = zero per-frame overhead
- Deterministic creation = predictable performance
- Linear scaling = production-ready for 1000+ nodes
- Compact buffers = minimal memory footprint
