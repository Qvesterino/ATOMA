================================================================================
API REFERENCE
================================================================================

CONSTRUCTOR:
  new NodeAuraSystem_v1({
    scene: THREE.Scene,                 // Required
    fxPerformance: FXController | null,  // Optional
    profileResolver: (node) => string,   // Optional
    enabled: boolean = true,             // Optional
    lowFXFade: number = 0.2,            // Optional
    lowFXRadiusFade: number = 0.5       // Optional
  })

METHODS:
  registerNode(node)
    • Create aura for node
    • Called on node spawn
    • Returns: void

  unregisterNode(node)
    • Remove aura from node
    • Called on node removal
    • Returns: void

  update(deltaTime)
    • Update all auras each frame
    • Call in render loop
    • Returns: void

  refreshAll()
    • Refresh all profiles (if categories change)
    • Optional, for runtime profile updates
    • Returns: void

  dispose()
    • Cleanup all auras
    • Called on world reset
    • Returns: void

PROPERTIES:
  enabled: boolean
    • System on/off flag

  auras: Map<nodeKey, AuraInstance>
    • Registry of node → aura mappings
    • Can inspect for debugging

  globalTime: number
    • Accumulated time in seconds
    • Used for all LFO/noise calculations

  profileLibrary: Object
    • Available profile definitions
    • Can be extended with custom profiles

================================================================================
SHADER UNIFORMS
================================================================================

Vertex Shader:
  uTime: global time (seconds)
  uAuraIntensity: [0, 1] overall brightness
  uAuraRadius: [0.5, 3.0] scale factor
  uNoiseScale: [0, 1] distortion intensity
  uLFOPeriod: breathing frequency (rad/s)
  uLFOAmplitude: breathing intensity
  uClarity, uResonance, uEntropy, uFocus, uCorruption: [0, 1] signals

Fragment Shader:
  uAuraIntensity: overall brightness
  uAuraColor: vec3 base color (by profile)
  uClarity, uResonance, uEntropy, uFocus, uCorruption: signal modulation

All uniforms automatically updated each frame

================================================================================
TROUBLESHOOTING
================================================================================

NO AURAS VISIBLE:
  ✗ System not enabled
    → console.log(auraSystem.enabled)
  ✗ Nodes not registered
    → auraSystem.registerNode(node)
  ✗ Additive blending not working
    → Verify THREE.AdditiveBlending in material
    → Check scene background (should be dark)

AURAS NOT REACTING:
  ✗ Missing personality signals
    → Verify Week 7 (EMA smoother) updating nodes
    → Check node.userData.personalityVisualSmoothed

PERFORMANCE DROP:
  ✗ Too many auras
    → Check auraSystem.auras.size
  ✗ Inconsistent frame timing
    → Use wall-clock deltaTime

FLICKERING AURAS:
  ✗ Inconsistent deltaTime
    → Clamp: Math.min(deltaTime, 0.033)

BEST PRACTICES
================================================================================

1. INITIALIZE EARLY:
   // After scene setup
   this.auraSystem = new NodeAuraSystem_v1({...});

2. REGISTER ON SPAWN:
   // In node creation
   this.auraSystem.registerNode(newNode);

3. UPDATE IN LOOP:
   // Before renderer.render()
   this.auraSystem.update(deltaTime);

4. UNREGISTER ON REMOVAL:
   // In node cleanup
   this.auraSystem.unregisterNode(removedNode);

5. HANDLE LOW-FX:
   // System automatically reduces intensity/radius
   // Configured via lowFXFade and lowFXRadiusFade options

6. CONSISTENT TIMING:
   const now = performance.now();
   const deltaTime = Math.min((now - lastTime) / 1000, 0.033);
   lastTime = now;
   this.auraSystem.update(deltaTime);
