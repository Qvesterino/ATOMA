⚙️ TECHNICAL ARCHITECTURE
─────────────────────────────────────────────────────────────────────────────

DATA STRUCTURE:
  resonancePairs: Map<linkId, resonanceState>
  resonanceState:
    ├── link: reference to link object
    ├── frequency: current resonance frequency (Hz)
    ├── phase: cumulative phase (radians, normalized 0–2π)
    ├── intensity: normalized resonance strength (0–1)
    ├── lastParticleEmit: timestamp for emission throttling
    ├── sourceAuraColor: THREE.Color for color blending
    ├── targetAuraColor: THREE.Color for color blending
    └── particleTrail: array of recent particles

  resonanceParticles: Array<particle>
  particle:
    ├── position: THREE.Vector3 (current location)
    ├── sourceNode: reference to source node
    ├── targetNode: reference to target node
    ├── linePath: THREE.LineCurve3 (path between nodes)
    ├── progress: normalized position along path (-1 to 1)
    ├── lifetime: remaining seconds
    ├── maxLifetime: initial lifetime
    ├── resonance: reference to parent resonance state
    ├── color: THREE.Color (cyan-blue range)
    └── size: particle scale

FREQUENCY MAPPING:
  normalized_synergy = (synergy - minThreshold) / (maxThreshold - minThreshold)
  frequency = baseFrequency + (normalizedSynergy × frequencyAmplitude)
  
  Default ranges:
    minThreshold = 0.3 (resonance starts)
    maxThreshold = 0.9 (full resonance)
    baseFrequency = 2.0 Hz
    frequencyAmplitude = 3.0
    
  Result: 0.3 synergy = 2.0 Hz, 0.9 synergy = 5.0 Hz

UPDATE FLOW:
  1. Per frame: deltaTime + avgSynergy passed to update()
  2. For each resonance pair:
     a. Calculate synergy from link
     b. Clamp to [minThreshold, maxThreshold]
     c. Calculate resonance intensity (EMA smoothing)
     d. Calculate frequency (synergy-driven)
     e. Accumulate phase (frequency × deltaTime × 2π)
     f. Apply node shimmer effects
     g. Modulate link glow
     h. Emit particles based on intensity
  3. Update all active particles:
     a. Decrement lifetime
     b. Move along path (+ oscillation)
     c. Fade alpha on expiration
     d. Remove dead particles
