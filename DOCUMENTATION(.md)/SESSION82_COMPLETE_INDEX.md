## 🎓 Learning Resources

### Understanding Knot Topology
- Integration nodes use **knot theory** - distinct elements topologically interlocked
- TrefoilEnhanced: 3-lobe knot (basic topology)
- InterwovenLoops: Borromean rings (advanced topology)
- KnotSingularity: Figure-8 convergence (dynamic topology)

### Geometry Implementation
- All use custom **BufferGeometry** (no Three.js primitives)
- All use **parametric curves** for topology preservation
- All use **Frenet frames** for perpendicular vectors
- All support **asymmetric cross-sections** for visual richness

### Performance Optimization
- Static geometry = zero per-frame overhead
- Deterministic creation = predictable performance
- Linear scaling = production-ready for 1000+ nodes
- Compact buffers = minimal memory footprint
