================================================================================
QUALITY FORMULA (v1.0)
================================================================================

Components (5 weighted factors):
  1. Internal Stability     (30%)  → stability, harmony, clarity
  2. Energy Factor          (15%)  → energyNorm × 100
  3. Load Stress Penalty    (15%)  → 100 - (loadRatio × 100)
  4. Corruption Penalty     (20%)  → 100 - corruption
  5. Link Quality           (20%)  → avg(70%) + min(30%)

Final Score:
  score = Σ(component × weight)
  score = clamp(0, 100)

Quality Levels:
  Prime    (85–100)   🟢 Optimal performance
  Stable   (65–84)    🔵 Good health
  Weak     (40–64)    🟡 Below average
  Critical (0–39)     🔴 Severe problems

Update Order (Critical):

  4. Rest of game logic...

PERFORMANCE
================================================================================

Computational Complexity: O(N + L)
  N = number of nodes
  L = number of links

Benchmark Results:
  Small   (50 nodes, 100 links)   → 0.3ms/frame
  Medium  (100 nodes, 500 links)  → 0.7ms/frame
  Large   (200 nodes, 2000 links) → 1.5ms/frame

Memory Footprint:
  Base: 1KB
  Per-node cache: ~50 bytes
  Total (100 nodes): ~6KB
  Negligible overhead

Per-Frame Impact:
  < 1ms for typical networks
  < 1% FPS impact at 60 FPS
