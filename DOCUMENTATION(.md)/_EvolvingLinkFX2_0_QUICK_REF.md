## 📊 LINK EVOLUTION STAGES

| Stage | Name | Appearance | Triggers | Rarity |
|-------|------|------------|----------|--------|
| 1️⃣ | **Basic** | Thin line, soft glow | New link | 100% |
| 2️⃣ | **Enhanced** | Thicker, brighter, pulsing | Node L2+ or 50% load | ~40% |
| 3️⃣ | **Advanced** | Dual-layer, arcs, cyan | Node L3+ or 3-node chain | ~20% |
| 4️⃣ | **Ascended** | Gold, crown, elegant | Node L4 or 4-node cluster | ~1-3% |

---

## 🎯 EVOLUTION TRIGGERS

### Primary (Node Evolution)
- Stage 2: Both nodes Level 2+
- Stage 3: Both nodes Level 3+
- Stage 4: Both nodes Ascended (Level 4)

### Secondary (Synergy)
- Stage 3: Connected to 3+ node chain
- Stage 4: Part of 4+ node cluster

### Tertiary (Link Load)
- Stage 2: ≥ 50% throughput
- Stage 3: ≥ 70% throughput

### Time-Based
- Stage 2: Alive 30+ seconds
- Stage 3: Alive 90+ seconds
- Stage 4: Alive 180+ seconds

**Result:** Highest applicable trigger wins

- **Stage 1:** Minimal, just connected
