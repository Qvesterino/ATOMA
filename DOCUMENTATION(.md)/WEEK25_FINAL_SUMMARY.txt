DECAY FORMULA (Physics)
─────────────────────────────────────────────────────────────────────────────

Per Hop:    I(n) = I₀ × 0.82^n

Example with I₀ = 1.0:
  Hop 0: 100%
  Hop 1: 82%
  Hop 2: 67%
  Hop 3: 55%
  Hop 4: 45%
  Hop 5: 37%
  Hop 6: 30%
  Hop 7: 25%
  Hop 8: 20% (stopping point)

Total Cascade Duration:
  = (maxHops × waveDuration) + dampingTime
  = (8 × 0.5) + 2.0
  = 6.0 seconds

USAGE EXAMPLE (5 MINUTES TO WORKING CASCADE)
─────────────────────────────────────────────────────────────────────────────

Step 1: Import
  import { CascadePropagationFX_v1 } from './CascadePropagationFX_v1.js';

Step 2: Initialize
  this.cascadeFX = new CascadePropagationFX_v1(this);
  this.cascadeFX.init();

Step 3: Trigger
  this.cascadeFX.triggerCascade(node, 0.85);

Step 4: Update
  this.cascadeFX.update(deltaTime);  // In animate loop

Step 5: Apply Effects
  const linkState = this.cascadeFX.getLinkCascadeState(link);
  if (linkState) {
      link.material.uniforms.uCascadeIntensity.value = 
          linkState.smoothedIntensity;
  }
