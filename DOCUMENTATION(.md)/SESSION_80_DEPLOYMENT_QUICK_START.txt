================================================================================
TROUBLESHOOTING: IF SOMETHING GOES WRONG
================================================================================

PROBLEM                              SOLUTION

Particles not scaling                Check link.trafficMagnitude is set
                                     Verify updateLinkParticleEmissionRate() called

Enhanced models not used             Call enableEnhancedModels()
                                     Verify node stability score < 0.5

Links not pulsing                    Check EMISSION_PULSING_CONFIG.enabled = true
                                     Verify channels enabled (glow/thickness/opacity)
                                     Verify updateLinkEmissionPulsing() called

Wrong pulsing speed                  Adjust frequencyMin/frequencyMax in config
                                     Verify traffic magnitude source

All links pulsing synchronized       Increase phaseRandomization to 0.7+

Performance issues                   Use batch operations (5-10x faster)
                                     Disable expensive channels if needed
                                     Reduce update frequency if necessary

Memory leaks                         Verify links properly cleaned up on disposal
                                     Monitor with getConfiguration() diagnostics

Console won't run                    npm install not needed (no dependencies)
                                     Verify THREE.js is imported globally
