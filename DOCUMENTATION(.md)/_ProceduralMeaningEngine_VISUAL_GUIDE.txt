================================================================================
ANIMATION INTENSITY EFFECTS
================================================================================

Node State:  How it affects glyphs:

CALM:        - Slower rotation/pulsing
             - Lower opacity variations
             - Reduced emissive intensity
             - Smooth, predictable motion

NEUTRAL:     - Standard animation speeds
             - Normal opacity (0.6)
             - Standard emissive (0.3)
             - Balanced motion

INTENSE:     - Faster rotation/pulsing
             - Higher opacity variations
             - Increased emissive intensity
             - More dramatic motion

STRESSED:    - Rapid animation
             - Maximum opacity variations
             - Maximum emissive (0.8+)
             - Chaotic motion

================================================================================
LIFECYCLE TIMELINE
================================================================================

Birth:
    0ms   → Glyph creation triggered
    1-5ms → Procedural mesh generation from pool
    5ms   → Geometry attached to node.visualGroup
    5ms+  → First animation frame

Life:
    100ms → Stable animation established
    1000ms+ → Continuous animation driven by semantic state
    Intensity updates → Opacity/animation speed adjust
    Emotion changes → Emissive intensity adjusts

Removal:
    0ms   → Remove glyph call
    0-400ms → Fade-out (opacity decreases)
    400ms → Geometry disposed
    400ms → Removed from registry

PERFORMANCE TARGETS

Per-glyph budget:
  Creation: 0.1ms (amortized across frames)
  Animation: 0.003ms per frame
  Rendering: Batched (1-2 draw calls total)

System budget (50 nodes):
  Total animation: 0.15ms
  Semantic updates: 0.05ms
  Cleanup/create: 0.03ms
  ──────────────────────
  Total per frame: 0.23ms
  Budget: 0.4ms
  Headroom: 57%

Memory:
  Per node: ~0.5KB (transform + metadata)
  50 nodes: ~25KB
  Pools: ~2MB (pre-allocated)
  Total: ~2.1MB (negligible)
