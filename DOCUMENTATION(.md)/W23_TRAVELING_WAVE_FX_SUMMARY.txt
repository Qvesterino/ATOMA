ARCHITECTURE
════════════════════════════════════════════════════════════════════════════════

System Flow:
    Chain Reaction Event
         ↓
    triggerWave(material, depth, synergyLevel)
         ↓
    WaveMaterialState created/activated
         ↓
    GPU Uniforms updated
         ↓
    Fragment Shader calculations
         ↓
    Visual traveling wave rendered

Shader Layers:
    1. Vertex Shader: Wave UV setup
    2. Fragment Shader: 
       - Wavefront calculation (smoothstep)
       - Intensity profile (distance-based)
       - Noise modulation (FBM)
       - Color blending (polarity-dependent)
       - Final composite (additive blend)

Methods
───────────────────────────────────────────────────────────────────────────────
registerMaterial(material, options)
  - Register material for wave effects
  - Options: type ('link'|'node'), polarity ('positive'|'negative'|'resonance'|'corrupted')

triggerWave(material, depth, synergyLevel, duration)
  - Activate wave on material
  - Parameters: depth (0–8), synergyLevel (0–1), duration (seconds)

update(deltaTime)
  - Update all active waves (call once per frame)

setWaveSpeed(material, speed)
  - Set wave speed (2–8 units/sec)

setWaveIntensity(material, intensity)
  - Set peak brightness (0–1)

setWaveColor(material, color)
  - Set RGB color (THREE.Color)

setPropagationDirection(material, direction)
  - Set direction (+1=forward, -1=backward)

getMetrics()
  - Get performance metrics

dispose()
  - Cleanup all resources


GPU UNIFORMS

─────────────

Wave Appearance
───────────────
uWaveIntensity (float)          Peak brightness: 0–1

uWaveSharpness (float)          Edge hardness: 0–1
uNoiseStrength (float)          FBM distortion: 0–1
uPulsationFreq (float)          Oscillation rate: 0–4 Hz

Synergy Context
───────────────
uCascadeDepth (float)           Normalized depth: 0–1 (maps 0–8 hops)
uSynergyLevel (float)           Synergy quality: 0–1
uChainEvent (float)             Trigger pulse: 0–1 (decays each frame)


SHADER CALCULATIONS
════════════════════════════════════════════════════════════════════════════════

Wavefront Position
──────────────────
wavePosition = uWaveSpeed * uTime * uPropagationDirection

Example progression (speed=4.0):
  t=0.0s → position=0.0
  t=0.5s → position=2.0
  t=1.0s → position=4.0
  t=1.5s → position=6.0

Wave Intensity Profile
──────────────────────
Positive:     intensity = 1.0 - (distFromWave * 0.5)      [sharp falloff]
Negative:     intensity = smoothstep(3.0, 0.5, distFromWave) [soft, inverted]
Resonance:    intensity = pulse * (1.0 - distFromWave * 0.3) [pulsating]
Corrupted:    intensity = varied by fbm(...)              [noisy]

Color Blending
──────────────
finalColor = waveColor * intensity * uSynergyLevel + glow + pulse
Additive blend: color.rgb += finalWaveColor * 0.5

USAGE EXAMPLES
════════════════════════════════════════════════════════════════════════════════

Example 1: Basic Setup
───────────────────────
const waveFX = new SynergyTravelingWaveFX_v1();
waveFX.registerMaterial(linkMaterial, {
    type: 'link',
    polarity: 'positive'
});
waveFX.triggerWave(linkMaterial, depth=2, synergyLevel=0.85);
waveFX.update(deltaTime);


Example 2: Polarity Selection
─────────────────────────────
const polarity = synergyLevel < 0.3 ? 'corrupted' :
                 synergyLevel > 0.8 ? 'resonance' :
                 isNegative ? 'negative' : 'positive';

waveFX.registerMaterial(material, { type: 'link', polarity });


Example 3: Dynamic Speed
─────────────────────────
const waveSpeed = 2.0 + (synergyLevel * 6.0);  // 2–8 range
waveFX.setWaveSpeed(material, waveSpeed);


Example 4: Wave Chaining
────────────────────────
for (let i = 0; i < links.length; i++) {
    setTimeout(() => {
        waveFX.triggerWave(links[i].material, i, 0.8);
    }, i * 100);  // 100ms stagger
}
