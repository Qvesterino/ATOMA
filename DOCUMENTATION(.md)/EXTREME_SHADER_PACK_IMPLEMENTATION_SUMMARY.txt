TECHNICAL IMPLEMENTATION
================================================================================

SHADER STRUCTURE:

Each shader consists of:
  - Vertex Shader: Position/normal/UV transformation
  - Fragment Shader: Color/effect calculation
  - Uniforms: time, synergy, harmony, corruption, instability, colors
  - Material: THREE.ShaderMaterial instance per mesh

SHADER UTILITIES PROVIDED:

  1. createGlassShaderMaterial() — Fresnel + refraction
  2. createRadialFalloffShader() — Vignette + gravity lens
  3. createGridShader() — Procedural grid + flicker
  4. createPulsingShader() — Emissive pulsing + rim
  5. createNoiseDistortionShader() — Noise + perturbation
  6. createEdgeHighlightShader() — Fresnel highlights
  7. createScrollingUVShader() — UV scrolling + light band
  8. createDarkShader() — Dark + specular highlights
  9. createGlitchShader() — Time-glitch effect
  10. createRadialGradientShader() — Multi-layer gradient

LIFECYCLE MANAGEMENT:

Initialization:
  - Create ExtremeAIShaderPack instance
  - Initialize material cache
  - Setup uniform tracking

Node Registration:
  - Detect archetype type
  - Create appropriate shader material
  - Replace all meshes with shader material
  - Store shader data for tracking

Update:
  - Accumulate time
  - Read metrics from node.userData (read-only)
  - Update all uniform values
  - No geometry modifications

Cleanup:
  - Dispose shader materials
  - Remove from tracking map
  - Prevent memory leaks

PERFORMANCE CHARACTERISTICS:

Memory:
  - Per-shader material: ~2-5KB VRAM
  - Shader program: ~10-20KB (shared cache)
  - Uniform buffer: ~1KB per material
  - Total per node: ~3-6KB

CPU:
  - Initialization: ~0.5-1ms per archetype
  - Update (per 10 nodes): <0.5ms
  - Cleanup: <0.5ms per node

GPU:
  - Shader compilation: One-time ~50-100ms per type
  - Runtime rendering: Part of standard rendering
  - No additional processing required

COLOR CUSTOMIZATION:

    0x00ffff,  // Color A

Available Colors:
  0x00ffff — Cyan
  0xff00ff — Magenta
  0xffff00 — Yellow
  0xff00aa — Pink
  0x00ffaa — Aqua
  0xff0055 — Red
  0x001111 — Dark
  0xff6644 — Orange
  0xffffff — White

ANIMATION SPEED ADJUSTMENT:

Modify time multipliers in shaders:

  // Speed up: multiply by higher factor
  float pulse = sin(u_time * 4.0) * 0.5 + 0.5;  // 2x faster
  
  // Slow down: multiply by lower factor
  float pulse = sin(u_time * 1.0) * 0.5 + 0.5;  // 2x slower

METRIC INFLUENCE TUNING:

Adjust multipliers in shader calculations:

  // Stronger influence: increase multiplier
  color += u_edgeColor * edgeIntensity * 0.8;  // 80% influence
  
  // Weaker influence: decrease multiplier
  color += u_edgeColor * edgeIntensity * 0.3;  // 30% influence
