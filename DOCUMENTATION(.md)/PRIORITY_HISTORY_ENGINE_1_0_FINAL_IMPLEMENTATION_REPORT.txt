WHAT WAS BUILT
==============

Priority History Engine 1.0 is a temporal analytics system that tracks the evolution 
of link.priority over time. It records samples of score, tier, and traffic intensity 
at regular intervals, stores them in efficient circular buffers (60 samples = ~30s), 
and provides a comprehensive analytics API for querying trends and statistics.

CORE COMPONENTS:
  ✓ PriorityHistoryEngine1_0.js (520 lines)

ARCHITECTURE
============

DATA STRUCTURE:

Per-Link History State:
  ├─ id: "node-1_to_node-2"
  ├─ category: "sigma"
  ├─ createdAt: timestamp
  ├─ lastUpdatedAt: timestamp
  ├─ buffer: Array(60)      [Circular buffer of samples]
  ├─ writeIndex: number     [Current write position]
  ├─ size: number           [Buffer fill level (0-60)]
  └─ aggregates: {
      ├─ minScore, maxScore, avgScore, lastScore
      ├─ risingTicks, fallingTicks, stableTicks
      └─ activeTicks, idleTicks
     }

Sample Structure:
  {
    t: timestamp (ms),
    score: 0-1,
    tier: 0-3,
    traffic: 0-1
  }


DATA FLOW:

  Animation Loop
    │
    ├─ PriorityDecayEngine.tick()
    │  └─ Updates link.priority.score
    │
    ├─ PriorityHistoryEngine.tick()
    │  ├─ Reads link.priority.score/tier/traffic
    │  ├─ Records sample in circular buffer
    │  ├─ Updates aggregates
    │  └─ Tracks trends & activity
    │
    └─ Renderer.render()


BUFFER MANAGEMENT:

  writeIndex cycles: 0 → 1 → 2 → ... → 59 → 0 → 1 ...
  size grows: 0 → 1 → 2 → ... → 60 → 60 → 60 ...
  
  Result: Always have most recent 30 seconds of history

KEY FEATURES
============

1. CIRCULAR HISTORY BUFFERS ✓
   - 60 samples per link (~30s at 500ms tick interval)
   - Fixed memory allocation (no growth)
   - Efficient chronological data retrieval
   - Safe to query anytime without waiting

2. REAL-TIME AGGREGATION ✓
   - Min/Max/Avg score tracking
   - Incremental calculation (no recomputes)
   - Trend tick counting
   - Activity ratio tracking

3. TREND ANALYSIS ✓
   - Detects 'rising' (score increasing)
   - Detects 'falling' (score decreasing)
   - Detects 'stable' (no significant change)
   - Configurable sensitivity (minDeltaScore)

4. TOP-N QUERIES ✓
   - getTopBy('metric', limit)
   - Supports nested metrics (e.g., 'score.avg')
   - Sorted in descending order
   - Examples:
     * getTopBy('activity.activeTicks', 10) — Most active links
     * getTopBy('score.avg', 5) — Highest priority links
     * getTopBy('score.max', 20) — Links with highest peaks

5. GLOBAL ANALYTICS ✓
   - getSnapshotSummary() returns:
     * Global average score
     * Highest/lowest links
     * Activity ratio
     * Trend distribution (rising/falling/stable)

6. FULL CONTROL ✓
   - enable() / disable() — Pause tracking
   - reset() / resetAll() — Clear data
   - cleanup() — Remove old entries
   - resetLink() — Clear single link

7. DIAGNOSTIC REPORTING ✓
   - status() — Quick overview
   - getDiagnosticReport() — Formatted ASCII report
   - debugLink() — Per-link debugging

INSTALLATION
=============

STEP 1: COPY FILE
─────────────────
Copy PriorityHistoryEngine1_0.js to project root (same folder as other engines)


STEP 2: IMPORT IN main.js
────────────────────────
Add near top of file (with other imports):

    import { PriorityHistoryEngine1_0 } from './PriorityHistoryEngine1_0.js';


STEP 3: INITIALIZE (AFTER PriorityDecayEngine)
───────────────────────────────────────────────
In your initialization code (where linkingSystem is created), add:

    window.game = window.game || {};
    window.game.priorityHistoryEngine = new PriorityHistoryEngine1_0(
      window.game.linkingSystem,
      window.game.priorityDecayEngine || null,
      window.game.metricsSystem || null
    );

    console.log('[ATOMA] Priority History Engine 1.0 initialized');


STEP 4: CALL IN ANIMATION LOOP (AFTER PriorityDecayEngine)
──────────────────────────────────────────────────────────
IMPORTANT: Must be called AFTER PriorityDecayEngine so history captures
updated scores. Add to your animate() function:

    function animate(now) {
      const deltaMs = now - lastFrameTime;
      lastFrameTime = now;

      // 1. Decay engine updates link.priority.score
      if (window.game.priorityDecayEngine) {
        window.game.priorityDecayEngine.tick(deltaMs);
      }

      // 2. History engine reads updated scores and records samples
      if (window.game.priorityHistoryEngine) {
        window.game.priorityHistoryEngine.tick(deltaMs);
      }

      renderer.render(scene, camera);
    }

    requestAnimationFrame(animate);


STEP 5: VERIFY (DEVELOPER CONSOLE)
──────────────────────────────────
Run after engine initialized:

    window.game.priorityHistoryEngine.status()

Expected output:
    {
      enabled: true,
      linksTracked: 0,          (increases as you create links)
      samplesTotal: 0,          (increases over time)
      errors: 0,
      bufferSize: 60,
      memoryEstimate: "0KB"
    }

If status shows enabled: true and no errors → ✓ WORKING!

CONSOLE API REFERENCE
======================

QUICK STATUS:
    window.game.priorityHistoryEngine.status()
    Returns: { enabled, linksTracked, samplesTotal, errors, bufferSize, memoryEstimate }


HISTORY QUERIES:
    window.game.priorityHistoryEngine.getLinkHistory('link-id')
    Returns: Array of { t, score, tier, traffic } in chronological order

    window.game.priorityHistoryEngine.getLinkStats('link-id')
    Returns: {
      id, category, createdAt, lastUpdatedAt, ageMs,
      score: { current, min, max, avg, range },
      trend: { risingTicks, fallingTicks, stableTicks },
      activity: { activeTicks, idleTicks, activityRatio }
    }


TREND DETECTION:
    window.game.priorityHistoryEngine.getTrend('link-id')
    Returns: 'rising' | 'falling' | 'stable' | 'unknown'


TOP-N QUERIES:
    window.game.priorityHistoryEngine.getTopBy('metric', limit)
    
    Examples:
      getTopBy('activity.activeTicks', 10)  — Top 10 most active
      getTopBy('score.avg', 5)              — Top 5 highest priority
      getTopBy('score.max', 20)             — Top 20 highest peaks

    Returns: Array of stats objects, sorted descending


GLOBAL SNAPSHOT:
    window.game.priorityHistoryEngine.getSnapshotSummary()
    Returns: {
      linksTracked, samplesTotal,
      scoreStats: { globalAvg, highestLink, lowestLink },
      activityStats: { globalActivityRatio },
      trends: { rising, falling, stable }
    }


CONTROL:
    window.game.priorityHistoryEngine.enable()      — Resume tracking
    window.game.priorityHistoryEngine.disable()     — Pause tracking
    window.game.priorityHistoryEngine.resetLink('id') — Clear one link
    window.game.priorityHistoryEngine.resetAll()    — Clear all data
    window.game.priorityHistoryEngine.cleanup()     — Remove old entries


CONFIGURATION:
    window.game.priorityHistoryEngine.getConfig()
    window.game.priorityHistoryEngine.setConfig({ minDeltaScore: 0.02, ... })


DIAGNOSTIC:
    console.log(window.game.priorityHistoryEngine.getDiagnosticReport())
    Prints: Formatted ASCII report with all stats

CONFIGURATION
==============

DEFAULT CONFIG:

    {
      enabled: true,              // Global enable/disable
      tickIntervalMs: 500,        // Expected interval between ticks
      bufferSize: 60,             // 60 samples = ~30s at 500ms tick
      minDeltaScore: 0.01,        // Threshold for trend detection
      trendWindow: 10,            // Last N samples for trend analysis
      maxHistoricalLinks: 5000,   // Safety limit on tracked links
    }


TUNING FOR DIFFERENT NEEDS:

Longer History (1 minute):
    new PriorityHistoryEngine1_0(linkingSystem, null, null, {
      bufferSize: 120             // 120 samples = 60 seconds
    })

Faster Trend Detection:
    setConfig({
      trendWindow: 5,             // Use fewer samples
      minDeltaScore: 0.02         // Require larger changes
    })

Smoother Trends (less sensitive):
    setConfig({
      trendWindow: 20,            // Use more samples
      minDeltaScore: 0.005        // Detect smaller changes
    })


IMPORTANT: bufferSize cannot be changed after initialization (safety feature).
Other parameters can be tuned with setConfig().

METRICS AVAILABLE FOR QUERIES
==============================

Score-Based:
  score.current    — Latest recorded score
  score.min        — Minimum in buffer
  score.max        — Maximum in buffer
  score.avg        — Average
  score.range      — Max - Min

Trend-Based:
  trend.risingTicks   — Samples where score increased
  trend.fallingTicks  — Samples where score decreased
  trend.stableTicks   — Samples with no significant change

Activity-Based:
  activity.activeTicks      — Samples with traffic > 0
  activity.idleTicks        — Samples with traffic = 0
  activity.activityRatio    — active / total
