TASK 2: NODE CORE OPACITY FIX
================================================================================

OBJECTIVE:
Node cores must ALWAYS remain solid and clearly visible.
Only auras, shells, fields, and auxiliary effects may use transparency.

ROOT CAUSE IDENTIFIED:
- Cores, auras, effects were NOT properly separated into distinct layers
- Parent group transparency inheritance affected core materials
- No material immutability enforcement
- Aura opacity modifiers bled into core geometry

ARCHITECTURE SOLUTION: THREE-LAYER RENDERING SYSTEM

Layer 0: CORE (renderOrder=0)
├─ ALWAYS opaque: transparent=false, opacity=1.0
├─ Main node geometry (icosahedron, octahedron, cube)
├─ userData.isNodeCore = true
├─ depthWrite=true, depthTest=true
└─ NO transparency inheritance from parent

Layer 1: AURA (renderOrder=1)
├─ ALLOWED transparent: separate material instances
├─ Hologram shell from createNodeHologramShell()
├─ userData.isAura = true
├─ Renders AFTER core, doesn't affect it
└─ Can fade/pulse independently

Layer 2: EFFECT (renderOrder=2)
├─ ALLOWED transparent: edges, rings, panels, accents
├─ userData.isEffect = true
├─ Renders LAST
└─ Visual enhancements only

IMPLEMENTATION:

✅ AINodeModel.js - Opacity enforcement for all cores
   - Added material property locks at creation:
     material.transparent = false;
     material.opacity = 1.0;
     material.depthWrite = true;
     material.depthTest = true;
   
   - Applied to all node types:
     ✓ createCoreNode() (icosahedron)
     ✓ createDataNode() (octahedron)
     ✓ createMemoryNode() (cube)
     ✓ createLogicNode() (tetrahedron) - same pattern
     ✓ createNeuralNode() (complex shape) - same pattern

✅ AINodeModel.js - Layer identification and render ordering
   - All cores: renderOrder=0, userData.isNodeCore=true
   - All auras: renderOrder=1, userData.isAura=true
   - All effects: renderOrder=2, userData.isEffect=true

✅ NodeCoreOpaqueEnforcer_Session113.js - NEW ENFORCEMENT SYSTEM
   - Per-node registration: registerNode(nodeGroup)
   - Per-frame validation: validateFrame(deltaTime, time)
   - Violation detection: logs all opacity changes
   - Console API: window.NodeCoreOpaqueDebug.*
   
   Validates:
   ├─ transparent === false (or flag violation)
   ├─ opacity === 1.0 (or flag violation)
   ├─ depthWrite === true (or flag violation)
   └─ depthTest === true (or flag violation)

EXPECTED CONSOLE OUTPUT:
   [NODE CORE OPAQUE ENFORCER] Registered node Node_42 with 1 core meshes
   [NODE CORE OPAQUE CHECK] id=Node_42 opacity=1.0 transparent=false ✓ OK

VIOLATION DETECTION:
   [NODE CORE OPAQUE ENFORCER] VIOLATION: Node Node_42 core material transparent=true (should be false)
   [NODE CORE OPAQUE ENFORCER] VIOLATION: Node Node_42 core material opacity=0.6 (should be 1.0)

RESULT: ✅ Node cores now architecturally separated from aura/effect transparency
