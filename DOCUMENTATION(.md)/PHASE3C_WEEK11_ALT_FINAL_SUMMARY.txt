SYSTEM OVERVIEW
================================================================================

WHAT IT DOES:
  Classifies every node and link into 5 evolution tiers (Dormant to 
  Transcendent) based on existing Phase 3 metrics. Computes continuous 
  "Ascension Scores" (0–1) and exposes visual driver signals for other 
  systems to enhance visuals.

FIVE EVOLUTION TIERS:
  0 - Dormant       (Score 0.00–0.20, Gray)      → Sleeping
  1 - Awakened      (Score 0.18–0.40, Blue)      → Growing
  2 - Ascending     (Score 0.35–0.65, Lime)      → Progressing
  3 - Mythic        (Score 0.60–0.85, Purple)    → Legendary ✨
  4 - Transcendent  (Score 0.80–1.00, Yellow)    → Divine 🔮

ASCENSION FORMULAS:
  Node: 0.40*quality + 0.25*harmony + 0.15*synergy + 0.10*energy + 
        0.10*(1-corruption)
  
  Link: 0.45*quality + 0.35*synergy + 0.10*(1-corruption) + 0.10*resonance

  (All normalized to 0–1, with EMA smoothing α=0.20)

KEY FEATURES:
  ✓ Pure logic layer (no shader modifications)
  ✓ Clean visual driver signals (auraBoost, fxIntensity, etc.)
  ✓ Hysteresis to prevent tier flicker
  ✓ EMA smoothing for organic progression
  ✓ 4 visual signals per node/link (0–1 range)
  ✓ Tier-based color hints for UI/auras
  ✓ Boolean flags (isMythic, isAscending, isFalling)

================================================================================
OUTPUT DATA STRUCTURE
================================================================================

STORED IN: node.userData.mythicEvolution (and link.userData.mythicEvolution)

CONTENTS:
  ascensionRaw            number    0–1, raw score
  ascensionSmoothed       number    0–1, EMA filtered
  tier                    number    0–4
  tierName                string    'Dormant' | 'Awakened' | etc.
  
  isMythic                boolean   tier >= 3
  isAscending             boolean   tier >= 2
  isFalling               boolean   tier decreased last frame
  
  auraBoost               number    0–1, aura intensity multiplier
  fxIntensity             number    0–1, general FX strength
  trailIntensity          number    0–1, for trails (future)
  glowIntensity           number    0–1, for glow (future)
  
  hintColorHex            string    '#808080' | '#0088ff' | etc.
  lastTierChangeTime      number    timestamp

AUTOMATIC: No manual setup needed, all written automatically on update()

  Week 11 is computation + signals, not shader/visual changes.
  Provides hooks for Week 12+ to enhance visuals.

FANTASY/IMMERSION:
  Players visually read node/link power levels through tier progression:
  - Dormant → Awakened → Ascending → Mythic → Transcendent
  - Visual intensity grows with tier
  - Special states (Mythic) feel earned

  - Input: Read from existing metrics (quality, harmony, etc.)

  Visual driver signals are intentionally generic:
  - auraBoost can drive any aura intensity
  - fxIntensity can drive any shader effect
  - Week 12+ decides how to use signals
  - Extensible without modifying Week 11
