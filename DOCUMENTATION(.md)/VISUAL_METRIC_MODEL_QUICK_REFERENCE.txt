OVERVIEW
================================================================================

VisualMetricModel_v1.js is a safe, non-invasive visual adapter layer that:
- Reads from Phase 3 metrics (NodeDynamics, LinkQuality, NodeQuality)
- Normalizes all values to 0–1 shader-friendly range
- Writes to node.userData.visualMetrics and link.userData.visualMetrics
- Never modifies existing systems (purely additive)
- Handles missing systems gracefully with safe defaults

================================================================================
INITIALIZATION
================================================================================

1. Import:
   import { VisualMetricModel } from "./VisualMetricModel_v1.js";

2. In AtomaGame constructor:
   this.nodeDynamics = new NodeDynamicMetrics(this.aiNodes, this.nodeLinkingSystem);
   this.linkQuality = new LinkQualityCalculator(this.nodeLinkingSystem, this.nodeDynamics);
   this.nodeQuality = new NodeQualityCalculator(
       this.aiNodes,
       this.nodeLinkingSystem,
       this.nodeDynamics,
       this.linkQuality
   );
   this.visualMetrics = new VisualMetricModel(
       this.aiNodes,
       this.nodeLinkingSystem,
       this.nodeDynamics,
       this.nodeQuality,
       this.linkQuality
   );

3. In game update loop (AFTER all Phase 3 systems):
   this.nodeDynamics.update(dt);
   this.linkQuality.update(dt);
   this.nodeQuality.update(dt);
   this.visualMetrics.update(dt);  // <-- Always last!

node.userData.visualMetrics = {

  loadNorm: 0.0–1.0,          // From NodeDynamicMetrics.loadRatio (already 0–1)
  qualityNorm: 0.0–1.0,       // From NodeQualityCalculator.score / 100
  isPrime: boolean,            // NodeQualityCalculator.level === "Prime"
  isCritical: boolean,         // NodeQualityCalculator.level === "Critical"
  updatedAt: timestamp,        // Last update milliseconds
};

================================================================================
NORMALIZATION RULES
================================================================================

RULE 1: From 0–100 Scale
  normalized = Math.max(0, Math.min(1, raw / 100))
  
  Examples:
    stability: 85 → stabilityNorm: 0.85
    harmony: 60 → harmonyNorm: 0.60
    corruption: 25 → corruptionNorm: 0.25
    quality: 100 → qualityNorm: 1.0

RULE 2: Already 0–1 Scale
  normalized = Math.max(0, Math.min(1, raw))
  
  Examples:
    energyNorm: 0.75 → energyNorm: 0.75 (unchanged)
    loadRatio: 0.5 → loadNorm: 0.5 (unchanged)

RULE 3: Computed Values
  synergyNorm = (harmonyNorm * 0.6 + stabilityNorm * 0.4)
  stressNorm = (100 - structuralScore) / 100

RULE 4: Safety Clamping
  All values clamped to [0, 1]
  NaN/Infinity values replaced with safe defaults
  No value can ever be outside [0, 1] range

================================================================================
USAGE EXAMPLES
================================================================================

EXAMPLE 1: Color by Quality
  const visualMtx = node.userData.visualMetrics;
  if (visualMtx) {
    if (visualMtx.isPrime) {
      node.material.color = new THREE.Color(0x00ff00);
    } else if (visualMtx.isCritical) {
      node.material.color = new THREE.Color(0xff0000);
    } else {
      const h = visualMtx.qualityNorm * 0.3;
      node.material.color.setHSL(h, 1.0, 0.5);
    }
  }

EXAMPLE 2: Emissive by Harmony
  const visualMtx = node.userData.visualMetrics;
  if (visualMtx) {
    const emissiveness = visualMtx.harmonyNorm * 0.7 + visualMtx.energyNorm * 0.3;
    node.material.emissiveIntensity = emissiveness * 2.0;
  }

EXAMPLE 3: Scale Link by Quality
  const visualMtx = link.userData.visualMetrics;
  if (visualMtx) {
    link.material.linewidth = 1.0 + visualMtx.qualityNorm * 3.0;  // 1–4
  }

EXAMPLE 4: Pulse Speed by Synergy
  const visualMtx = node.userData.visualMetrics;
  if (visualMtx) {
    const pulseFreq = 1.0 + visualMtx.synergyNorm * 5.0;  // 1–6 Hz
    const pulse = Math.sin(Date.now() * 0.001 * pulseFreq) * 0.5 + 0.5;
    node.material.emissiveIntensity = 1.0 + pulse;
  }

================================================================================
TROUBLESHOOTING
================================================================================

Problem: visualMetrics are always 0.5 (default)
Solution:
  1. Check getSystemStatus() - ensure all Phase 3 systems initialized
  2. Verify update order - visualMetrics.update() must be LAST
  3. Check if source systems are actually running

Problem: NaN or Infinity values appearing
Solution:
  1. VisualMetricModel should auto-repair these
  2. If persisting, check source systems for NaN generation
  3. Enable debug output: console.log(getNodeVisualMetrics(node))

Problem: Performance degradation
Solution:
  1. Check getPerformanceStats() for actual frame time
  2. Profile with DevTools to isolate bottleneck
  3. Consider disabling link metrics: config.enableLinkMetrics = false
  4. Check node/link counts - may have grown unexpectedly

Problem: isPrime/isCritical flags not working
Solution:
  1. Verify NodeQualityCalculator is running
  2. Check threshold values: primeThreshold (default 85), criticalThreshold (default 39)
  3. Confirm node quality scores are in expected ranges
