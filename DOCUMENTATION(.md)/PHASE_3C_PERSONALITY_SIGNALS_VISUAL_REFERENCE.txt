THE 5 PERSONALITY SIGNALS – AT A GLANCE

================================================================================
SIGNAL 1: clarityBoost (Intellectual Clarity / Coherence)
================================================================================

Formula:
  clarityBoost = (harmonyNorm × 0.40) + (stabilityNorm × 0.30) + (qualityNorm × 0.30)

Range: 0–1

Meaning:
  0.0 → Node is chaotic, incoherent, poor quality connections
  0.5 → Node is balanced, moderately focused
  1.0 → Node is crystal-clear, highly coherent, excellent quality

Input Drivers:
  • harmonyNorm (40%) ........... How well its connections work
  • stabilityNorm (30%) ......... How stable the node is
  • qualityNorm (30%) ........... Overall node quality

Visual Manifestation:
  LOW (0.0–0.3)
  └─ Fuzzy, blurred, low definition
  └─ Muted colors, washed out
  └─ No sparkle or clarity effects
  └─ Appearance: "confused, lost"

  MEDIUM (0.3–0.7)
  └─ Normal appearance
  └─ Clear outline but not special
  └─ Some definition visible
  └─ Appearance: "normal, focused"

  HIGH (0.7–1.0)
  └─ Crystal clear, sharp definition
  └─ Vivid, saturated colors
  └─ Sparkle/glow effects
  └─ Appearance: "brilliant, coherent"

Use Cases for VFX:
  ✓ Modulate glow intensity
  ✓ Sharpen geometric edges
  ✓ Increase material saturation
  ✓ Brighten emissive components
  ✓ Enhance label/text visibility
  ✓ Add sparkle or clarity particles

Shader Integration (Week 3+):
  uniform float personality_clarity;
  gl_FragColor.rgb *= (1.0 + clarity * 0.3);      // Brighter
  gl_FragColor.rgb = mix(gl_FragColor.rgb, 
                          gl_FragColor.rgb + 0.2,  // Sharper
                          clarity * 0.5);


================================================================================
SIGNAL 2: resonanceBoost (Connection Harmony / Resonance)
================================================================================

Formula:
  resonanceBoost = (avgSurroundingSynergy × 0.70) + (harmonyNorm × 0.30)
  
  [If no links: resonanceBoost = harmonyNorm]

Range: 0–1

Meaning:
  0.0 → Node is isolated, poorly connected to neighbors
  0.5 → Node has moderate connection resonance
  1.0 → Node is highly resonant with neighbors, excellent synergy

Input Drivers:
  • avgSurroundingSynergy (70%) .. How synergistic its links are
  • harmonyNorm (30%) ........... Node's own harmony (fallback)

Visual Manifestation:
  LOW (0.0–0.3)
  └─ Links dim or broken
  └─ Isolated appearance
  └─ Slow/sluggish animation
  └─ Appearance: "disconnected, alone"

  MEDIUM (0.3–0.7)
  └─ Links glow normally
  └─ Connected appearance
  └─ Steady animation
  └─ Appearance: "connected, balanced"

  HIGH (0.7–1.0)
  └─ Links shine brightly
  └─ Vibrant connections
  └─ Fast, rhythmic animation
  └─ Energy flows visibly through links
  └─ Appearance: "resonant, harmonious"

Use Cases for VFX:
  ✓ Modulate link pulse frequency
  ✓ Speed up rotation/orbiter animation
  ✓ Increase link glow intensity
  ✓ Add harmonic ripple effects
  ✓ Enhance connection visualization
  ✓ Trigger resonance patterns

Shader Integration (Week 3+):
  uniform float personality_resonance;
  float pulseSpeed = 1.0 + personality_resonance * 3.0;
  float linkGlow = mix(0.5, 1.5, personality_resonance);


================================================================================
SIGNAL 3: entropyPenalty (Chaos / Disorder / Degradation)
================================================================================

Formula:
  entropyPenalty = (corruptionNorm × 0.50) + ((1 - stabilityNorm) × 0.30) + (loadNorm × 0.20)

Range: 0–1

Meaning:
  0.0 → Node is perfectly ordered, no chaos
  0.5 → Node has moderate disorder, visible degradation
  1.0 → Node is maximum chaos, severe corruption

Input Drivers:
  • corruptionNorm (50%) ........ Actual corruption level
  • (1 - stabilityNorm) (30%) ... Instability penalty
  • loadNorm (20%) ............. System load penalty

Visual Manifestation:
  LOW (0.0–0.3)
  └─ Clean, perfect appearance
  └─ No artifacts or noise
  └─ Smooth animations
  └─ Appearance: "pristine, perfect"

  MEDIUM (0.3–0.7)
  └─ Minor glitches/artifacts
  └─ Some visual noise
  └─ Slightly jerky animation
  └─ Appearance: "degrading, stressed"

  HIGH (0.7–1.0)
  └─ Severe glitches and distortion
  └─ Heavy noise/static
  └─ Chaotic, broken animation
  └─ Cracks or tears visible
  └─ Appearance: "corrupted, failing"

Use Cases for VFX:
  ✓ Trigger glitch/distortion effects
  ✓ Add particle scatter/noise
  ✓ Modulate color saturation (desaturate)
  ✓ Add crackling/decay sounds
  ✓ Increase animation jitter
  ✓ Spawn corruption particles
  ✓ Add visual "decay" effects

Shader Integration (Week 3+):
  uniform float personality_entropy;
  vec3 glitch = vec3(sin(time * 10.0 + entropy * 50.0)) * entropy;
  gl_FragColor.rgb = mix(gl_FragColor.rgb, gl_FragColor.rgb + glitch, entropy);
  gl_FragColor.rgb = mix(gl_FragColor.rgb, 
                         vec3(length(gl_FragColor.rgb)),  // Desaturate
                         entropy * 0.5);


================================================================================
SIGNAL 4: focusShift (Overload / Scattered Attention)
================================================================================

Formula:
  focusShift = ((1 - stabilityNorm) × 0.60) + (loadNorm × 0.40)

Range: 0–1

Meaning:
  0.0 → Node is fully focused, no overload
  0.5 → Node is moderately distracted/overloaded
  1.0 → Node is severely overloaded, completely scattered

Input Drivers:
  • (1 - stabilityNorm) (60%) ... Instability (inverse of focus)
  • loadNorm (40%) ............. System load penalty

Visual Manifestation:
  LOW (0.0–0.3)
  └─ Centered, focused appearance
  └─ Tight, compact representation
  └─ Smooth, controlled motion
  └─ Appearance: "focused, alert"

  MEDIUM (0.3–0.7)
  └─ Slightly dispersed particles
  └─ Minor jitter in position/rotation
  └─ Somewhat erratic animation
  └─ Appearance: "distracted, busy"

  HIGH (0.7–1.0)
  └─ Particles scattered outward
  └─ Heavy jitter and vibration
  └─ Chaotic, uncontrolled motion
  └─ Spread out appearance
  └─ Appearance: "overwhelmed, scattered"

Use Cases for VFX:
  ✓ Scatter particles outward
  ✓ Increase position jitter
  ✓ Speed up animation/rotation
  ✓ Add erratic motion patterns
  ✓ Flicker or pulse chaotically
  ✓ Reduce coherence of representation
  ✓ Add "overwhelmed" visual cues

Shader Integration (Week 3+):
  uniform float personality_focus;
  vec2 jitter = (vec2(noise) - 0.5) * personality_focus * 0.1;
  gl_FragCoord += jitter;


================================================================================
SIGNAL 5: corruptionSignal (Corruption / Degradation)
================================================================================

Formula:
  corruptionSignal = corruptionNorm  (direct pass-through)

Range: 0–1

Meaning:
  0.0 → Node is pristine, not corrupted
  0.5 → Node is moderately corrupted
  1.0 → Node is severely corrupted, near collapse

Input Drivers:
  • corruptionNorm (100%) ....... Direct corruption measure

Visual Manifestation:
  LOW (0.0–0.3)
  └─ Normal appearance, no corruption
  └─ Healthy color palette
  └─ Smooth surfaces
  └─ Appearance: "healthy, intact"

  MEDIUM (0.3–0.7)
  └─ Slight red/orange tint
  └─ Some surface degradation
  └─ Visible but not severe
  └─ Appearance: "damaged, worn"

  HIGH (0.7–1.0)
  └─ Heavy red/dark overlay
  └─ Cracks, tears, decay visible
  └─ Nearly complete degradation
  └─ Appearance: "severely corrupted, collapsing"

Use Cases for VFX:
  ✓ Apply red/orange tint
  ✓ Reduce brightness/emission
  ✓ Add crack/tear effects
  ✓ Trigger decay particles
  ✓ Modulate opacity (fading)
  ✓ Add "pain" or "damage" effects
  ✓ Visualize degradation

Shader Integration (Week 3+):
  uniform float personality_corruption;
  vec3 tint = mix(vec3(1.0), vec3(1.0, 0.3, 0.2), personality_corruption);
  gl_FragColor.rgb *= tint;
  gl_FragColor.rgb *= (1.0 - personality_corruption * 0.3);  // Darken

================================================================================
IMPLEMENTATION QUICK-COPY SNIPPETS
================================================================================

Read Signals:
─────────────
const pv = node.userData.personalityVisual;
if (!pv) return;

const clarity = pv.clarityBoost;       // 0–1
const resonance = pv.resonanceBoost;   // 0–1
const entropy = pv.entropyPenalty;     // 0–1
const focus = pv.focusShift;           // 0–1
const corruption = pv.corruptionSignal; // 0–1


Basic VFX (Copy-Paste):
──────────────────────

// Clarity effect: brighten glow
node.material.emissiveIntensity = 0.5 + (clarity * 0.5);

// Resonance effect: speed up rotation
node.userData.rotationSpeed = 1.0 + (resonance * 2.0);

// Entropy effect: add particles
if (entropy > 0.3) {
  spawnEntropyParticles(node, entropy);
}

// Focus effect: jitter position
const jitter = focus * 0.02;
node.position.x += (Math.random() - 0.5) * jitter;
node.position.y += (Math.random() - 0.5) * jitter;
node.position.z += (Math.random() - 0.5) * jitter;

// Corruption effect: red tint
node.material.color.lerp(
  new THREE.Color(1.0, 0.3, 0.2),
  corruption * 0.3
);


Smooth Lerp (Copy-Paste):
─────────────────────────
const target = 0.5 + (clarity * 0.5);
node.material.emissiveIntensity = THREE.MathUtils.lerp(
  node.material.emissiveIntensity,
  target,
  deltaTime * 2.0  // Smooth over 0.5 seconds
);


Multi-Signal Blending (Copy-Paste):
────────────────────────────────────
// Compute overall "health"
const health = (
  clarity * 0.25 +              // Clear is good
  resonance * 0.25 +            // Connected is good
  (1 - entropy) * 0.25 +        // Low chaos is good
  (1 - corruption) * 0.25       // No corruption is good
);

// Use health to drive effects
node.material.emissiveIntensity = 0.3 + (health * 0.7);


================================================================================
TIPS FOR VFX ARTISTS
================================================================================

TIP 1: Start Simple
───────────────────
Don't try to use all 5 signals at once. Start with 1–2.
→ Example: Just use clarity for brightness, that's it.
→ Then add resonance for link animation.
→ Build up gradually.

TIP 2: Layer Effects
────────────────────
Stack multiple effects for richer personality.
→ Clarity + resonance = bright AND harmonious
→ Entropy + corruption = chaotic AND damaged
→ Focus + load = erratic AND overloaded

TIP 3: Smooth Animations
─────────────────────────
Use lerp/easing to smooth signal-driven animations.
→ Don't jump between values (looks jerky)
→ Smoothly interpolate over 0.2–0.5 seconds
→ Creates more natural, fluid effects

TIP 4: Thresholds vs. Gradients
────────────────────────────────
Compare:
  if (entropy > 0.5) spawnParticles();      // Threshold (sudden)
  const amount = entropy * 3.0;             // Gradient (smooth)
  
Use gradients for better visual transitions.

TIP 5: Combine Signals
──────────────────────
Create composite effects:
  health = clarity * resonance              // Good if both high
  chaos = entropy + (1 - focus)             // Total disorder

TIP 6: Test Edge Cases
──────────────────────
Check what happens when:
  • All signals are 0 (should look calm)
  • All signals are 1 (should look intense)
  • Mix (should look balanced)

PERFORMANCE TIPS
================================================================================

✓ Compute all 5 signals once per node per frame (already optimized)
✓ Cache results in node.userData.personalityVisual
✓ Use signals directly (no recomputation needed)
✓ Lerp/smooth at VFX system level (not in adapter)
✓ Use thresholds to trigger expensive effects (not every frame)

Example:
  const entropy = pv.entropyPenalty;
  if (entropy > 0.5 && !node.userData.particlesSpawned) {
    spawnParticles(node);
    node.userData.particlesSpawned = true;
  }
