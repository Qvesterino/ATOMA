ISSUE:
──────────────────────────────────────────────────────────────────────────────
  • Small blue/teal pill-shaped bar appears top-right
  • Displays "SELECTED: NONE" when no node selected
  • Overlaps with Selected Node HUD
  • Should not be visible

ROOT CAUSE:
──────────────────────────────────────────────────────────────────────────────
  File: /UISelectedHUD.js
  Issue: HUD element created with display: block by default
  Issue: clear() method shows "SELECTED: NONE" text
  Issue: Element not hidden when no node is selected

SOLUTION (2 CHANGES):
──────────────────────────────────────────────────────────────────────────────

Change 1: Hide element by default (_createHudElement method)
  BEFORE:
    this.hudElement.textContent = 'SELECTED: NONE';
    document.body.appendChild(this.hudElement);
  
  AFTER:
    this.hudElement.style.display = 'none'; // HIDDEN until node selected
    this.hudElement.textContent = '';
    document.body.appendChild(this.hudElement);

Change 2: Hide on clear (clear method)
  BEFORE:
    clear() {
      this.hudElement.textContent = 'SELECTED: NONE';
      this.hudElement.classList.remove('selected');
      this.hudElement.classList.add('none');
    }
  
  AFTER:
    clear() {
      this.hudElement.textContent = '';
      this.hudElement.style.display = 'none'; // HIDDEN when no node selected
      this.hudElement.classList.remove('selected');
      this.hudElement.classList.add('none');
      this.selectedNode = null;
    }

Change 3: Show on updateDisplay (updateDisplay method)
  BEFORE:
    this.hudElement.textContent = displayText;
    this.hudElement.classList.remove('none');
    this.hudElement.classList.add('selected');
  
  AFTER:
    this.hudElement.textContent = displayText;
    this.hudElement.style.display = 'block'; // SHOW when node selected
    this.hudElement.classList.remove('none');
    this.hudElement.classList.add('selected');
    this.selectedNode = node;
