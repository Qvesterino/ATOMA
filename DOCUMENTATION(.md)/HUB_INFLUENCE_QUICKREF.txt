OVERVIEW
────────────────────────────────────────────────────────────────────────────
Visual field projection from harmonic hubs that influences connected links
and neighboring nodes through two distance-based zones.

Core Concept: Network is continuous field, hubs are field generators


QUICK SETUP
────────────────────────────────────────────────────────────────────────────
1. Import:
   import { HubInfluencePropagation } from './HubInfluencePropagation.js';

2. Initialize:
   const influence = new HubInfluencePropagation();

3. Update (in animation loop):
   influence.update(deltaTime, hubSystemData, nodeRegistry, linkRegistry);

4. Apply to visuals:
   // Links read: link.userData.influenceFields
   // Nodes read: node.userData.influenceFields


INFLUENCE ZONES
────────────────────────────────────────────────────────────────────────────
Zone 1 (Direct Influence)
  • Direct links connected to hub
  • Nodes one hop away
  • 60% of hub strength
  • Strong visual effect

Zone 2 (Secondary Reach)
  • Nodes reachable via one intermediate
  • Via one-hop nodes
  • 25% of hub strength
  • Very subtle visual effect
  • Suppressed if instability > 0.7


INFLUENCE STRENGTH FORMULA
────────────────────────────────────────────────────────────────────────────
strength = syncStrength
         × (harmony×0.5 + synergy×0.5)
         × (1 - corruption×0.3)
         × (1 - instability×0.4)
         × (0.7 + resilience×0.3)

Result: 0-1 scalar (hub's influence capacity)


ZONE ATTENUATION
────────────────────────────────────────────────────────────────────────────
Zone 1 Strength = hubStrength × 0.6   (60%)
Zone 2 Strength = hubStrength × 0.25  (25%)


VISUAL EFFECTS
────────────────────────────────────────────────────────────────────────────
Links (Zone 1):
  • Phase bias 15% toward hub
  • Reduced variance (coherent)
  • Streaks more aligned
  • Pulses synchronized

Links (Zone 2):
  • Phase bias 5% toward hub
  • Barely visible rhythm hint
  • No brightness changes

Nodes (Zone 1):
  • Secondary halo (0-0.15 intensity)
  • Pulse synchronized with hub
  • Gentle field glow

Nodes (Zone 2):
  • Glow hint (0-0.08 intensity)
  • No pulse, phase suggestion only
  • Extremely subtle


STATE MODULATION
────────────────────────────────────────────────────────────────────────────
Harmony         → Clarity + smoothness
Synergy         → Strength +20-50%
Corruption      → Intensity -30%, distortion
Instability     → Reach -40%, Zone 2 suppressed if high
Resilience      → Stabilization +30%

PERFORMANCE
────────────────────────────────────────────────────────────────────────────
Per-Hub:           ~0.5ms
Per-Frame Allocs:  0
Memory Per Hub:    ~200 bytes
Topology Cache:    Persistent (only invalidate on network change)

Scaling:
  10 hubs    → 5ms
  20 hubs    → 10ms
  50 hubs    → 25ms

Recommendation: Very efficient at all scales

TROUBLESHOOTING
────────────────────────────────────────────────────────────────────────────
No influence visible?
  • Check hub system data is provided
  • Verify network has links
  • Inspect node.userData.influenceFields

Influence too weak/strong?
  • Adjust ZONE_*_ATTENUATION constants
  • Modify state modulation weights

Performance issues?
  • Topology is cached (unlikely culprit)
  • Profile with getStats()
  • Check network size
