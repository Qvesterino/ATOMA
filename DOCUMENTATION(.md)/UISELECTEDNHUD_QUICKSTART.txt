📌 WHAT WAS FIXED
═══════════════════════════════════════════════════════════════════════════

HUD showed "LINKED: NONE" even when nodes had connections.

Root Cause:  Checked userData.type FIRST (wrong priority)
Solution:    Implemented proper priority chain (category → nodeType → type)
Status:      ✅ FIXED & PRODUCTION READY


🎯 THE FIX (3 LINES)
═══════════════════════════════════════════════════════════════════════════

Added method _getCategoryFromNode(node):

    const cat = 
        node.userData.category ||      // ← Check this FIRST!
        node.userData.nodeType ||      // Fallback 1
        node.userData.type ||          // Fallback 2
        node.userData.aiCategory ||    // Fallback 3
        'UNKNOWN';                     // Safety net
