## 🔄 Variant Distribution

Each category has **4 design variants**, automatically distributed based on node creation order:

```
Node 0 → Variant 0 (primary shape)
Node 1 → Variant 1 (secondary shape)
Node 2 → Variant 2 (tertiary shape)
Node 3 → Variant 3 (quaternary shape)
Node 4 → Variant 0 (cycle repeats)
...
```

This ensures visual variety while maintaining organization within each category.

## ⚙️ Animation Behaviors

### Primary Rotation
- **Axis:** Y-axis (vertical)
- **Speed:** 0.3 radians/frame
- **Purpose:** Gentle spinning indicating activity

### Secondary Rotations
- **Pattern:** Category-specific rotation axes
- **Speed:** 0.2 radians/frame per axis
- **Examples:**
  - Process nodes: Complex multi-axis rotation
  - Control nodes: Ring-specific independent rotation
  - Storage nodes: Vertical emphasis

### Pulsing Glow
- **Frequency:** 2 Hz sine wave
- **Intensity Range:** 0.15 - 0.35
- **Effect:** Breathing glow on all materials

### Floating Motion
- **Amplitude:** ±0.1 units
- **Frequency:** 0.5 Hz sine wave
- **Pattern:** Gentle up/down bobbing

## 💾 Technical Details

### Model Creation
```javascript
const node = EnhancedNodeModels.create(
  category,      // 'input', 'process', etc.
  variantIndex,  // 0-3, cycles through variants
  color          // Hex color (auto-selected by category)
);
```

### Animation System
```javascript
EnhancedNodeModels.animate(nodeGroup, deltaTime, time);
```

### Color System
```javascript
const color = EnhancedNodeModels.getCategoryColor('input');
// Returns: 0x00ddff (cyan)
```
