QUICK API

  getRenderOrder(layerId, fallback)     → Get renderOrder for layer
  getLayer(layerId)                     → Get full layer definition
  getOpacityBounds(layerId)             → Get { min, max } opacity
  clampOpacity(layerId, value)          → Clamp opacity to layer bounds
  compareOrder(layer1, layer2)          → Compare layer priority (-1, 0, 1)
  getAllLayers()                        → Get all layers sorted by renderOrder
  isValidRenderOrder(layerId, value)    → Verify renderOrder matches canonical
  printHierarchy(verbose)               → Print visual stack to console

3-STEP INTEGRATION

  1. IMPORT
     import { VisualHierarchyRegistry } from './VisualHierarchyRegistry.js';

  2. QUERY (when creating mesh)
     const ro = VisualHierarchyRegistry?.getRenderOrder('EVOLUTION', 50) ?? 50;
     mesh.renderOrder = ro;

  3. TAG (for debugging)
     mesh.userData.visualLayer = 'EVOLUTION';

COMMON PATTERNS

  PATTERN 1: Simple mesh in layer
    const mesh = new THREE.Mesh(geom, mat);
    mesh.renderOrder = VisualHierarchyRegistry?.getRenderOrder('FX', 100) ?? 100;
    mesh.userData.visualLayer = 'FX';

  PATTERN 2: With opacity constraint
    const bounds = VisualHierarchyRegistry.getOpacityBounds('AURA');
    mesh.material.opacity = VisualHierarchyRegistry.clampOpacity('AURA', 0.8);

  PATTERN 3: Batch of meshes
    const layer = VisualHierarchyRegistry.getLayer('EVOLUTION');
    meshes.forEach(m => {
      m.renderOrder = layer?.renderOrder ?? 50;
      m.userData.visualLayer = layer?.id ?? 'EVOLUTION';
    });

🔴 COMMON MISTAKES

  ✗ Forgetting fallback:
    mesh.renderOrder = VisualHierarchyRegistry.getRenderOrder('FX')  // ← CRASH

  ✓ With fallback:
    mesh.renderOrder = VisualHierarchyRegistry?.getRenderOrder('FX', 100) ?? 100

  ✗ Querying but not using:
    VisualHierarchyRegistry.getRenderOrder('FX', 100);
    mesh.renderOrder = 100;  // ← Still hardcoded!

  ✓ Using query result:
    mesh.renderOrder = VisualHierarchyRegistry?.getRenderOrder('FX', 100) ?? 100;

  ✗ Wrong layer name:
    VisualHierarchyRegistry.getRenderOrder('EXTREME', 50)  // ← Unknown layer

  ✓ Correct layer:
    VisualHierarchyRegistry.getRenderOrder('EVOLUTION', 50)  // ← Valid
