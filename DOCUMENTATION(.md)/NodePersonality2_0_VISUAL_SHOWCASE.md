### 1. THE PULSAR 🌊 (Integration / Solar)

**Visual Signature:** Rhythmic breathing glow

```
Animation Cycle:
  T=0.0s: Glow = 0.6 (Min)      ◯ (dim)
  T=0.4s: Glow = 0.75           ◯• (brightening)
  T=0.8s: Glow = 0.9            ◉ (bright)
  T=1.2s: Glow = 0.75           ◯• (dimming)
  T=1.5s: Glow = 0.6 (Min)      ◯ (dim)
  [Repeat]

Intensity Level Effects:
  Level 1 (Subtle):   Min=0.6, Max=0.8, Speed=1.5s/breath
  Level 2 (Normal):   Min=0.55, Max=0.95, Speed=1.5s/breath
  Level 3 (Rare):     Min=0.5, Max=1.0, Speed=1.2s/breath
  Level 4 (Ascended): Min=0.4, Max=1.1, Speed=1.0s/breath
```

**Visual Effect Description:**
- Core glow pulsates like a beating heart or stellar pulse
- Smooth, periodic intensity modulation
- Creates organic, alive appearance
- Synchronizes all connected nodes if linked

**Best For:** Integration nodes, solar-themed nodes, rhythm-focused designs

```

  Emissive Base: 1.0

Rotation Complexity:
  ┌─────────────────┐

  │   ╱───╲       │
  │  │     │      │
  │   ╲───╱       │
  │     ↺ ↺ ↺     │
  └─────────────────┘
  
Intensity Level Effects:
  Level 1: Slow rotation, subtle flicker
  Level 2: Medium rotation, clear flicker
  Level 3: Fast rotation, intense flicker + glow
  Level 4: Very fast rotation, maximum flicker + aura
```

**Visual Effect Description:**
- Inner core spins smoothly in multiple axes
- Creates hypnotic, analytical appearance
- Emissive intensity pulses with data-like rhythm
- Communicates processing/calculation

**Best For:** Analytics nodes, processing nodes, computation-focused designs

### 7. THE QUANTUM FLICKER ⚡ (Quantum)

**Visual Signature:** Micro jitter (< 0.5%) + frame-displacement shimmer

```
Jitter Pattern (Stored in userData, not applied to position):
  X-jitter = sin(time * 10Hz) * 0.003
  Y-jitter = sin(time * 10Hz * 0.7) * 0.003
  Z-jitter = sin(time * 10Hz * 0.5) * 0.003
  
Jitter Visualization:
  ◉  (position before)
  │\
  │ ◯ (position with jitter applied)
  │ │ 
  │ └─ Offset: < 0.5% (barely perceptible)
  │
  Next frame: New jitter direction

Shimmer Effect:
  Glow = base * (1.0 + sin(time * 2π / 2.0s) * 0.3)
  
Shimmer Timeline:
  T=0.0s: Glow normal (1.0x)
  T=0.5s: Glow peak (1.3x)
  T=1.0s: Glow normal (1.0x)
  T=1.5s: Glow dip (0.7x)
  T=2.0s: Glow normal (1.0x) - repeat
  
Ghost Frame Effect:
  Frame N:   Alpha = 1.0 (full)     ◉
  Frame N+1: Alpha = 0.3 (ghosted)  ◎ (30% opacity previous frame)
             + New frame = 1.0       ◉
  Result: Slight motion trail effect
  
Intensity Level Effects:
  Level 1: Minimal jitter, subtle shimmer
  Level 2: Noticeable jitter, clear shimmer
  Level 3: Pronounced jitter, intense shimmer + trails
  Level 4: Intense jitter, maximum shimmer + visible ghosting
```

**Visual Effect Description:**
- Ultra-fast micro-oscillations (10 Hz, barely perceptible)
- Creates "quantum uncertainty" visual effect
- Glow shimmers smoothly every 2 seconds
- Creates unsettling, probabilistic appearance

**Best For:** Quantum nodes, uncertainty-focused designs, superposition effects
