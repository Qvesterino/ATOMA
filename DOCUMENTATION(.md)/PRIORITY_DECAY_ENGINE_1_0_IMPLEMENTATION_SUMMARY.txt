HOW IT WORKS
============

PRIORITY EVOLUTION FLOW:
━━━━━━━━━━━━━━━━━━━━━━━

Link Created
    ↓
Engine tracks: { smoothedScore, lastTraffic, lastActiveAt }
    ↓
Every 500ms: tick() called
    ↓
For each link:
    • Get traffic activity (0-1)
    • If active (>0.1): boost score += 0.06 × activity
    • If idle (>3s):     decay score -= 0.03
    • Smooth with lerp
    • Add jitter
    • Clamp [0.05, 1.0]
    ↓
Convert score → tier (0-3)
    ↓
Write to link.priority.score + link.priority.tier
    ↓
NeonLinkVisuals reads tier → adjusts VFX
    ↓
UISelectedHUD displays updated priority
    ↓
Next frame: visual effects rendered ✓


TIER SYSTEM:
━━━━━━━━━━━

Score >= 0.85  →  Tier 3 (CRITICAL)
   Visual: Thickest, brightest glow, fastest pulse

Score >= 0.60  →  Tier 2 (HIGH)
   Visual: Thick, bright glow, fast pulse

Score >= 0.25  →  Tier 1 (NORMAL)
   Visual: Normal thickness/glow/pulse

Score <  0.25  →  Tier 0 (LOW)
   Visual: Thinnest, dimmest glow, slow pulse


CONFIGURATION PARAMETERS:
━━━━━━━━━━━━━━━━━━━━━━━

tickIntervalMs: 500
   How often engine updates (milliseconds)
   500ms = 2 updates per second
   Recommendation: 500ms for smooth updates

idleDelayMs: 3000
   Time before marking link as idle (milliseconds)
   3000ms = 3 seconds
   After this time: decay starts

baseDecayRate: 0.03
   Decay rate per tick (3% per 500ms)
   Accelerates based on idle duration
   decayFactor = 1 + (timeSinceActive / 10000)

boostRate: 0.06
   Boost rate when traffic detected (6% per tick)
   Only applied when activity > 0.1

stabilizeAlpha: 0.15
   Lerp smoothing factor (15% per update)
   Higher = faster response, more jitter
   Lower = smoother transitions

jitterAmount: 0.01
   Random variation amplitude (±1%)
   Adds natural feel to score changes

INSTALLATION
=============

FILE: PriorityDecayEngine1_0.js (602 lines)

LOCATION: Root directory (same as NodeLinkingSystem.js)

STEP 1: IMPORT
──────────────
In main.js, add:

    import { PriorityDecayEngine1_0 } from './PriorityDecayEngine1_0.js';


STEP 2: INITIALIZE
──────────────────
After linkingSystem is created, add:

    window.game = window.game || {};
    window.game.priorityDecayEngine = new PriorityDecayEngine1_0(
      window.game.linkingSystem,
      window.game.metricsSystem || null,
      {
        enabled: true,
        tickIntervalMs: 500,
        idleDelayMs: 3000,
        baseDecayRate: 0.03,
        boostRate: 0.06,
      }
    );

    console.log('[ATOMA] Priority Decay Engine 1.0 initialized');


STEP 3: CALL IN ANIMATION LOOP
───────────────────────────────
In your animate() function, add:

    function animate(now) {
      const deltaMs = now - lastFrameTime;
      lastFrameTime = now;

      // Add this line BEFORE rendering:
      if (window.game.priorityDecayEngine) {
        window.game.priorityDecayEngine.tick(deltaMs);
      }

      // ... rest of render loop
      renderer.render(scene, camera);
    }

TIMING: Call tick() BEFORE rendering so changes are visible immediately.


STEP 4: VERIFY
──────────────
In browser console:

    window.game.priorityDecayEngine.status()

Expected output should show:
  - enabled: true
  - updatedLinks: (number > 0)
  - errors: 0

If yes → ✓ ENGINE IS WORKING!
