HOW IT WORKS
================================================================================

Simple concept: Linear interpolation of multipliers over time

When LowFX toggles:
  1. Capture current multipliers (startValues)
  2. Read target multipliers (endValues)
  3. Initialize: progress = 0, duration = 0.6s

Each frame:
  4. progress += deltaTime / duration
  5. For each multiplier:
     multiplier = start * (1-t) + end * t
  6. When progress >= 1.0: done

Result: Smooth fade from start to end

Example (Clarity: 1.0 → 0.4):
  Frame 0:   1.0   (full)
  Frame 10:  0.84  (fading)
  Frame 20:  0.67  (halfway)
  Frame 30:  0.51  (almost done)
  Frame 37:  0.40  (complete)

================================================================================
INTERPOLATION FORMULA
================================================================================

Linear interpolation (smooth, predictable):

  interpolated = start * (1 - t) + end * t

  where:
    start = multiplier at transition start
    end   = target multiplier
    t     = progress (0.0 → 1.0)
    progress = elapsedTime / duration

Example (clarity: 1.0 → 0.4, t=0.5):
  interpolated = 1.0 * 0.5 + 0.4 * 0.5
  interpolated = 0.5 + 0.2
  interpolated = 0.7  (halfway point)

All 7 multipliers use identical formula, so all fade together.
