LinkCorruptionMorphingSystem — Quick Reference Card
================================================================================

OVERVIEW
────────────────────────────────────────────────────────────────────────────
Dynamic link morphing based on corruption flow state. Links visually degrade
through five phases as corruption spreads through the network.

Five Phases: Healthy → Stressed → Infected → Degraded → Collapsed


INSTALLATION
────────────────────────────────────────────────────────────────────────────
1. Copy files:
   - LinkCorruptionMorphingSystem.js
   - LINK_MORPHING_*.md (documentation)
   - LINK_MORPHING_EXAMPLES.js (patterns)

2. Import in main.js:
   import { LinkCorruptionMorphingSystem } from './LinkCorruptionMorphingSystem.js';

3. Initialize:
   const morphingSystem = new LinkCorruptionMorphingSystem();

4. Add to animation loop:
   morphingSystem.update(deltaTime, linkRegistry);


MORPHING PHASES
────────────────────────────────────────────────────────────────────────────
Healthy     (0.0-0.2)  → Clean blue, subtle ripples, organized
Stressed    (0.2-0.45) → Orange warning, desaturated, tighter braids
Infected    (0.45-0.65)→ Amber corruption, fraying, dark pulses
Degraded    (0.65-0.85)→ Red corruption, severe warping, chaotic
Collapsed   (0.85-1.0) → Dark red, complete breakdown, max chaos


TRANSFORMATION PIPELINES
────────────────────────────────────────────────────────────────────────────
Braid Morphing    → Geometry compression (1.0 → 0.2)
Color Morphing    → Saturation + hue shift (blue → red)
Emission Morphing → Intensity + pulsing (0.3 → 1.0)
Ripple Morphing   → Chaos + coherence (smooth → chaotic)
Particle Morphing → Density scaling (0.1 → 1.0)
Deformation Morphing → Geometric warping (0.0 → 0.15)


API REFERENCE
────────────────────────────────────────────────────────────────────────────
Constructor:
  new LinkCorruptionMorphingSystem()

Methods:
  update(deltaTime, linkRegistry)
    Main frame update. Call once per frame.

  initializeLinkState(linkId, link)
    Initialize morphing state for a new link.

  getPhaseNameForLink(linkId)
    Returns: "Healthy", "Stressed", "Infected", "Degraded", or "Collapsed"

  getCorruptionForLink(linkId)
    Returns: 0-1 corruption value

  getDebugInfoForLink(linkId)
    Returns: debug object with all state info

  getStats()
    Returns: { morphedLinkCount, trackedLinkCount, morphingSpeed }

  setMorphingSpeed(speed)
    Set morphing speed (default: 2.0). Higher = faster response.

  dispose()
    Cleanup. Clear all state.


CONSOLE API
────────────────────────────────────────────────────────────────────────────
window.linkMorphingSystem.getStats()

window.linkMorphingSystem.getDebugInfoForLink('link_0')
  Get detailed info for specific link

window.linkMorphingSystem.getPhaseNameForLink('link_0')
  Get phase name

window.linkMorphingSystem.getCorruptionForLink('link_0')
  Get corruption value

window.linkMorphingSystem.setMorphingSpeed(3.0)
  Adjust morphing speed (1.0 = slow, 5.0 = fast)


PERFORMANCE
────────────────────────────────────────────────────────────────────────────
Per-Link Overhead:  ~0.5ms
Memory Per-Link:    ~200 bytes
Per-Frame Allocs:   0 (fully cached)

Scaling:
  10 links   → 5ms
  30 links   → 15ms
  50 links   → 25ms
  100 links  → 50ms

Recommendation: 30-50 links for smooth 60 FPS


CUSTOMIZATION
────────────────────────────────────────────────────────────────────────────
Adjust Phase Profiles:
  Edit PHASE_PROFILES in LinkCorruptionMorphingSystem.js
  Each phase has properties: braid_tightness, color_saturation, etc.

Adjust Color Palette:
  Edit COLOR_TRANSITIONS
  Map phase names to RGB values

Adjust Morphing Speed:
  linkMorphingSystem.setMorphingSpeed(3.0)

Extend Transformations:
  Subclass LinkCorruptionMorphingSystem and override applyMorphing()

         ↓

         ↓

TROUBLESHOOTING
────────────────────────────────────────────────────────────────────────────
Links not morphing?
  • Check corruption values: linkMorphingSystem.getDebugInfoForLink(id)
  • Verify linkRegistry is passed to update()
  • Enable debug HUD (see examples)

Morphing too slow/fast?
  • Adjust speed: linkMorphingSystem.setMorphingSpeed(value)
  • Default: 2.0, Higher = faster

Performance issues?
  • Reduce morphing speed
  • Enable frustum culling
  • Monitor getStats()

Colors not changing?
  • Verify link materials have emissive color
  • Set material.needsUpdate = true if needed
