## 🎯 Key Design Decisions

### Architecture
- **Pure TypeScript** - Full type safety, no `any`
- **Framework Agnostic** - Works with vanilla or React
- **Modular** - Independent from other systems
- **Event-Driven** - Callbacks for loose coupling

### Implementation
- **Deterministic** - Reproducible except quantum
- **Cached** - Automatic pair/path caching
- **Efficient** - Optimized for 100+ links
- **Extensible** - Easy to add layer pairs

### API Design
- **Simple** - 13 core methods only
- **Composable** - Can chain operations
- **Queryable** - Rich analysis methods
- **Debuggable** - Detailed explanation strings

### Performance
- **Target <5%** - FPS impact target
- **Lazy Eval** - Only compute what's needed
- **Aggressive Cache** - Pair + path caches
- **Efficient Lookup** - Map-based compatibility
