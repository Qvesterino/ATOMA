THE 7 GPU UNIFORMS
================================================================================

Material uniforms automatically created:

uArchetypePrimaryColor       Main archetype color (RGB vec3)
uArchetypeSecondaryColor     Transition color (RGB vec3)
uArchetypeAccentColor        Highlight color (RGB vec3)
uArchetypeColorBlend         Blend 0–1 (primary→secondary)
uArchetypeWarmShift          -1 to +1 (cool to warm)
uArchetypeSaturation         0–2 (desaturated to super-vibrant)
uArchetypeAscensionGlow      0–1 (glow from ascension)

These are injected via material.onBeforeCompile (safe, non-invasive)

================================================================================
COMMON ISSUES & FIXES
================================================================================

Issue: Colors not showing
Fix:   1. Check archetypeCurves.update() called BEFORE archetypeColorFX.update()
       2. Verify archetype evolution exists on node
       3. Enable debugEnabled: true

Issue: Colors too subtle
Fix:   Colors increase with ascension. To see more:
       - Wait for nodes to reach higher ascension levels
       - Check saturation values (should be 0.8–2.0)

Issue: Warm shift not visible
Fix:   Warm shift (-1 to +1) is subtle. Visible through:
       - Corruption signal → red tint (Warlock)
       - Clarity signal → cyan tint (Sage)

Issue: Performance is slow
Fix:   Check DevTools - should be <0.6ms per 200 nodes

Issue: Colors aren't smooth
Fix:   EMA alpha = 0.15. If transitions too slow:
       - Lower alpha (faster, choppier)
       - Higher alpha (slower, smoother)
