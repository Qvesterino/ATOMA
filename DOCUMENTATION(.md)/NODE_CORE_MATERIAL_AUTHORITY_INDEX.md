## 🎓 Key Concepts

### Material Profiles
Three canonical profiles ensure consistency:
- **Holographic**: Additive blending, 0.95 opacity (default)
- **Solid**: Normal blending, 1.0 opacity (physics-based)
- **Mythic**: Additive blending, 0.98 opacity (legendary)

See [Complete Guide - Material Profiles](#complete-guide)

---

### Event-Driven Design
Authority executes only on:
- Node spawn (register core)
- Link creation (re-assert core)
- Evolution (optional re-assertion)
- Events (optional protection)

**Never** per-frame — zero animation loop overhead.

See [Technical Reference - Event Flow](#technical-reference)

---

### Opacity Dominance
4:1 ratio enforced:
- Core: 0.95 (95% opaque)
- Aura: ≤ 0.25 (25% opaque)

Prevents aura from visually overpowering core.

See [Complete Guide - Opacity Clamping](#complete-guide)

---

### Silent Failure Handling
System never crashes:
- Incompatible nodes: skipped
- Missing cores: graceful skip
- Material errors: caught
- Edge cases: handled

Perfect for production environments.

See [Technical Reference - Error Handling](#technical-reference)

## ❓ Frequently Asked Questions

### Q: What changed from Session 25?
**A**: Session 25 used invisible depth anchor meshes. Session 26 uses material-level control (blend mode + opacity). More reliable for holographic cores.

See [Session Summary - Problem Analysis](#session-summary)

---

### Q: Do I need to modify my code?
**A**: Main.js is already modified. For custom auras/evolution/events, optionally integrate using documented APIs.

See [Complete Guide - Integration Points](#complete-guide)

---

### Q: What's the performance impact?
**A**: Zero per-frame overhead. Event-driven only (~0.1ms per spawn, ~0.05ms per link).

See [Technical Reference - Performance](#technical-reference)

---

### Q: Is it backward compatible?
**A**: Yes, 100%. No breaking changes. Silent failures if nodes lack core.

See [Complete Guide - Guarantees](#complete-guide)

---

### Q: How do I debug issues?
**A**: Use console API: `window.debugCoreAuthority.checkNode(node)`

See [Quick Reference - Console Debugging](#quick-reference)

---

### Q: What are the guarantees?
**A**: Core never overridden, aura never dominant, zero per-frame overhead, 100% backward compatible.
