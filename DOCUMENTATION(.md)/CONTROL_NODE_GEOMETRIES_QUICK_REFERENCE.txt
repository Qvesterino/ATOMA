THREE NEW CONTROL MESHES — AUTHORITY IN FORM
────────────────────────────────────────────────────────────────────────────

1. JUDGMENT SEAL
   └─ Thick circular ring + floating inner sphere
   └─ Intent: Final decision, locked, sealed, non-negotiable
   └─ Specs: 1344 vertices, ~2700 triangles
   └─ Materials: High metalness (0.85), polished (roughness 0.15)
   └─ Use: Finalized states, irreversible decisions, absolute locks

2. SIGNAL CITADEL
   └─ Compact core + 4-6 defensive towers
   └─ Intent: Control as defense, protective, fortified
   └─ Specs: 144 vertices, ~288 triangles
   └─ Materials: Strong metalness (0.7), worn (roughness 0.25)
   └─ Use: Access control, boundaries, defense barriers, rate limits

3. LAW CORE
   └─ Single monolithic cube, absolutely minimal
   └─ Intent: Law itself, inevitable, immovable, absolute
   └─ Specs: 8 vertices, 12 triangles (lowest polycount)
   └─ Materials: Extreme metalness (0.9), precise (roughness 0.1)
   └─ Use: Constants, rules, invariants, truths, core values

================================================================================
                          SPAWN CYCLE
================================================================================

When you spawn Control nodes sequentially:

Node 1: createControlNode0()        (OctagonalCore+Rim)
Node 2: createControlNode2()        (ControlRingLattice)
Node 3: createControlNode1()        (SpikedControlFrame)
Node 4: createJudgmentSealNode()    (JudgmentSeal)  ← NEW
Node 5: createSignalCitadelNode()   (SignalCitadel) ← NEW
Node 6: createLawCoreNode()         (LawCore)       ← NEW
Node 7: createExtremeControl0()     (InfiniteSpiral)
Node 8: createExtremeControl1()     (ChronoRipper)

Node 9: Back to createControlNode0() (cycle repeats)

The spawn cycle uses modulo indexing:
  variantIndex = index % 8
