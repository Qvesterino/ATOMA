## 🎓 Console API Reference

### 14 Console Commands

```javascript
// Frame tracking
window.frameUpdateValidator.startFrame()
window.frameUpdateValidator.markUpdate('SystemName', timeMs)
window.frameUpdateValidator.endFrame(deltaTime)

// Reporting
window.frameUpdateValidator.printReport()          // Frame report
window.frameUpdateValidator.printPerformance()     // System analysis

// Validation
window.frameUpdateValidator.isValid()              // Boolean
window.frameUpdateValidator.getViolations()        // Frame violations
window.frameUpdateValidator.getAllViolations()     // All violations

// Analysis
window.frameUpdateValidator.getStats()             // Frame stats
window.frameUpdateValidator.getPerformance()       // Timeline
window.frameUpdateValidator.getHistory(count)      // Frame history

// Debugging
window.frameUpdateValidator.enableDebug()
window.frameUpdateValidator.disableDebug()
window.frameUpdateValidator.exportData()           // JSON export
```
