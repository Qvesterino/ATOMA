IMPLEMENTATION OVERVIEW
================================================================================

Healing Contention enables networks competing for the same healing resources
to experience efficiency penalties when their healing efforts overlap.

Healing is never denied — it only becomes less efficient under contention.

KEY PRINCIPLE: Contention, not conflict. Cooperation yields better outcomes.

CORE MECHANICS
================================================================================

HEALING CONTENTION FORMULA:
  efficiency = 1 / (1 + 0.10 × (contenders - 1))
  
  Hard floor: MIN_EFFICIENCY = 0.60 (60% minimum)

EFFICIENCY EXAMPLES (with 0.10 factor):
  1 network: 100% efficiency
  2 networks: 90.9% efficiency
  3 networks: 83.3% efficiency
  4 networks: 76.9% efficiency
  5 networks: 71.4% efficiency
  10+ networks: 60% efficiency (hard clamped)

SPATIAL OVERLAP:
  Same link/region = contention
  Future: Can extend to N-hop topological distance

TEMPORAL OVERLAP:
  Within 350ms = simultaneous (tunable via TEMPORAL_WINDOW_MS)
  Outside 350ms = independent heals

MIN CONTENDERS:
  Need 2+ networks to trigger contention (1 network always 100%)

================================================================================
SPATIAL + TEMPORAL OVERLAP DEFINITION
================================================================================

TEMPORAL WINDOW: 350ms
  - Healing events within 350ms of each other count as overlapping
  - Auto-cleanup: events expire after 2× window (700ms max retention)
  - Reversible: separate heals stop contending immediately after window

SPATIAL RANGE: Same region (extensible to 2 hops)
  - Current: Same link ID = same region
  - Future: Could extend to adjacent links/zones
  - Prevents global contention (only local regions affected)

COMBINED DETECTION:
  Contention detected when:
    1. 2+ networks healing
    2. In same spatial region (link/zone)
    3. Within 350ms temporal window

  Result: All overlapping heals apply symmetric penalty

================================================================================
EXACT CONTENTION FORMULA & CAPS
================================================================================

FORMULA (Primary):
  effectiveHealing = baseHealing × (1 / (1 + FACTOR × (contenders - 1)))

  Where:
    - baseHealing = intended healing amount (input)
    - contenders = count of networks healing simultaneously
    - FACTOR = 0.10 (10% efficiency loss per additional network)

HARD MINIMUM (Safety Floor):
  effectiveHealing = max(effectiveHealing, baseHealing × 0.60)
  
  Healing never drops below 60% efficiency
  Healing is never denied, only reduced

TEMPORAL DECAY:
  Events auto-expire after 350ms
  recentHealingEvents automatically cleaned (circular buffer)
  No accumulation, no memory

SPATIAL LIMITS:
  Contention limited to same region (SPATIAL_RANGE_HOPS = 2)
  Distant networks never contend

================================================================================
INTEGRATION POINT
================================================================================

ENTRY POINT: recordHealingEvent()

When healing is calculated, call:

  const result = linkCorruptionTransmission.recordHealingEvent({
    networkId: network.id,          // Network performing heal
    link: linkBeingHealed,          // Link object
    amount: intendedHealingAmount,  // Base healing amount
    regionId: linkBeingHealed.id    // Region (optional)
  });

  // Use effective amount (includes penalty)
  const effectiveHealing = result.effectiveAmount;
  
  // Apply to link
  link.corruption = Math.max(0, link.corruption - effectiveHealing);

RETURN VALUE:
  {
    eventId: string,                // Unique event ID
    effectiveAmount: number,        // Healing after contention
    contentionMultiplier: number,   // 0.60-1.0
    contendersCount: number         // How many networks overlapping
  }

EFFECT: Healing automatically penalized if contested, no further action needed.
