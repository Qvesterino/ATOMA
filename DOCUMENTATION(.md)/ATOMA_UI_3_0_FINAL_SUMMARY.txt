NEW UI SYSTEMS
================================================================================

1. TOP STATUS BAR (UIWorldStatusBar)
   Location: Fixed to top edge of screen
   Display: ATOMA | World | Seed | FPS | Nodes | Links | Network Mood
   Update: Real-time (FPS every 0.5s)
   Performance: <0.02ms/frame

2. LEFT NODE INSPECT PANEL (UINodeInspectPanel)
   Location: Fixed top-left quadrant
   Trigger: Left-click on node
   Display: Archetype code, meaning, tags, 6 metrics, poetry
   Close: ESC, click outside, select different node
   Performance: <0.05ms on change

3. BOTTOM-RIGHT HUD (UIHudManager)
   Location: Fixed bottom-right corner
   Modes: COMPACT (default) / FULL (TAB toggle)
   COMPACT: Synergy, Harmony, Instability, Corruption, Load, Cycle, Score, Aeon
   FULL: All above + Node Distribution table (16 categories)
   Update: Throttled every 0.5s
   Performance: <0.08ms/frame

4. RIGHT-CLICK NODE MENU (UINodeContextMenu)
   Location: Near cursor (clamped to viewport)
   Trigger: Right-click on node
   Options:
      - INSPECT NODE (open panel)
      - FOCUS CAMERA (smooth 1s lerp)
      - LINK MODE (enter linking)
      - DISCONNECT LINKS (safe removal)
      - MARK NODE (10s pulsing highlight)
   Performance: <0.02ms/frame

5. HELP TEXT (UIHelpText)
   Location: Fixed bottom-center
   Display: Control hints (WASD, Mouse, Space, LMB, RMB, TAB, ESC)
   Update: Static
   Performance: <0.001ms/frame

TOTAL PERFORMANCE: <0.3ms/frame (well under budget)

KEY INTERACTIONS
================================================================================

LEFT-CLICK NODE
  → Node Inspect Panel opens (left side)
  → Shows archetype, metrics, poetry
  → Stays open until ESC, different node, or click outside

RIGHT-CLICK NODE
  → Context Menu appears (near cursor)
  → 5 actions available
  → ESC or click outside to close

TAB KEY
  → Toggle HUD Compact / Full mode
  → Smooth 0.3s animation
  → Preserves current metrics

ESC KEY
  → Close all panels
  → Close context menu
  → Clear selections

FOCUS CAMERA (from menu)
  → 1-second smooth lerp to node
  → Camera positioned 5 units above/behind node
  → Non-jarring ease-out cubic animation

MARK NODE (from menu)
  → 10-second pulsing highlight glow
  → Highlights visualized on node's existing vfxGlow element
  → Auto-removes after duration

INTEGRATION INSTRUCTIONS
================================================================================

1. ADD IMPORTS (top of main.js)
   import { UIWorldStatusBar } from './UIWorldStatusBar.js';
   import { UINodeInspectPanel } from './UINodeInspectPanel.js';
   import { UIHudManager } from './UIHudManager.js';
   import { UINodeContextMenu } from './UINodeContextMenu.js';
   import { UIHelpText } from './UIHelpText.js';

2. INITIALIZE IN CONSTRUCTOR
   this.ui = {
     statusBar: new UIWorldStatusBar(),
     nodePanel: new UINodeInspectPanel(this.languageEngine, this.poetryEngine),
     hud: new UIHudManager(this.aiNodes),
     helpText: new UIHelpText()
   };
   this.ui.contextMenu = new UINodeContextMenu(
     this.scene, this.camera, this.linkingSystem, this.ui.nodePanel
   );

3. ADD EVENT HANDLERS
   - Left-click: nodePanel.show(node)
   - Right-click: contextMenu.open(node, screenPos)
   - ESC: nodePanel.hide() + contextMenu.close()
   - TAB: Built into UIHudManager (no handler needed)

4. ADD UPDATE CALLS (in animate loop)
   this.ui.statusBar.update(deltaTime, { worldName, seed, fps, nodes, links, mood });
   this.ui.hud.update(deltaTime, { synergy, harmony, instability, corruption, load, ... });
   this.ui.contextMenu.update(deltaTime);  // For camera focus animation

5. ADD CLEANUP (in dispose)
   this.ui.statusBar.dispose();
   this.ui.nodePanel.dispose();
   this.ui.hud.dispose();
   this.ui.contextMenu.dispose();
   this.ui.helpText.dispose();

ESTIMATED INTEGRATION TIME: 15–30 minutes
