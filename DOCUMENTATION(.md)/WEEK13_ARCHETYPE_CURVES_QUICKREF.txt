SUMMARY
-------
Week 13 adds personality-driven ascension curves. Each archetype has a unique
non-linear curve that modifies base ascension from MythicEvolutionFX_v1.

Output: node.userData.archetypeEvolution.ascensionMultiplier (used by weeks 14–16)

================================================================================
1. INTEGRATION (3 EASY STEPS)
================================================================================

STEP 1: IMPORT
-----------
import { ArchetypeAscensionCurves_v1 } from './ArchetypeAscensionCurves_v1.js';

STEP 2: CONSTRUCTOR (in game init)
--------------------------------
this.archetypeCurves = new ArchetypeAscensionCurves_v1({
  mythicEvolutionFX: this.mythicEvolutionFX,
  aiNodes: this.aiNodes.nodes,
  personalitySignals: this.nodePersonality,
  debugEnabled: false,
  autoAssignArchetypes: false,  // true = auto-assign based on signals
});

STEP 3: UPDATE LOOP (after MythicEvolutionFX_v1.update)
-----------------------------------------------------
this.mythicEvolutionFX.update(deltaTime);
this.archetypeCurves.update(deltaTime);  // NEW

CLEANUP:
--------
this.archetypeCurves.dispose();

MYTHIC — Transcendent

5. OUTPUT STRUCTURE

  archetypeId,           // "sage", "warlock", "sentinel", "empath", "invoker", "mythic"
  archetypeName,         // "Sage", "Warlock", ...

  curveRaw,              // Raw curve value
  curveSmoothed,         // After hysteresis
  personalityInfluence,  // 0–1 (how much personality bent curve)
  tierBoost,             // 1.0–2.0+ (tier multiplier)
  nextTierProgress,      // 0–1 (progress to next tier)
  lastUpdateTime,        // Timestamp
}

================================================================================
6. HOW CURVES WORK (MATH SUMMARY)
================================================================================

Step 1: Read base ascension from Week 11
  baseAsc = node.userData.mythicEvolution.ascensionSmoothed

Step 2: Apply curve based on archetype
  curveRaw = evaluate_curve(baseAsc, archetype.curveType)
  
  Examples:
    sage: logistic(0.5) ≈ 0.50
    warlock exponential(0.8) ≈ 0.87 (spike!)
    sentinel: linear(0.5) = 0.5
    empath: sigmoid(0.5) ≈ 0.50
    invoker: easeInOut(0.5) = 1.0 (peak!)

Step 3: Apply personality influence (0–1)
  influence = avg(clarity, harmony, ...) * (1 + corruption_sensitivity * corruption)

Step 4: Modulate curve by personality
  curveModulated = curveRaw * (0.5 + influence)
  → Low personality: curve * 0.5 (dampened)
  → High personality: curve * 1.5 (amplified)

Step 5: Apply hysteresis smoothing
  if |change| < threshold:
    curveSmoothed = lastValue
  else:
    curveSmoothed = lastValue * 0.85 + curveModulated * 0.15

Step 6: Compute tier boost (1.0–2.0)
  tierBoost = [1.0, 1.2, 1.4, 1.7, 2.0][tier]

Step 7: Final multiplier
  mult = baseMultiplier + curveSmoothed * (peakMultiplier - baseMultiplier)
  finalMult = mult * tierBoost
  → Written to node.userData.archetypeEvolution.ascensionMultiplier

================================================================================
7. PERFORMANCE BUDGET
================================================================================

Per-node cost: ~0.002ms
Per-frame (200 nodes): ~0.4ms
Per-frame (500 nodes): ~1.0ms

All curves are O(1) — no loops, lightweight math
EMA smoothing is single alpha factor (0.15)
Hysteresis prevents oscillation without complex state

12. COMMON ERRORS & FIXES
================================================================================

ERROR: "Cannot read property 'ascensionSmoothed' of undefined"
FIX:   Call this.mythicEvolutionFX.update() BEFORE archetypeCurves.update()

ERROR: "archetypeCurves.update is not a function"
FIX:   Make sure you called 'new ArchetypeAscensionCurves_v1(...)' in constructor

ERROR: "Unknown archetype: xyz"
FIX:   Use only: 'sage', 'warlock', 'sentinel', 'empath', 'invoker', 'mythic'

ERROR: undefined getNodeState() result
FIX:   Node might not have userData initialized yet. Add null check:
       const state = node?.userData?.archetypeEvolution;
