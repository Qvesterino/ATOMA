WHAT IT DOES
────────────────────────────────────────────────────────────────────────────

Validates node categories when spawning:
  • SAFE categories → spawn normally
  • UNSAFE categories → spawn as 'input' + warning
  • DEPRECATED categories → redirect to new name + info
  • UNKNOWN categories → spawn as 'input' + helpful message


SAFE CATEGORIES (ALWAYS SAFE TO SPAWN)
────────────────────────────────────────────────────────────────────────────

✅ 'input'        → Cyan triangular prism
✅ 'process'      → Amber/gold cubes
✅ 'integration'  → Green dual-sphere
✅ 'analytics'    → Violet octahedron
✅ 'storage'      → Silver pillars
✅ 'control'      → Red/magenta octagon
✅ 'quantum'      → Bright green anomaly


DO NOT SPAWN (WILL FALLBACK TO INPUT)
────────────────────────────────────────────────────────────────────────────

❌ 'mythic'       → No geometry (missing: createMythicNode())
❌ 'prime'        → No geometry (missing: createPrimeNode())
❌ 'error'        → No geometry (missing: createErrorNode())
❌ 'emotional'    → No geometry (missing: createEmotionalNode())

Attempting to spawn these will:
  1. Log warning to console
  2. Spawn as 'input' node (safe fallback)
  3. Store validation details in node.userData


DEPRECATED (WILL REDIRECT)
────────────────────────────────────────────────────────────────────────────

⚠️  'sigma'       → Redirects to 'quantum'
    - Still works (old code compatible)
    - Console info: "Redirecting to quantum"
    - Use 'quantum' directly in new code


================================================================================
                          HOW IT WORKS
================================================================================

SPAWN SAFE CATEGORY
  const node = aiNodes.createNode('control', position);
  ✅ Spawns normally with full geometry
  ✅ No console output
  ✅ category = 'control'

SPAWN UNSAFE CATEGORY
  const node = aiNodes.createNode('mythic', position);
  ⚠️ Console warning: "Category 'mythic' is NOT implemented"
  ✅ Spawns as 'input' (safe fallback)
  ✅ category = 'input'
  ✅ requestedCategory = 'mythic'

SPAWN DEPRECATED CATEGORY
  const node = aiNodes.createNode('sigma', position);
  ℹ️ Console info: "Redirecting to 'quantum'"
  ✅ Spawns as 'quantum'
  ✅ category = 'quantum'

SPAWN UNKNOWN CATEGORY
  const node = aiNodes.createNode('foobar', position);
  ⚠️ Console warning: "Unknown category 'foobar'"
  ✅ Spawns as 'input'
  ✅ Lists valid categories in message


================================================================================
                        NODE DATA ACCESS
================================================================================

After spawning, check validation in node.userData:

  node.userData.category           ← Final category used
  node.userData.requestedCategory  ← What user requested
  node.userData.categoryValidation ← Full validation result
  
  // Example:
  if (!node.userData.categoryValidation.valid) {
    console.log('Used fallback:', node.userData.category);
  }

VALIDATION RESULT OBJECT
  {
    valid: boolean,       // true if safe
    category: string,     // final category to use
    reason: string,       // explanation
    redirected?: boolean, // true if deprecated→safe
    blocked?: boolean,    // true if UNSAFE
    unknown?: boolean     // true if unrecognized
  }


================================================================================
                        API REFERENCE
================================================================================

STATIC PROPERTIES

  AINodes.SAFE_CATEGORIES
    → Array: ['input', 'process', 'integration', 'analytics', ...]

  AINodes.UNSAFE_CATEGORIES
    → Array: ['mythic', 'prime', 'error', 'emotional']

  AINodes.DEPRECATED_CATEGORIES
    → Object: { 'sigma': 'quantum' }

VALIDATE METHOD

  const validation = aiNodes.validateCategory(category)
  → Returns: { valid, category, reason, ... }

================================================================================
                        QUICK TESTING
================================================================================

TEST SAFE CATEGORY
  const node = aiNodes.createNode('control', new THREE.Vector3(0,0,0));
  assert(node.userData.category === 'control');
  assert(node.userData.categoryValidation.valid === true);

TEST UNSAFE CATEGORY
  const node = aiNodes.createNode('mythic', new THREE.Vector3(0,0,0));
  assert(node.userData.category === 'input');
  assert(node.userData.categoryValidation.valid === false);
  assert(node.userData.categoryValidation.blocked === true);

TEST DEPRECATED CATEGORY
  const node = aiNodes.createNode('sigma', new THREE.Vector3(0,0,0));
  assert(node.userData.category === 'quantum');
  assert(node.userData.categoryValidation.redirected === true);
