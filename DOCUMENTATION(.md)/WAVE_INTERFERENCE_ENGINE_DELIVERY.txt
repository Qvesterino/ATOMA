PHYSICS IMPLEMENTATION
─────────────────────────────────────────────────────────────────────────────

Base Wave Formula:
  wave = A * attenuation * sin(ω*t - k*d + φ)

Where:
  A = baseAmplitude (0–1)
  attenuation = 1 / (1 + d / R)
  ω = 2πf (angular frequency)
  t = time since wave start
  k = 1 / R (wave number)
  d = graph distance (hops)
  φ = basePhase (offset)
  R = decayRadius (spatial scale)

Amplitude Modifiers:
  A *= lerp(0.8, 1.3, synergyBoost)       // +30% max with synergy
  A *= lerp(0.8, 1.3, resonanceBoost)     // +30% max with resonance
  A *= lerp(1.0, 0.5, corruptionBoost)    // -50% min with corruption

Interference:
  totalAmplitude = |Σ waves|
  constructivePower = Σ max(wave, 0)
  destructivePower = Σ max(-wave, 0)

Standing Wave Factor:
  dA = |max(waves) - min(waves)|
  standingWaveFactor = clamp01(1 - dA × 4)

  → waveField (object) | null

clear()
  → void
  Stop all waves

dispose()
  → void
