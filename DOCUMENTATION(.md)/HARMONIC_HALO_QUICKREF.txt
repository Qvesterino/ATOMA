OVERVIEW
────────────────────────────────────────────────────────────────────────────
Soft, volumetric energy envelopes around harmonic hubs that visually
communicate synchronization strength, health, and resilience.

Core Concept: Halos = hub authority visualization


QUICK SETUP
────────────────────────────────────────────────────────────────────────────
1. Import:
   import { HarmonicNodeResonanceHalos } from './HarmonicNodeResonanceHalos.js';

2. Initialize:
   const halos = new HarmonicNodeResonanceHalos();

3. Update (in animation loop):
   halos.update(deltaTime, nodeRegistry, hubSystemData);


ACTIVATION
────────────────────────────────────────────────────────────────────────────
Halos appear when:
  • Node is harmonic hub (activeLinkCount >= 2)
  • Hub has sync strength (hubSyncStrength > 0)
  • Node is not collapsed

Halos fade when conditions cease


VISUAL STATES
────────────────────────────────────────────────────────────────────────────
Healthy         → Blue glow, smooth breathing, 0.4 intensity
Synergized      → Cyan, energetic pulse, 0.5 intensity
Stressed        → Orange warning, irregular, 0.5 intensity
Corrupted       → Red, choppy, distorted, 0.3 intensity
Collapsed       → Dark red, thin, flickering, 0.3 intensity


VISUAL BEHAVIOR
────────────────────────────────────────────────────────────────────────────
Breathing       → ±3-6% scale oscillation (smooth, calming)
Luminance Wave  → Radial intensity modulation
Phase Pulse     → Synchronized to hub phase (deterministic)
Color Morphing  → Blue → Cyan → Orange → Red → Dark Red
Distortion      → Corruption causes shape warping
Wobble          → Instability causes phase irregularity
Stability       → Resilience dampens all distortions


STATE MODULATION
────────────────────────────────────────────────────────────────────────────
Harmony         → Primary modulator (clarity, smoothness)
Synergy         → Brightness boost (+20-40%)
Corruption      → Intensity reduction (-30%), shape distortion
Instability     → Visibility dampening (-40%), wobble
Resilience      → Stabilization, faster recovery

PERFORMANCE
────────────────────────────────────────────────────────────────────────────
Per-Halo:           ~0.2ms
Per-Frame Allocs:   0
Memory Per Halo:    ~150 bytes
Geometry:           Shared (1x)
Material:           Cloned (1 per halo)

Scaling:
  10 halos    → 2ms
  25 halos    → 5ms
  50 halos    → 10ms
  100 halos   → 20ms

Recommendation: Very efficient at all scales

TROUBLESHOOTING
────────────────────────────────────────────────────────────────────────────
Halos not showing?
  • Check node has 2+ links
  • Verify syncStrength > 0
  • Inspect with getDebugInfoForNode()

Halos too dim?
  • Increase HALO_VISUALS.HEALTHY_INTENSITY
  • Check harmony/synergy values

Halos too bright?
  • Decrease intensity constant
  • Reduce synergy effect

Performance issues?
  • Halos are very cheap (unlikely culprit)
  • Monitor getStats() for count
  • Check frustum culling enabled
