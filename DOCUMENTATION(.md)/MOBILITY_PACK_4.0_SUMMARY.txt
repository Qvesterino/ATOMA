Edit SafeMobilityPack4.js to adjust:

dash.cooldown = 0.55              → Cooldown time between dashes
dash.distance = 3.5               → How far to dash
dash.recoveryDuration = 0.2       → Recovery time after dash

doubleJump.pressWindow = 0.26     → Time window for double press
doubleJump.boostMultiplier = 1.35 → Jump boost amount (+35%)
doubleJump.airFrictionReduction = 0.12  → Air float feeling

Or adjust at runtime:
atomaGame.mobilityPack.dash.cooldown = 0.5
atomaGame.mobilityPack.doubleJump.boostMultiplier = 1.4

🐛 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Dash not working?
→ Check cooldown (should show in status)
→ Verify SHIFT key is working
→ Call getStatus() to verify system

Double jump not triggering?
→ Must be mid-air (not on ground)
→ Must press SPACE twice within 0.26s
→ Check console for ground detection

VFX not showing?
→ Verify mobilityPack is initialized
→ Check that update() is called each frame
→ Monitor activeTrails/activePulses count

Camera issues?
→ Roll should be locked to 0
→ Bob should be disabled during dash
→ FOV should spike and return smoothly

Enter safe mode (disable abilities):
atomaGame.mobilityPack.state.safeMode = true

Exit safe mode (re-enable abilities):
atomaGame.mobilityPack.state.safeMode = false
