═══════════════════════════════════════════════════════════════════════════════
DISCRETE STATES
════════════════════════════════════════════════════════════════════════════════

SynergyState.LOW       ← synergy < 0.50  [Barely connected]
SynergyState.ACTIVE    ← 0.50 ≤ synergy < 0.75  [Connected, working]
SynergyState.STRONG    ← 0.75 ≤ synergy < 0.85  [High quality]
SynergyState.AWAKENED  ← synergy ≥ 0.85  [Peak connection]

═══════════════════════════════════════════════════════════════════════════════
CORE API
═════════════════════════════════════════════════════════════════════════════════

1. CREATE INSTANCE
   ─────────────────
   const resolver = new SynergyStateResolver();
   
   Optional: Custom thresholds
   const resolver = new SynergyStateResolver({
     activeThreshold: 0.40,
     strongThreshold: 0.70,
     awakenedThreshold: 0.90
   });

2. RESOLVE (Main Function)
   ────────────────────────
   const state = resolver.resolve(synergyValue);
   
   Input:  synergy number (0–1)
   Output: SynergyState string ("LOW", "ACTIVE", "STRONG", "AWAKENED")
   
   Example:
   resolver.resolve(0.30)   → "LOW"
   resolver.resolve(0.60)   → "ACTIVE"
   resolver.resolve(0.80)   → "STRONG"
   resolver.resolve(0.90)   → "AWAKENED"

3. IS_AT_LEAST (Query Function)
   ──────────────────────────────
   boolean = resolver.isAtLeast(synergyValue, minState);
   
   Example:
   resolver.isAtLeast(0.80, SynergyState.STRONG)    → true
   resolver.isAtLeast(0.50, SynergyState.AWAKENED)  → false
   
   Use: if (isAtLeast(synergy, SynergyState.STRONG)) { ... }

4. GET_STATE_INFO (Detailed Info)
   ───────────────────────────────
   info = resolver.getStateInfo(synergyValue);
   
   Returns: {
     state,               // "STRONG"
     value,               // 0.80
     progress,            // 0.667 (how far through this state)
     nextState,           // "AWAKENED" or null
     distanceToNext,      // 0.05 (how close to next state)
     isNearTransition,    // false
     threshold            // {lower, upper, range}
   }

5. SET_THRESHOLDS (Configuration)
   ────────────────────────────────
   resolver.setThresholds({
     activeThreshold: 0.50,
     strongThreshold: 0.75,
     awakenedThreshold: 0.85
   });
   
   Can change at runtime for difficulty scaling

6. GET_THRESHOLDS (Query)
   ───────────────────────
   thresholds = resolver.getThresholds();
   // { active: 0.50, strong: 0.75, awakened: 0.85 }

7. UTILITY: getStateDescription
   ─────────────────────────────
   desc = SynergyStateResolver.getStateDescription(SynergyState.AWAKENED);
   // "Peak connection — Nodes fully synchronized and resonant"

8. UTILITY: getStats
   ──────────────────
   stats = resolver.getStats();
   // {
   //   resolveCount: 1500,
   //   averageTimeMs: 0.003,
   //   stateDistribution: { LOW: 200, ACTIVE: 500, STRONG: 600, AWAKENED: 200 }
   // }

USAGE PATTERNS

PATTERN 1: Simple State Check
───────────────────────────────
const state = resolver.resolve(link.synergy);
if (state === SynergyState.AWAKENED) {
  applyAwakeningEffect();
}

PATTERN 2: Tiered Effects
──────────────────────────
const state = resolver.resolve(link.synergy);
if (state === SynergyState.AWAKENED) {
  intensity = 1.0;
} else if (state === SynergyState.STRONG) {
  intensity = 0.7;
} else if (state === SynergyState.ACTIVE) {
  intensity = 0.3;
} else {
  intensity = 0;
}

PATTERN 3: Switch Statement
─────────────────────────────
const state = resolver.resolve(link.synergy);
switch(state) {
  case SynergyState.LOW:
    // No effects
    break;
  case SynergyState.ACTIVE:
    // Apply basic effects
    break;
  case SynergyState.STRONG:
    // Apply stronger effects
    break;
  case SynergyState.AWAKENED:
    // Apply full awakening effects
    break;
}

PATTERN 4: Query Threshold
───────────────────────────
if (resolver.isAtLeast(link.synergy, SynergyState.STRONG)) {
  // This link is strong quality or better
  applyRevealEffect();
}

PATTERN 5: Get Transition Info
────────────────────────────────
const info = resolver.getStateInfo(link.synergy);
if (info.isNearTransition) {
  // Show warning that synergy is about to change
  console.warn(`Synergy near transition: ${info.distanceToNext.toFixed(2)} away`);
}

TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════════

Q: Why is my state always LOW?
A: Check that synergy values are normalized (0–1). If values are 0–100, divide by 100.

Q: Why is state not changing at threshold?
A: Check threshold values. resolver.getThresholds() to verify.

Q: Can I use different thresholds for different systems?
A: Yes! Create separate resolver instances:
   const resolverA = new SynergyStateResolver({ awakenedThreshold: 0.80 });
   const resolverB = new SynergyStateResolver({ awakenedThreshold: 0.90 });

Q: Does it work with negative synergy?
A: Yes, negative values clamp to LOW state.
