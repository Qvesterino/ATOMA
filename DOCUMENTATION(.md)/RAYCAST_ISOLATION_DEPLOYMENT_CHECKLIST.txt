TROUBLESHOOTING
================================================================================

Issue: Console shows errors on startup
Solution:
  1. Check: Are imports present in main.js?
  2. Check: Is _RaycastIsolationFailsafeSystem.js present?
  3. Check: Are all files spelled correctly?
  4. Fix: Correct file paths or missing imports
  5. Reload page

Issue: HitProxyDebug not defined
Solution:
  1. Reload page
  2. Check console for initialization messages
  3. Verify createAINodes() completed
  4. Verify setupHitProxyDebugAPI() was called

Issue: Node selection not working
Solution:
  1. Test: HitProxyDebug.testRaycast()
  2. Check: HitProxyDebug.stats() - verify proxy count
  3. Try: Clicking different node locations
  4. Try: Activating failsafe: RaycastFailsafeDebug.activateFailsafe()

Issue: FPS dropping significantly
Solution:
  1. Check: HitProxyDebug.stats() - sync time
  2. Check: Number of nodes spawned
  3. Normal: 0-5% impact is acceptable
  4. If higher: Check browser CPU usage

Issue: "Cannot assign to read only property" error
Solution:
  This should NOT occur with the system installed
  1. Check: RaycastFailsafeDebug.violations()
  2. Check: RaycastFailsafeDebug.status()
  3. Report: Include full violation data
  4. Failsafe: Should activate automatically
