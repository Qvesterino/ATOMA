  are redirected to aura/halo systems instead of overlaying core.

IMPLEMENTATION:
  File: EventVisualSuppression_v1.js (240 lines)
  Integration: main.js (lines ~1653-1696, +45 lines)
  Approach: Event-driven redirection with CoreAuthority integration

CORE OPERATIONS:
  1. suppressVFXEventEffects(nodes) — Suppress core-level effects
  2. redirectToAura(node, intensity) — Redirect intensity to aura
  3. protectCoreFromEvent(node) — Guard core from event changes
  4. validateEventVisuals(nodes) — Debug validation

  Rule 1: Emissive reduction — Core emissive suppressed 80%
  Rule 2: Opacity clamping — Core opacity clamped to 0.85 minimum

  Event glows → Aura glow effect
