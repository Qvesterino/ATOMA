TECHNICAL APPROACH
================================================================================

DETERMINISTIC HASHING:
  Uses node UUID as seed for stable "pseudo-random" values
  Same node always gets same pattern
  Different nodes get different patterns
  Zero per-frame randomness
  
  Formula: Math.sin(node.uuid.charCodeAt(i) * PRIME) * 43758.5453

SMOOTH SINE INTERPOLATION:
  Replaces random per-frame jitter with deterministic curves
  Smooth acceleration/deceleration
  Predictable motion paths
  Professional appearance
  
  Formula: Math.sin(progress * Math.PI * frequency + phase) * amplitude

FREQUENCY REDUCTION:
  Reduces shader jitter from high-frequency to low-frequency
  Eliminates visible micro-shake
  Preserves smooth breathing effect
  Below perception threshold
  
  Before: 20-30 Hz (visible), After: 2-3 Hz (smooth)
