TECHNICAL SPECIFICATIONS:

SIMPLE SYNERGY PULSE:
  Trigger:        synergy > 0.6
  Formula:        pulse = 1.0 + sin(time * 1.5) * 0.03 * synergy
  Frequency:      1.5 rad/s (~0.24 Hz)
  Amplitude:      ±3% (scales with synergy)
  Applied To:     Node scale (world-space)
  Fade:           Smooth in/out with no snapping
  Performance:    <0.5ms per frame (50 nodes)

VISUAL TIME ELASTICITY:
  Trigger:        avgSynergy > 0.85 sustained for 5+ seconds
  Update Formula: visualTime -= dt * 0.4
  Fade Duration:  1.0 second
  Rewind Speed:   40% (subtle, not jarring)
  Clamp:          No rewind beyond -60 seconds
  Game Impact:    ZERO (only affects animation parameter)
  Performance:    <0.05ms per frame

================================================================================

INTEGRATION FLOW:

Main Loop Update:
  1. Read avgSynergy from nodeDynamicMetrics
  2. Update SynergyPulseVisuals
     - If synergy > 0.6 → apply pulse to all nodes
     - If synergy < 0.6 → fade out pulse
  3. Update VisualNetworkTimeElasticity
     - If avgSynergy > 0.85 for 5s → rewind visualTime
     - If avgSynergy < 0.85 → sync visualTime with gameTime
  4. Store visualTime in window.VISUAL_TIME for external systems

Data Flow:
  nodeDynamicMetrics.avgSynergy
    ↓
  SynergyPulseVisuals_v1 (pulse effect)
  VisualNetworkTimeElasticity_v1 (time effect)
    ↓
  Visual animations (scale, glow phases, etc.)
  Game logic (UNAFFECTED - uses real time)
