HOW IT WORKS
================================================================================

BEFORE (Modulo-based, global cycling):
  Node 1 spawns geometry variant % 5
  Node 2 spawns geometry variant % 5
  ... possible duplicates in same cycle

AFTER (Spawn Cycle Validation, per-category):
  INPUT Cycle 0:
    Node 1: TriangularPrism+Rim (variant % 5 = 0)
    Node 2: PyramidSpike (variant % 5 = 1)
    Node 3: WireframeSphere (variant % 5 = 2)
    Node 4: Icosahedron (variant % 5 = 3)
    Node 5: HyperbolicPrism (variant % 5 = 4)
  
  INPUT Cycle 1 (automatically reset):
    Node 6: TriangularPrism+Rim (variant % 5 = 0)
    ... cycle repeats

KEY ENFORCEMENT:
  ✓ Each geometry spawns ONCE per category cycle
  ✓ After all geometries used → cycle resets
  ✓ Each category cycles independently
  ✓ Validation on every spawn (transparent)
  ✓ Cycle metadata stored on nodes

================================================================================
KEY METHODS (SpawnCycleValidator)
================================================================================

getNextGeometry(category, variantIndex)
  → Validates and cycles geometry for category
  ← Returns: {geometry, category, cycleNumber, positionInCycle, ...}

validateGeometryAssignment(geometryName, category)
  → Checks if geometry belongs to category
  ← Returns: {isValid, belongsTo, error}

getCycleStats(category)
  → Get current cycle state for category
  ← Returns: {cycleNumber, usedInCycle, percentageUsed, ...}

getAllStats()
  → Get cycle stats for all categories at once
  ← Returns: {input: {...}, process: {...}, ...}

resetCategoryyCycle(category)
  → Reset cycle for specific category

resetAllCycles()
  → Reset all cycles (for new game)

printVerificationReport()
  → Print canonical map verification to console
