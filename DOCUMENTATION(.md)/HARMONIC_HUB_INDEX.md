## 🛠️ Using Debug Utilities

### HarmonicHubDebugger

**Import**:
```javascript
import { HarmonicHubDebugger } from './HarmonicHubDebugger.js';
```

**Methods**:
- `watchHub(nodeId, interval)` — Monitor hub in real-time
- `getAllHubs()` — Get all active hubs
- `showHubInfo(nodeId)` — Detailed hub info
- `showActiveHubs()` — List active hubs
- `analyzeSyncQuality()` — Calculate phase coherence
- `showModeReference()` — Show harmonic mode reference
- `testModeTransitions(nodeId)` — Test mode transitions
- `watchOrbitalRotation(nodeId, duration)` — Watch orbital pattern
- `stopWatchingHub(nodeId)` — Stop watching
- `stopWatchingAll()` — Stop all watches

See: `/HarmonicHubDebugger.js` for full API
