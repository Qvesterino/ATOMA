# Input Node Variants - Visual Design Guide (Session 84)

## Category Overview
**Input Nodes** represent data reception, sensing, signal acquisition, and information gathering.
**All use RECEPTION/SENSING TOPOLOGY** - the visual principle that data flows inward to be perceived and processed.

## NEW Session 84 Enhanced Variants

### Input 8: SensorArray ⭐ NEW
```
Visual Structure:

Top View:            Side View (one sensor):

    ●                    ◆─ (sensor tip)
   ╱ ╲                   │
  ●───●                  │ (tapered sensor)
   ╲ ╱                   │
    ●                    ◆─ (central hub)

Radial arrangement:

    ⊕(sensor)
    │
  ◆─●─◆  (hub)
  ◆   ◆
    │
    ⊕(sensor)
```

**What Makes It Input?**
- Central hub represents unified reception
- 5 asymmetric sensors radiating outward
- Each sensor independently oriented
- Represents "multi-directional sensory input"

**Visual Metaphor**:
- Multiple independent data channels
- Each sensor asymmetrically shaped
- Central coordination point
- Cyan metallic for reception aesthetic

**Geometry Details**:
- Central hub: 12-vertex asymmetric icosahedron-like
- 5 sensor probes: 12 segments each, 4-point asymmetric cross-section
- Sensors taper from 0.08 to near-point
- Variable material per sensor (metalness, emissive)
- Total ~3.6 KB geometry, ~2,200 vertices

**Design Inspiration**: Antennae arrays, sensor clusters, multi-directional microphones, sensory organs

### Input 9: PerceptionVortex ⭐ NEW
```
Visual Structure:

Front View:                Side View:

   ▼ (tight spiral)            ╱─╲ (spiraling)
  ╱╱▼╲╲                       │   │
 ╱▼   ▼╲                      │ ◆ │ (central point)
 ╲ ◆ ◆ ╱                      │   │
  ╲╲▲╱╱                        ╲─╱
   ▲ (wide spiral)

3D Spiral Pattern:

    ╭─╮
   ╱   ╲ (spiral inward)
  │  ◆  │
   ╲   ╱
    ╰─╯
```

**What Makes It Input?**
- 3 spiral arms at 120° separation
- Spirals twist inward (convergence)
- Radius decreases as spirals approach center
- Represents "sensory information focusing inward"

**Visual Metaphor**:
- Sensory input swirling to perception center
- Spiral suggests continuous flow
- Convergence shows unified gathering
- Cyan metallic for reception

**Geometry Details**:
- 3 independent spiral arms
- 2.5 rotations per spiral (80 total segments)
- Each arm: 32 segments with 5-point asymmetric cross-section
- Radius tapers: 0.7 → 0 (convergence)
- Height rises: -0.3 → +0.3
- Central octahedron convergence point
- Total ~3.9 KB geometry, ~2,400 vertices

**Design Inspiration**: Whirlpool, spiral galaxy, spiral staircases, tornado funnels, yin-yang spirals

**What Makes It Input?**
- Central chamber structure (3-tier asymmetric)

- Total ~4.0 KB geometry, ~2,400 vertices

| Variant | Metalness | Roughness | Emissive | Opacity |

| ResonanceChamber | 0.70 (chamber) 0.90 (nodes) | 0.30 (chamber) 0.10 (nodes) | 0.20 / 0.40 | 0.70 / varied |

**Design Philosophy**: 
- Base materials consistent with legacy Input nodes
- All maintain cyan metallic reception aesthetic
- Material variation subtle enough to enhance without distract
- Node brightness increases for perception centers

## Scene Integration

### Typical Input Node Placement
```
In 3D Network View:

    [Input] ──→ [Process] ──→ [Integration] ──→ [Analytics]
       │           │              │                   │
       └───────┬───┘              └────────┬──────────┘
               │                           │
            [Control] ◀─────[Storage]─────┘

Input nodes often:
- Start network data flows
- Receive external signals
- Gather diverse data sources
- Act as sensor/perception points
```

### Visual Recognition at Distance
```
All Input variants immediately recognizable by:
✓ Cyan color (vs red/green/magenta/violet/silver)
✓ Reception/sensing topology (antenna, spiral, convergence)
✓ Asymmetric structure (complex, not simple)
✓ 3D volumetric form (not flat)
✓ Inward-focused sense (gathering, not dispersing)
```
