SUPPORT & TROUBLESHOOTING
================================================================================

Common Issues & Solutions:

1. Particles not scaling with traffic:
   → Check that link.trafficMagnitude is set
   → Verify updateLinkParticleEmissionRate() called in update loop
   → Run diagnostic: console.log(link.particleEmissionRate)

2. Enhanced models not replacing unstable nodes:
   → Verify enableEnhancedModels() was called
   → Check that node stability score < 0.5
   → Run report: getDiagnosticReport()

3. Performance degradation:
   → Reduce update frequency (Task 1: 500ms → 1000ms)
   → Check node count (Task 2: scales linearly)
   → Verify no other systems blocking main thread

4. Memory increasing:
   → Check visualStabilityMonitor.stabilityScores.size
   → Expected: grows with unique node count, then stable
   → Investigate if nodes being properly cleaned up
