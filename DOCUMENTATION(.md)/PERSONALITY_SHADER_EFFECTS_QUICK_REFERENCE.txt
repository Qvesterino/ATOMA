BASIC USAGE
================================================================================

1. INITIALIZATION (already done in main.js)
   const effectsPack = new PersonalityShaderEffects_Pack_v1({
     enableDebug: false,
     clarityEmissiveMax: 0.4,
     corruptionTintMax: 0.25,
     resonancePulseFrequency: 2.0,
     // ... other options
   });

2. REGISTER MATERIAL
   effectsPack.registerNodeMaterial(material, 'clarity_bloom');
   effectsPack.registerNodeMaterial(material, 'corruption_rift');

3. REGISTER LINK
   effectsPack.registerLinkMaterial(linkMat, 'resonance_wave');

4. APPLY TO SCENE
   effectsPack.applyDefaultNodeProfile(scene);   // clarity_bloom to all
   effectsPack.applyDefaultLinkProfile(scene);   // resonance_wave to all

5. QUERY STATS
   const info = effectsPack.getDebugInfo();
   console.log(info.stats);

    clarityEmissiveMax: 0.6 (from 0.4)
    corruptionTintMax: 0.4  (from 0.25)
    resonancePulseAmplitude: 0.35 (from 0.2)

    corruptionTintMax: 0.1  (from 0.25)
    entropyWobbleStrength: 0.01 (from 0.02)

Faster/Slower Pulse?

================================================================================
TROUBLESHOOTING
================================================================================

Effects Not Visible?
  → Ensure PersonalityShaderBridge_v1.update() called each frame
  → Verify material is registered
  → Enable debug mode to see registration logs

Shader Errors?
  → Check browser console for WebGL errors
  → Verify shader uses standard three.js patterns
  → Try simpler profile first (clarity_bloom)

Performance Drop?
  → Reduce number of registered materials
  → Use simpler profiles
  → Check GPU load with DevTools

Visual Glitches?
  → Reduce effect intensity multipliers
  → Check that uniforms are updating
  → Try disabling time-based effects

================================================================================
PERSONALITY PIPELINE FLOW
================================================================================

Phase 3c Week 1: PersonalityVisualAdapter
  ↓ Computes 5 personality signals (clarity, resonance, entropy, focus, corruption)
  ↓ Stores in node.userData.personalityVisual

Phase 3c Week 2: PersonalityVFXLayer_v1
  ↓ Applies CPU-side frame-local transformations
  ↓ Modulates emissive, pulse, jitter, rotation, color

Phase 3c Week 3: PersonalityShaderBridge_v1
  ↓ Binds personality signals to shader uniforms
  ↓ Updates uniforms each frame (uClarity, uResonance, uEntropy, uFocus, uCorruption, etc)

Phase 3c Week 4: PersonalityShaderEffects_Pack_v1 ✨
  ↓ Uses Week 3 uniforms (read-only)
  ↓ Defines shader effect profiles
  ↓ Applies effects via safe onBeforeCompile hooks
  ↓ Creates gameplay-readable visual expressions
