================================================================================
TROUBLESHOOTING
================================================================================

Q: "Cannot assign to read only property 'boundingSphere'" error
A: This is the exact error the system prevents. If it occurs:
   1. Check: RaycastFailsafeDebug.violations()
   2. Check: HitProxyDebug.stats()
   3. Report with violation details

Q: Nodes not selecting
A: 1. Test: HitProxyDebug.testRaycast()
   2. Check: RaycastFailsafeDebug.status()
   3. Manual fallback: Click different node

Q: "HitProxyDebug not defined"
A: Reload page. Ensure setupHitProxyDebugAPI() was called.

Q: FPS dropping
A: Normal range is 0-5% impact. If higher:
   1. Check: HitProxyDebug.stats() for proxy counts
   2. Check: Are nodes spawning normally?
   3. Check: Browser dev tools for GPU usage
