================================================================================
                          TROUBLESHOOTING
================================================================================

Q: Node renders as INPUT when I spawn MYTHIC
A: Correct. MYTHIC geometry not implemented yet.
   Use only SAFE_CATEGORIES until mythic is added to EnhancedNodeModels.
   
Q: WaveShaderBridge not affecting my node
A: Check readiness: getVisualReadinessReport(node)
   If phase='SPAWN': wait for bootstrap
   If phase='LOCKED': check if category is registered in shader system

Q: Node visual degrades after linking
A: Should not happen with readiness gate active.
   Verify markNodeVisualReady() was called BEFORE linking.
   Check console for "[NodeVisualReadinessGate] BLOCKED" warnings.

Q: How do I know when a node is ready for effects?
A: Check: isNodeVisualReady(node) === true
   Or call getVisualReadinessReport(node).phase === 'LOCKED'
