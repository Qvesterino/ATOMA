Dash not working?
→ Check cooldown is ready
→ Verify SHIFT key works
→ Call getStatus() to debug

Double jump not triggering?
→ Must be mid-air (not grounded)
→ Must press SPACE twice within 0.26s
→ Jump counter resets on ground

VFX not showing?
→ Check mobilityPack is initialized
→ Verify update() is called each frame
→ Check console for errors

Camera acting weird during dash?
→ Bob should be disabled
→ Roll should be locked to 0
→ FOV should spike and return
