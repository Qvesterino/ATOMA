## Code Reference

### Main Entry Points

**Initialize**:
```javascript
new RecursiveGlyphMessaging4_0(scene, semanticGlyphAI)
```

**Enable/Disable**:
```javascript
.setEnabled(true/false)
```

**Generate Chain**:
```javascript
.generateChainForLink(linkId, linkData)
```

**Update**:
```javascript
.update(deltaTime, aiNodes, linkingSystem)
```

**Cleanup**:
```javascript
.cleanup()
```

### Key Methods

- `generateChainForLink()` - Create chain for link
- `createRecursiveChain()` - Build chain structure
- `generateChainSentences()` - Create semantic sequence
- `updateChain()` - Advance chain animation
- `updateChainMeshPositions()` - Position glyphs
- `applyChainAnimations()` - Animate glyphs
- `getStats()` - View statistics
- `printStatusReport()` - Console output

### Configuration Keys

All in `this.config` object:

**Structure**: `minSentencesPerChain`, `maxSentencesPerChain`, etc.  
**Transport**: `baseChainSpeed`, `synergySpeeedBoost`, etc.  
**Distortion**: `jitterAmplitude`, `distortionFromCorruption`, etc.  
**Recursion**: `branchingProbability`, `loopingProbability`, etc.  
**Performance**: `maxChainsPerLink`, `updateThrottle`, etc.

See `_RecursiveGlyphMessaging4_0_QUICKREF.md` for full table.

## Visual Summary

### System Stack

```
SemanticGlyphAI (Layer 5.0) — Provides semantic state
         ↓
LinkedGlyphMessaging3.0 — Basic symbolic messages
         ↓
RecursiveGlyphMessaging4.0 ← NEW
         ↓
AdaptiveGlyphRendering1.0 — Metric-driven animations
         ↓
LinkedGlyphSynchronization1.0 — Coordinated animations
         ↓
Render Loop
```

### Message Flow

```
Node A (source)
    ↓
Chain generated (2-6 sentences)
    ↓
Chain transports (3-5 seconds)
    ├─ Glyphs animate
    ├─ Sentences evolve semantically
    ├─ Optional branching/looping
    ↓
Node B (target)
    ├─ Chain dissolves
    ├─ Response chain generated
    ↓
Node A (back to A)
```

Creates living "conversation" across network.
