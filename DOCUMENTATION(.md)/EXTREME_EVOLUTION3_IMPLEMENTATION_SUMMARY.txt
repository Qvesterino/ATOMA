3-STAGE EVOLUTION MODEL
================================================================================

STAGE 0: BASE (Default, 0-10 seconds)
  - Minimal animation
  - Rotation: 0.001-0.005 rad/frame
  - Emissive: 0.3-0.5
  - Visual: Dormant, subtle presence
  - Feel: Potential waiting

STAGE 1: EVOLVING (10-25 seconds)
  - Moderate animation
  - Rotation: 0.005-0.015 rad/frame
  - Emissive: 0.6-0.8
  - Visual: Activation visible
  - Feel: Building energy

STAGE 2: ASCENDED (25+ seconds)
  - Intense animation
  - Rotation: 0.015-0.040 rad/frame
  - Emissive: 0.8-1.0 (pulsing)
  - Visual: Full consciousness
  - Feel: Mastery and power

DEBUG API
================================================================================

Get Statistics:
  game.extremeEvolution3.getStats()
  → Returns: { totalTrackedNodes, stageDistribution, archetypeBreakdown, ... }

Force Evolution Stage:
  game.extremeEvolution3.forceEvolutionStage(nodeIndex, stage)
  → stage: 0 (BASE), 1 (EVOLVING), 2 (ASCENDED)
  → Useful for testing specific stages

Reset All Nodes:
  game.extremeEvolution3.resetAllNodes()
  → Returns all nodes to BASE stage

Enable/Disable:
  game.extremeEvolution3.setEnabled(false)  // Pause evolution
  game.extremeEvolution3.setEnabled(true)   // Resume evolution

Debug Log:
  game.extremeEvolution3.debugLog()
  → Detailed console output with full stats table

Remove Node:
  game.extremeEvolution3.removeNode(node)
  → Cleanup when node is destroyed
