## 7. GEOMETRY SAFETY

### 7.1 Precomputation
All geometries compute `boundingSphere` before freezing:
```javascript
geometry.computeBoundingSphere();
Object.freeze(geometry);  // Immutable
```

### 7.2 Frozen Geometry Protection
VisualHierarchyCorrectionSystem_v1 now checks before mutation:
```javascript
const isFrozen = Object.isFrozen(geometry);
if (!isFrozen) {
  geometry.computeBoundingSphere();  // Only if mutable
} else {
  // Use fallback radius
}
```

### 7.3 No Mutation
- ✅ Geometries precomputed (boundingSphere, normals, vertices)
- ❌ Never call computeBoundingSphere() on frozen geometry
- ❌ Never modify vertices after freezing
- ❌ Never alter material after mesh creation
