## 🧠 CONTEXTUAL MEANING ENGINE

The core innovation: glyphs adapt their behavior based on:

### Analyzed Metrics
```javascript
{
  synergy: 0–1,        // Connection strength
  instability: 0–1,    // Chaos level
  harmony: 0–1,        // Emotional balance
  corruption: 0–1,     // Damage level
  load: 0–1,           // Computational load
  energy: 0–1,         // Energy reserves
  clarity: 0–1,        // Processing clarity
  evolutionStage: 1–3, // Growth phase
  isMythic: boolean,   // Legendary state
  isAscended: boolean, // Transcended state
  linked: boolean,     // Connected to others
  distanceToCamera: Infinity–0 // Proximity
}
```

### Animation Response Examples
```
High Synergy:
  • AI Consciousness: Faster rotation, brighter core
  • Evolution Stage 2: Intense shimmering
  • Mythic Seed: Larger expansion

High Instability:
  • AI Consciousness: Sharper breathing
  • Personality: More chaotic jittering
  
High Harmony:
  • Harmony Glyph: Larger bloom, higher opacity
  • All glyphs: More stable, less flicker

High Corruption:
  • Corruption Glyph: Dimmer, faster drift
  • All glyphs: Subtle desaturation

Player Proximity:
  • Ascended Node: Tilts toward camera
  • All glyphs: Become more prominent visually

Cluster Formation:
  • Synergy glyphs: Faster rotation
  • All nearby glyphs: Synchronize rhythm
```

## 🎮 USAGE

### Debug Commands
```javascript
// Check Glyph System 4.0 status
debugGlyphs4()

// Clear all 4.0 glyphs
clearGlyphs4()

// Create specific glyph
createGlyph4('node-0', 'aiConsciousness')
createGlyph4('node-5', 'mythicSeed')
createGlyph4('node-12', 'eventWorldEvent')
```

### Programmatic Access
```javascript
const sys = window.game.glyphSystem4;

// Get status
const status = sys.getStatus();
console.log(status.activeGlyphs);
console.log(status.lastUpdateMs);

// Create glyph
sys.createAIConsciousnessGlyph(nodeObject, 'node-0');
sys.createMythicSeedGlyph(nodeObject, 'node-1');
// ... (one method per type)

// Remove with fade-out
sys.removeGlyph('node-0');

// Manual update
sys.update(deltaTime, aiNodes.nodes);

// Cleanup all
sys.cleanup();
```

### Integration Example
```javascript
// When node state changes:
if (node.userData.personality.mood === 'HARMONIC') {
  glyphSystem4.createPersonalityHarmonyGlyph(node, nodeId);
  // → Glyph auto-responds to harmony metric
}

// When evolution progresses:
if (node.userData.evolutionStage === 3) {
  glyphSystem4.createEvolutionStage3Glyph(node, nodeId);
  // → Glyph animates 3-axis rotation + shimmering
}

// When ritual triggers:
glyphSystem4.createEventMythicRitualGlyph(node, nodeId);
// → Glyph pulses and brightens with ritual
```

## 🎨 ANIMATION CAPABILITIES

### Supported Operations (GPU-Light)
- ✅ Rotation (X, Y, Z axes)
- ✅ Scale (uniform or per-axis)
- ✅ Opacity/transparency
- ✅ Color lerp (material.color.lerpColors)
- ✅ Position offset (translate)
- ✅ Emissive intensity

### NOT Supported (Avoided)
- ❌ Geometry rebuilds
- ❌ Mesh generation per frame
- ❌ Post-processing effects
- ❌ Particle systems
- ❌ Custom shaders
- ❌ Volumetric effects
