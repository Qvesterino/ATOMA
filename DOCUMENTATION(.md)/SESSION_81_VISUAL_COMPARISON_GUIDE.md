## ANALYTICS VARIANTS

### 1. SharedBloom vs InterpretiveSpine vs SignalDrift

#### SharedBloom: "Analytical Decomposition"
```
Visual Impression:
  └─ Exploding sunburst pattern
  └─ 8 thin shards radiating outward
  └─ Empty center (implied, not occupied)
  └─ Lightweight, exploratory feeling

Geometry Blueprint:
  └─ 8 custom tapered box meshes
  └─ Shard length varies: 0.45-1.15x base
  └─ Shard angles: ±45° variation
  └─ Positioned via golden ratio randomness
  └─ Rotation per shard: deterministic asymmetry

Color Palette:
  └─ Base color: Cyan/teal (Analytics core)
  └─ Opacity: 0.8 (readable, solid)
  └─ Metalness: 0.5 (analytical shine)
  └─ Emissive: 0.15 intensity (gentle)

Read As:
  "Data breaking apart, separated into components"
  "Analysis through decomposition"
```

#### InterpretiveSpine: "Reasoning Flow"
```
Visual Impression:
  └─ Central curved backbone
  └─ 5 asymmetric branches
  └─ Directional bias without symmetry
  └─ "Thinking process" or "interpretation path" feeling

Geometry Blueprint:
  └─ Main spine: CatmullRomCurve3 + TubeGeometry
  └─ Spine path: Asymmetric sine + cos waves
  └─ 5 branches: LineCurve3 + TubeGeometry
  └─ Branch lengths: Deterministically varied
  └─ Branch angles: Off-axis, irregular attachment

Color Palette:
  └─ Main spine: Violet (core Analytics color)
  └─ Branches: Cyan accents (highlight)
  └─ Opacity: 0.75 (secondary elements)
  └─ Metalness: 0.5-0.6 (analytical quality)

Read As:
  "Logical progression with branching decisions"
  "Interpretation tree, flowing reasoning"
```

#### SignalDrift: "Pattern Extraction"
```
Visual Impression:
  └─ 4 spiral ribbon trajectories
  └─ "Captured motion" appearance
  └─ Ethereal, transparent quality
  └─ Significant empty space between ribbons

Geometry Blueprint:
  └─ 4 spiral paths (2.5 ± 0.8 turns each)
  └─ Ribbons: Custom gradient ribbon geometry
  └─ Spiral-in effect: Converging radius
  └─ Ribbon width: 0.12 units (thin, elegant)
  └─ Ribbon separation: 0.35+ units

Color Palette:
  └─ Color: Desaturated cyan/teal (low saturation)
  └─ Opacity: 0.5 (very transparent)
  └─ Metalness: 0.3 (minimal reflection)
  └─ Emissive: 0.08 intensity (very subtle)

Read As:
  "Signal paths showing flow and interpretation"
  "Pattern visibility, signal detection"
```

## STORAGE VARIANTS

### 1. ArchiveNexus vs MemoryCrypts vs DepthLayers

#### ArchiveNexus: "Distributed Redundancy"
```
Visual Impression:
  └─ 4 vertical strands arranged in circle
  └─ Cross-connecting bridges
  └─ Small connector nodes at intersections
  └─ "Multi-shaft archive tower" feeling
  └─ Reliable, interconnected system

Geometry Blueprint:
  └─ 4 main strands: Asymmetric BoxGeometry
  └─ Strand positioning: Golden ratio spacing
  └─ Strand heights: ±20% variation via sine
  └─ 4 bridge connectors: Dynamic BoxGeometry
  └─ Bridge heights: -0.7 to +0.1 units variation
  └─ 4 connector nodes: Asymmetric octahedra

Color Palette:
  └─ Base color: Silver/pale blue (Storage)
  └─ Opacity: 0.85 (solid, trustworthy)
  └─ Metalness: 0.75 (protective, vault-like)
  └─ Emissive: 0.15 intensity (slight glow)

Read As:
  "Multiple storage channels with backup paths"
  "Distributed, redundant architecture"
```

#### MemoryCrypts: "Layered Security"
```
Visual Impression:
  └─ 5 stacked irregular chambers
  └─ Sealed entry points with mechanisms
  └─ Erosion/decay marks showing history
  └─ "Ancient vault" or "secure archive" feeling
  └─ Protected, layered storage

Geometry Blueprint:
  └─ 5 chambers: Custom asymmetric polyhedra
  └─ Chamber vertices: 12 each (no symmetry)
  └─ Chamber stacking: 0.32 unit intervals
  └─ Chamber offsets: ±0.15 units XZ variation
  └─ 5 seals: Asymmetric octahedra on edges
  └─ Erosion marks: 12-15 decay details total

Color Palette:
  └─ Main: Silver/pale blue (Storage)
  └─ Seals: Accent color (bright highlights)
  └─ Chamber opacity: 0.7 (depth suggestion)
  └─ Metalness: 0.8+ (protective seal)

Read As:
  "Layered security with sealed compartments"
  "Ancient storage showing time and use"
```

#### DepthLayers: "Historical Depth"
```
Visual Impression:
  └─ 4 concentric irregular shells
  └─ Spiral arrangement (not concentric)
  └─ Erosion details on outer layers
  └─ Opacity fade showing depth
  └─ "Time-worn, nested storage" feeling

Geometry Blueprint:
  └─ 4 shells: Custom irregular polyhedra
  └─ Shell vertices: 16 each (dodecahedron-like)
  └─ Shell scaling: 0.65 → 0.29 units (converging)
  └─ Shell rotation: Asymmetric spiral pattern
  └─ Erosion marks: 3 per layer (layers 1-3)
  └─ Opacity per layer: 1.0, 0.85, 0.7, 0.55

Color Palette:
  └─ Base color: Silver fading to gray
  └─ Opacity fade: 1.0 → 0.55 (depth perception)
  └─ Metalness: 0.75-0.65 per layer (aging)
  └─ Emissive: 0.1 intensity (buried quality)

Read As:
  "Nested storage with historical layers"
  "Time-worn persistence, deep memory"
```
