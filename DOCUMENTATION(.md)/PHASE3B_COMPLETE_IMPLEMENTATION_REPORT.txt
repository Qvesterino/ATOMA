CORE MECHANICS
================================================================================

Harmony Feedback Loop:

TRIGGER:
  ├─ Phase 3 healing occurs (phase3b sees healedAmount > 0)
  ├─ 500ms cooldown has passed (per-link)
  ├─ Harmony not at max (< 1.0)
  └─ Feedback enabled (toggle flag true)

EXECUTION:
  ├─ Calculate gain: harmonyGain = healedAmount × 0.02
  ├─ Find target: link.userData OR sourceNode.userData
  ├─ Apply cap: newHarmony = min(currentHarmony + gain, 1.0)
  └─ Record event: Track in history for stats

RESULT:
  ├─ Link/node harmony increases slightly
  ├─ Higher harmony → Better healing next frame (Phase 3)
  ├─ Creates self-reinforcing cycle
  └─ Loop is weak but persistent

SAFEGUARDS:
  ├─ Hard harmony cap (max 1.0)
  ├─ Per-link cooldown (500ms minimum between gains)
  ├─ Tiny gain factor (2%, not explosive)
  ├─ Reduced cascade feedback (50% strength)
  ├─ Natural decay applies (external system)
  └─ Feedback doesn't trigger new healing

EXAMPLE PROGRESSION:
  T=0:    Harmony=0.80, Corruption=0.5
  T=5s:   Harmony=0.80, Corruption=0.4 (healing)
  T=5.5s: Harmony≈0.851 (gained ~0.001 from healing)
  T=10s:  Harmony≈0.852, Corruption=0.3
  T=30s:  Harmony≈0.87, Corruption=0.0
  
Result: Harmony grows slowly but steadily from successful healing
