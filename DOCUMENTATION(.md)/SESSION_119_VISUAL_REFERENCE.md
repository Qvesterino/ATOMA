## Color Perception & Recognition

### Player Color Recognition Thresholds

```
Magenta vs Yellow (Most distinguishable):
  Magenta: ███████ (hue 300°)
  Yellow:  ███████ (hue 60°)
  Difference: 240° → EASY to distinguish

Cyan vs Green (Medium difficulty):
  Cyan:    ███████ (hue 180°)
  Green:   ███████ (hue 120°)
  Difference: 60° → MEDIUM to distinguish
  
Red vs Magenta (Challenging):
  Red:     ███████ (hue 0°)
  Magenta: ███████ (hue 300°)
  Difference: 60° (wraparound) → CHALLENGING
  
Solution: Use brightness to separate:
  Red (Corruption):     #FF3333 (bright)
  Magenta (Destructive):#FF3366 (medium)
  → Now clearly distinct through both hue and saturation
```

### Brightness Encoding

```
Within single color type:

Low intensity:    ░░░░░░░░░░  (pale, subtle)
  Example: #FF6699 magenta
  Use: Early cascade, weak conflict

Medium intensity: ▒▒▒▒▒▒▒▒▒▒  (bright, obvious)
  Example: #FF3366 magenta
  Use: Active conflict, medium cascade

High intensity:   ▓▓▓▓▓▓▓▓▓▓  (deep, strong)
  Example: #FF0033 red-magenta
  Use: Peak conflict, max cascade

Combined effect:
  Player sees both HUE (conflict type) and BRIGHTNESS (intensity)
  Single color conveys: type + intensity (2D encoding)
```

## Particle Color Usage in Code

### WaveParticleEmitter Integration Example
```javascript
// In particle emission loop:
const cascadeColor = link.userData.cascadeParticleColor ?? 0xFFFFFF;
const emissionBoost = link.userData.cascadeParticleEmissionBoost ?? 1.0;
const conflictType = link.userData.cascadeConflictType;

// Emit color-coded particle
particle.position = link.midpoint;
particle.color = cascadeColor;
particle.velocity = cascadeDirection * emissionBoost;
particle.lifetime = 0.5;  // Shorter at high intensity
particle.mass = 1.0 + emissionBoost * 0.5;  // Heavier/faster
```

### Visual Effect Stacking
```
Layer 1: Particle color (from ColorTinting)
Layer 2: Emission rate (from EmissionBoost)
Layer 3: Burst modulation (oscillation)
Layer 4: Link glow (reactive to cascade)
Result:  Complex visual language from simple mechanics
```

- [ ] Oscillatory balance shows green shimmer
