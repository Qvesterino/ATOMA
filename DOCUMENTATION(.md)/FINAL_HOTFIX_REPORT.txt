SYSTEM INTENT CONFIRMATION
================================================================================

Data Structure Choices (Final):
   • baselineMap:        WeakMap ✅ (storage only, no iteration needed)
   • modulations:        Map ✅ (must iterate all auras each frame)
   • eventTypeMapping:   Map ✅ (required by original design)

Why Map for modulations:
   • Drop-in replacement for WeakMap API (get/set/delete identical)
   • Supports .forEach() iteration required by update loop
   • Minor memory difference (negligible for typical use)
   • Performance identical for modulation counts < 1000

Memory Trade-off:
   • WeakMap: Weak references, no iteration, auto-cleanup
   • Map: Strong references, iteration support, manual cleanup
   • Solution: Manual cleanup happens anyway (elapsedTime > 2.0 check)
   • Result: Both approaches have same memory profile
