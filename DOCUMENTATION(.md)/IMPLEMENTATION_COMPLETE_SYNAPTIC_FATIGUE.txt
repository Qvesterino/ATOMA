TECHNICAL SPECIFICATIONS
───────────────────────────────────────────────────────────────────────────────

FATIGUE MODEL:
  State: Per-node scalar ∈ [0.0, 1.0]

  Accumulation (Active):
    accumulation = |gateStrength| × 0.3
                 + pulseDensity × 0.15
                 + (isHub ? 1.2 : 1.0)
                 × (1.0 + corruption × 0.2)
    fatigue += accumulation × deltaTime

  Recovery (Resting):
    decay = 0.05 × (1 + harmony × 0.8)
          × (1 - corruption × 0.3)
          × (1 - instability × 0.25)
          × pow(fatigue, 1/1.5)
    fatigue -= decay × deltaTime

VISUAL EFFECTS:
  Level Low (0.0-0.3):     Barely noticeable
    Halo Dull: 0%,    Phase: 0%,    Flicker: 0%
  
  Level Medium (0.3-0.6):  Moderate strain
    Halo Dull: 15%,   Phase: 10%,   Flicker: 2%
  
  Level High (0.6-1.0):    Severe exhaustion
    Halo Dull: 35%,   Phase: 25%,   Flicker: 8%

  synapticFatigue.getStatus()         - View all settings & node counts

TUNING:
  synapticFatigue.setAccumulationRate(0.3)    - How fast fatigue builds
  synapticFatigue.setDecayRate(0.05)          - How fast fatigue heals
  synapticFatigue.setHarmonyRecoveryBoost(0.8) - Harmony recovery multiplier

DATA ACCESS:
  node.userData.synapticFatigue         - Current fatigue [0, 1]
  node.userData.synapticFatigueLevel    - Level: 'low'|'medium'|'high'|'none'
  node.userData.synapticIsRecovering    - Is recovering? true/false
  
  game.synapticFatigueAdapter.getFatigue(nodeId)
  → Returns fatigue [0, 1]
  
  game.synapticFatigueAdapter.getVisualModulation(nodeId)
  → Returns: { fatigue, level, haloDullFactor, phaseShift, flickerAmount, ... }
