IMPLEMENTATION SUMMARY
═════════════════════════════════════════════════════════════════════════════

ENTRY POINT:
  updateLinkMetrics(link, metrics) in NodeLinkingSystem.js
  └─ Called from updateLinkAnimations() every frame
  └─ Automatically applies corruption when metric >= 0.65

LINK CORRUPTION PIPELINE:
  updateMetricLinks()
    ├─ _applyCorruptionVisuals(state.mesh, state.corruption)  [NEW]
    ├─ _applySynergyVisuals(state.mesh, ...)
    └─ _applyHarmonyVisuals(state.mesh, ...)
  
  Order matters: Corruption first, then synergy/harmony on top

NODE CORRUPTION PIPELINE:
  updateLinkMetrics()
    └─ For both link.source and link.target:
       ├─ IF corruption >= 0.65:
       │  └─ _applyCorruptionToNode(node, corruption)
       ├─ ELSE IF was corrupted:
       │  └─ _removeCorruptionFromNode(node)
       ├─ [Then apply synergy/harmony]

INTERNAL STATE STORAGE:
  Link segments:
    userData.corruptionActive (bool)
    userData.corruptionLevel (float)
    userData.corruptionDeviation (float)
    userData.baseSpacing (Vector3)
    userData.baseRotation (Euler)
  
  Node layers:
    userData.isCorrupted (bool)
    userData.corruptionLevel (float)
    userData.baseCorruptionOpacity (float)
    userData.basePosition (Vector3)
    userData.baseRotation (Euler)
