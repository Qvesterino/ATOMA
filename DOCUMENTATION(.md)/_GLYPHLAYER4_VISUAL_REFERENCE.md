## Animation Type Reference

### ROTATION
```
  ↻  Y-Axis (horizontal spin)
  ↻→ Y+X-Axis (tumbling)
  ↻◁ Z-Axis (tilting)
```

### ORBIT
```
  ⭕ Circle around core at 0.25u
  ~0.4-0.6 rad/s speed
  Synchronized with core rotation
```

### PULSE
```
  ◦→● Opacity breathing
  0.3-0.5 range
  1.5Hz typical speed
```

### BOB
```
  ⤴⤵ Vertical sine wave
  ±0.02 units
  2Hz typical speed
```

### BREATHE
```
  ◦ ◆ ◦ Expanding/contracting scale
  0.96-1.04 range
  Smooth sinusoidal
```

## Layer Decision Tree

```
NODE EXISTS
    ↓
LAYER 1: CORE
├─ Always created
├─ Color from category
└─ Visible: YES

LAYER 2: EVOLUTION
├─ If evolutionStage: 1-3
├─ Color + visual by stage
└─ Visible: IF STAGE SET

LAYER 3: PERSONALITY
├─ If highest metric > 0.3
├─ Color + visual by type
└─ Visible: IF PERSONALITY

LAYER 4: STATE
├─ If state flag: true
├─ Color + visual by state
└─ Visible: IF FLAG SET

NO LAYERS?
└─ FALLBACK: Tiny white dot
```
