🎵 WHAT IT IS
─────────────────────────────────────────────────────────────────────────────
Synergy-driven visual coupling between linked nodes. Creates harmonic resonance
effects: particle flow, phase-locked shimmer, glow pulsing, and color shifts.

PURE VISUAL EFFECT — Zero gameplay impact, <1ms overhead, 100% backward compatible

═══════════════════════════════════════════════════════════════════════════════

📊 ACTIVATION THRESHOLDS
─────────────────────────────────────────────────────────────────────────────
Synergy 0.0–0.3:   No resonance (threshold)
Synergy 0.3–0.6:   Gentle resonance, 2–3 Hz frequency
Synergy 0.6–0.9:   Medium resonance, 3–4 Hz frequency  
Synergy 0.9–1.0:   Strong resonance, 4–5 Hz frequency

Particle emission scales with synergy intensity and frequency

═══════════════════════════════════════════════════════════════════════════════

🎯 VISUAL EFFECTS BREAKDOWN
─────────────────────────────────────────────────────────────────────────────

1. RESONANCE PARTICLES
   • Flow between source → target → source
   • Speed: 0.15 units/second (configurable)
   • Lifetime: 1.5 seconds
   • Emission: 0.02 particles/frame per link
   • Size: 0.12–0.25 units (scales along path)
   • Color: Cyan-blue range (0.45–0.65 hue)

2. NODE SHIMMER (Phase-Locked)
   • Source node: sin(phase) × 0.08 × intensity
   • Target node: sin(phase + π/4) × 0.08 × intensity
   • Effect: ±8% scale modulation (breathing)
   • Result: Target node lags source by ~45° (feels coupled)

3. LINK GLOW MODULATION
   • Glow intensity: 1 + sin(phase) × 0.3 × intensity × 1.4
   • Pulses in sync with resonance frequency
   • Scales with synergy intensity
   • Creates visual "energy flow" along link

4. HARMONY COLOR INFLUENCE
   • Reads: source.userData.harmony + target.userData.harmony
   • Lerp toward harmony-based hue
   • Intensity: 0.25 × intensity × 0.2 (subtle)
   • Result: Link takes on harmony tint

═══════════════════════════════════════════════════════════════════════════════

⚡ FREQUENCY CALCULATION
─────────────────────────────────────────────────────────────────────────────

normalized_synergy = (synergy - 0.3) / (0.9 - 0.3)  [clamped 0–1]

frequency = 2.0 + (normalized_synergy × 3.0)

Result:
  Synergy 0.3:  2.0 Hz
  Synergy 0.6:  3.5 Hz
  Synergy 0.9:  5.0 Hz

Higher synergy = faster oscillation = more energetic resonance

🚨 TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────

NO RESONANCE VISIBLE?
  → Check: game.nodeDynamicMetrics.avgSynergy > 0.3?
  → Check: game.linkingSystem.links.length > 0?
  → Check: game.harmonicResonanceCoupling.enabled = true?
  → Debug: game.harmonicResonanceCoupling.getDebugInfo()

PERFORMANCE ISSUE?
  → Reduce particle emission: config.particleEmissionRate = 0.01
  → Reduce shimmer: config.shimmerIntensity = 0.04
  → Check particle count: resonanceParticles.length

NODES SCALING WRONG?
  → Applied to core mesh first, fallback to node.scale
  → Check node structure: node.userData.coreMesh
  → Physics colliders NOT affected (visual only)
