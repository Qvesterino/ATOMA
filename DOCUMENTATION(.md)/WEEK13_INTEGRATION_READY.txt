================================================================================
WHAT WEEK 13 DOES
================================================================================

Reads:  node.userData.mythicEvolution.ascensionSmoothed (from Week 11)
        node.userData.personality signals (clarity, harmony, energy, etc.)

Applies: Archetype-specific curve (logistic, exponential, sigmoid, etc.)
         Personality influence modulation
         Tier-based multiplier boosts
         Hysteresis smoothing

Outputs: node.userData.archetypeEvolution = {
           archetypeId,           // "sage", "warlock", etc.
           archetypeName,         // "Sage", "Warlock", etc.
           ascensionModified,     // 0–1 (curve-mapped)
           ascensionMultiplier,   // 1.0–5.0+ (for weeks 14–16 FX)
           curveRaw,              // Pre-smoothing
           curveSmoothed,         // Post-smoothing
           personalityInfluence,  // 0–1
           tierBoost,             // 1.0–2.0+
           nextTierProgress,      // 0–1
           lastUpdateTime,        // Timestamp
         }

Primary output: ascensionMultiplier (used by weeks 14–16 for visual effects)

================================================================================
TROUBLESHOOTING
================================================================================

Q: "Cannot read property 'ascensionSmoothed' of undefined"
A: Make sure mythicEvolutionFX.update() is called BEFORE archetypeCurves.update()

Q: "archetypeCurves.update is not a function"
A: Check that you called new ArchetypeAscensionCurves_v1(...) in constructor

Q: Nodes don't have archetypeEvolution data
A: Set node.userData.archetypeId = 'sage' before first update()

Q: Performance is slow
A: Check that archetypeCurves.update() is <1ms in DevTools Performance tab

Q: getNodeState returns null
A: Node might not be initialized. Add null check: node?.userData?.archetypeEvolution
