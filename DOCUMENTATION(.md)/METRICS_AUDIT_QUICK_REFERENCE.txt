CORE METRICS SYSTEM (Primary 5)
================================================================================

SOURCE: CoreMetricsCalculator.js
UPDATE: Every 0.5 seconds (2Hz)
CACHE: CoreMetricsOverlay.currentMetrics

Calculation Formulas:
────────────────────────────────────────────────────────────────────────────

SYNERGY = (active_links / max_potential_links) × 100
  INPUT: linkCount.total, nodeCount.total
  FORMULA: links ÷ (n×(n-1)/2) × 100
  
HARMONY = (supportive_archetypes - weighted_challenging) / totalNodes + 50
  INPUT: archetype counts (crystal, solar, echo, convergence, harmonic)
  FORMULA: (support - 0.7×quantum - 0.9×umbra) / nodeCount + 50
  
INSTABILITY = (quantum + umbra) / total × 100
  INPUT: quantum + umbra node counts
  FORMULA: unstable_nodes ÷ nodeCount × 100
  
CORRUPTION = (umbra×3 + quantum) / (total×4) × 100
  INPUT: umbra count (weight 3), quantum count (weight 1)
  FORMULA: weighted_corruption / total × 100
  
NETWORKLOAD = avg_link_load × 100
  INPUT: link traffic data or link_density × 20
  FORMULA: totalLoad ÷ activeLinks × 100

CONSUMERS (All Read Every Frame):
────────────────────────────────────────────────────────────────────────────
1. CoreMetricsHUD → Display as XX% on screen
2. MetricReactiveWorldEvents → Trigger environmental VFX
3. SafeMetricsFX1_1 → Node glow based on harmony/instability/corruption
4. NodePersonalitySystem2_0 → Personality determination
5. SynergyRecommendationDebugHUD → Statistics display

LINK QUALITY SYSTEM (Per-Link Metrics)
================================================================================

LAYER 1: Synergy Computation (ComputeSynergyScore2_0)
────────────────────────────────────────────────────────────────────────────
Formula:
  Score = (0.35 × TypeSynergy) +
          (0.25 × PrioritySynergy) +
          (0.20 × TrafficSynergy) +
          (0.10 × DecaySynergy) +
          (0.10 × TopologySynergy)

Output: { score: 0-1, tier: 'low'|'medium'|'high'|'critical', components }
Consumers: Recommendation AI, Quality Predictor, VFX systems

LAYER 2: Decay Tracking (LinkPriorityDecayEngine)
────────────────────────────────────────────────────────────────────────────
Metrics:
  • age: createdAt - now (seconds)
  • idleTime: lastActivityAt - now (seconds)
  • staleness: combined age + idle metric
  • decayFactor: priority multiplier

Thresholds:
  idle: 300s (5 min)
  stale: 7200s (2 hours)
  critical: 10800s (3 hours)

Consumers: Repair layer, Quality feedback, Decay suggestions

LAYER 3: Quality Feedback (LinkQualityFeedbackLoop1_0)
────────────────────────────────────────────────────────────────────────────
Fusion Formula:
  finalQuality = (synergy × 0.6) + (mlPrediction × 0.4)

Categories:
  poor < 25
  medium: 25-60
  strong: 60-85
  excellent: 85+

Tracks: Creation, acceptance, rejection, predictions
Consumers: ML engine, Automation decisions, Statistics

LAYER 4: ML Learning (LinkMLRecommendationEngine1_0)
────────────────────────────────────────────────────────────────────────────
Input: LinkQualityFeedbackLoop outcomes (accepted/rejected)
Output: Updated weights per category pair
Status: ⚠️ MANUAL UPDATE ONLY (should be automatic)

CRITICAL ISSUES RANKED BY PRIORITY

🔴 HIGH PRIORITY (Production Impact)

1. ML Learning Loop is Manual (not automatic)
   • LinkML weights never auto-adjust after link acceptance/rejection
   • Automation quality plateaus
   • Fix: Close the feedback loop

2. Link Quality Metrics Fragmented (4 independent systems)
   • Synergy ≠ Quality ≠ Feedback ≠ Decay
   • Automation uses synergy, not feedback quality
   • Fix: Unified LinkQualityCalculator

3. Node Personality Never Updates (assigned once, frozen forever)
   • Personality locked on node creation
   • No visible evolution even as metrics change
   • Fix: Real-time personality re-evaluation

🟡 MEDIUM PRIORITY (Data Accuracy)
────────────────────────────────────────────────────────────────────────────
4. Duplicate Metric Computation (4x per cycle)
   • Core, personality, evolution, effects all read metrics
   • Possible desynchronization
   • Fix: NodeDynamicMetrics cache layer

5. Evolution Energy ≠ Core Energy (two definitions)
   • SafeEvolutionManager uses link count
   • CoreMetricsCalculator uses node data
   • Fix: Single energy source for all systems

6. Stale Links Not Cleaned Up (marked but not removed)
   • Decay marks stale, repair doesn't check
   • Zombie links persist indefinitely
   • Fix: Decay → Repair integration

🟢 LOW PRIORITY (Cosmetic/Unused)
────────────────────────────────────────────────────────────────────────────
7. No Node Quality Calculation (missing completely)
   • Can't filter recommendations by node reliability
   • Fix: NodeQualityCalculator (parallel to LinkQuality)

8. Temporal Metrics Unused (cosmetic only)
   • Time passes but doesn't affect metrics
   • Fix: Design-level decision (may be intentional)
