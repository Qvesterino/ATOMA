HOW PHASE 3 GUARDS WORK
================================================================================

NODE SPAWN CYCLE:
1. Node created at position
2. Check collision radius (occupancyRadius)
3. If collision found:
   - visualReady = false
   - visualActivationDelay set to 150ms
   - Node added to scene (hidden)
4. After ~150ms:
   - _checkVisualReadiness() called
   - Re-check collision
   - If clear: visualReady = true
   - Bootstrap all secondary visuals
5. Secondary systems check visualReady before activating:
   - NodeAuraSystem: Skip if !visualReady
   - Evolution: Skip if !visualReady
   - Rituals: Skip if !visualReady

RESULT: Zero visual overlaps + coordinated activation ✓
