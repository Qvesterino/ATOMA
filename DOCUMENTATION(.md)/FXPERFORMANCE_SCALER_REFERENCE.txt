BASIC WORKFLOW

   ↓

   ↓

   ↓

================================================================================
TROUBLESHOOTING
================================================================================

F7 Key Not Working?
  → Check that setupPerformanceMode() is called
  → Verify listener is attached to document
  → Check browser console for errors

Effects Don't Change?
  → Check that scaler.update() is called each frame
  → Verify scaler runs AFTER PersonalityVisualAdapter
  → Check console: game.fxPerformance.logDebugInfo()

Performance Drop?
  → Check scaler performance stats
  → Verify update called once per frame
  → Check node count and signal presence

Shader Errors?
  → This should not happen (no shader modifications)
  → Check PersonalityShaderBridge still working
  → Verify uniforms are updating

================================================================================
ARCHITECTURE
================================================================================

Data Flow
  PersonalityVisualAdapter
  ↓ (generates signals)
  node.userData.personalityVisual {
    clarityBoost, resonanceBoost, entropyPenalty, focusShift, corruptionSignal
  }
  ↓
  [NEW] FXPerformanceScaler_v1
  ↓ (multiplies by controller multipliers)
  node.userData.personalityVisual {
    clarityBoost * mult, resonanceBoost * mult, ...
  }
  ↓
  Week 2-4 systems (read scaled values)
  ↓
  Visual effects

State Machine
  LowFX OFF (mult = 1.0) ←→ LowFX ON (mult = 0.4/0.2/0.3/0.5)
  Toggle via F7 or setLowFX()
