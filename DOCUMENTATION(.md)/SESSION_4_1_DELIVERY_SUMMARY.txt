FIX #1: Node Auto-Detection (8° Cone)
───────────────────────────────────────────────────────────────────────────────
  PROBLEM:   Players had to manually click nodes to inspect
  SOLUTION:  Automatic detection when aiming at node
  
  Specs:     • 8° half-angle detection cone
             • 10m max detection range
             • Instant panel switch on target change
             • 0.2s timeout to close
             • <0.3ms/frame performance

FIX #2: HUD Toggle Keybind (TAB → C)
───────────────────────────────────────────────────────────────────────────────
  PROBLEM:   TAB key conflicts with Rosebud platform
  SOLUTION:  Changed toggle to 'C' key (for Compact/Full)
  
  Change:    • UIHudManager.js line ~150
             • 1 line modification
             • <1 minute to deploy

FIX #3: Poetry System Transformation
───────────────────────────────────────────────────────────────────────────────
  PROBLEM:   Static poetry didn't reflect network state
  SOLUTION:  Dynamic poetic feed reflecting real-time network emotions
  
  Specs:     • Generates every 8-20 seconds (random)
             • 6 state categories detected
             • 36 poetic templates (6 × 6)
             • Adds [tag] suffixes for clarity
             • <0.02ms/frame performance

FEATURE #1: Category Legend Panel
───────────────────────────────────────────────────────────────────────────────
  PURPOSE:   Visual reference for all 16 node categories
  
  Specs:     • Fixed left-upper panel
             • All 16 categories with color dots
             • Scrollable for mobile
             • Hover effects
             • Position: top 60px, left 16px

FEATURE #2: Node Hover Tooltip
───────────────────────────────────────────────────────────────────────────────
  PURPOSE:   Quick-look node info without opening full panel
  
  Specs:     • Triggers at 2-10m from camera
             • Displays: CODE | CATEGORY | METRICS
             • Follows node position
             • Auto-hides outside range
             • <0.05ms/frame performance

ENHANCEMENT: Node Linking 2.0
───────────────────────────────────────────────────────────────────────────────
  PURPOSE:   Improved intuitive interaction model
  
  LMB:       • Click node = select
             • Click 2nd node = link
             • Click empty = deselect
  
  RMB:       • Click node = context menu
             • Click empty = cancel linking
             • Long-press (300ms) = focus camera
  
  ESC:       • Close all UI
             • Deselect nodes
             • Cancel linking mode
