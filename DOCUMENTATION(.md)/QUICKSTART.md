## 🔧 Quick Customization Cheat Sheet

Want to change something fast?

### Line Too Thin?
Edit `NeonLinkVisuals.js`:
```javascript
baseLineWidth: 3,    // was 2
maxLineWidth: 10,    // was 8
```

### Too Many Particles?
```javascript
particleCount: 1,    // was 3
```

### Glow Too Strong?
```javascript
bloomIntensity: 1.0,  // was 1.5
```

### Want Performance?
Use "Performance Mode" preset (see VISUAL_TUNING_GUIDE.md)

## 🎮 Interactive Guide

### Action → What You See

| Action | Visual Result |
|--------|---------------|
| Click & drag nodes | Cyan preview curve follows cursor |
| Hover over node | Node glows (category color) |
| Drag to valid node | Curve stays cyan, target glows |
| Drag to invalid node | Curve turns red, target red |
| Release over valid | Neon link appears, particles flow |
| Release over invalid | Red pulse animates backward |
| Right-click link | Context menu appears |
| Delete link | Shatter effect, fragments fade |
| Move node (drag) | Links stretch, tension effect |
| Set priority high | Link pulses faster, brighter |
| Set priority low | Link pulses slower, dimmer |

## 🆘 Something Not Working?

### Link doesn't glow?
- Check console for errors
- Verify NodeLinkingSystem.js imported NeonLinkVisuals

### FPS is low?
- Use "Performance Mode" preset from VISUAL_TUNING_GUIDE.md
- Reduce particleCount

### Colors look wrong?
- Check browser console
- Verify Three.js is loaded

### Need help?
- Check NEON_VISUAL_SYSTEM.md "Debugging" section
