INTEGRATION (4 SIMPLE STEPS)
================================================================================

STEP 1: Import (main.js, line ~96)
────────────────────────────────────────────────────────────────────────────

Add import:
  import { applyHitProxyIntegration, setupHitProxyDebugAPI } 
    from './_HitProxyIntegrationPatch.js';


STEP 2: Initialize (createAINodes method, after NodeLinkingSystem)
────────────────────────────────────────────────────────────────────────────

Add after:   this.linkingSystem = new NodeLinkingSystem(...)

const hitProxyResult = applyHitProxyIntegration(
    this.scene,
    this.aiNodes,
    this.linkingSystem,
    {
        proxyRadius: 0.7,
        layer: 10,
        autoSync: true,
        autoHookSpawning: true
    }
);

this.hitProxySystem = hitProxyResult.hitProxySystem;
this.safeProxyRaycaster = hitProxyResult.safeRaycaster;

setupHitProxyDebugAPI();

console.log('[main.js] Hit-Proxy System initialized ✓');


STEP 3: Update Loop (animate method)
────────────────────────────────────────────────────────────────────────────

Add in render loop before renderer.render():

if (this.hitProxySystem) {
    this.hitProxySystem.update(deltaTime);
}

→ Check console for errors

→ Run: HitProxyDebug.testRaycast()
→ Verify raycast is hitting proxies

================================================================================
WHAT CHANGED
================================================================================

BEFORE:
- Raycasting on real node geometry
- Risk of geometry.computeBoundingSphere() mutations
- Potential frozen BufferGeometry access issues

AFTER:
- ONLY raycasting on invisible hit-proxies
- Real visuals 100% immutable
- Zero geometry mutation possible
- Deterministic selection behavior
