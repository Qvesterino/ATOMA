🧠 WHAT IS SYNERGYENGINE?
═══════════════════════════════════════════════════════════════════════════════

SynergyEngine analyzes emergent behavior and visual properties of connections
between AI consciousness nodes in the ATOMA network.

It transforms raw node pairs into meaningful synergy analysis with:
  • Type classification (7 types)
  • Intelligent scoring (0.0-3.0)
  • Energy calculation (0.0-1.0)
  • Visual recommendations (color, pulse, warp, glitch, thickness)

⚡ QUICK START (5 MINUTES)
═══════════════════════════════════════════════════════════════════════════════

1. Import the engine
   import { SynergyEngine } from './SynergyEngine';

2. Create instance
   const engine = new SynergyEngine(nodesMap);

3. Evaluate a link
   const result = engine.evaluateLink(link);

4. Extract visuals
   const visual = result.visual;
   // color, pulseSpeed, warpIntensity, thickness, glitch

5. Apply to shader
   uniforms.linkColor = new THREE.Color(visual.color);
   uniforms.pulseSpeed = visual.pulseSpeed;

6. Render with synergy!

  validateSynergy(link, minScore)  → {valid, result}
  getGroupVisual(linkIds[])        → SynergyVisual

Management
  setNodes(nodes)                  → void
  setLinks(links)                  → void
  clearCache()                     → void
