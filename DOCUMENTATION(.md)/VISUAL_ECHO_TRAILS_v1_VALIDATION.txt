🎯 WHAT IT IS
─────────────────────────────────────────────────────────────────────────────
Pure shader-level visual enhancement adding echo trails to link pulses.
Makes network flow feel smoother and more alive through delayed pulse copies.

SHADER ONLY — No gameplay impact, no state changes, additive visual only

📊 ECHO TRAIL MODEL
─────────────────────────────────────────────────────────────────────────────

FORWARD ECHOES (Synergy > 0.70):
  Primary Pulse:  fract(time × 0.95)
  Echo 1:         fract((time - 0.10) × 0.95) @ 0.65 intensity
  Echo 2:         fract((time - 0.22) × 0.95) @ 0.35 intensity

REVERSE ECHO (Synergy > 0.85):
  Position:       fract(visualTime × 0.95)
  Intensity:      0.18 × echoStrength × 0.60
  Purpose:        Subtle "rewind" effect at extreme harmony

GATING (Mandatory):
  Gate = smoothstep(0.70, 0.90, synergy)
  Echo Strength = echoOpacity × gate
  → No echo visible until synergy > 0.70
  → Smooth transition 0.70–0.90
  → Full strength above 0.90

🔧 SHADER UNIFORMS
─────────────────────────────────────────────────────────────────────────────

PER-FRAME (Updated each frame):
  uTime          [≥0 seconds]        Game time
  uVisualTime    [≥0 seconds]        Visual time (may be reversed)
  uSynergy       [0–1]               Network synergy

PULSE SHAPE:
  uPulseSpeed    [Default: 0.95]     Cycles per second
  uPulseWidth    [Default: 0.085]    Pulse band width
  uBaseIntensity [Default: 0.20]     Base glow strength

ECHO PARAMETERS:
  uEchoOpacity   [Default: 0.25]     Max echo visibility
  uEchoDelay1    [Default: 0.10]     First echo delay (seconds)
  uEchoDelay2    [Default: 0.22]     Second echo delay (seconds)
  uEchoAtten1    [Default: 0.65]     First echo attenuation
  uEchoAtten2    [Default: 0.35]     Second echo attenuation

SYNERGY GATING:
  uEchoGateMin   [Default: 0.70]     Echo activation threshold
  uEchoGateMax   [Default: 0.90]     Full strength threshold

REVERSE ECHO:
  uReverseThreshold [Default: 0.85]  Reverse echo activation
  uReverseStrength  [Default: 0.60]  Reverse echo intensity

🎓 TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────

ISSUE: No echo visible even at high synergy

CHECK:
  1. game.echoTrailsIntegration.enabled = true?
  2. game.nodeDynamicMetrics.avgSynergy > 0.70?
  3. game.echoTrailsIntegration.getStats().linksEnhanced > 0?
  4. Shader compilation errors in console?

FIX:
  game.echoTrailsIntegration.enable()
  game.echoTrailsIntegration.setIntensity(0.35)
  Check console for shader warnings

───────────────────────────────────────────────────────────────────────────────

ISSUE: Echo appears but only faintly

CHECK:
  1. Check uEchoOpacity: game.echoTrailsSystem.params.echoOpacity
  2. Check gating calculation at your synergy level
  3. Link color too dark?

FIX:
  game.echoTrailsIntegration.setIntensity(0.4)
  game.echoTrailsSystem.params.pulseWidth = 0.12 (wider pulse)

───────────────────────────────────────────────────────────────────────────────

ISSUE: Shader compilation failed

CHECK:
  1. Browser console for GLSL errors
  2. WebGL version compatibility
  3. Graphics card support

FIX:
  Disable: game.echoTrailsIntegration.disable()
  Check: game.echoTrailsIntegration.getDebugInfo().validation

───────────────────────────────────────────────────────────────────────────────

ISSUE: Performance drop with many links

CHECK:
  1. Material count: game.echoTrailsIntegration.getStats()
  2. Frame time: DevTools Performance tab
  3. GPU load

FIX:
  Reduce intensity: game.echoTrailsIntegration.setIntensity(0.15)
  Or disable entirely: game.echoTrailsIntegration.disable()
