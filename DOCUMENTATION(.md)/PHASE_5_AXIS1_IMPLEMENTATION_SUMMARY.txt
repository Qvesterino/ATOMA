IMPLEMENTATION OVERVIEW
================================================================================

Stress Coupling enables networks to influence each other through environmental
pressure. High corruption in one network subtly increases ambient stress in
adjacent networks, creating a shared sense of ecological pressure.

KEY PRINCIPLE: Pressure, not damage. Stress spreads like weather, not warfare.

CORE MECHANICS
================================================================================

STRESS PROPAGATION FORMULA:
  ambient_stress = average(neighbor_stress) × distance_dampening × 0.05
  capped to: max 0.02 per frame

DISTANCE DAMPENING:
  1 hop: 100% (full effect)
  2 hops: 50% (half strength)
  3 hops: 20% (minimal)
  4+ hops: 0% (fully decoupled)

AMBIENT STRESS DECAY:
  stress *= 0.85 per frame
  half-life: ~4 frames (66ms @ 60fps)
  full dissipation: ~8-10 frames (150ms @ 60fps)

EFFECT ON GAMEPLAY:
  ambient_stress → increases corruption emergence probability
  modifier = 1 + (ambient_stress × 0.5)
  (e.g., 0.1 ambient stress = +5% corruption emergence)

================================================================================
SAMPLING & PERFORMANCE
================================================================================

SAMPLING INTERVAL: 100ms (10x per second, not every frame)
  - Networks change stress slowly, don't need frame-rate updates
  - Ambient stress still decays every frame for smooth feel
  - ~0.2ms per sample, negligible CPU cost

DECAY SYSTEM: Runs every frame
  - Multiplicative decay ensures natural dissipation
  - No accumulation or runaway
  - <0.1ms total overhead per frame

CPU IMPACT: <0.1ms per frame in normal case
MEMORY IMPACT: <100KB total
SCALING: O(1) stress lookup, efficient for 100+ networks

SAFETY & CONSTRAINTS
================================================================================

✅ "No new stats"
   - ambientStress is metadata only (not UI, not save state)
   - No core stat modifications

✅ "No new feedback loops"
   - All stress decays passively (15% per frame)
   - No cascade or self-reinforcement
   - Decay rate > injection rate always

✅ "Coupling is transient and reversible"
   - All stress dissipates in ~150ms when source pressure drops
   - Full isolation if networks separate
   - No persistent dominance states

✅ "No TIER 1 modifications"
   - Pure overlay layer on top of existing systems
   - LinkCorruptionTransmission_v1 core methods untouched

✅ "No power escalation"
   - Read-only modulation only (0.85-1.15 range in normal use)
   - Weak networks still function at full efficiency

✅ "Bounded and symmetric"
   - Hard caps on injection (2% per frame max)
   - Distance dampening prevents global escalation
   - All networks affected equally by same conditions

DEBUG API REFERENCE
================================================================================

AVAILABLE COMMANDS (via window.linkCorruptionDebug):

toggleStressCoupling()
  → Enable/disable stress coupling system

stressCouplingStats()
  → View current ambient stress in all pressurized networks
  → Shows which networks are under environmental pressure

stressCouplingHistory()
  → View last 20 coupling events
  → Timestamp, network ID, stress injection, current ambient

getNetworkAmbientStress(networkId)
  → Get ambient stress for specific network (0-1)
  → Returns float value and percentage

networkAdjacency()
  → View network topology and distance relationships
  → Shows connections, distance, and dampening factors

clearAmbientStress()
  → Force clear all ambient stress (testing only)
  → Useful for resetting state between tests

EXAMPLE USAGE:
  window.linkCorruptionDebug.stressCouplingStats();
  window.linkCorruptionDebug.toggleStressCoupling();
  const stress = window.linkCorruptionDebug.getNetworkAmbientStress('network_1');
