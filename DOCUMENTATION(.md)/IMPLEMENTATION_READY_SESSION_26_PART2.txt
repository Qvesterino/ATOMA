SUPPRESSION RULES
────────────────────────────────────────────────────────────────────────────────

RULE 1: Emissive Reduction
  Event boosts core emissive → Suppressed 80% → Redirected to aura

RULE 2: Opacity Clamping
  Event reduces core opacity → Clamped to 0.85+ → Aura modulates instead

RULE 3: Overlay Prevention
  Event adds layers over core → Blocked by CoreAuthority → Aura receives layer

RULE 4: Material Guard
  Event replaces core material → Detected and restored → Aura material changed
