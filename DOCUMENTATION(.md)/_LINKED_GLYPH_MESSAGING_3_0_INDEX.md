## 🎯 Key Concepts Quick Reference

### Message Structure
```
SENTENCE = SUBJECT + STATE + LINK
WORD = 1-5 glyphs encoding concept
GLYPH = Procedural shape with semantic meaning
```

### Glyph Roles
| Role | Shapes | Meaning |
|------|--------|---------|
| SUBJECT | Dot, Shard, Hex | "I am..." |
| STATE | Lotus, Shard | "I feel..." |
| TENDENCY | Triangle, Shard | "I am becoming..." |
| LINK | Diamond, Arrow | "Our bond is..." |
| CONTEXT | Ring, Fractal | "In this context..." |

### Color Encoding
| Color | Meaning | Metric |
|-------|---------|--------|
| Cyan | Strong | Synergy ≥70% |
| Red | Corrupt | Corruption ≥60% |
| Magenta | Peaceful | Harmony ≥70% |
| Yellow-Green | Balanced | Neutral state |

### Transport Speed
```
Base: 2.0 units/sec
Boost: +synergy (up to ×1.5)
Penalty: -instability (down to ×0.7)
Acceleration: +harmony (up to ×1.2)
```
