================================================================================
WHAT IS IT?
================================================================================
Bridge that binds CPU personality signals to GPU shader uniforms.
Enables subtle visual effects driven by node personality state.
Non-breaking, fully reversible, backward compatible.

================================================================================
KEY UNIFORMS (Per-Node)
================================================================================
uClarity       0–1  From: personalityVisual.clarityBoost
uResonance     0–1  From: personalityVisual.resonanceBoost
uEntropy       0–1  From: personalityVisual.entropyPenalty
uFocus         0–1  From: personalityVisual.focusShift
uCorruption    0–1  From: personalityVisual.corruptionSignal
uEnergy        0–1  From: visualMetrics.energyNorm
uQuality       0–1  From: visualMetrics.qualityNorm

Per-Link (optional):
uLinkGlow      0–1  From: visualGlow.glowIntensity
uLinkQuality   0–1  From: visualGlow.qualityNorm
uLinkCorruption 0–1 From: visualGlow.corruptionPulse

================================================================================
INTEGRATION (5 STEPS)
================================================================================

1) IMPORT
   import { PersonalityShaderBridge_v1 } from './PersonalityShaderBridge_v1.js';

2) CONSTRUCTOR FIELD
   this.personalityShaderBridge = null;

3) INITIALIZE (in createAINodes, after PersonalityVFXLayer_v1)
   this.personalityShaderBridge = new PersonalityShaderBridge_v1(
       this.scene,
       this.aiNodes,
       { enableDebug: false, enableWarnings: false }
   );
   console.log('[main.js] PersonalityShaderBridge_v1 initialized ✓');

4) UPDATE LOOP (in animate, after PersonalityVFXLayer_v1.update)
   if (this.personalityShaderBridge && this.scene) {
       this.personalityShaderBridge.update(deltaTime);
   }

5) CLEANUP (in switchMode, after PersonalityVFXLayer)
   if (this.personalityShaderBridge) {
       if (this.personalityShaderBridge.dispose) {
           this.personalityShaderBridge.dispose();
       }
       this.personalityShaderBridge = null;
   }

================================================================================
USING UNIFORMS IN SHADERS
================================================================================

OPTION A: onBeforeCompile (Recommended)
-------
material.onBeforeCompile = (shader, renderer) => {
    // Bridge automatically injects uniforms here
    // shader.uniforms now includes: uClarity, uResonance, uEntropy, etc.
    
    shader.fragmentShader = shader.fragmentShader.replace(
        '#include <emissive_fragment>',
        `
        #include <emissive_fragment>
        emissiveColor.rgb *= (1.0 + uClarity * 0.4);  // Clarity brightens
        emissiveColor.rgb += vec3(uCorruption * 0.3); // Corruption tints
        `
    );
};

OPTION B: ShaderMaterial
-------
const material = new THREE.ShaderMaterial({
    uniforms: {
        baseColor: { value: new THREE.Color(0x00ff00) }
        // Personality uniforms injected by bridge
    },
    fragmentShader: `
        uniform float uClarity;
        uniform float uCorruption;
        
        void main() {
            vec3 color = vec3(0.0, 1.0, 0.0);
            color *= (1.0 + uClarity * 0.4);           // Clarity effect
            color += vec3(uCorruption * 0.3);          // Corruption effect
            gl_FragColor = vec4(color, 1.0);
        }
    `
});

OPTION C: MeshStandardMaterial
-------
const material = new THREE.MeshStandardMaterial({
    color: 0x00ff00,
    emissive: 0x00ff00
});
// Bridge automatically hooks this material
// Uniforms available in onBeforeCompile

================================================================================
COMMON SHADER EFFECTS
================================================================================

EFFECT 1: Emissive Modulation
----
#include <emissive_fragment>
emissiveColor.rgb *= (1.0 + uClarity * 0.4);              // Clarity brightens
emissiveColor.rgb = mix(emissiveColor.rgb, 
                        vec3(1.0, 0.5, 0.0) * emissiveColor.rgb,
                        uCorruption * 0.25);              // Corruption tints

EFFECT 2: Color Tinting (Corruption)
----
vec3 tint = mix(baseColor, vec3(1.0, 0.3, 0.0), uCorruption * 0.25);

EFFECT 3: Brightness (Energy)
----
color *= (1.0 + uEnergy * 0.3);

EFFECT 4: Noise/Distortion (Entropy)
----
vec3 distorted = position + normal * (uEntropy * noise * 0.01);

EFFECT 5: Wobble (Focus)
----
float wobble = sin(uTime * 3.0) * uFocus * 0.05;
vec3 wobbled = position + normal * wobble;

================================================================================
SAFETY RULES (IMPORTANT!)
================================================================================

✓ DO:
  - Read uniforms in shader code (they have no effect if not used)
  - Mix personality effects with existing shader logic
  - Call dispose() on world transitions
  - Check for null before updating
  - Use optional chaining (?.)

✗ DON'T:
  - Modify PersonalityVisualAdapter or NodePersonalitySystem2_0
  - Rewrite core shader files
  - Permanently replace materials
  - Leave NaN/Infinity values (bridge clamps to 0–1)
  - Forget to cleanup on world reset

================================================================================
PERFORMANCE
================================================================================

Per-frame cost:        <2ms for 200 nodes
Mesh scan (throttled): Every 30 frames (configurable)
Memory per material:   ~100 bytes
Total for 200 nodes:   ~1–2 MB

Optimize by:
  - Increasing meshScanInterval (scan less often)
  - Disabling enableDebug and enableWarnings
  - Reducing uniformLerpFactor (less smoothing)

================================================================================
TROUBLESHOOTING
================================================================================

Issue: Uniforms not visible in shader
→ Ensure shader is compiled (rendered at least once)
→ Check shader.uniforms in onBeforeCompile callback

Issue: Effects not showing
→ Verify uniforms are used in fragment/vertex shader code
→ Check that PersonalityVisualAdapter is running
→ Enable debug mode: enableDebug: true

Issue: Performance drop
→ Call clearCache() during world transitions
→ Reduce mesh scan frequency
→ Check for shader compilation errors

Issue: Conflicts with existing hooks
→ Bridge automatically wraps existing onBeforeCompile
→ No manual fix needed – it's designed for this
