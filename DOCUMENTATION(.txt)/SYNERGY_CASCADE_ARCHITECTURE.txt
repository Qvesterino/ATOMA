CASCADE DETECTION REQUIREMENTS (SynergyChainReaction_v1)
═══════════════════════════════════════════════════════════════════════════════

For cascade to trigger on a node, ALL conditions must be met:

1. Synergy Threshold
   - node.userData.synergyBonus.tier ≥ 0.75 (normalized)
   - From Week 19 synergy calculation

2. Resonance Similarity Check
   - Between current node and trigger node
   - Similarity = 1.0 - |resonanceA - resonanceB|
   - Must exceed: resonanceSimilarityThreshold (0.6)

3. Personality Compatibility Check
   - Between current node and trigger node
   - Compatibility = 1.0 - |harmonyA - harmonyB|
   - Must exceed: personalityCompatibilityThreshold (0.5)

4. Intensity Threshold
   - Cascade intensity ≥ minimumIntensity (0.1)
   - Dies out when dropped below

5. Hop Limit
   - hopIndex < maxHops (8)
   - Stops propagation after 8 levels deep

If ANY condition fails, cascade stops propagating through that link.
