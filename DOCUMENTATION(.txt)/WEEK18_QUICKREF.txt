📌 WHAT IS IT?
Selection-aware GPU shader intensity amplification. When a node is selected, its
archetype shader mode brightens and becomes more visually active.

┌─ VISUAL IMPACT ─────────────────────────────────────────────────────────────┐
│ UNSELECTED NODE:  intensity 0.50, distortion 0.20 (normal)                 │
│ SELECTED NODE:    intensity 0.68, distortion 0.25 (bright, active) ✨      │
│ DESELECTED:       Smooth fade back to normal (≈0.3s)                        │
└─────────────────────────────────────────────────────────────────────────────┘

🔄 STATE MACHINE

IDLE STATE:
  Node not selected
  All shader states at base values
  No hooks active

SELECTION EVENT:
  selectionCore.selectNode(node) triggered
    → Store base intensity/distortion
    → Multiply by boost factors
    → Fade smoothly over 0.3s

ACTIVE STATE:
  Node selected
  Shader state target = boosted value
  EMA smoothing interpolates to target
  Frame rate independent

DESELECTION EVENT:
  selectionCore.deselectNode() triggered
    → Restore base intensity/distortion
    → Fade smoothly back to normal
