┌─ SYSTEM OVERVIEW ──────────────────────────────────────────────────────────┐
│                                                                            │
│  NODE METRICS (Updated every frame)                                        │
│       ↓                                                                    │
│       • loadRatio, instability, corruption, harmony                        │
│       ↓                                                                    │
│  FATIGUE SYSTEM (Checks stress conditions)                                 │
│       ├─ If stressed → ACCUMULATE (fatigue increases)                      │
│       ├─ If healthy → RECOVER (fatigue decreases)                          │
│       └─ If mixed → STABLE (fatigue holds)                                 │
│       ↓                                                                    │
│  FATIGUE STORAGE (Per node)                                                │
│       • node.userData.fatigue ∈ [0.0, 1.0]                                 │
│       ↓                                                                    │
│  SOFT MULTIPLIERS (Applied to other systems)                               │
│       • Harmony Rate ×(1 - fatigue×0.40)                                   │
│       • Synergy ×(1 - fatigue×0.35)                                        │
│       • Corruption Decay ×(1 - fatigue×0.30)                               │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘
