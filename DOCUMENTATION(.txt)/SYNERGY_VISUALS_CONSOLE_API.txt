================================================================================
SYNERGY VISUAL EFFECTS v1.0 — CONSOLE API REFERENCE
================================================================================

Access systems via: window.atoma.synergyPulseVisuals
                   window.atoma.visualNetworkTimeElasticity

================================================================================

SYNERGY PULSE VISUALS COMMANDS
================================================================================

// ENABLE/DISABLE
window.atoma.synergyPulseVisuals?.setEnabled(true)   // Enable pulse effect
window.atoma.synergyPulseVisuals?.setEnabled(false)  // Disable pulse effect

// MANUAL CONTROL
window.atoma.synergyPulseVisuals?.setAverageSynergy(0.8)  // Set average synergy [0..1]

// DEBUGGING
window.atoma.synergyPulseVisuals?.dispose()  // Clean up and remove pulse

// CHECK STATUS
window.atoma.synergyPulseVisuals  // Returns system object

================================================================================

VISUAL TIME ELASTICITY COMMANDS
================================================================================

// ENABLE/DISABLE
window.atoma.visualNetworkTimeElasticity?.setEnabled(true)   // Enable time elasticity
window.atoma.visualNetworkTimeElasticity?.setEnabled(false)  // Disable time elasticity

// MANUAL CONTROL
window.atoma.visualNetworkTimeElasticity?.setAverageSynergy(0.9)  // Set average synergy [0..1]

// QUERY STATE
window.atoma.visualNetworkTimeElasticity?.isRewinding()      // Returns boolean
window.atoma.visualNetworkTimeElasticity?.getFadeAlpha()     // Returns [0..1]
window.atoma.visualNetworkTimeElasticity?.getVisualTime()    // Returns current visual time
window.atoma.visualNetworkTimeElasticity?.getStateInfo()     // Returns full state object

// DEBUGGING
window.atoma.visualNetworkTimeElasticity?.dispose()  // Clean up

// CHECK STATUS
window.atoma.visualNetworkTimeElasticity  // Returns system object

================================================================================

STATE INFO OUTPUT (Time Elasticity)
================================================================================

Command:
  window.atoma.visualNetworkTimeElasticity?.getStateInfo()

Output Example:
{
  isRewinding: true,               // Boolean: is effect active?
  fadeAlpha: 0.850,                // Number [0..1]: effect intensity
  visualTime: 45.230,              // Number: current visual animation time
  gameTime: 50.480,                // Number: current game world time
  timeOffset: 5.250,               // Number: how far back visual time is
  avgSynergy: 0.900,               // Number [0..1]: current average synergy
  sustainStartTime: 45.230,        // Number: when high synergy started
  sustainedDuration: 5.250         // Number: how long sustained above 0.85
}

================================================================================

STORED IN GLOBAL WINDOW
================================================================================

Visual Animation Time Parameter (updated every frame):
  window.VISUAL_TIME  // Use this in any animation calculations

Example Usage:
  const pulsePhase = Math.sin(window.VISUAL_TIME * frequency) * amplitude

When time elasticity is active:
  window.VISUAL_TIME runs BACKWARD at 40% speed
  All animations using this parameter play in reverse

When time elasticity is inactive:
  window.VISUAL_TIME = window.game.time (normal forward time)
  All animations play normally

QUICK TEST SEQUENCE
================================================================================

// 1. Check both systems are initialized
console.log(window.atoma.synergyPulseVisuals)           // Should be object
console.log(window.atoma.visualNetworkTimeElasticity)   // Should be object

// 2. Test synergy pulse
window.atoma.synergyPulseVisuals?.setAverageSynergy(0.7)  // Enable pulse
// Should see nodes gently breathing (±3% scale)
window.atoma.synergyPulseVisuals?.setAverageSynergy(0.3)  // Disable pulse
// Pulse should fade out

// 3. Test time elasticity activation
window.atoma.visualNetworkTimeElasticity?.setAverageSynergy(0.9)
// Wait 5 seconds...
window.atoma.visualNetworkTimeElasticity?.getStateInfo()
// Should show: isRewinding = true, sustainedDuration >= 5

// 4. Test time elasticity deactivation
window.atoma.visualNetworkTimeElasticity?.setAverageSynergy(0.5)
window.atoma.visualNetworkTimeElasticity?.getStateInfo()
// Should show: isRewinding = false, fade alpha decreasing

// 5. Monitor visual time
setInterval(() => {
  const info = window.atoma.visualNetworkTimeElasticity?.getStateInfo()
  console.log(`Visual Time: ${info?.visualTime?.toFixed(2)}, Fade: ${info?.fadeAlpha?.toFixed(2)}`)
}, 1000)

MANUAL INTEGRATION TESTING
================================================================================

For custom animation systems that want to use VISUAL_TIME:

JavaScript:
  const animationTime = window.VISUAL_TIME
  const phase = Math.sin(animationTime * frequency) * amplitude
  material.uniforms.uPhase.value = phase

Three.js Materials:
  uniform float uVisualTime;
  
  void main() {
    float phase = sin(uVisualTime * frequency) * amplitude;
    // Use phase in calculation
  }

Dynamic Update:
  // In animation loop
  if (window.VISUAL_TIME !== undefined) {
    // Visual time is available - time elasticity system active
    material.uniforms.uVisualTime.value = window.VISUAL_TIME
  }

TROUBLESHOOTING
================================================================================

Issue: Systems not found in window.atoma
Cause: Systems may not have been initialized yet
Solution: Wait a moment after game loads
Test: window.atoma.synergyPulseVisuals should be defined

Issue: Synergy pulse not visible even with high synergy
Cause: Effect only triggers for synergy > 0.6
Solution: Check avgSynergy value: console.log(window.game.nodeDynamicMetrics?.avgSynergy)
Test: window.atoma.synergyPulseVisuals?.setAverageSynergy(0.7)

Issue: Time reversal not appearing after 5 seconds
Cause: avgSynergy may not be > 0.85 sustained
Solution: Check state: window.atoma.visualNetworkTimeElasticity?.getStateInfo()
Test: Manually set avgSynergy to 0.95 and wait 5 seconds

Issue: Effects causing performance drop
Cause: Too many nodes or very high frame rate
Solution: Reduce node count or enable performance mode
Test: console.log('FPS:', performance metrics) during effect
