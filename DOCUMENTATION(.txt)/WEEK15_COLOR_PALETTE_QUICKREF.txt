================================================================================
THE 7 GPU UNIFORMS
================================================================================

Material uniforms automatically created:

uArchetypePrimaryColor       Main archetype color (RGB)
uArchetypeSecondaryColor     Ascension transition color (RGB)
uArchetypeAccentColor        Peak highlight color (RGB)
uArchetypeColorBlend         Blend 0–1 (primary to secondary)
uArchetypeWarmShift          -1 to +1 (cool to warm)
uArchetypeSaturation         0–2 (desaturated to super-vibrant)
uArchetypeAscensionGlow      0–1 (glow from ascension)

These are injected via material.onBeforeCompile (safe, non-invasive)

In shaders, use them:
  arcColor = mix(uArchetypePrimaryColor, uArchetypeSecondaryColor, uArchetypeColorBlend);
  arcColor *= uArchetypeSaturation;

================================================================================
HOW COLORS WORK
================================================================================

Per frame, for each node:

1. Read ascensionModified from Week 13
2. Compute colorBlend (0–1):
   - Linear archetypes: ascensionModified directly
   - Exponential: ascensionModified² (slow start, spike)
   - Sigmoid: S-curve (smooth transition)
   - Ease-in-out: peaks mid-range

3. Compute warmShift (-1 to +1):
   - Clarity → cool (-negative)
   - Corruption → warm (+positive)
   - Entropy → warm
   - Resonance/Harmony → cool
   - Energy → warm
   - Archetype base temperature applied

4. Compute saturation (0–2):
   - Base: 0.85
   - +ascensionModified * 0.5
   - For exponential archetypes: +ascMod² * 0.3

5. Smooth via EMA (alpha=0.15):
   - current = current * 0.85 + target * 0.15
   - Results in ~0.4–0.6s smooth transitions

6. Apply to material uniforms:
   - Colors interpolated
   - Saturation multiplied
   - Warm shift applied
   - Glow = ascensionModified²

================================================================================
COMMON ISSUES & FIXES
================================================================================

Issue: Colors not changing
Fix:   1. Check archetypeCurves.update() called first
       2. Check archetype evolution: node.userData.archetypeEvolution
       3. Enable debugEnabled: true

Issue: Colors too desaturated
Fix:   Colors are subtle (0.7–2.0 saturation). To make more visible:
       - Wait for higher ascension (saturation increases)
       - Check personality signals (corruption/chaos = more vivid)

Issue: Warm shift not visible
Fix:   Warm shift is subtle (-1 to +1). Visible through:
       - Warlock (corruption pushes warm) vs Sage (clarity pushes cool)
       - Check corruption signal: high = warm (orange→red)

Issue: Performance is slow
Fix:   Check DevTools - should be <0.6ms per 200 nodes
       If slower, may be linked to other systems
