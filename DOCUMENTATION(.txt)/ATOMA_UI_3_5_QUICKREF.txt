COMPLETE MOUSE BEHAVIOR
================================================================================

LMB (LEFT MOUSE BUTTON)
──────────────────────────────────────────────────────────────────────────────
LMB on Node:
  ├─ No selection → SELECT node
  │   └─ Show: TopBar, Badge, Highlight, Label, Panel
  │
  ├─ Same node → DO NOTHING (stay selected)
  │   └─ All visuals remain active
  │
  └─ Different node → CREATE LINK + SELECT new
      ├─ createLink(old → new)
      ├─ Deselect old (hide visuals)
      └─ Select new (show visuals)

LMB on Empty Space:
  ├─ DESELECT all
  ├─ Hide: TopBar, Badge, Highlight, Label, Panel
  └─ Close: Context menu, all UI


RMB (RIGHT MOUSE BUTTON)
──────────────────────────────────────────────────────────────────────────────
RMB on Selected Node WITH Links:
  ├─ UNLINK ALL (bidirectional)
  ├─ Keep selected (no deselect)
  ├─ Keep visuals (TopBar, Badge, Highlight, Label stay)
  └─ Node returns to "clean pre-link state"

RMB on Selected Node WITHOUT Links:
  ├─ HIGHLIGHT BLINK (visual feedback)
  ├─ Opacity pulse 150ms
  └─ Message: "No links to unlink"

RMB on Empty Space:
  └─ DO NOTHING (no action)


E KEY (CONTEXT MENU)
──────────────────────────────────────────────────────────────────────────────
E with Selected Node:
  ├─ OPEN context menu
  └─ Options: Inspect, Focus, Link, Disconnect, Mark, Close

E without Selection:
  └─ BLOCKED (no menu appears)


ESC KEY (CLOSE ALL)
──────────────────────────────────────────────────────────────────────────────
ESC Anytime:
  ├─ CLOSE all UI
  └─ DESELECT everything

================================================================================
UNLINKING BEHAVIOR
================================================================================

When you RMB on a selected node WITH existing links:

1. System finds ALL connections:
   - Outgoing links FROM this node
   - Incoming links TO this node

2. Bidirectional cleanup:
   - Removes node from all link arrays
   - Calls runtime.unlink() callbacks
   - Returns node to clean state

3. Node stays selected:
   - Selection NOT cleared
   - Visuals NOT removed
   - TopBar remains visible
   - Node ready for new links

4. Non-destructive:
   - Node data preserved
   - Link data preserved
   - Only array entries removed
   - Fully reversible if desired

Example Flow:
  Node A links: [B, C, D]
  Node B links: [A]
  Node C links: [A]
  
  RMB on A
  
  Node A links: []  (cleared)
  Node B links: []  (A removed)
  Node C links: []  (A removed)
  
  Selection: A (still selected)
  Visuals: All active

================================================================================
INTERACTION SEQUENCES
================================================================================

SEQUENCE 1: Basic Selection
─────────────────────────────────────────────────────────────────────────────
1. LMB on Node
   → selectNode(node)
   → TopBar shows: "SELECTED NODE: [code]"
   → Badge shows
   → Highlight appears
   → Label floats
   → Panel opens

2. LMB on Empty
   → deselectNode()
   → TopBar hides (150ms fade)
   → Badge hides
   → Highlight removed
   → Label hides
   → Panel closes


SEQUENCE 2: Linking Two Nodes
─────────────────────────────────────────────────────────────────────────────
1. LMB Node A
   → Select A, show all visuals

2. LMB Node B
   → createLink(A → B)
   → Hide A visuals
   → Select B, show B visuals

Result: A has outgoing link to B
        B is now selected
        A and B visually distinct


SEQUENCE 3: Unlinking
─────────────────────────────────────────────────────────────────────────────
1. LMB Node A (with links: [B, C])
   → Select A, show visuals

2. RMB on A
   → unlinkAll(A)  [both outgoing and incoming]
   → A.links = []
   → All other nodes remove A from their links
   → A stays selected
   → Visuals stay active
   → TopBar still visible

Result: All connections removed
        Node ready for new links


SEQUENCE 4: Context Menu (E key)
─────────────────────────────────────────────────────────────────────────────
1. LMB Node
   → Select, show visuals

2. E Key
   → contextMenu.open()
   → Show: Inspect, Focus, Link, Disconnect, Mark, Close

3. Click "Inspect Node"
   → Inspect panel focused
   → Selection stays active

4. ESC or Menu Click "Close"
   → Menu closes
   → Selection stays active
