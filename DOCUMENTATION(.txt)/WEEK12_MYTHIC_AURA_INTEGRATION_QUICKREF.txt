================================================================================
2. WHAT IT DOES
================================================================================

Reads mythic evolution signals from MythicEvolutionFX_v1:
  ✓ auraBoost (0–1)     → Scales aura intensity
  ✓ fxIntensity (0–1)   → Drives distortion/thickness
  ✓ glowIntensity (0–1) → Boosts glow/bloom
  ✓ hintColorHex        → Color hint for tier

Applies to aura systems WITHOUT modifying them:
  ✓ NodeAuraSystem_v1 auras get intensity + color boost
  ✓ LinkAuraSystem_v1 auras get intensity + radius boost
  ✓ All via shader uniform updates (safe, non-destructive)

Result:
  ✓ Mythic nodes/links glow significantly brighter
  ✓ Colors shift toward tier-based hints
  ✓ Smooth 0.4–0.6s animations on tier changes
  ✓ Transcendent state = maximum visual impact

================================================================================
3. ENHANCEMENT FORMULAS
================================================================================

INTENSITY BOOST:
  boosted = base * (1 + auraBoost * 0.5)
  
  Dormant:      auraBoost=0.0  → no boost
  Mythic:       auraBoost=0.9  → +45% intensity
  Transcendent: auraBoost=1.0  → +50% intensity

COLOR TINTING:
  colorInfluence = 0.0 to 0.25 based on tier
  
  Dormant:      influence=0.0  (no color shift)
  Mythic:       influence=0.20 (purple tint 20%)
  Transcendent: influence=0.25 (yellow tint 25%)

GLOW ENHANCEMENT:
  glowIntensity = 0.0 to 0.80 based on tier
  
  Dormant:      glow=0.0  (no glow)
  Mythic:       glow=0.64 (pronounced bloom)
  Transcendent: glow=0.80 (intense bloom)

LINK RADIUS SCALING:
  radius *= (1 + fxIntensity * 0.2)
  
  Ascending:    fxIntensity=0.42 → radius × 1.084
  Transcendent: fxIntensity=1.0  → radius × 1.2

================================================================================
4. SHADER UNIFORMS MODIFIED
================================================================================

EXISTING (always present):
  uAuraIntensity  ← Boosted by integration

OPTIONAL (graceful fallback if missing):
  uMythicColorTint         ← Color for tier
  uMythicColorInfluence    ← Tint strength (0–1)
  uMythicGlowIntensity     ← Glow boost
  uMythicTier              ← Tier number
  uMythicResonance         ← Harmonic waveform
  uMythicDistortion        ← Distortion boost

SAFETY: If uniform doesn't exist, enhancement is skipped (no error).

9. INTEGRATION EXAMPLE (COMPLETE)
================================================================================

// In game constructor:
import { MythicAuraIntegration_v1 } from './MythicAuraIntegration_v1.js';

this.mythicAuraIntegration = new MythicAuraIntegration_v1({
  mythicEvolutionFX: this.mythicEvolutionFX,
  intensityMultiplier: 0.5,
  colorTintStrength: 0.15,
});

this.mythicAuraIntegration.registerNodeAuraSystem(this.nodeAuraSystem);
this.mythicAuraIntegration.registerLinkAuraSystem(this.linkAuraSystem);

// In game.update(deltaTime):
// 1. Update metrics
this.nodeDynamicMetrics.update(deltaTime);
this.linkQualityCalculator.update(deltaTime);
this.nodeQualityCalculator.update(deltaTime);

// 2. Compute tiers
this.mythicEvolutionFX.update(deltaTime);

// 3. APPLY MYTHIC ENHANCEMENTS ← NEW (Week 12)
this.mythicAuraIntegration.update(deltaTime);

// 4. Render auras (they now use enhanced signals)
this.nodeAuraSystem.update(deltaTime);
this.linkAuraSystem.update(deltaTime);

// In game.dispose():
this.mythicAuraIntegration.dispose();
