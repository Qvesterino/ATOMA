2. CORE ALGORITHMS QUICK REFERENCE
================================================================================

ALGORITHM A: PRIMARY TRIGGER

When: node.synergyBonus.tier / 3.0 >= primaryThreshold (default: 0.75)
Action: State transition: idle → charged → reacting
Output: Node event with reactionLevel = 1.0

ALGORITHM B: CHAIN PROPAGATION

For each connected node:
  1. Check resonance similarity: |resA - resB| < 0.6
  2. Check synergy value: synergyNorm >= 0.3
  3. Check personality compatibility: |harmonyA - harmonyB| < 0.5
  4. If all pass: propagate with decay

Output: Link event + recursive call to propagateChain()

ALGORITHM C: REACTION DECAY

intensity *= 0.82         (per hop)
duration *= 0.85          (per hop)
hopIndex++                (max 8)

Stop when: intensity < 0.1 OR hopIndex > 8

ALGORITHM D: STATE MACHINE (5 states)

idle ──[synergy ≥ 0.675]──→ charged
                              ↓
                          [trigger]
                              ↓
                            reacting ──[0.3s]──→ stabilizing
                                                    ↓
                                                [0.5s]
                                                    ↓
                                                cooled ──[1–1.5s]──→ idle

================================================================================
4. NODE STATE MACHINE EXPLAINED
================================================================================

IDLE:
  Duration: Variable
  Behavior: No reaction, baseline state
  Output: Zero reaction
  Transition: When synergy ≥ 0.675 → charged

CHARGED:
  Duration: ≤ 0.5s
  Behavior: Synergy accumulating, ready to trigger
  Output: Low-intensity buildup
  Transition: Auto-discharge after 0.5s → idle, or manual trigger

REACTING:
  Duration: 0.3s
  Behavior: Chain propagating, high intensity
  Output: Full intensity, generating events
  Transition: After 0.3s → stabilizing

STABILIZING:
  Duration: 0.5s
  Behavior: Cooling down, intensity decaying
  Output: Ramping down intensity
  Transition: After 0.5s → cooled

COOLED:
  Duration: 1–1.5s
  Behavior: Refractory period, cannot trigger
  Output: Zero reaction
  Transition: After cooldown expires → idle

================================================================================
5. PROPAGATION CRITERIA
================================================================================

A node qualifies for chain propagation if ALL of these pass:

1. Resonance Similarity:
   similarity = 1.0 - |resonanceA - resonanceB|
   Pass if: similarity >= 0.4

2. Synergy Value:
   synergyNorm = synergyTier / 3.0
   Pass if: synergyNorm >= 0.3

3. Personality Compatibility:
   compatibility = 1.0 - |harmonyA - harmonyB|
   Pass if: compatibility >= 0.5

4. Intensity Threshold:
   Pass if: intensity > 0.1

All 4 must pass for propagation to occur.
