2. CORE ALGORITHMS QUICK REFERENCE
================================================================================

ALGORITHM A: LOCAL NODE RESONANCE

localResonance =
    0.35 * personality.resonanceBoost +
    0.25 * synergy.pulseStrength +
    0.15 * (1 - personality.entropy) +
    0.15 * avg(link.feedback.pulseStrength) +
    0.10 * archetype.ascensionMultiplier

Range: 0–1
Output: node.userData.resonanceFeedback.localResonance

ALGORITHM B: LINK FEEDBACK METRICS

pulseStrength = 0.5 * resonanceLevel + 0.5 * (synergyTier / 3.0)
coherenceBoost = synergyTier * 0.1
stabilityPenalty = -(entropy * 0.2)
chromaticIntensity = resonanceLevel * 0.3 + chromaShift * 0.7

Output: link.userData.resonanceFeedback (4 values)

ALGORITHM C: GLOBAL MOOD AGGREGATION & CLASSIFICATION

harmony = avg(node.resonanceFeedback.localResonance)
entropy = avg(node.resonanceFeedback.entropyShock)
coherence = avg(link.resonanceFeedback.pulseStrength)
corruption = avg(node.resonanceFeedback.corruptionDrift)
ascension = avg(node.archetypeEvolution.ascensionMultiplier)

Mood Classification:
  harmony > 0.7 && entropy < 0.3           → "calm"
  harmony > 0.5 && ascension > 0.4        → "growing"
  entropy > 0.6                            → "chaotic"
  coherence < 0.3 && harmony < 0.4        → "overloaded"
  coherence > 0.75 && harmony > 0.6       → "resonant"
  else                                     → "calm"

Output: this.networkMood

3. OUTPUT DATA STRUCTURES
================================================================================

NODE FEEDBACK (written to node.userData.resonanceFeedback):
  localResonance: 0–1          (composite resonance)
  harmonyShift: float          (change from baseline)
  entropyShock: 0–1            (entropy perturbation)
  corruptionDrift: 0–1         (corruption change)
  clarityBoost: float          (clarity from synergy)
  reactivePulse: 0–1           (reactive strength)
  lastUpdate: timestamp        (update time)

LINK FEEDBACK (written to link.userData.resonanceFeedback):
  pulseStrength: 0–1           (oscillation intensity)
  coherenceBoost: float        (+0.0 to +0.3)
  stabilityPenalty: float      (-0.2 to 0.0)
  chromaticIntensity: 0–1      (shader effect)
  lastUpdate: timestamp        (update time)

GLOBAL MOOD (stored in this.networkMood):
  harmony: 0–1                 (avg local resonance)
  entropy: 0–1                 (avg entropy shock)
  coherence: 0–1               (avg link pulse)
  corruption: 0–1              (avg corruption drift)
  ascension: 0–1               (avg archetype ascension)
  moodState: string            ("calm" | "growing" | "chaotic" | "overloaded" | "resonant")
  moodStrength: 0–1            (intensity)
  moodDuration: float          (seconds in mood)
  moodChangeTime: float        (seconds since change)

4. MOOD STATES EXPLAINED
================================================================================

CALM (Baseline):
  Conditions: harmony > 0.7 && entropy < 0.3
  Visual: Stable, peaceful network
  Node behavior: Normal, stable personality
  Duration: Sustained

GROWING (Ascension):
  Conditions: harmony > 0.5 && ascension > 0.4
  Visual: Expanding, evolving
  Node behavior: Accelerated evolution, clarity boost
  Duration: During evolution phases

CHAOTIC (Instability):
  Conditions: entropy > 0.6
  Visual: Turbulent, perturbed
  Node behavior: Erratic shifts, reduced clarity
  Duration: Temporary

OVERLOADED (Stress):
  Conditions: coherence < 0.3 && harmony < 0.4
  Visual: Fractured, disconnected
  Node behavior: Communication breakdown
  Duration: Requires recovery

RESONANT (Synchronization):
  Conditions: coherence > 0.75 && harmony > 0.6
  Visual: Synchronized, flowing
  Node behavior: Peak performance, unified
  Duration: Rare, short bursts

7. API METHODS QUICK REFERENCE
================================================================================

update(deltaTime, allNodes, allLinks)
  → Main per-frame function
  → Samples nodes, samples links, aggregates, computes mood

getMood() → Object
  → Returns current mood state
  → { harmony, entropy, coherence, corruption, ascension, moodState, moodStrength, moodDuration }

getStatistics() → Object
  → Detailed stats
  → { processedNodesCount, processedLinksCount, lastFrameUpdateTime, networkMood, aggregates }

getMoodTransition() → Object
  → Mood change info
  → { harmonyChange, entropyChange, coherenceChange, moodChanged, moodChangeTime, moodStrength }

sampleNode(node)
  → Update single node feedback
  → Automatically called by update()

sampleLink(link)
  → Update single link feedback
  → Automatically called by update()

dispose()
  → Cleanup and shutdown
  → Safe to call multiple times
