     archetypeCurves: this.archetypeCurves,

2. Update in game loop:
   
   this.archetypeShaderModes.update(deltaTime);

3. Dispose on cleanup:
   
   this.archetypeShaderModes.dispose();

SIX ARCHETYPE SHADER MODES
================================================================================

0. SAGE MODE
   Clarity-Shifting Bloom | Smooth cyan glow | Clean look
   Driver: clarity signal [0–1]
   Range: intensity [0.4–0.8], bloom [0.3–0.8], distortion [0.0–0.1]

1. WARLOCK MODE
   Chaos Tearing | Red-orange chaos streaks | High turbulence
   Drivers: entropy, corruption [0–1]
   Range: intensity [0.6–1.2], distortion [0.5–1.0], bloom [0.7–1.0]

2. SENTINEL MODE
   Ordered Waveform | Steel-blue structured glow | Stoic stability
   Driver: harmony signal [0–1]
   Range: intensity [0.5–0.8], bloom [0.0–0.4], distortion [0.0–0.1]

3. EMPATH MODE
   Harmonic Resonance | Vibrant green rings | Gentle pulsation
   Driver: resonance signal [0–1]
   Range: intensity [0.5–1.0], bloom [0.5–0.8], distortion [0.0–0.2]

4. INVOKER MODE
   Radiant Energy | Golden-yellow radiance | High saturation bloom
   Drivers: energy, focus [0–1]
   Range: intensity [0.6–1.0], bloom [0.8–1.0], distortion [0.3–0.5]

5. MYTHIC MODE
   Transcendent Iridescent | Violet→gold shimmer | Legends-tier polish
   Driver: ascensionMultiplier + ascensionTier
   Range: intensity [0.7–1.0+], bloom [0.9–1.0+], iridescence [0.5–1.0]

================================================================================
GPU UNIFORMS (Injected per material)
================================================================================

uShaderModeId        → int (0–5, archetype selector)
uModeIntensity       → float [0–1] (visual strength)
uModeDistortion      → float [0–1] (distortion amount)
uModeBloom           → float [0–1] (bloom intensity)
uModeHueShift        → float [-1–+1] (hue rotation)
uModeNoiseShift      → float [0–1] (noise animation)
uModeGradientMix     → float [0–1] (color blend)
uModeIridescence     → float [0–1] (Mythic-only effect)

EMA SMOOTHING (For Organic Transitions)
================================================================================

Default: emaAlpha = 0.12
Transition time: 0.4–0.6s at 60 FPS

Slower (0.08–0.10): 0.7–0.9s transitions, organic feel

Formula: current ← current + (target - current) × factor

COMMON ISSUES
================================================================================

Issue: Uniforms not updating
  → Verify material.uniforms exists after compilation
  → Check archetypeEvolution data on node
  → Enable debugEnabled and check logs

Issue: Flickering / visual artifacts
  → Reduce emaAlpha for slower transitions
  → Verify value clamping is applied
  → Check Week 13–15 systems

Issue: Performance drop
  → Verify material patching isn't repeated
  → Check loop isn't processing dead nodes/links
  → Enable debugEnabled to measure update time
