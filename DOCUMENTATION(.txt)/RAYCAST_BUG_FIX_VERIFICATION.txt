  2. Checks each object for violations
  3. Logs warnings if violations detected
  4. Records in audit trail

  1. Disables raycaster entirely
  2. Uses nearest-distance heuristic
  3. Pure math (no Three.js internals)
  4. Safe selection continues
  5. Game plays normally

KEY: The failsafe never attempts raycasting itself
