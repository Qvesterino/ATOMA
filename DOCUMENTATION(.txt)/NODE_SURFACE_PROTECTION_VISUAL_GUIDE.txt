================================================================================
OPACITY ATTENUATION FORMULA
================================================================================

effectiveOpacity = ceiling × (1 - overlap × 0.8)

Where:
  ceiling = max aura opacity (0.25 default)
  overlap = node-aura overlap factor (0..1)

Examples:
─────────────────────────────────────────────────────────────────────────────

Overlap Factor: 0.0 (no overlap)
  effectiveOpacity = 0.25 × (1 - 0 × 0.8) = 0.25 × 1.0 = 0.25 (full)
  ░░░░░░░░░░░░░░░░░░░  ← Aura fully visible in background
    ◆◆◆◆◆◆◆◆◆◆

Overlap Factor: 0.3 (30% overlap)
  effectiveOpacity = 0.25 × (1 - 0.3 × 0.8) = 0.25 × 0.76 = 0.19
  ▒▒▒░░░░░░▒  ← Aura mostly transparent
    ◆◆◆◆◆◆◆◆◆  ← Node clearly visible

Overlap Factor: 0.5 (50% overlap)
  effectiveOpacity = 0.25 × (1 - 0.5 × 0.8) = 0.25 × 0.6 = 0.15
  ▒░░░░░░░░░  ← Aura very faint
    ◆◆◆◆◆◆◆◆◆  ← Node prominent

Overlap Factor: 0.7 (70% overlap, typical for links)
  effectiveOpacity = 0.25 × (1 - 0.7 × 0.8) = 0.25 × 0.44 = 0.11
  ▒░░░░░░░░░░  ← Aura barely visible
    ◆◆◆◆◆◆◆◆◆  ← Node very prominent

Overlap Factor: 1.0 (100% overlap)
  effectiveOpacity = 0.25 × (1 - 1.0 × 0.8) = 0.25 × 0.2 = 0.05
  ▒░░░░░░░░░░░  ← Aura almost invisible
    ◆◆◆◆◆◆◆◆◆  ← Node maximally visible ✅
