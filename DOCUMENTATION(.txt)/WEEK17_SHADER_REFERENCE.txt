1.1 Hash Function (1D)
─────────────────────

float hash(float n) {
    return fract(sin(n) * 43758.5453123);
}

Purpose: Pseudo-random value generation from single float input
Range: [0, 1]
Computational Cost: Low (~2–3 ops)

Explanation:
• sin(n) spreads input across full sine wave range
• Multiply by large prime (43758.5453123) to break periodicity
• fract() extracts fractional part for [0, 1] range
• Deterministic: same input → same output (seedable randomness)

Application:
• Base function for fractal brownian motion (fBm)
• Input seeding for per-vertex/per-pixel variation
• Temporal noise basis (hash(n + uTime))


1.2 Improved Noise (1D Perlin-style)
─────────────────────────────────────

float noise(float x) {
    float i = floor(x);
    float f = fract(x);
    f = f * f * (3.0 - 2.0 * f);           // Smoothstep interpolation
    return mix(hash(i), hash(i + 1.0), f);
}

Purpose: Smooth interpolated noise with C2 continuity
Range: [0, 1]
Computational Cost: Medium (~8–10 ops)

Explanation:
• floor(x) → integer part; fract(x) → fractional part
• Smoothstep: f = 3f² - 2f³ (smooth Hermite curve)
  - Provides C² continuity at integer boundaries
  - Derivative = 0 at integer points (no kinks)
• mix() linearly interpolates between adjacent hash values
• Result: smooth, natural-looking noise with good visual flow

Mathematical Derivation:
  Hermite smoothstep(t) = t² * (3 - 2t)
  Derivative = 2t(3 - 2t) + t²(-2) = 6t - 6t² = 6t(1 - t)
  At t=0: output=0, derivative=0
  At t=1: output=1, derivative=0
  Perfect for continuous gradient interpolation

Application:
• Per-frame jitter in Low Compatibility Flux effect
• Temporal variations in Harmonic Resonance
• Seamless noise sampling along vUv.y

2.1 High Compatibility Beam (compatibility > 0.75)
────────────────────────────────────────────────

// Fragment shader effect:
if (uCompatibility > 0.75) {
    float wave = sin(vUv.y * 10.0 - uTime * 2.0 + uResonance * 6.28) * 0.5 + 0.5;
    diffuseColor.xyz = mix(uColorA, uColorB, wave);
    diffuseColor.a = 0.8 * uCompatibility;
}

Mathematical Breakdown:

Wave Pattern:
  • vUv.y ∈ [0, 1] (normalized vertical texture coordinate)
  • vUv.y * 10.0 → frequency compression (10 complete waves)
  • -uTime * 2.0 → temporal animation (2 radians per frame)
  • +uResonance * 6.28 → phase offset from resonance signal
    - uResonance ∈ [0, 1]
    - Multiplied by 2π (6.28) → full phase range [0, 2π]
    - Higher resonance = faster oscillation (more "jitter")

Color Interpolation:
  • mix(uColorA, uColorB, wave) → linear color blend
  • wave ∈ [0, 1] (sine range normalized)
  • At wave=0: full uColorA (source color)
  • At wave=0.5: 50/50 blend
  • At wave=1: full uColorB (target color)

Alpha Blending:
  • 0.8 * uCompatibility → scaled brightness
  • At compatibility=1.0: alpha = 0.8 (bright, slightly transparent)
  • At compatibility=0.75: alpha = 0.6 (threshold, still visible)
  • Creates natural fade-to-transparency at low compatibility

Visual Result:
  Smooth oscillating gradient between archetype colors
  Frequency increases with resonance (chaotic harmony)
  Brightness scales with compatibility (stable link strength)


2.2 Low Compatibility Flux (compatibility < 0.4)
──────────────────────────────────────────────

// Fragment shader effect:
else if (uCompatibility < 0.4) {
    float jitter = noise(vUv.y * 20.0 + uTime) * uEntropy * 0.5;
    diffuseColor.xyz = mix(uColorA, uColorB, 0.5 + jitter);
    diffuseColor.a = 0.5 * uCompatibility;
}

Mathematical Breakdown:

Jitter Calculation:
  • vUv.y * 20.0 → high-frequency noise sampling (20 waves)
  • +uTime → temporal animation (seeded noise changes per frame)
  • noise(...) ∈ [0, 1] (smooth interpolated noise)
  • *uEntropy → scaled by chaos signal [0, 1]
  • *0.5 → clamped to [-0.25, 0.25] effective range
    (prevents wild color swings, preserves readability)

Color Blending:
  • Base: 0.5 (50/50 color blend midpoint)
  • Jitter range: ±0.25 (max deviation ±25%)
  • Final blend ∈ [0.25, 0.75]
  • Creates chaotic flicker between source/target with stability envelope

Noise Evolution:
  • Per-frame variation in +uTime term → continuous change
  • smooth noise() ensures C² continuity → no frame-to-frame popping
  • High frequency (20.0) provides fine detail
  • Entropy modulation → chaotic systems show more jitter

Alpha Blending:
  • 0.5 * uCompatibility → dim, barely coherent
  • At compatibility=0.4: alpha = 0.2 (threshold, faint)
  • At compatibility=0.0: alpha = 0.0 (invisible)
  • Emphasizes visual conflict: weak links fade away

Visual Result:
  Chaotic, jittery beam with noisy color fluctuation
  High entropy → more visible flicker (unstable system)
  Low compatibility → dims further (breaks down link cohesion)


2.3 Mythic Resonance Thread (ascension > 1.5)
──────────────────────────────────────────────

// Fragment shader effect:
else if (uAscension > 1.5) {
    float iridescence = sin(vUv.y * 8.0 - uTime + uAscension * 3.14) * 0.5 + 0.5;
    vec3 rainbowColor = mix(uColorA, uColorB, iridescence);
    rainbowColor = mix(rainbowColor, vec3(1.0, 0.0, 1.0), 0.3 * (uAscension - 1.0));
    diffuseColor.xyz = rainbowColor;
    diffuseColor.a = 0.7 * uAscension * 0.5;
}

Mathematical Breakdown:

Iridescence Pattern:
  • vUv.y * 8.0 → medium frequency (8 complete iridescent waves)
  • -uTime → temporal animation (phase shifts)
  • +uAscension * 3.14 → phase boost from ascension level
    - π multiplier → roughly full 180° phase shift per ascension tier
    - uAscension ∈ [1.0, 2.0] → phase range [π, 2π]
    - Higher ascension = faster iridescence frequency
  • Result: iridescence ∈ [0, 1] (normalized sine)

Rainbow Color Blending:
  • mix(uColorA, uColorB, iridescence) → smooth gradient sweep
  • iridescence cycles [0, 1] → sweeps from source to target repeatedly
  • Creates smooth spectral animation (rainbow effect)

Magenta Overlay:
  • vec3(1.0, 0.0, 1.0) → pure magenta (R=255, G=0, B=255)
  • 0.3 * (uAscension - 1.0) → overlay intensity
    - At ascension=1.5: 0.3 * 0.5 = 0.15 (15% magenta tint)
    - At ascension=2.0: 0.3 * 1.0 = 0.30 (30% magenta tint)
    - Creates "mythic" iridescent shimmer
  • Magenta (R+B) complements yellow-green spectral colors
  • Visual signature: "legendary" link appearance

Alpha Blending:
  • 0.7 * uAscension * 0.5 → luminous but constrained
  • At ascension=1.5: 0.7 * 1.5 * 0.5 = 0.525 (medium-bright)
  • At ascension=2.0: 0.7 * 2.0 * 0.5 = 0.7 (very bright)
  • *0.5 prevents over-exposure (keeps alpha ≤0.7)
  • High ascension links stand out visually

Visual Result:
  Shimmering iridescent rainbow thread
  Magenta undertone signals "legendary" status
  Brightness scales with ascension power
  Smooth spectral animation (no jitter)


2.4 Harmonic Resonance (Neutral, else)

// Fragment shader effect (default):
else {

Mathematical Breakdown:

Resonance Pulsing:
  • uTime → global animation counter (in seconds/frames)

    - uResonance=0.1 → slow pulse (~0.2 Hz)
    - uResonance=0.5 → medium pulse (~1.0 Hz)
    - uResonance=1.0 → fast pulse (~2.0 Hz)
  • *2.0 → radians per pulse unit
  • Result: pulse ∈ [0, 1] (normalized sine)

Color Modulation:
  • Base blend: 0.5 (50/50 midpoint)
  • Pulse offset: pulse * 0.3 → ±0.15 range (±15% deviation)
  • Final blend ∈ [0.35, 0.65]
  • Creates gentle oscillation between source/target
  • Not too extreme (no violent color swings)

Alpha Blending:
  • 0.6 * uCompatibility → baseline visibility
  • At compatibility=0.75: alpha = 0.45 (threshold, visible)
  • At compatibility=0.5: alpha = 0.30 (moderate)
  • At compatibility=0.4: alpha = 0.24 (faint)
  • Graceful falloff toward Low Compatibility Flux tier

Visual Result:
  Balanced, gentle pulsing link
  Resonance determines pulse speed
  Compatibility determines overall brightness
  Professional, readable appearance

SECTION 3: UNIFORM UPDATE FORMULAS

3.1 Per-Frame Uniform Updates (TypeScript/JavaScript)
──────────────────────────────────────────────────

For each link mesh material, each frame:

// Clamped to safe ranges:
uCompatibility = max(0, min(1, state.currentCompatibility))
uResonance     = max(0, min(1, state.currentResonance))
uEntropy       = max(0, min(1, state.currentEntropy))
uAscension     = max(1, min(2, state.currentAscension))
uColorA        = state.currentColorA  (THREE.Color)
uColorB        = state.currentColorB  (THREE.Color)
uTime          = (previous_uTime + deltaTime)  (accumulated)

3.2 EMA Smoothing Interpolation
───────────────────────────────

Each frame, before updating uniforms:

const factor = min(1.0, emaAlpha * deltaTime * 60.0)

// Normalize to 60 FPS baseline:
// emaAlpha = 0.15
// At 60 FPS: factor = 0.15 * (1/60 * 60) = 0.15 (full step in 1 frame)
// At 30 FPS: factor = 0.15 * (2/60 * 60) = 0.30 (adjusted for lower framerate)

state.currentCompatibility += (target - current) * factor
state.currentResonance     += (target - current) * factor
state.currentEntropy       += (target - current) * factor
state.currentAscension     += (target - current) * factor

// For colors (THREE.Color.lerp):
state.currentColorA.lerp(state.targetColorA, factor)
state.currentColorB.lerp(state.targetColorB, factor)

Behavior:
• At 60 FPS: smooth transition time ≈ 6–8 frames (0.1–0.13s)
• At 30 FPS: same subjective speed (auto-normalized)
• Graceful degradation: lower FPS gets adjusted smoothing

4.1 Archetype ID → RGB Color Mapping

switch(archetypeId % 6) {
    case 0: return vec3(0.0, 1.0, 1.0)   // Cyan:   (0, 255, 255)
    case 1: return vec3(1.0, 0.4, 0.0)   // Orange: (255, 102, 0)
    case 2: return vec3(0.0, 0.4, 1.0)   // Blue:   (0, 102, 255)
    case 3: return vec3(0.0, 1.0, 0.4)   // Green:  (0, 255, 102)
    case 4: return vec3(1.0, 1.0, 0.0)   // Yellow: (255, 255, 0)
    case 5: return vec3(1.0, 0.0, 1.0)   // Magenta:(255, 0, 255)
}

Design Rationale:
• Full saturation (1.0 or 0.0 per channel) → bright, recognizable
• Complementary pairs: cyan-orange, blue-yellow, green-magenta
  - Creates visual contrast when linking different archetypes
• No grays or low-saturation → ensures visual readability at distance

4.2 RGB Color Blending (mix function)
──────────────────────────────────

mix(vec3 a, vec3 b, float t) = a * (1.0 - t) + b * t

Used for smooth gradient transitions:
• High Compat: mix(uColorA, uColorB, wave)
• Low Compat: mix(uColorA, uColorB, 0.5 + jitter)
• Mythic: mix(rainbow, magenta, overlayIntensity)

Linear blending in RGB space ensures smooth color transitions.
Alternative: HSV space → more perceptually uniform transitions
(not used to reduce GPU cost)

6.1 Adjusting Wave Frequencies
──────────────────────────────

Current formula: sin(vUv.y * 10.0 - uTime * 2.0 + ...)

To change wave speed:
  Replace "2.0" with desired radians/frame:
  • 1.0 = slower, more flowing waves
  • 3.0 = faster, more energetic animation
  • 0.5 = very slow, meditation-like

To change spatial frequency:
  Replace "10.0" with desired waves per link:
  • 5.0 = fewer, larger waves
  • 20.0 = many tiny ripples
  • 30.0 = ultra-fine detail


6.2 Adjusting Noise Intensity
──────────────────────────────

Current formula: noise(...) * uEntropy * 0.5

Change "0.5" multiplier:
  • 0.3 = subtle jitter
  • 0.7 = prominent chaos
  • 1.0 = extreme instability


6.3 Adjusting Alpha Thresholds
───────────────────────────────

Current: 0.8 (high), 0.5 (low), 0.7 (mythic), 0.6 (neutral)

Scale all by factor k:
  • k=0.5: dimmer links (more transparent)
  • k=1.5: brighter links (more opaque)
  • k=2.0: very bright (potential visual overload)


6.4 Adding Harmonic Overtones
──────────────────────────────

To add visual richness, layer multiple frequency components:

float wave1 = sin(vUv.y * 8.0 - uTime * 1.5) * 0.6;
float wave2 = sin(vUv.y * 16.0 - uTime * 3.0) * 0.3;
float wave3 = sin(vUv.y * 32.0 - uTime * 6.0) * 0.1;
float combined = (wave1 + wave2 + wave3) / 2.0;  // Average

This creates "harmonic" multiple frequencies (musical analogy):
• Fundamental (1x) + Overtones (2x, 4x) = richer visual texture
