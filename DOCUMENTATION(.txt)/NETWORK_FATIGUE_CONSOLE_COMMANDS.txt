FEATURE FLAG (Global Control)
================================================================================

Enable fatigue system:
  window.ENABLE_NETWORK_FATIGUE = true

Disable fatigue system (instantly):
  window.ENABLE_NETWORK_FATIGUE = false

Check current state:
  console.log(window.ENABLE_NETWORK_FATIGUE)


DEBUG API (window.FATIGUE_DEBUG)
================================================================================

Print all nodes' fatigue status:
  FATIGUE_DEBUG.printAll(aiNodes.nodes)
  
  Output format:
    Node 0 [input]
      Fatigue: 0.1234 | State: ACCUMULATING
      Stress: 0.6543 | Health: 0.0000
      Metrics: Load=0.850 Inst=75.0 Corr=25.0 Harm=15.0
      Multipliers: Harmony=0.951 Synergy=0.957 Decay=0.963


Get detailed state of single node:
  const state = FATIGUE_DEBUG.getState(node)
  
  Returns object with:
    - fatigue: current value (0-1)
    - state: STABLE / ACCUMULATING / RECOVERING
    - stressComposite: current stress (0-1)
    - healthComposite: current health (0-1)
    - category: node category (input/process/etc)
    - metrics: load, instability, corruption, harmony
    - multipliers: harmonyRate, synergy, corruptionDecay
    
  Access individual fields:
    state.fatigue                           // 0.1234
    state.state                             // "ACCUMULATING"
    state.multipliers.corruptionDecay       // 0.763
    state.metrics.loadRatio                 // 0.850


Seed fatigue value (for testing):
  FATIGUE_DEBUG.seedFatigue(node, value)
  
  Examples:
    FATIGUE_DEBUG.seedFatigue(aiNodes.nodes[0], 0.5)      // 50%
    FATIGUE_DEBUG.seedFatigue(aiNodes.nodes[0], 0.0)      // 0%
    FATIGUE_DEBUG.seedFatigue(aiNodes.nodes[0], 1.0)      // 100%


Enable system:
  FATIGUE_DEBUG.enable()
  
  Restarts fatigue accumulation
  Console will show: ✓ Network Fatigue ENABLED


Disable system:
  FATIGUE_DEBUG.disable()
  
  Stops all fatigue, resets to 0
  Console will show: ✓ Network Fatigue DISABLED (all nodes reset to fatigue=0)


Enable verbose logging:
  FATIGUE_DEBUG.setLogging(true)
  
  Shows accumulation/recovery logs for all changes
  Console shows: ✓ Fatigue logging: ON


Disable verbose logging:
  FATIGUE_DEBUG.setLogging(false)
  
  Silent mode (only errors logged)
  Console shows: ✓ Fatigue logging: OFF


COMMON TEST SEQUENCES
================================================================================

Test 1: Verify Initialization
  1. Open console (F12)
  2. Paste: console.log(window.FATIGUE_DEBUG)
  3. Should show: {enable, disable, setLogging, getState, seedFatigue, printAll}
  4. Paste: FATIGUE_DEBUG.printAll(aiNodes.nodes)
  5. Should show all nodes with fatigue = 0.0, state = STABLE


Test 2: Accumulate Fatigue
  1. Create high-load scenario (build 10+ links on one node)
  2. Wait 30+ seconds
  3. Paste: FATIGUE_DEBUG.printAll(aiNodes.nodes)
  4. Look for: fatigue > 0.1, state = ACCUMULATING
  5. Check: stressComposite > 0.5 (indicates high stress)


Test 3: Verify Multiplier Effect
  1. Get a node: const node = aiNodes.nodes[0]
  2. Seed high fatigue: FATIGUE_DEBUG.seedFatigue(node, 0.8)
  3. Get state: const state = FATIGUE_DEBUG.getState(node)
  4. Check: state.multipliers.corruptionDecay should be ~0.76 (1 - 0.8*0.30)
  5. Expected: ~0.76, not 1.0


Test 4: Test Recovery
  1. Find a fatigued node (or seed one)
  2. Remove all links (unload the node)
  3. Wait for metrics to become healthy:
     - loadRatio < 0.5
     - instability < 30
     - corruption < 30
     - harmony > 40
  4. Wait 60+ seconds
  5. Paste: FATIGUE_DEBUG.printAll(aiNodes.nodes)
  6. Check: fatigue decreasing, state = RECOVERING


Test 5: Disable & Verify No Change
  1. Note current fatigue: FATIGUE_DEBUG.printAll(aiNodes.nodes)
  2. Disable: FATIGUE_DEBUG.disable()
  3. Wait 5 seconds
  4. Check: FATIGUE_DEBUG.printAll(aiNodes.nodes)
  5. All fatigue should = 0.0
  6. Play normally - no behavioral change should be visible

TROUBLESHOOTING
================================================================================

"FATIGUE_DEBUG is undefined"
  → Try: window.FATIGUE_DEBUG
  → Check: Is NodeDynamicMetrics.js loaded?
  → Check: Browser console showing any errors?


"All nodes have fatigue = 0 even under stress"
  → Check: window.ENABLE_NETWORK_FATIGUE == true
  → Check: Stress thresholds:
     - loadRatio must be > 0.75
     - instability must be > 60
     - corruption must be > 40
     - harmony must be < 20
  → Enable logging: FATIGUE_DEBUG.setLogging(true)


"Fatigue not recovering"
  → Verify ALL recovery conditions:
     const state = FATIGUE_DEBUG.getState(node);
     state.metrics.loadRatio   // Must be < 0.5
     state.metrics.instability // Must be < 30
     state.metrics.harmony     // Must be > 40
     state.metrics.corruption  // Must be < 30
  → If not all met, node is in "STABLE" state (no recovery)


"No console logging appearing"
  → Check: Is fatigue > 0.1 or is recovery active?
  → Enable: FATIGUE_DEBUG.setLogging(true)
  → Seed fatigue: FATIGUE_DEBUG.seedFatigue(node, 0.5)
  → Try again
