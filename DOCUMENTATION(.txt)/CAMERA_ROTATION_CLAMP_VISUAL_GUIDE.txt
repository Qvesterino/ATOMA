CAMERA ROTATION AXES
═══════════════════════════════════════════════════════════════════════════════

        UP
        │
        │
        ●───── FORWARD  (viewer looking this way)
       /│
      / │
    LEFT

Camera has 3 rotation axes:

X-AXIS (PITCH - Up/Down Look):
────────────────────────────
   camera.rotation.x
   
   Range: -89° to +89° (prevents looking completely behind head)
   
   Rotation: Looking UP   (-x)  →  Looking DOWN  (+x)
   
        ↑                                          ↓
        |                                          |
        |                                          |
   Max -89°                                    Max +89°


Y-AXIS (YAW - Left/Right Look):
───────────────────────────────
   camera.rotation.y
   
   Range: Full 360° (free rotation)
   
   Rotation: Looking LEFT  (-y)  →  Looking RIGHT  (+y)
   
   ← ← ← ←                              → → → →
   
   Can spin full circle around


Z-AXIS (ROLL - Camera Spin):
────────────────────────────
   camera.rotation.z
   
   SHOULD ALWAYS BE: 0°
   
   ⭐ THIS IS WHAT WE HARD-LOCK ⭐
   
   Never spin sideways!
   Never flip upside down!
   Never tilt camera!
   
   camera.rotation.z = 0  ← ALWAYS

WHAT THE CLAMP DOES (EVERY FRAME)
═══════════════════════════════════════════════════════════════════════════════

Frame N:
───────
   1. Read: camera.rotation = { x: pitch, y: yaw, z: roll }
   
   2. Detect: Did mouse move REALLY fast?
      if (|Δrotation| / Δtime > threshold) {
        isMouseMovingFast = true;
      }
   
   3. Clamp: pitch = clamp(pitch, -89°, +89°)
   
   4. LOCK: roll = 0  ← CRITICAL OPERATION
   
   5. Smooth: if (isMouseMovingFast) {
        pitch = lerp(oldPitch, newPitch, 0.12);
        yaw = lerp(oldYaw, newYaw, 0.12);
      }
   
   6. Apply: camera.rotation = { x: pitch, y: yaw, z: 0 }
   
   7. Verify: if (camera.rotation.z != 0) {
        camera.rotation.z = 0;  ← FAILSAFE
      }
   
   8. Log: if (debug) console.log(...stats)
   
   9. Render: scene

FAST MOUSE HANDLING
═══════════════════════════════════════════════════════════════════════════════

Slow Mouse Movement:
───────────────────
   Δrotation = 0.01 rad/frame
   velocity = 0.01 / 0.016 = 0.625 rad/s
   
   < 0.5 rad/s threshold
   
   ✗ No smoothing applied
   ✓ Normal responsive camera


Fast Mouse Swipe:
───────────────────
   Δrotation = 0.2 rad/frame
   velocity = 0.2 / 0.016 = 12.5 rad/s
   
   > 0.5 rad/s threshold
   
   ✓ Smoothing applied (lerp factor 0.12)
   ✓ Applies low-pass filter
   ✓ Prevents jitter and excessive rotation
   
   newRotation = oldRotation * (1 - 0.12) + targetRotation * 0.12
               = oldRotation * 0.88 + targetRotation * 0.12

═══════════════════════════════════════════════════════════════════════════════
CONFIGURATION OPTIONS
═══════════════════════════════════════════════════════════════════════════════

setPitchLimits(minDegrees, maxDegrees)
─────────────────────────────────────
   Default: -89°, +89°
   
   Examples:
   setPitchLimits(-85, 85)    ← Tighter limits
   setPitchLimits(-89, 89)    ← Standard FPS
   setPitchLimits(-60, 60)    ← Very restricted


setSmoothingFactor(factor)
──────────────────────────
   Range: 0.05 - 0.25
   Default: 0.12
   
   Lower values = more responsive
   Higher values = smoother/more dampened
   
   Examples:
   setSmoothingFactor(0.10)   ← Responsive
   setSmoothingFactor(0.12)   ← Balanced
   setSmoothingFactor(0.18)   ← Very smooth


setFastMouseThreshold(radians)
──────────────────────────────
   Default: 0.5 rad/frame
   
   Lower values = smoothing applies sooner
   Higher values = smoothing only on extreme speed
   
   Examples:
   setFastMouseThreshold(0.3)  ← Apply at lower speeds
   setFastMouseThreshold(0.5)  ← Standard
   setFastMouseThreshold(0.8)  ← Only extreme speeds
