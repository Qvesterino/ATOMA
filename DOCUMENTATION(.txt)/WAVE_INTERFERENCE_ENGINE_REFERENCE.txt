addWaveSource(config) → string | null
──────────────────────────────────────

Add a new wave source to the system.

PARAMETERS
──────────
config: object
  type: 'NODE' | 'LINK' | 'EVENT' | 'WORLD'
    Wave origin type
  
  nodeId?: string
    If type='NODE', the source node ID
  
  linkId?: string
    If type='LINK', the source link ID
  
  originPosition: THREE.Vector3
    World position of wave origin
  
  baseAmplitude: number (0–1)
    Peak wave strength (default: 0.8)
  
  baseFrequency: number
    Oscillation frequency in Hz (default: 2.0)
  
  basePhase: number
    Initial phase offset in radians (default: 0)
  
  decayRadius: number
    Spatial decay distance (default: 10)
  
  profile: 'SYNERGY' | 'CORRUPTION' | 'MYTHIC' | 'EMOTIONAL' | 'SYSTEM'
    Wave profile type (default: 'SYNERGY')
  
  synergyBoost: number (0–1)
    Synergy amplitude multiplier (default: 0.5)
  
  resonanceBoost: number (0–1)
    Resonance amplitude multiplier (default: 0.3)
  
  corruptionBoost: number (0–1)
    Corruption amplitude reduction (default: 0)
  
  ttl: number
    Time to live in seconds (default: 10)

RETURNS
───────
string: Wave source ID (unique identifier)
null:   If error occurred

EXAMPLE
───────
const sourceId = engine.addWaveSource({
  type: 'NODE',
  nodeId: 'myNode',
  originPosition: new THREE.Vector3(5, 10, 0),
  baseAmplitude: 0.85,
  baseFrequency: 3.0,
  decayRadius: 20,
  synergyBoost: 0.7,
  ttl: 6.0
});


update(deltaTime, entities = {}) → void
────────────────────────────────────────

Compute wave interference across entire network.

PARAMETERS
──────────
deltaTime: number
  Time elapsed since last update (seconds)

entities: object
  nodes: Array<Node>
    All nodes in scene
  
  links: Array<Link>
    All links in scene

EFFECTS
───────
- Ages all wave sources
- Removes expired sources
- Computes BFS propagation targets
- Calculates interference at each node/link
- Writes userData.waveField on each entity

EXAMPLE
───────
engine.update(0.016, {
  nodes: game.scene.nodes,
  links: game.scene.links
});


getNodeWaveField(nodeId) → object | null
──────────────────────────────────────────

Query wave field at a specific node.

PARAMETERS
──────────
nodeId: string
  ID of the node to query

RETURNS
───────
object:
{
  totalAmplitude: number (0–1),       // Sum of absolute wave values
  constructivePower: number (0–1),    // Sum of positive waves
  destructivePower: number (0–1),     // Sum of negative waves
  interferenceIndex: number (0–1),    // Number of sources / maxSources
  standingWaveFactor: number (0–1),   // Measure of standing wave
  travelPhase: number (0–1),          // Accumulated phase (normalized)
  sourceCount: number,                // How many sources reach this node
  timestamp: number                   // When computed
}

null: If no wave field at this node

EXAMPLE
───────
const field = engine.getNodeWaveField('node-42');
if (field) {
  const glow = field.totalAmplitude;
  const resonance = field.standingWaveFactor;
}

Get engine performance metrics.

clear() → void
──────────────

Stop all waves and reset state.

EFFECTS
───────
- Removes all wave sources
- Clears all wave fields
- Clears propagation cache
- Resets update count

EXAMPLE
───────

─────────────────

Cleanup and release resources. Call on shutdown.

EFFECTS
───────
- Calls clear()
- Nullifies internal managers
- Prepares for garbage collection

EXAMPLE
───────

================================================================================
WAVE SOURCE STRUCTURE
================================================================================

COMPLETE CONFIGURATION OBJECT
─────────────────────────────────────────────────────────────────────────────

{
  // IDENTIFICATION
  type: 'NODE' | 'LINK' | 'EVENT' | 'WORLD',
    Required. Wave origin type.
  
  nodeId?: string,
    Optional. Source node (if type='NODE').
  
  linkId?: string,
    Optional. Source link (if type='LINK').
  
  originPosition: THREE.Vector3,
    Required. World position of wave origin.
  
  // WAVE PROPERTIES
  baseAmplitude: number (0–1),
    Optional. Default 0.8.
    Peak wave strength. Decays to zero as source ages.
  
  baseFrequency: number,
    Optional. Default 2.0.
    Oscillations per second (Hz).
    Higher = faster oscillations.
  
  basePhase: number,
    Optional. Default 0.
    Initial phase offset in radians.
  
  decayRadius: number,
    Optional. Default 10.
    Spatial scale for wave attenuation.
    Larger = waves propagate further.
  
  // PROFILE & BOOSTS
  profile: 'SYNERGY' | 'CORRUPTION' | 'MYTHIC' | 'EMOTIONAL' | 'SYSTEM',
    Optional. Default 'SYNERGY'.
    Wave profile type (informational).
  
  synergyBoost: number (0–1),
    Optional. Default 0.5.
    Multiplier from synergy: amplitude × lerp(0.8, 1.3, synergyBoost)
  
  resonanceBoost: number (0–1),
    Optional. Default 0.3.
    Multiplier from resonance: amplitude × lerp(0.8, 1.3, resonanceBoost)
  
  corruptionBoost: number (0–1),
    Optional. Default 0.
    Reduction from corruption: amplitude × lerp(1.0, 0.5, corruptionBoost)
  
  // LIFETIME
  ttl: number,
    Optional. Default 10.
    Time to live in seconds.
    Source dies when age >= ttl.
}


================================================================================
WAVE FIELD STRUCTURE
================================================================================

RETURNED BY: getNodeWaveField(), getLinkWaveField()
──────────────────────────────────────────────────────

{
  // AMPLITUDE METRICS
  totalAmplitude: number (0–1),
    Sum of absolute values from all waves reaching this point.
    Useful for: glow intensity, general strength.
  
  constructivePower: number (0–1),
    Sum of positive waves (phases align).
    Useful for: harmony, constructive interference glow.
  
  destructivePower: number (0–1),
    Sum of negative waves (destructive interference).
    Useful for: corruption, distortion effects.
  
  // INTERFERENCE CHARACTERISTICS
  interferenceIndex: number (0–1),
    Number of active sources / maxSources.
    Range: 0 (no sources) to 1 (all sources active).
    Useful for: complexity visualization.
  
  standingWaveFactor: number (0–1),
    Measure of standing wave (0) vs. traveling wave (1).
    1.0 = pure standing wave (all sources exactly in phase)
    0.0 = pure traveling wave (sources out of phase)
    Useful for: resonance detection, mode visualization.
  
  // WAVE PROPERTIES
  travelPhase: number (0–1),
    Accumulated phase normalized to 0–1.
    Useful for: animate wave motion, phase gradient.
  
  // METADATA
  sourceCount: number,
    How many wave sources reach this node/link.
    Range: 0 (no waves) to maxSources (all sources).
  
  timestamp: number,
    When this field was computed (in seconds).
}

function bindWaveUniforms() {

    const field = engine.getNodeWaveField(node.id);
    if (field && node.material.uniforms) {
      node.material.uniforms.uWaveAmplitude.value =

SAFETY FEATURES
================================================================================

OPTIONAL CHAINING
─────────────────
All accesses use `?.` operator:
  config?.graph?.getLinksForNode?.()
  node?.position?.clone?.()
  link?.userData?.waveField

TRY/CATCH BLOCKS
────────────────
Every public method wrapped:
  try {
    // implementation
  } catch (e) {
    console.warn('Error:', e);
    return null;  // or safe default
  }

DEFENSIVE DEFAULTS
───────────────────
Missing values get safe defaults:
  baseFrequency ??= 2.0
  maxSources ??= 8
  decayRadius ??= 10

NO SIDE EFFECTS
────────────────
Only writes to:
  entity.userData.waveField (additive)
  internal state (engine-only)

Never modifies:
  entity.material
  entity.geometry
  entity.position
  scene graph
  linking system


================================================================================
TROUBLESHOOTING
================================================================================

WAVES NOT PROPAGATING
─────────────────────
Q: addWaveSource returns ID but waves don't reach nodes/links
A: 1. Check graph.getLinksForNode(nodeId) returns valid links
   2. Verify node/link IDs match network structure
   3. Check BFS traversal with engine.propagationGraph.cache
   4. Verify update() called each frame
   5. Check nodes/links array passed to update() has entities

SOURCE EXPIRED IMMEDIATELY
──────────────────────────
Q: sourceId valid but getActiveSources() empty immediately
A: 1. Check ttl >= 0.1 (default 10.0 is fine)
   2. Verify update() called each frame with correct deltaTime
   3. Check source age with getActiveSources()[i].age

WAVE FIELDS ALL ZEROS
──────────────────────
Q: field.totalAmplitude always 0
A: 1. Check addWaveSource() returns valid ID
   2. Verify update() called BEFORE query
   3. Check baseAmplitude > 0.1
   4. Verify entities.nodes/links passed to update()
   5. Check node IDs exist in network

PERFORMANCE ISSUES
─────────────────
Q: Engine slow with many sources/nodes
A: 1. Reduce maxSources (fewer concurrent waves)
   2. Reduce decayRadius (smaller propagation)
   3. Increase maxHops limit (already 6, increase if needed)
   4. Cache BFS results (already done)
   5. Update every Nth frame instead of every frame

MEMORY GROWING
──────────────
Q: Memory usage increases over time
A: 1. Call engine.clear() periodically
   2. Ensure dispose() called on shutdown
   3. Check TTL values (sources should expire)
   4. Verify pruneExpiredSources() working (check metrics)
   5. Invalidate cache if network changes
