MAIN LOOP UPDATE (every frame, after PersonalityVisualAdapter)
==============================================================
function animate() {
  // ... other updates ...
  
  // PersonalityVisualAdapter update first
  if (this.personalityVisualAdapter) {
    this.personalityVisualAdapter.update(deltaTime);
  }
  
  // THEN PersonalityVFXLayer
  if (this.personalityVFXLayer) {
    this.personalityVFXLayer.update(deltaTime, this.time);
  }
  
  // Other VFX systems after
  if (this.nodePersonalitySystem) {
    this.nodePersonalitySystem.update(deltaTime, this.aiNodes.nodes);
  }
}

THE 5 VFX EFFECTS
=================

1. Clarity Boost → Emissive Intensity
   Input: clarityBoost (0–1)
   Effect: base + clarityBoost × 0.4 brightness
   Result: Brighter = clearer thinking

2. Resonance Boost → Pulse Oscillation
   Input: resonanceBoost (0–1)
   Effect: scale × sin(time × (1 + resonance × 2)) × 0.1
   Result: Breathing pulse = good connection

3. Entropy Penalty → Jitter Movement
   Input: entropyPenalty (0–1)
   Effect: position += random(±0.01 × entropy)
   Result: Jitter = chaos

4. Focus Shift → Rotation Drift
   Input: focusShift (0–1)
   Effect: rotation += random(±0.005 × focus)
   Result: Wobble = overloaded

5. Corruption Signal → Color Tint
   Input: corruptionSignal (0–1)
   Effect: color.lerp(red-orange, 0.25 × corruption)
   Result: Red tint = corrupted

INTEGRATION LOCATION
====================

1. Import at top of main.js
2. Declare variable in constructor: this.personalityVFXLayer = null;
3. Initialize in createAINodes() after LinkPriorityDecayEngine
4. Update in animate() AFTER PersonalityVisualAdapter, BEFORE NodePersonalitySystem2_0
5. Cleanup in switchMode() when disposing systems

ORDER IN UPDATE LOOP
====================
1. Safe Metrics FX (computes visual metrics)
2. PersonalityVisualAdapter (computes personality signals)
3. ✓ PersonalityVFXLayer (applies VFX effects) ← YOU ARE HERE
4. NodePersonalitySystem2_0 (physical personality)
5. All other VFX systems


DATA REQUIREMENTS
=================

Reads from:
  node.userData.personalityVisual = {
    clarityBoost: 0–1,
    resonanceBoost: 0–1,
    entropyPenalty: 0–1,
    focusShift: 0–1,
    corruptionSignal: 0–1
  }

All values required to be present (or effect skipped).
All values guaranteed 0–1 by PersonalityVisualAdapter.


WRITES TO (FRAME-LOCAL, REVERSIBLE)
===================================
node.position (jitter, reset each frame)
node.scale (pulse, reset each frame)
node.rotation (drift, reset each frame)
node.mesh.material.emissiveIntensity (brightness, reset each frame)
node.mesh.material.color (tint, reset each frame)

NO permanent modifications.
NO shader changes.
NO material assignments.

TROUBLESHOOTING
================

Issue: Effects not visible
→ Check PersonalityVisualAdapter is running first
→ Check personality signals are being computed
→ Check update() is called with correct signature

Issue: Performance degradation
→ Profile with getStats()
→ Check node count
→ Reduce effect intensity in config

Issue: Visual flickering
→ Check update() called only once per frame
→ Check elapsedTime parameter is monotonic
→ Verify personality signals are stable

Issue: Effects too subtle / too strong
→ Adjust configuration values
→ See CONFIGURATION CUSTOMIZATION above
