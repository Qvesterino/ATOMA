                        INTEGRATION DETAILS
================================================================================

LOCATION:       computeTransmissionRate() method in LinkCorruptionTransmission_v1.js
SCOPE:          Inside corruption transmission rate calculation
TRIGGER:        Called once per link per frame during corruption updates

LOGIC:
  1. Read synergy value: const synergy = link.synergy ?? 0
  2. Compute blocking multiplier:
     - synergy >= 85: multiplier = 0.0 (HARD BLOCK)
     - synergy 60-85: multiplier = 1.0 - ((synergy - 60) / 25) (SOFT DAMPING)
     - synergy < 60: multiplier = 1.0 (NO EFFECT)
  3. Apply to transmission rate: baseRate *= synergyBlockMultiplier

================================================================================
                          GAMEPLAY IMPACT
================================================================================

LOW SYNERGY (0-59):
  ↳ Corruption spreads normally through link
  ↳ No blocking effect

MEDIUM SYNERGY (60-85):
  ↳ Corruption spreads slower (gradually damped)
  ↳ Synergy 60: 0% reduction
  ↳ Synergy 72: 48% reduction
  ↳ Synergy 85: 100% reduction

HIGH SYNERGY (85+):
  ↳ Corruption is completely blocked
  ↳ Link acts as a barrier to corruption spread
  ↳ Creates "synergy walls" in network
