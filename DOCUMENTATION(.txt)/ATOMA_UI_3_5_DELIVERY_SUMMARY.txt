UNIFIED MOUSE BEHAVIOR (FINAL)
================================================================================

LMB (LEFT MOUSE BUTTON)
──────────────────────────────────────────────────────────────────────────────
If LMB hits node:
  if (no selection):
    selectNode(node)
  else if (node == selectedNode):
    do nothing
  else:
    createLink(selectedNode, node)
    selectNode(node)

If LMB hits empty:
  deselectNode()
  closeAllUI()

Result: EXPLICIT selection model, no proximity


RMB (RIGHT MOUSE BUTTON)
──────────────────────────────────────────────────────────────────────────────
If RMB on selected node WITH links:
  unlinkAll(node)  [bidirectional]
  Keep selectedNode = true
  Keep visuals = active
  Keep TopBar = visible

If RMB on selected node NO links:
  blinkHighlight(node)  [visual feedback 150ms]
  Selection unchanged

If RMB on empty:
  do nothing

Result: FULL UNLINKING SUPPORT, safe + reversible


OTHER KEYS
──────────────────────────────────────────────────────────────────────────────
E Key (if selected):
  contextMenu.open()

E Key (if not selected):
  blocked (no action)

ESC Key (any state):
  closeAllUI()
  deselectNode()

Result: INTUITIVE KEY BEHAVIOR
