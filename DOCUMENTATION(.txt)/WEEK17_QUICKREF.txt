KEY INTERNAL FUNCTIONS
───────────────────────────────────────────────────────────────────────────────

_computeCompatibility(sourceNode, targetNode)
  → Looks up compatibility matrix value based on archetype IDs
  → Scales by ascension multiplier
  → Returns 0–1 value

_computeResonance(sourceNode, targetNode)
  → Reads harmony signals from personality system
  → Returns alignment score 0–1
  
_computeEntropy(sourceNode, targetNode)
  → Reads entropy signals from personality system
  → Returns maximum entropy 0–1

_computeAscension(sourceNode, targetNode, linkObject)
  → Checks linkObject.userData or averages node ascensions
  → Returns 1–2 multiplier

_getArchetypeColor(archetypeId)
  → Maps archetype ID (0–5) to RGB color
  → Returns THREE.Color

_patchMaterial(material, linkObject, sourceNode, targetNode)
  → Wraps material.onBeforeCompile
  → Injects 7 uniforms + noise functions
  → Replaces fragment shader color logic with effect types
  → One patch per material (cached via patchedMaterials WeakSet)
