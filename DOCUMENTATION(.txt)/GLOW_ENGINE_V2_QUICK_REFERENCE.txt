ONE-LINER: WHAT IS IT?
================================================================================

Safe wrapper that adds synergyNorm + qualityNorm glow effects to links while
maintaining perfect backward compatibility with v1.0.

================================================================================
QUICK SETUP (3 STEPS, 5 MINUTES)
================================================================================

STEP 1: Import
  import { LinkGlowSynergyEngine_v2 } from './LinkGlowSynergyEngine_v2.js';

STEP 2: Initialize (in AtomaGame constructor)
  this.glowEngine_v2 = new LinkGlowSynergyEngine_v2({
    enableVisualMetrics: true,
    enableDebug: false,
    fallbackToLegacy: true
  });

STEP 3: Update (in game loop, after ComputeSynergyScore2_1)
  this.glowEngine_v2.update(this.nodeLinkingSystem.links, deltaTime);

DONE! Now every link has:
  link.userData.visualGlow = {
    glowIntensity: 0–1,
    synergyNorm: 0–1,
    qualityNorm: 0–1,
    corruptionPulse: 0–1
  };

================================================================================
WEEK 2 FORMULA
================================================================================

glowIntensity =
  (synergyNorm × 0.70) +              // Synergy 70% (primary)
  (qualityNorm × 0.30)                // Quality 30%

If corruption > 0.60:
  glowIntensity += corruptionPulse    // Add chaos effect

Result: 0–1 normalized value

================================================================================
OUTPUT STRUCTURE
================================================================================

link.userData.visualGlow = {
  glowIntensity: 0–1,           // Normalized brightness (use for shaders)
  synergyNorm: 0–1,             // From ComputeSynergyScore2_1
  qualityNorm: 0–1,             // Avg quality of both nodes
  corruptionPulse: 0–1,         // Extra pulse for chaotic nodes
  updatedAt: timestamp,         // Last update (ms)
  debug: {
    method: 'visual'|'legacy'|'default',
    nodeAId: string,
    nodeBId: string
  }
};

================================================================================
KEY FIELDS EXPLAINED
================================================================================

glowIntensity:
  Range: 0–1
  Use: Feed to material.emissiveIntensity or opacity
  Meaning: How bright should the link glow?
  
synergyNorm:
  Range: 0–1
  From: ComputeSynergyScore2_1.synergyNorm
  Meaning: Connection quality/strength

qualityNorm:
  Range: 0–1
  From: Avg(nodeA.qualityNorm, nodeB.qualityNorm)
  Meaning: How stable are the connected nodes?

corruptionPulse:
  Range: 0–1
  Triggered: When corruption > 0.60
  Meaning: "Chaos flicker" – extra pulse for unstable links

================================================================================
USAGE EXAMPLES
================================================================================

EXAMPLE 1: Get glow intensity for material
  const glow = link.userData.visualGlow;
  if (glow) {
    link.material.emissiveIntensity = glow.glowIntensity * 2.0;
  }

EXAMPLE 2: Quality-based coloring
  const glow = link.userData.visualGlow;
  if (glow?.qualityNorm > 0.75) {
    link.material.color.setHex(0x00ff00);  // Green for high quality
  } else if (glow?.qualityNorm < 0.40) {
    link.material.color.setHex(0xff0000);  // Red for low quality
  }

EXAMPLE 3: Detect chaotic links
  const chaoticLinks = links.filter(l => {
    const glow = l.userData.visualGlow;
    return glow && glow.corruptionPulse > 0.3;
  });

EXAMPLE 4: Monitor performance

================================================================================
FALLBACK BEHAVIOR
================================================================================

When visual metrics unavailable:
  → Falls back to LinkGlowSynergyEngine1_0 logic (v1.0)
  → result.debug.method = 'legacy'
  → Result identical to v1.0 (perfectly safe)

When both systems disabled:
  → Falls back to v1.0
  → Zero overhead
  → Completely safe

Result: Perfect backward compatibility guaranteed

TROUBLESHOOTING
================================================================================

Q: glowIntensity not updating?
A: Check if ComputeSynergyScore2_1 and VisualMetricModel running
   Verify link.userData.synergy2_1 exists
   Verify node.userData.visualMetrics exists

Q: All links using fallback?
A: Normal if metrics not initialized yet
   Check console for errors
   Enable debug: engine.setDebug(true)

Q: Performance slow?
A: Check stats: engine.getStats()
   If visual metrics high usage but slow → check VisualMetricModel
   If fallback high → metrics unavailable (normal, zero overhead)

Q: Chaotic nodes not showing pulse?
A: Check if enableChaosFlicker: true in config
   Verify corruption values > 0.60
   Check link.userData.visualGlow.corruptionPulse

Q: Getting NaN values?
A: Should not happen (defensive clamp in place)
   Enable debug and check console
   Verify input data is valid
