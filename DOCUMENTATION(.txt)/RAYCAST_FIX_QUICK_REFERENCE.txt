Issue: Raycaster crashes when intersecting frozen canonical geometries
Root Cause: Three.js tries to call computeBoundingSphere() on frozen objects
Impact: No raycasting works on MYTHIC, PRIME, ERROR, EMOTIONAL nodes
Solution: Precompute ALL bounds BEFORE freezing

  └─ Added getBoundingBox() helper
  └─ All geometries precompute bounds BEFORE freeze

File 2: RaycastGuardSystem_v1.js (NEW)
  └─ Safe raycasting interface

KEY PRINCIPLE: COMPUTE BEFORE FREEZE, NEVER AFTER

PRECOMPUTATION ORDER:
  1. Compute boundingSphere()
  2. Compute boundingBox()
  3. Compute vertexNormals()
  4. Set userData flags
  5. THEN freeze geometry
  6. Mark as ready

⚙️ PRECOMPUTATION PROCESS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

When canonical geometry is created:

  1. Create geometry (vertices, indices)
  2. computeVertexNormals() ← For lighting
  3. computeBoundingSphere() ← CRITICAL for raycasting
  4. computeBoundingBox() ← Secondary support
  5. Set userData flags (precomputedAndFrozen = true)
  6. Object.freeze(geometry) ← NOW immutable
  7. NEVER attempt to modify after this point

All 24 canonical geometries follow this pattern.
