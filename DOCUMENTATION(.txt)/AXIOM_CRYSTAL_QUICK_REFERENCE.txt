🔷 MESH NAME
   CONTROL_AXIOM_CRYSTAL

📐 GEOMETRY
   ├─ Type: Vertical crystal monolith, fully faceted
   ├─ Vertices: 19 (asymmetrical distribution)
   ├─ Triangles: 22
   ├─ Height:Width Ratio: 1.8:1
   ├─ Base: Irregular heptagon (7-sided, asymmetrical)
   ├─ Apex: Single point, offset from center (asymmetrical)
   ├─ Twist: 5° around Y-axis
   └─ Edges: Sharp, no bevels, no curves

🎨 MATERIAL
   ├─ Type: THREE.MeshPhysicalMaterial
   ├─ Color: Gold (0xffd700) → Amber (0xffb347) blend
   ├─ Transmission: 0.9 (highly transparent)
   ├─ Roughness: 0.1 (polished)
   ├─ IOR: 1.45 (crystal-like refraction)
   ├─ Metalness: 0.0 (dielectric, not metallic)
   ├─ Emissive: Dark honey (0x8b6914) at 0.05 intensity
   └─ Reflectivity: 0.9 (strong Fresnel reflections)

⛔ IMMUTABILITY
   ├─ FROZEN: geometry and material objects
   ├─ NO STATE CHANGES: immutable flag set
   ├─ NO ANIMATION: mesh static (group can rotate)
   ├─ NO MATERIAL MUTATION: color/transmission locked
   ├─ NO FX TWEAKS: skipped by FXRuntime, WaveShaderBridge
   └─ GUARDS: noMaterialMutation flag prevents all runtime changes

✅ IMPLEMENTATION
   Location: EnhancedNodeModels.js
   Function: createAxiomCrystalNode(group, color)
   Category: control
   Registration: Always index 0 (canonical form, singleton)
   Returns: group with CONTROL_AXIOM_CRYSTAL mesh

🎭 VISUAL BEHAVIOR
   ┌─ At Distance: Tall crystalline tower, commanding
   ├─ Silhouette: Irregular spike with asymmetrical lean-left
   ├─ Lighting (head-on): Gold-amber faces, sharp facet edges
   ├─ Lighting (glancing): Fresnel brightens edges, honey transmission
   ├─ Backlighting: Strong golden glow from interior
   ├─ Animation: NONE (static, authoritative)
   └─ Mutation: NONE (immutable form)

⚙️ RENDERING PIPELINE
   1. Create BufferGeometry (19 vertices, 22 triangles)
   2. Apply computeVertexNormals() for facet lighting
   3. Create MeshPhysicalMaterial with transmission params
   4. Freeze material object (immutable)
   5. Create mesh, apply 5° Y-axis twist
   6. Freeze geometry object (immutable)
   7. Add to group, mark userData flags
   8. Return group (no further modifications)

🚫 FORBIDDEN OPERATIONS
   ├─ Changing color (gold-amber blend locked)
   ├─ Modifying transmission value
   ├─ Animating mesh rotation (group can rotate, mesh cannot)
   ├─ Adjusting emissive intensity (locked at 0.05)
   ├─ Applying state-based effects
   ├─ Linking to node state (no responsiveness)
   └─ Mutating geometry after creation

✨ SPECIAL PROPERTIES
   userData.isStaticAxiomCrystal:    true
   userData.immutable:                true
   userData.noMaterialMutation:       true
   geometry[frozen]:                  true
   material[frozen]:                  true
   material.userData[sealed]:         true
