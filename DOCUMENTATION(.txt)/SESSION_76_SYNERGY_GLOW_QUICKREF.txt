SESSION 76 — CORE SYNERGY GLOW SCALING — QUICK REFERENCE
═══════════════════════════════════════════════════════════════════════════════

WHAT IT DOES
────────────
Scales node core glow intensity based on link synergy magnitude.
  High synergy  → bright core glow (intensity 1.0)
  Low synergy   → subtle core glow (intensity 0.3)

PURPOSE
───────
Provides instant visual feedback on link quality without changing gameplay.

SCALING FORMULA
────────────────
scaledIntensity = 0.3 + (synergy * 0.7)

Examples:
  synergy = 0.0  → intensity = 0.30 (minimal)
  synergy = 0.5  → intensity = 0.65 (moderate)
  synergy = 1.0  → intensity = 1.00 (maximum)

API FUNCTIONS
─────────────
1. applyCoreSynergyGlowScaling(sourceNode, targetNode, synergy)
   → Applies synergy glow to BOTH nodes in a link
   → Returns { success, sourceIntensity, targetIntensity, synergy }

2. removeCoreSynergyGlow(node)
   → Removes synergy glow, restores baseline intensity
   → Returns boolean success

3. getCoreSynergyGlowState(node)
   → Queries current synergy glow state
   → Returns { active, intensity, synergy, appliedAt, baseIntensity }

INTEGRATION POINTS
───────────────────
Link Creation (attemptLink):
  const glowResult = applyCoreSynergyGlowScaling(sourceNode, targetNode, synergy);

Link Removal (removeLink):
  if (link.source && link.target) {
    removeCoreSynergyGlow(link.source);
    removeCoreSynergyGlow(link.target);
  }

SAFETY
──────
✓ Material-only (no color, opacity, geometry, scale changes)
✓ Baseline preservation (restores exact pre-synergy intensity)
✓ Type-safe (only applies to emissive-capable materials)
✓ Idempotent (safe to remove/apply multiple times)
✓ Zero gameplay impact (purely visual feedback)
✓ Performance: O(1) per node, zero per-frame cost

MATERIAL SUPPORT
─────────────────
✓ MeshStandardMaterial   (supports emissiveIntensity)
✓ MeshLambertMaterial    (supports emissiveIntensity)
✓ MeshPhongMaterial      (supports emissiveIntensity)
✓ MeshToonMaterial       (supports emissiveIntensity)
✗ MeshBasicMaterial      (NO emissive support, silently skipped)

BEHAVIOR
────────
On Link Creation:
  1. Calculate synergy (0.0 to 1.0)
  2. Scale: intensity = 0.3 + (synergy * 0.7)
  3. Apply to source and target core meshes
  4. Store base intensity for restoration

On Link Removal:
  1. Restore core emissiveIntensity to baseline
  2. Clear synergy tracking metadata
  3. Node returns to default appearance

Multi-Link Behavior:
  - Each link has independent glow calculation
  - Last applied glow "wins" if multiple links on same node
  - Removing one link may expose glow from another link (expected)

VISUAL CHARACTERISTICS
───────────────────────
Low Synergy (0.0-0.3):
  → Barely noticeable glow
  → Link appears weak/incompatible
  → Suggests relinking to stronger partner

Medium Synergy (0.4-0.6):
  → Clear, visible glow
  → Link appears functional
  → Standard, acceptable connection

High Synergy (0.7-1.0):
  → Bright, striking glow
  → Link appears powerful/optimal
  → Suggests excellent compatibility

EDGE CASES
──────────
• Node with no core mesh    → Gracefully skipped, no error
• Node with multiple cores  → Applies to first matching mesh
• Material with no emissive → Uses core color as emissive color
• Link between already-linked nodes → No double-glow artifacts

METADATA STORED
────────────────
node.userData.coreSynergyGlowActive       (boolean) - Is glow on?
node.userData.coreSynergyGlowIntensity    (number)  - Current intensity
node.userData.coreSynergyMagnitude        (number)  - Synergy value
node.userData.coreSynergyGlowAppliedAt    (number)  - Timestamp
node.userData.baseCoreGlowIntensity       (number)  - Baseline intensity
