┌─────────────────────────────────────────────────────────────────────────────┐
│ HASH WITHOUT BRANCHING                                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                               │
│ Formula:  fract(sin(n) * 43758.5453123)                                      │
│                                                                               │
│ Properties:                                                                   │
│   ✓ Zero if/else branches (perfect GPU parallelism)                         │
│   ✓ O(1) performance                                                         │
│   ✓ Deterministic (same input → same output)                                 │
│   ✓ Spatially variant (each point gets unique value)                        │
│   ✗ Discrete (jumps between values, not smooth)                             │
│                                                                               │
│ Used for: Random value generation, noise basis                               │
│ Speed:     Fastest (1 sin + 1 multiply + 1 fract)                           │
│                                                                               │
│ Graph:                                                                        │
│   1.0 ├─┐─┐─┐─┐─┐─┐─┐─┐─┐─┐─┐─┐─┐─┐─┐─┐─┐─┐─┐                           │
│   0.5 ├─┼─┼─┼─┼─┼─┼─┼─┼─┼─┼─┼─┼─┼─┼─┼─┼─┼─┼─┼─┤                           │
