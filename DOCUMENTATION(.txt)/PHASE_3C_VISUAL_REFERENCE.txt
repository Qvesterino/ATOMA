================================================================================
PERSONALITY SIGNAL OVERVIEW
================================================================================

5 PERSONALITY SIGNALS (0–1 NORMALIZED):

1. CLARITY (clarityBoost)
   Source: coherence metric
   Meaning: How clear and coherent is this node?
   ┌─────────────────────────────────┐
   │ Low (0.0)  │ Medium (0.5) │ High (1.0) │
   │ Confused   │ Ok           │ Crystal Clear │
   └─────────────────────────────────┘
   CPU Effect: Emissive intensity ↓ ↑ Bright
   GPU Effect: Available as uClarity uniform
   Visual: Coherent nodes glow

2. RESONANCE (resonanceBoost)
   Source: connection harmony metric
   Meaning: How harmonious are this node's connections?
   ┌─────────────────────────────────┐
   │ Low (0.0)  │ Medium (0.5) │ High (1.0) │
   │ Isolated   │ Connected    │ In Harmony │
   └─────────────────────────────────┘
   CPU Effect: Pulse oscillation ↓ ↑ Fast pulse
   GPU Effect: Available as uResonance uniform
   Visual: Connected nodes pulse faster

3. ENTROPY (entropyPenalty)
   Source: disorder metric (inverted)
   Meaning: How chaotic is this node?
   ┌─────────────────────────────────┐
   │ Low (0.0)  │ Medium (0.5) │ High (1.0) │
   │ Stable     │ Turbulent    │ Chaotic    │
   └─────────────────────────────────┘
   CPU Effect: Jitter movement ↓ ↑ More jitter
   GPU Effect: Available as uEntropy uniform
   Visual: Chaotic nodes shimmer and twitch

4. FOCUS (focusShift)
   Source: load metric (overload)
   Meaning: Is this node overloaded/scattered?
   ┌─────────────────────────────────┐
   │ Low (0.0)  │ Medium (0.5) │ High (1.0) │
   │ Focused    │ Busy         │ Overloaded │
   └─────────────────────────────────┘
   CPU Effect: Rotation drift ↓ ↑ More wobble
   GPU Effect: Available as uFocus uniform
   Visual: Overloaded nodes lose composure

5. CORRUPTION (corruptionSignal)
   Source: corruption metric
   Meaning: How corrupted is this node?
   ┌─────────────────────────────────┐
   │ Low (0.0)  │ Medium (0.5) │ High (1.0) │
   │ Pure       │ Tainted      │ Corrupted  │
   └─────────────────────────────────┘
   CPU Effect: Color tinting ↓ ↑ Red/orange
   GPU Effect: Available as uCorruption uniform
   Visual: Corrupted nodes turn crimson

2 VISUAL METRICS (0–1 NORMALIZED):

1. ENERGY (energyNorm)
   Meaning: How energetic is this node?
   Low (0.0): Dim and quiet
   High (1.0): Bright and vibrant
   GPU Effect: Available as uEnergy uniform
   Visual: Energetic nodes shine brighter

2. QUALITY (qualityNorm)
   Meaning: How high quality is this node?
   Low (0.0): Rough and blurry
   High (1.0): Sharp and precise
   GPU Effect: Available as uQuality uniform
   Visual: High-quality nodes have crisp edges

================================================================================
DATA FLOW VISUALIZATION
================================================================================

FROM METRIC TO VISUAL EFFECT:

CLARITY (0–1)
   ↓
   PersonalityVisualAdapter computes: clarityBoost
   ↓
   PersonalityVFXLayer_v1 applies: emissive intensity change
   ↓
   PersonalityShaderBridge_v1 exposes: uniform float uClarity
   ↓
   GPU Shader uses: emissiveColor *= (1.0 + uClarity * 0.4)
   ↓
   RESULT: Coherent nodes glow brighter

CORRUPTION (0–1)
   ↓
   PersonalityVisualAdapter computes: corruptionSignal
   ↓
   PersonalityVFXLayer_v1 applies: color tinting toward red
   ↓
   PersonalityShaderBridge_v1 exposes: uniform float uCorruption
   ↓
   GPU Shader uses: color += vec3(uCorruption * 0.3)
   ↓
   RESULT: Corrupted nodes tint crimson

(And so on for resonance, entropy, focus...)

================================================================================
SHADER EFFECT POSSIBILITIES
================================================================================

EFFECT 1: EMISSIVE MODULATION (Clarity-driven)
   CODE:
   emissiveColor *= (1.0 + uClarity * 0.4);
   
   LOW CLARITY (0.0):  No extra emissive
   MID CLARITY (0.5):  Emissive × 1.2
   HIGH CLARITY (1.0): Emissive × 1.4
   
   VISUAL: Node glows brighter as it becomes more coherent

EFFECT 2: CORRUPTION TINTING
   CODE:
   vec3 tint = mix(baseColor, vec3(1.0, 0.3, 0.0), uCorruption * 0.25);
   
   NO CORRUPTION (0.0):  Base color unchanged
   MID CORRUPTION (0.5): 12.5% red-orange tint
   HIGH CORRUPTION (1.0):25% red-orange tint
   
   VISUAL: Node color shifts toward red-orange

EFFECT 3: ENERGY BRIGHTNESS
   CODE:
   color *= (1.0 + uEnergy * 0.3);
   
   LOW ENERGY (0.0):  No extra brightness
   MID ENERGY (0.5):  × 1.15 brightness
   HIGH ENERGY (1.0): × 1.3 brightness
   
   VISUAL: Energetic nodes shine brighter

EFFECT 4: ENTROPY NOISE (Optional, advanced)
   CODE:
   float noise = sin(position.x * 10.0 + uTime) * 0.5 + 0.5;
   vec3 distorted = position + normal * (uEntropy * noise * 0.01);
   
   NO ENTROPY (0.0):  No distortion
   HIGH ENTROPY (1.0):Max distortion
   
   VISUAL: Chaotic nodes shimmer with wave patterns

EFFECT 5: FOCUS WOBBLE
   CODE:
   float wobble = sin(uTime * 3.0) * uFocus * 0.05;
   vec3 wobbled = position + normal * wobble;
   
   NO FOCUS ISSUES (0.0):  No wobble
   HIGH FOCUS (1.0):       Max wobble
   
   VISUAL: Overloaded nodes waver unstably
