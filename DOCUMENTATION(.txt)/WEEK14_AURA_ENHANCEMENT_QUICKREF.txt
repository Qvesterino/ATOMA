SUMMARY

Week 14 adds GPU-driven archetype-specific enhancements to node and link auras.
Maps ascensionMultiplier (Week 13) to GPU uniforms for visual FX.

Output: Material uniforms (uArchetypeIntensity, uArchetypeBloomBoost, etc.)

================================================================================
1. INTEGRATION (4 EASY STEPS)
================================================================================

STEP 1: IMPORT
-----------
import { ArchetypeAuraEnhancement_v1 } from './ArchetypeAuraEnhancement_v1.js';

STEP 2: CONSTRUCTOR (in game init, after aura systems)
-----------------------------------------------------
this.archetypeAuraFX = new ArchetypeAuraEnhancement_v1({
  nodeAura: this.nodeAuraSystem,        // Week 9
  linkAura: this.linkAuraSystem,        // Week 10 (can be null)
  archetypeCurves: this.archetypeCurves,  // Week 13
  debugEnabled: false,
});

STEP 3: UPDATE LOOP (AFTER archetypeCurves.update)
-------------------------------------------------
this.archetypeCurves.update(deltaTime);        // Week 13 first!
this.archetypeAuraFX.update(deltaTime);        // NEW Week 14

STEP 4: CLEANUP (on shutdown)
-----------------------------
this.archetypeAuraFX.dispose();

DONE! 🎉 Week 14 is integrated!

================================================================================
2. HOW IT WORKS
================================================================================

Week 14 reads archetype evolution from Week 13:
  node.userData.archetypeEvolution.ascensionMultiplier

Maps to enhancement parameters per archetype:
  - Sage: smooth cyan glow, steady breathing
  - Warlock: chaotic red flicker, rapid pulsing
  - Sentinel: stable blue breathing, stoic
  - Empath: warm harmonic waves
  - Invoker: golden vibrant energy
  - Mythic: purple legendary maximum

Applies via EMA smoothing (alpha 0.12):
  Material uniforms gradually transition to target values
  No jarring jumps, organic visual flow

Result: Auras now reflect archetype personality!

4. GPU UNIFORMS INJECTED
================================================================================

Material uniforms automatically created and updated:

uArchetypeIntensity          (0.5–2.5)    Aura glow strength
uArchetypeRadiusBoost        (0.5–2.0)    Sphere radius scale
uArchetypeColorShift         vec3         RGB additive shift
uArchetypeBloomBoost         (0.5–2.5)    Bloom/glow strength
uArchetypeDistortionAmount   (0.0–1.0)    Shader distortion

These are injected via material.onBeforeCompile (safe, non-invasive)

In shaders, use them like:
  baseColor *= uArchetypeIntensity;
  baseColor += uArchetypeColorShift * 0.5;

9. COMMON ISSUES & FIXES
================================================================================

Issue: "Cannot read property 'auras' of undefined"
Fix:   Make sure nodeAura (NodeAuraSystem_v1) is initialized first

Issue: Auras not showing enhancements
Fix:   1. Check archetypeCurves.update() is called BEFORE archetypeAuraFX.update()
       2. Check archetype evolution exists: node.userData.archetypeEvolution
       3. Enable debugEnabled: true to see what's happening

Issue: Performance is slow
Fix:   Check DevTools Performance tab - should see <0.5ms per 200 nodes
       If slower, may be linked to other systems

Issue: Color shifts not visible
Fix:   Color shifts are subtle by design (5–15%)
       To make more visible, increase colorShift values in code

Issue: Transitions feel choppy
Fix:   EMA alpha = 0.12 (current)
       Lower = smoother but delayed (try 0.08)
       Higher = more responsive but choppier (try 0.20)
