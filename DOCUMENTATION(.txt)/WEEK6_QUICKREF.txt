================================================================================
5. INTEGRATION SNIPPET
================================================================================

// In AtomaGame constructor:
this.materialRegistry = null;

// In init():
this.materialRegistry = new PersonalityMaterialProfileRegistry_v1({
  advancedFX: this.advancedShaderFX,
  debugEnabled: false,
});

// When nodes spawn (modify node creation function):
createNode(nodeData) {
  const node = createNodeMesh(nodeData);
  this.materialRegistry?.registerNode(node);
  return node;
}

// For existing nodes (in loadLevel):
loadLevel() {
  const nodes = this.aiNodes.nodes || [];
  this.materialRegistry?.registerNodes(nodes);
}

// In dispose():
if (this.materialRegistry) {
  this.materialRegistry.dispose();
}

================================================================================
9. HANDLING EDGE CASES
================================================================================

// Missing AdvancedFX - still works, no crash:
const registry = new PersonalityMaterialProfileRegistry_v1({});
registry.setAdvancedFX(advancedFX); // Add reference later

// Missing materials - graceful:
registry.registerNode(nodeMissingMaterial); // Logs warning, returns false

// Null inputs - all safe:
registry.registerNode(null);              // No crash
registry.assignProfile(node, null);       // No crash
registry.registerNodes([]);               // Returns 0

// Already registered - idempotent:
registry.registerNode(node);              // Success
registry.registerNode(node);              // Returns true (already done)

// Multiple materials per node - all get same profile:
node with 3 materials → registry.registerNode(node) → all 3 get profile

10. MATERIAL EXTRACTION
================================================================================

Registry finds materials in any of these locations:
- node.material
- node.material[]
- node.materials
- node.mesh.material
- node.mesh.material[]
- node.mesh.materials

Works with both single materials and arrays automatically.

================================================================================
11. CATEGORY DETECTION
================================================================================

Registry checks in order:
1. node.category (primary)
2. node.nodeType (fallback)
3. node.type (fallback)

Lowercased, trimmed, case-insensitive matching.

Partial matches supported (e.g., "corrupted_node" matches "corrupted").

================================================================================
15. TROUBLESHOOTING
================================================================================

Materials not getting effects:
  → registry.advancedFX !== null ? (check AdvancedFX)
  → registry.getRegisteredCount() > 0 ? (check registration)
  → setDebugEnabled(true) (check logging)
  → getNodeInfo(node).materialCount > 0 ? (check node has materials)

Profile not applied:
  → getProfileMap().hasOwnProperty('chaos') (check profile exists)
  → getMaterialProfile(material) !== null (check registration)
  → assignProfile(node, 'chaos') (manual override)

No debug output:
  → setDebugEnabled(true)
  → Check browser Console (dev tools)
  → Look for [Registry] prefix
