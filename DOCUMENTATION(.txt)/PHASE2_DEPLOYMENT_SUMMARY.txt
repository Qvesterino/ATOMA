LOGIC:
  1. Read harmony value: const harmony = link.userData?.harmonyLevel ?? ...
  2. Compute blocking multiplier:
     - harmony >= 0.8: multiplier = 0.0 (HARD BLOCK)
     - harmony 0.4-0.8: multiplier = 1.0 - ((harmony - 0.4) / 0.4) (SOFT DAMPING)
     - harmony < 0.4: multiplier = 1.0 (NO EFFECT)
  3. Apply to transmission rate: baseRate *= harmonyBlockMultiplier

================================================================================
                        MULTIPLICATIVE STACKING
================================================================================

Why Multiplicative (Not Additive)?

Example: Link with Synergy = 0.4x and Harmony = 0.5x

  ADDITIVE (wrong):  0.4 + 0.5 = 0.9x
    → Only 10% reduction
    → Both effects nearly cancel out
    → Weak barrier

  MULTIPLICATIVE (correct): 0.4 × 0.5 = 0.2x
    → 80% reduction
    → Effects reinforce each other
    → Strong barrier ✓

Result: Encourages players to strategically combine Synergy and Harmony
for maximum corruption protection. Rewards network design optimization.
