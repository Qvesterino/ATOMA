SESSION 51: NODE VISUAL STATE REBIND FIX - QUICK SUMMARY
================================================================================

PROBLEM
─────
Nodes transition to LINKED/ACTIVE state but REMAIN IN PLACEHOLDER VISUALS
instead of applying final geometry and materials.

SOLUTION
────────
Canonical function + manager that applies final visuals on state transitions.

KEY COMPONENTS
──────────────

1. applyFinalNodeVisualState(node, options)
   → Removes fallback meshes
   → Applies final core geometry
   → Applies final materials
   → Corrects aura positioning (below core)
   → Enforces renderOrder + depth settings
   → Re-registers in visual hierarchy

2. NodeVisualStateBinder (Manager)
   → Tracks nodes per state
   → Auto-repairs LINKED nodes with fallback visuals
   → Fires callbacks on state changes
   → Auto-disposal

3. assertNodeVisualStateCorrect(node)
   → Development assertion
   → Catches placeholder nodes in LINKED state
   → Validates hierarchy and materials

───────────

ENFORCEMENT RULES (CANONICAL)
─────────────────────────────

NODE_CORE:
  - renderOrder = MAX
  - depthWrite = true
  - transparent = false
  - opacity = 1.0

NODE_SHELL:
  - renderOrder < CORE
  - depthWrite = false
  - transparent = true
  - opacity ≤ 0.4

NODE_AURA:
  - renderOrder < SHELL
  - depthWrite = false
  - transparent = true
  - opacity ≤ 0.06

NODE_HIERARCHY:
  - Core is direct child of nodeRoot
  - Shell is sibling of core (not parent)
  - Aura is sibling of core (not parent)
