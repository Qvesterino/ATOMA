WHAT HAPPENS
─────────────────────────────────────────────────────────────────────────────

Glyphs (node symbols) now progressively reveal as connection synergy increases:

  Synergy 0.70 ─────────────→ Engagement begins, glyph preparing to reveal
  Synergy 0.75 ─────────────→ Tier 1 REVEAL: Glyph fades in (+0 to +35% opacity)
  Synergy 0.85 ─────────────→ Tier 2 REVEAL: Full glyph + gold accent + faster animation


HOW IT WORKS
─────────────────────────────────────────────────────────────────────────────

1. Link synergy computed (0-1 scale)
2. updateLinkMetrics() called in NodeLinkingSystem
3. Glyph system notified: updateNodeSynergy(nodeId, synergy)
4. Reveal level determined: hidden → tier1 → tier2
5. Next glyph update applies visual effects
6. Animation continues, state removes when synergy drops

VISUAL EFFECTS BY TIER
─────────────────────────────────────────────────────────────────────────────

TIER 0 (0.00–0.69): HIDDEN
  • Glyph normal visibility
  • Standard animation speed
  • No special effects

TIER 1 (0.75–0.84): PARTIAL REVEAL
  • Opacity fades in smoothly
  • Formula: baseOpacity + (fadeProgress × 0.35)
  • Max opacity clamped to 0.60
  • Animation remains normal speed
  • Effect: Symbol becomes visible as you watch

TIER 2 (≥0.85): FULL REVEAL
  • Opacity boost: baseOpacity × 1.15 (15% increase)
  • Max opacity clamped to 0.85
  • Color accent: Shift toward gold/cyan blend (25%)
  • Animation boost: 1.3× speed (30% faster)
  • Effect: Symbol glows, pulses faster, premium appearance


ANIMATION BEHAVIOR
─────────────────────────────────────────────────────────────────────────────

At Tier 2, animation state receives:
  animState.synergyBoost = 1.3

All animation phases multiply by this factor:
  rotationPhase += deltaTime × 0.3 × synergyBoost
  pulsePhase += deltaTime × pulseSpeed × synergyBoost
  
Result: Glyphs spin/pulse 30% faster at peak cooperation


STATE TRACKING
─────────────────────────────────────────────────────────────────────────────

Per node, system maintains:
  {
    linkedSynergy: <number 0-1>,     // Current synergy from connected links
    revealLevel: <0|1|2>,             // 0=hidden, 1=tier1, 2=tier2
    revealed: <boolean>,              // Is symbol currently visible?
    lastRevealTime: <timestamp>       // When reveal level changed
  }


HOW TO USE (FOR DEVELOPERS)
─────────────────────────────────────────────────────────────────────────────

If you need to manually trigger glyph synergy reveals:

  // From any code with access to glyphSystem:
  if (window.glyphSystem && nodeId && synergyValue !== undefined) {
    window.glyphSystem.updateNodeSynergy(nodeId, synergyValue);
  }

Typically called from NodeLinkingSystem.updateLinkMetrics() automatically.

TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────

Problem: Glyphs not revealing
  → Check: window.glyphSystem exists?
  → Check: updateNodeSynergy() being called?
  → Check: Synergy value ≥ 0.75?

Problem: Glyphs too bright/dim
  → Adjust: glyphOpacityLimits in glyph system
  → Or:     Modify reveal opacity formula (line 1430)

Problem: Animation too fast/slow
  → Adjust: synergyBoost value (line 1462, currently 1.3)

Problem: Color accent wrong
  → Adjust: this.colors.gold or lerp percentage (line 1450)
