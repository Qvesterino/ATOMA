================================================================================
API REFERENCE
================================================================================

CONSTRUCTOR:
  new PersonalityShaderStabilizedFX_v1({
    advancedFX: PersonalityShaderAdvancedFX_v1 | null,    // Optional
    lowFXProvider: () => boolean,                          // Optional
    enabled: boolean = true                                // Optional
  })

METHODS:
  register(material, profileName)
    • Registers material with a GPU-stabilized profile
    • profileName: 'clarity_stable', 'resonance_stable', 'chaos_stable', 
                   'focus_stable', 'corruption_stable', 'entropy_stable'
    • Returns: void
    • Sets up onBeforeCompile shader injection

  unregister(material)
    • Removes material from system
    • Restores previous onBeforeCompile hook if it existed
    • Returns: void

  update(deltaTime)
    • Updates all uniform values (call every frame)
    • deltaTime: seconds since last frame
    • Returns: void
    • No-op if lowFXProvider() returns true

  dispose()
    • Cleanup all registered materials
    • Clears internal registries
    • Returns: void

PROPERTIES:
  materials: Map
    • Registered materials + metadata
    • Structure: { profile, uniforms, registered, lastPosX/Y/Z }

  profiles: Map
    • Profile data per material
    • Keyed by material reference

  globalTime: number
    • Accumulated time in seconds
    • Incremented by update()

  enabled: boolean
    • System on/off flag
