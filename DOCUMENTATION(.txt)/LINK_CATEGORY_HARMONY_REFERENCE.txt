5. PARTICLE SYSTEM
═══════════════════════════════════════════════════════════════════════════════════

Particle Count (scales with harmony):
  Formula: count = 10 + (harmonyScore × 20)
  
  Harmony 0.95 → 10 + 19 = 29 particles (HIGH FLOW)
  Harmony 0.70 → 10 + 14 = 24 particles (MEDIUM FLOW)
  Harmony 0.50 → 10 + 10 = 20 particles (LOW FLOW)
  Harmony 0.40 → 10 +  8 = 18 particles (MINIMAL FLOW)

Particle Properties:
  ├─ Size: 0.04–0.12 units (random per particle)
  ├─ Lifespan: 0.3–0.7 seconds
  ├─ Path: Direct from source to target
  ├─ Color: Interpolated between source & target palettes
  ├─ Motion: Linear along path + perpendicular oscillation
  ├─ Speed: Varies with particle index (staggered arrival)
  └─ Opacity: Fades with particle age

Motion Profile:
  ├─ 0% progress:   At source position
  ├─ 50% progress:  Midway along path + max perpendicular offset
  ├─ 100% progress: At target position
  └─ Perpendicular: ±0.1 unit oscillation (sin wave)

9. PERFORMANCE METRICS
═══════════════════════════════════════════════════════════════════════════════════

Memory:
  ├─ Per transition: 1–2 KB
  ├─ Per particle: ~50 bytes
  ├─ Color object: 32 bytes
  └─ Total (10 links @ 25 particles ea): ~20 KB

CPU:
  ├─ Per-frame update: 0.1–0.5ms (depends on particle count)
  ├─ Color interpolation: O(1)
  ├─ Particle simulation: O(n) where n = particles
  └─ 10 concurrent links: ~0.3ms at 60fps

Scalability:
  ├─ Safe maximum: 50–100 concurrent transitions
  ├─ Typical ATOMA session: 5–20 links at any time
  ├─ FPS impact: <1% on typical hardware
  └─ Works on mobile (scales particle count if needed)
