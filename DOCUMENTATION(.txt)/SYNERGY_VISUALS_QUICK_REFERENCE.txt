SYSTEM 1: SIMPLE SYNERGY PULSE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

WHAT IT DOES:
  Soft, breathing pulse on nodes when synergy is high

TRIGGER:
  synergy > 0.6

EFFECT:
  Node scale oscillates: 1.0 ± 3%
  Formula: pulse = 1.0 + sin(time * 1.5) * 0.03 * synergy

FREQUENCY:
  1.5 rad/s = ~0.24 Hz (very slow, calm breathing)

AMPLITUDE:
  ±3% at synergy=1.0 (barely noticeable)
  Scales with synergy value (higher synergy = more visible)

FADE:
  Smoothly appears when synergy > 0.6
  Smoothly disappears when synergy < 0.6

VISUAL CHARACTER:
  - Soft, elegant
  - Non-distracting
  - Makes network feel alive
  - Immediate feedback of synergy level

SYSTEM 2: VISUAL NETWORK TIME ELASTICITY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

WHAT IT DOES:
  Visual-only "time reversal" when network reaches extreme coherence

TRIGGER:
  avgSynergy > 0.85 for sustained 5+ seconds

EFFECT:
  Animation time parameter runs BACKWARD at 40% speed
  Creates illusion of "time rewinding" for visual effects

VISUAL TIME UPDATE:
  visualTime -= dt * 0.4  (when active)

FADE:
  Smooth 1s fade-in when condition met
  Smooth 1s fade-out when condition drops

GAME IMPACT:
  ZERO - all gameplay uses real deltaTime
  Only affects animation phase (visual only)

VISUAL CHARACTER:
  - Transcendent, alien
  - Network feels in alternate state
  - Smooth, not jarring
  - Reinforces extreme synergy state
