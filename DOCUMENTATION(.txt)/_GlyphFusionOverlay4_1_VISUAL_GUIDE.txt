BLENDING FORMULA:
─────────────────

  finalColor = baseColor * 0.7 + semanticColor * 0.3
  finalOpacity = 0.5 * fadePhase (0 to 1)

Example: Node at full focused intensity
  baseColor = node's layer color (e.g., cyan from Layer 5)
  semanticColor = cyan (0x00F2FF)
  result = very strong cyan (70% base + 30% semantic = cyan blend)
  opacity = 0.5 * 1.0 = 0.5 (semi-transparent)
