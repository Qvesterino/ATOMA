3. PROFILE RESOLVER TEMPLATE
================================================================================

_resolveLinkAuraProfile(link) {
  const q = link.userData?.quality?.score ?? 50;
  const synergy = link.userData?.quality?.synergyNorm ?? 0.5;
  const corruption = link.userData?.metrics?.corruption ?? 0.0;
  const entropy = link.userData?.metrics?.entropy ?? 0.0;

  if (corruption > 0.45) return 'corruption_aura';
  if (q > 80 && synergy > 0.6) return 'mythic_synergy_aura';
  if (synergy > 0.6) return 'synergy_aura';
  if (entropy > 0.7) return 'chaos_aura';
  if (q < 40) return 'corruption_aura';
  
  return 'stability_aura';  // Default
}

Read Sources (LinkAuraSystem reads ONLY, never modifies):

Mesh Properties (Updated per frame):
  mesh.position        → Aligned to link midpoint
  mesh.scale           → Scaled by link length + radius
  mesh.quaternion      → Rotated to match link vector
  mesh.visible         → Hidden if intensity < 0.01

Uniforms (Updated per frame):
  uTime               (global animation time)
  uAuraIntensity      (0-1, smoothed)
  uAuraRadius         (0.3-2.0)
  uAuraColor          (profile-specific)
  uSynergy, uQuality, uEntropy, uResonance, uCorruption

10. TROUBLESHOOTING
================================================================================

Problem: No auras visible
  → Check: registerLink() called on link creation
  → Check: update() called in render loop
  → Check: Scene reference correct
  → Try: Enable debugEnabled to see console logs

Problem: Wrong profile showing
  → Check: profileResolver logic
  → Check: link.userData.quality and metrics populated
  → Try: Force specific profile in resolver for testing

Problem: Performance degradation
  → Check: Number of visible links
  → Check: FX mode setting (LowFX should reduce auras)
  → Try: Reduce max link count or lower quality/radiusScale

Problem: Memory leak on link removal
  → Check: unregisterLink() called on link destruction
  → Try: manual dispose() and recreate system
  → Check: Scene reference still valid

Problem: Auras clipping through geometry
  → Try: Adjust frustumCulled setting or camera.far
  → Try: Increase radiusScale in profile
  → Check: Link alignment calculation (vector math)
