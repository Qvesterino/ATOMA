WHAT IS IT?
───────────
A lightweight system that makes ATOMA's 4 major HUDs collapsible. Players click
a button (▲/▼) to minimize panels. Layout is saved automatically.

FILES CREATED
──────────────
1. HUDRegistry.js              — HUD configuration definitions
2. HUDLayoutManager.js         — State management + persistence
3. CollapsibleHudWrapper.js    — DOM manipulation utilities
4. HudCollapseSystem1_0.js     — Master integration module

FILES MODIFIED
───────────────
1. main.js                     — Import + initialization call


HOW TO USE
──────────
FOR PLAYERS:
  1. Click the collapse button (▲) in any HUD header
  2. Panel minimizes to header-only
  3. Layout is saved automatically
  4. Persists across page reloads

FOR DEVELOPERS (Console):
  window.toggleHud('automationHUD')      — Toggle specific HUD
  window.resetAtomaHudLayout()            — Reset to defaults
  window.debugHuds()                      — Print state
  window.getHudState()                    — Get state object

TROUBLESHOOTING
────────────────
Button not showing?
  → Check HUD has correct DOM id in HUDRegistry.js
  → Check .hud-body wrapper exists in HUD

State not persisting?
  → Check if localStorage available (DevTools > Storage)
  → Clear corrupted data: window.resetAtomaHudLayout()

HUD not collapsing?
  → Run: window.debugHuds() to check state
  → Verify .hud-collapse-button exists
