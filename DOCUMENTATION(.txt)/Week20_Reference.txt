  • Blended into emissive color
  • Color varies from warm (low freq) → cool (high freq)

MODE B: CHROMATIC RIPPLE DISTORTION
  • Radial ripple pattern with RGB channel separation
  • Creates shimmering chromatic halo
  • Amplitude driven by resonanceLevel

  • Visual: Iridescent aberration effect

MODE C: COHERENCE FLOW MAP
  • Flowing band patterns along link
  • Y-axis bands + X-axis secondary ripples
  • Speed driven by coherenceLevel & flowSpeed
  • Color oscillates cyan ↔ magenta
  • Visual: Animated flow visualization

12. KEY FORMULAS
================================================================================

MULTI-FREQUENCY PULSE:
  basePulse = sin(time * baseFreq * 6.28) * 0.5 + 0.5
  midPulse = sin(time * midFreq * 6.28) * 0.3 + 0.7
  highPulse = sin(time * highFreq * 6.28) * 0.2 + 0.8
  result = basePulse * 0.5 + midPulse * 0.3 + highPulse * 0.2

CHROMATIC RIPPLE:
  ripple = sin(distance - time * 3.0 + phase) * resonance
  damping = exp(-distance * 0.5)
  final = ripple * damping

COHERENCE FLOW:
  bands = sin((y + time * flowSpeed * 2.0) * 6.0 * coherence)
  ripples = sin((x + time * flowSpeed * 1.5) * 4.0)
  flow = mix(bands, ripples, 0.3)

BRIGHTNESS MODULATION:
  brightnessMod = 0.8 + pulse * 0.2
  finalColor *= brightnessMod
