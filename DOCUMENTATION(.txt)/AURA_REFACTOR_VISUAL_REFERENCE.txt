DESIGN VISION
=============

Think of the aura as:
  "A thin energetic outline hugging the node's edge"
  
NOT:
  - A glowing bubble (too spherical)
  - A thick halo (too prominent)
  - A volumetric fog (too diffuse)
  - A neon glow (too saturated)

ANIMATION REFERENCE
===================

Breathing Effect Timeline (3 seconds):

Time: 0s    1s    2s    3s    4s    5s    6s
      │────────────────────────────────────│

Intensity:
1.5   │      ╱╲              ╱╲
      │    ╱    ╲          ╱    ╲
1.0   │──╱──────╲────────╱──────╲───
      │╱          ╲    ╱          ╲
0.5   │

Pattern: sin(time * speed) * amplitude + (1 - amplitude)
  - Amplitude: 0.4 (oscillates 0.6 to 1.4x)
  - Speed: 1.5 cycles per 3 seconds (~0.5Hz)
  - Result: Smooth, calm pulsing

NO PULSING SCALE (common mistake):
  ✗ Don't do this:  Scale oscillates 0.8x to 1.2x
  ✓ Do this:        Intensity oscillates only
                    (geometry stays fixed)

GEOMETRY SCALING REFERENCE
===========================

Node Core → Aura Shell:

Without aura:
    ● 
   Core

With aura (1.25x scale):
    ⊙  ← Shell (25% larger)
   ●   ← Core (unchanged)

Scaling factor options:
  1.15x = Narrow, delicate rim
  1.20x = Medium, balanced rim
  1.25x = Standard, recommended
  1.30x = Wide, pronounced rim
  1.35x = Very wide, dramatic rim

Never scale below 1.15x (rim too thin to see)
Never scale above 1.35x (rim appears disconnected)

SHADER PARAMETER EFFECTS
========================

rimPower (Fresnel exponent):
  1.5 = Very soft falloff (wide rim visible)
  2.0 = Balanced (standard)
  3.0 = Very sharp falloff (narrow rim)

Visual effect on rim:
  Low power:   ╱════════════╲  (gradual fade)
  Mid power:   ╱══════╲      (smooth)
  High power:  ╱═╲            (sharp edge)

rimIntensity (Base strength):
  0.05 = Very subtle (barely visible)
  0.10 = Standard (default)
  0.15 = Bold (stands out)

fresnelMin (Center visibility):
  0.00 = Completely invisible at center
  0.01 = Nearly invisible (recommended)
  0.05 = Slightly visible at center

fresnelMax (Edge brightness):
  0.80 = Capped brightness
  1.00 = Full brightness (recommended)

auraOpacity (Final alpha):
  0.05 = Very subtle, barely visible
  0.10 = Standard, elegant
  0.15 = Bold, prominent

breathingAmplitude (Oscillation range):
  0.20 = Minimal breathing (subtle)
  0.40 = Standard (recommended)
  0.50 = Strong breathing (obvious)

LIGHTING SCENARIOS
==================

  Bright scene:
    ─── Good contrast ───
    Aura visible: ★★★
    
  Dark scene:
    ─ Good visibility ─
    Aura visible: ★★
    (additive blending helps)
    
  Very bright (HDR):
    Can bloom if desired ★
    Additive blending handles well

Camera Positioning:
  Close (< 20 units):
    Aura very visible, clear
    Fresnel effect obvious
    
  Medium (20-100 units):
    Aura visible, balanced
    Fresnel effect proportional
    
  Far (> 100 units):
    Aura still visible
    Can add distance fade (Phase 2)

TEXTURE REFERENCE
=================

Aura appears as:
  • Smooth gradient at edges
  • No visible polygons (due to 16 subdivisions)
  • Organic, natural falloff
  • No banding or posterization

NOT:
  • Pixelated or blocky
  • Banded like a logo
  • Jagged or noisy
  • Low-poly appearance

STATE INDICATION
================

Aura profile → Visual meaning:

  default  (aquamarine)   = Normal, balanced state
  clarity  (bright cyan)  = Sharp focus, signal
  resonance (teal)       = Harmonic, connected
  corrupted (pale violet) = Degraded, unstable
  harmony  (soft amber)   = Unified, balanced

Users should be able to identify state at a glance:
  • Different colors read clearly
  • No confusion between profiles
  • Colorblind-friendly (use distinct hues)

ANTI-PATTERNS
==============

Don't do this:

  ✗ Full sphere glow:    ⊙⊙⊙⊙⊙
  ✗ Thick halo:          ╔═════╗
  ✗ Opaque "shield":     ▓▓▓▓▓▓
  ✗ Flickering noise:    ◯~◯~◯~◯
  ✗ Scale pulsing:       ◯ → ⊙ → ◯
  ✗ Neon saturation:     ⊙ (too bright)
  ✗ Always visible:      ● (should fade at center)

Do this instead:

  ✓ Rim-only outline:    ⊗ (thin line at edge)
  ✓ Soft gradient:       ⊙ (fade from edge)
  ✓ Transparent:         ◎ (see through)
  ✓ Smooth animation:    ──╱──╲── (sine curve)
  ✓ Intensity only:      Breathing ● size
  ✓ Cool colors:         ⊙ (cyan/teal/violet)
  ✓ Fresnel falloff:     Invisible at center
