================================================================================

Tier 0 – DORMANT         Score: 0.00–0.20   Color: Gray #808080
  → Sleeping, no activity

Tier 1 – AWAKENED        Score: 0.18–0.40   Color: Blue #0088ff
  → Beginning to grow

Tier 2 – ASCENDING       Score: 0.35–0.65   Color: Lime #88ff00

Tier 3 – MYTHIC          Score: 0.60–0.85   Color: Purple #ff00ff
  → Rare, special, legendary ✨

Tier 4 – TRANSCENDENT    Score: 0.80–1.00   Color: Yellow #ffff00
  → Peak, divine 🔮

Ranges use hysteresis to prevent flicker (5-10% margin on boundaries).

================================================================================
3. ASCENSION SCORE FORMULAS
================================================================================

NODE ASCENSION (0–1):
  = 0.40 * (quality / 100) +
    0.25 * harmony +
    0.15 * synergy +
    0.10 * energy +
    0.10 * (1 - corruption)
  
  Then: apply EMA smoothing with α=0.20

LINK ASCENSION (0–1):
  = 0.45 * (quality / 100) +
    0.35 * synergy +
    0.10 * (1 - corruption) +
    0.10 * resonance
  
  Then: apply EMA smoothing with α=0.20

All components clamped to [0,1].

4. OUTPUT DATA STRUCTURE
================================================================================

node.userData.mythicEvolution = {
  ascensionRaw:        number,       // 0–1, raw score
  ascensionSmoothed:   number,       // 0–1, EMA filtered

  trailIntensity:      number,       // Trail effect (0.0–1.0)
  glowIntensity:       number,       // Glow effect (0.0–1.0)
  
  hintColorHex:        string,       // Tier color hint
  lastTierChangeTime:  number        // Timestamp
};

Same structure for link.userData.mythicEvolution.

================================================================================
5. VISUAL DRIVER SIGNALS (0–1 RANGE)
================================================================================

auraBoost: Controls how much to boost auras
  Dormant:      0.0
  Awakened:     ascension * 0.4
  Ascending:    ascension * 0.7
  Mythic:       0.8 + (ascension - 0.60) * 0.25
  Transcendent: 1.0

fxIntensity: General FX strength
  Dormant:      0.0
  Awakened:     ascension * 0.3
  Ascending:    0.3 + (ascension - 0.35) * 0.5
  Mythic:       0.65 + (ascension - 0.60) * 0.5
  Transcendent: 1.0

trailIntensity: For trail/streak effects
  Tier 0–1:     0.0
  Tier 2+:      ascension * 0.6

glowIntensity: For glow/bloom effects
  Tier 0–1:     0.0
  Tier 2:       ascension * 0.4
  Tier 3+:      ascension * 0.8

12. TIER THRESHOLDS (WITH HYSTERESIS)
================================================================================

Forward progression (going UP):
  Dormant → Awakened:   ascension ≥ 0.20
  Awakened → Ascending: ascension ≥ 0.35
  Ascending → Mythic:   ascension ≥ 0.60
  Mythic → Transcendent:ascension ≥ 0.80

Backward fallback (going DOWN, with margin):
  Awakened → Dormant:   ascension ≤ 0.18
  Ascending → Awakened: ascension ≤ 0.30
  Mythic → Ascending:   ascension ≤ 0.55
  Transcendent → Mythic:ascension ≤ 0.75

This prevents rapid tier flipping when score hovers near a boundary.

14. TROUBLESHOOTING
================================================================================

Problem: All nodes stuck at tier 0
  Solution: Ensure NodeQualityCalculator runs before MythicEvolutionFX
  
Problem: Tier flickers near 0.40
  Solution: Reduce emasAlpha (0.10–0.15) or check hysteresis logic

Problem: ascensionSmoothed stays at 0
  Solution: Verify input metrics are populated (quality, harmony, etc.)

Problem: getStats() shows frameTime > 1ms
  Solution: Reduce node/link count or profile to find bottleneck

Problem: mythicEvolution is undefined on node
  Solution: Make sure game loop calls update(deltaTime) every frame

Problem: Visual signals always 0
  Solution: Check tier is >= 1 (Dormant tier has no signals)
