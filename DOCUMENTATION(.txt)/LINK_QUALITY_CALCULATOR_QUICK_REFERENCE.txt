│                                                                              │
│  Metadata                                                                   │
│  └─ q.updatedAt     : timestamp (ms) when last computed                    │
│                                                                              │

┌─ QUALITY LEVELS ───────────────────────────────────────────────────────────┐
│                                                                              │
│  score >= 80  →  "High"     ✓ Excellent link                               │
│  score >= 55  →  "Medium"   ○ Acceptable link                              │
│  score >= 30  →  "Low"      ⚠ Degraded link                                │
│  score < 30   →  "Critical" ✗ Broken link                                  │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

┌─ COMPUTATION FORMULA ──────────────────────────────────────────────────────┐
│                                                                              │
│  Component 1: STRUCTURAL (30%)                                              │
│  ├─ Check link validity (0 if dead)                                        │
│  ├─ Base score: 80 points                                                  │
│  ├─ Distance penalty: (distance - maxDist) * rate (if >50 units)          │
│  └─ Staleness penalty: -20 points (if >5 seconds since update)             │
│                                                                              │
│  Component 2: HARMONY (40%)                                                 │
│  ├─ Average stability of both nodes (60% weight)                           │
│  ├─ Average harmony of both nodes (40% weight)                             │
│  └─ Formula: stab*0.6 + harm*0.4                                           │
│                                                                              │
│  Component 3: LOAD (15%)                                                    │
│  ├─ Average load ratio of both nodes (0-1)                                 │
│  └─ Formula: 100 * (1 - average_load)                                      │
│                                                                              │
│  Component 4: CORRUPTION (15%)                                              │
│  ├─ Maximum corruption of both nodes (worst determines)                    │
│  └─ Formula: 100 - max_corruption                                          │
│                                                                              │
│  FINAL SCORE:                                                              │
│  score = structural*0.30 + harmony*0.40 + load*0.15 + corruption*0.15     │
│  Clamp to 0-100                                                             │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

┌─ DEPENDENCY CHAIN ─────────────────────────────────────────────────────────┐
│                                                                              │
│  IMPORTANT: NodeDynamics MUST be updated FIRST each frame                  │
│                                                                              │
│  ✓ Correct order:                                                           │
│    1. nodeDynamics.update(deltaTime)                                        │
│    2. linkQuality.update(deltaTime)                                         │
│    3. Use link.userData.quality for decisions                               │
│                                                                              │
│  ✗ Wrong order:                                                             │
│    1. linkQuality.update(deltaTime)                                         │
│    2. nodeDynamics.update(deltaTime)  ← Uses stale metrics!               │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘
