IMPORT
------
import { NodeQualityCalculator, getNodeQualityCalculator } from './NodeQualityCalculator.js';

INITIALIZE
----------
this.nodeQuality = new NodeQualityCalculator(
    this.aiNodes,
    this.linkingSystem,
    this.nodeDynamics,
    this.linkQuality
);

UPDATE LOOP (call once per frame)
---------------------------------
update(deltaTime) {
    this.nodeDynamics.update(deltaTime);    // 1st
    this.linkQuality.update(deltaTime);     // 2nd
    this.nodeQuality.update(deltaTime);     // 3rd
}

QUALITY LEVELS
--------------
Prime    → score >= 85
Stable   → score >= 65
Weak     → score >= 40
Critical → score <  40

QUALITY FORMULA (v1.0)
----------------------
score =
    internal          × 0.30 +
    energyComponent   × 0.15 +
    loadComponent     × 0.15 +
    corruptionComponent × 0.20 +
    linkComponent     × 0.20

internal =
    stability × 0.50 +
    harmony × 0.30 +
    clarity × 0.20

linkComponent =
    avgLinkQuality × 0.70 +
    minLinkQuality × 0.30

INTEGRATION PATTERNS
--------------------

HUD Display:

    }

Link Automation:
    sourceQuality = sourceNode.userData?.quality?.score ?? 50;
    targetQuality = targetNode.userData?.quality?.score ?? 50;
    if (sourceQuality > 30 && targetQuality > 30) {
        // Safe to create link
    }

Network Analysis:

        // Network is degraded
    }

Node Monitoring:

PERFORMANCE
-----------
Time: O(N + L) where N = nodes, L = links
Per-frame: < 1ms for typical networks (100 nodes, 500 links)
Memory: ~50 bytes per node (caching)

BACKWARD COMPATIBILITY
----------------------

VALIDATION CHECKLIST
--------------------
□ Nodes with no links receive quality values (default 50)
□ Sigma nodes degrade due to corruption
□ Legendary nodes get high quality naturally
□ High linkQuality lifts node quality

DATA FLOW
---------

ALL OUTPUT STORED IN NODE.USERDATA.QUALITY
