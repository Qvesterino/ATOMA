SESSION 76 — SPATIAL CORE OFFSET FIX — QUICK REFERENCE
═══════════════════════════════════════════════════════════════════════════════

PROBLEM
───────
After linking, node cores lost visual identity because core, aura, and context
geometry all share the same center point → visual flattening.

SOLUTION
────────
Offset CORE MESH ONLY by 0.15 units in local +Y direction → spatial separation
restores visual hierarchy and core readability.

KEY CHARACTERISTICS
───────────────────
✅ SPATIAL-ONLY: No color, emissive, or gameplay changes
✅ STATIC: Applied once per link, never animated
✅ IDEMPOTENT: Flag prevents re-application on re-linking
✅ SAFE: Does NOT affect raycasting or interaction
✅ COMPATIBLE: Zero impact on LOD, frustum, shaders, or performance

FILES MODIFIED
──────────────
/NodeVisualStateBinder.js
  - Added applyCoreSpacialOffset() function (lines 446-495)
  - Integrated into applyFinalNodeVisualState() Step 6b (lines 763-766)
  - Total: ~52 lines added

IMPLEMENTATION
───────────────
1. Find core mesh (userData.visualLayer === 'CORE' or isCoreMesh or opaque)
2. Check if already offset (flag: node.userData.coreOffsetApplied)
3. If not offset, apply: coreMesh.position.y += 0.15
4. Mark: node.userData.coreOffsetApplied = true
5. Store: coreOffsetAppliedAt, coreOffsetMagnitude for debugging

VISUAL HIERARCHY
─────────────────
BEFORE                          AFTER (FIXED)
─────────────────────────────   ──────────────────────────
Core @ center +0.15Y            Aura @ center
Aura @ center                    Core @ center + offset
Visual flattening               Visual depth restored

VERIFICATION
─────────────
✓ Linked nodes: core appears distinct from aura
✓ Core visual identity maintained (primary anchor)
✓ Aura remains background (visual hierarchy correct)
✓ Clicking node: selection works (center + offset = world position)
✓ Re-linking: offset NOT re-applied (idempotent)

INTERACTION SAFETY
───────────────────
Core offset does NOT affect raycasting because:
- Node group center remains at (0, 0, 0)
- Core child mesh offset is LOCAL ONLY
- Interaction targets node group center
- Core mesh world position = group center + offset

EDGE CASES
──────────
• Unlinking: offset persists (core stays offset)
• Multi-link same nodes: offset applied only once (idempotent)
• Spawn → Link: offset applied at link time, not spawn
• Re-linking same nodes: no offset re-application (flag prevents it)

  - 0.15 balances subtle visibility with effectiveness
