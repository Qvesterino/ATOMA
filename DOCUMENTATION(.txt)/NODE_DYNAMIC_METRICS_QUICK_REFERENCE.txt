┌─ METRICS AVAILABLE ─────────────────────────────────────────────────────────┐
│                                                                              │
│  STRUCTURAL (counts)                                                        │
│  ├─ linkCount          : Total connections (in + out)                       │
│  ├─ incomingLinks      : Incoming connections only                          │
│  ├─ outgoingLinks      : Outgoing connections only                          │
│  ├─ loadMax            : Maximum link capacity (default 4)                  │
│  └─ loadRatio          : Current load 0-1 (linkCount / loadMax)             │
│                                                                              │
│  DYNAMIC (0-100 scale, except energy)                                       │
│  ├─ energy             : 0-120 (higher = more active)                       │
│  ├─ stability          : 0-100 (higher = stable)                            │
│  ├─ harmony            : 0-100 (higher = balanced)                          │
│  ├─ instability        : 0-100 (100 - stability)                            │
│  ├─ clarity            : 0-100 (higher = coherent)                          │
│  └─ corruption         : 0-100 (higher = corrupted, esp sigma)              │
│                                                                              │
│  TIME-BASED                                                                 │
│  ├─ lastActiveSeconds  : Seconds since last activity                        │
│  └─ updatedAt          : Timestamp of last update (ms)                      │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

┌─ COMPUTATION FORMULAS ──────────────────────────────────────────────────────┐
│                                                                              │
│  Energy:         newEnergy += energyGainPerLink * linkCount * deltaTime     │
│                  decays when idle (>2 sec), clamped 0-120                   │
│                                                                              │
│  Stability:      baseStability + (1-loadRatio)*40 - linkCount*2             │
│                  clamped 0-100, then EMA smoothed                           │
│                                                                              │
│  Harmony:        stability*0.7 + (1-loadRatio)*30                           │
│                  represents node balance, then EMA smoothed                 │
│                                                                              │
│  Clarity:        50 + (stability*0.5 - 30)                                  │
│                  influenced by stability, then EMA smoothed                 │
│                                                                              │
│  Instability:    100 - stability                                            │
│                  direct inverse, no smoothing                               │
│                                                                              │
│  Corruption:     regular: decay at 5% per second                            │
│                  sigma: +15 per second                                      │
│                  clamped 0-100, then EMA smoothed                           │
│                                                                              │
│  LoadRatio:      min(1, linkCount / loadMax)                                │
│                  how "full" the node is                                     │
│                                                                              │
│  EMA:            result = alpha*new + (1-alpha)*prev                        │
│                  smooths all metrics (default alpha=0.2)                    │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

┌─ SIGMA NODE DETECTION ──────────────────────────────────────────────────────┐
│                                                                              │
│  Detected via (in order):                                                   │
│  1. node.userData.isSigma === true                                          │
│  2. node.userData.category === 'sigma'                                      │
│  3. node.userData.archetype includes 'SIGMA' or 'CHAOS'                     │
│  4. node.userData.name includes 'sigma' (case-insensitive)                  │
│                                                                              │
│  Result: Sigma nodes gain corruption 15 pts/sec instead of decaying        │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

┌─ PERFORMANCE ───────────────────────────────────────────────────────────────┐
│                                                                              │
│  Time Complexity:      O(N + L)  where N=nodes, L=links                    │
│  Space Complexity:     O(N)      for internal cache                         │
│  Typical Frame Time:   < 1ms     for 100 nodes + 500 links                 │
│  Per-Metric Cost:      ~0.01ms   (EMA + clamping)                          │
│                                                                              │
│  Optimization Tips:                                                         │
│  • Call update() once per frame (not per node)                             │
│  • Read metrics after update, not between                                  │
│  • Use getNodesSortedByMetric() sparingly (O(N log N))                     │
│  • Cache frequently-read metric values if checking many nodes              │
│                                                                              │

┌─ TROUBLESHOOTING ───────────────────────────────────────────────────────────┐
│                                                                              │
│  Q: Metrics all zero?                                                       │
│  A: Ensure update(deltaTime) called each frame with deltaTime > 0           │
│                                                                              │
│  Q: Metrics not changing?                                                   │
│  A: Check update() called BEFORE reading. Verify nodes have userData.       │
│                                                                              │
│  Q: Sigma corruption not increasing?                                        │
│  A: Check sigma detection flags. Use debugDumpAllMetrics() to debug.        │
│                                                                              │
│  Q: Performance issues?                                                     │
│  A: Check node/link count. Profile with DevTools. Verify deltaTime scale.  │
│                                                                              │
│  Q: Metrics flickering wildly?                                              │
│  A: Decrease emasAlpha (0.1-0.15) for more smoothing.                      │
