================================================================================
INTERPOLATION FORMULA
================================================================================

Linear interpolation (smooth transition):

  interpolated = start * (1 - t) + end * t

  where:
    start = multiplier at transition start
    end   = target multiplier (from FXPerformanceController)
    t     = progress from 0.0 to 1.0
    progress = elapsedTime / duration

Example:
  At t=0.5 (halfway):
    value = 1.0 * 0.5 + 0.4 * 0.5
    value = 0.5 + 0.2
    value = 0.7

This guarantees smooth, linear fade curve.

API REFERENCE
================================================================================

CLASS: FXPerformanceSmoothTransition_v1

Constructor:
  new FXPerformanceSmoothTransition_v1(perfController, options)
  
  Options:
    duration: 0.6      // seconds
    enableDebug: false // boolean

Methods:

  startTransition(toLowFX)
    • toLowFX: boolean (true = LowFX ON, false = LowFX OFF)
    • Starts a new transition
    • Captures current multipliers as start point
    • Reads target multipliers as end point
    • Resets progress to 0
    • Usage: transition.startTransition(true)

  update(deltaTime)
    • deltaTime: frame time in seconds
    • Called each frame from animate()
    • Advances progress
    • Interpolates multipliers
    • Writes back to perf.multipliers
    • Usage: transition.update(0.016)

  getState()
    • Returns debug state snapshot
    • Fields: blending, progress, duration, transitionCount,
             lastToggleState, startValues, endValues
    • Usage: console.log(transition.getState())

  snapToEnd()
    • Emergency: instantly complete current transition
    • Applies end values directly
    • Stops blending
    • Usage: transition.snapToEnd()

================================================================================
COMMON USE PATTERNS
================================================================================

Pattern 1: Manual Toggle (default)
  User presses F7
  → F7 handler calls startTransition(newState)
  → Smooth fade over 0.6s
  → Complete

Pattern 2: Automatic Toggle (adaptive)
  FPS drops below threshold for 3s
  → Adaptive monitor's transitionCallback fires
  → startTransition(true) called
  → Smooth fade to LowFX
  → User experiences quality reduction as polished fade

Pattern 3: Rapid Toggle (edge case)
  User presses F7, then immediately presses F7 again
  → First transition starts
  → User presses F7 before completion
  → startTransition() called again (interrupts previous)
  → New transition starts from current value toward opposite target
  → Smooth interpolation through intermediate state

Example: 
  Initial: clarity = 1.0
  F7 press 1: Start transition to 0.4 (LowFX ON)
  At progress=0.5: clarity = 0.7
  F7 press 2: Start new transition to 1.0 (LowFX OFF)
  New startValue = 0.7, new endValue = 1.0
  Smooth interpolation from 0.7 to 1.0 over 0.6s

Result: Seamless reversal, no popping or jumping

TRANSITION STATE MACHINE
================================================================================

┌───────────────────────────┐
│ Not Blending              │
│ (idle, multipliers stable)│
└──────────────┬────────────┘
               │ startTransition() called
               ↓
┌───────────────────────────┐
│ Blending Active           │
│ progress: 0.0 - 1.0       │
│ Interpolating values      │
└──────────────┬────────────┘
               │ Each frame: progress += dt/duration
               ├─ Increment progress
               ├─ Interpolate multipliers
               └─ Write to perf.multipliers
               │
               ↓ progress >= 1.0
┌───────────────────────────┐
│ Blend Complete            │
│ (back to idle)            │
│ Multipliers locked        │
└───────────────────────────┘

Can loop back to Blending if startTransition() called again
