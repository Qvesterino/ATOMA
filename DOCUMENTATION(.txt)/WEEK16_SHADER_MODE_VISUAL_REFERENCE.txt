║  uShaderModeId ────────→ int (0–5)                              ║
║                         Archetype selector                       ║
║                                                                   ║
║  uModeIntensity ───────→ float [0–1]                            ║
║                         Visual strength / opacity                ║
║                                                                   ║

================================================================================
UNIFORM COMPUTATION FLOW (Example: SAGE)
================================================================================

INPUT: node.userData
  {
    archetypeEvolution: {
      archetypeId: 0,           // SAGE
      ascensionMultiplier: 1.2
    },
    personalitySignals: {
      clarity: 0.8              // High clarity
    }
  }

    ↓

COMPUTE TARGET VALUES
  targetIntensity   = 0.4 + 0.8 * 0.4 = 0.72
  targetDistortion  = 0.1 * (1.0 - 0.8) = 0.02
  targetBloom       = 0.3 + 0.8 * 0.5 = 0.70
  targetHueShift    = 0.8 * 0.3 = 0.24
  targetNoiseShift  = 0.1 * (1.0 - 0.8) = 0.02
  targetGradientMix = 0.3 + 0.8 * 0.4 = 0.62
  targetIridescence = 0.0

    ↓

EMA SMOOTHING (every frame)
  factor = min(1.0, 0.12 * deltaTime * 60)
  
  currentIntensity += (0.72 - currentIntensity) * factor
  (smooth transition over 0.4–0.6 seconds)

    ↓

APPLY CLAMPING
  intensity    = max(0, min(1, 0.72))   = 0.72 ✓
  distortion   = max(0, min(1, 0.02))   = 0.02 ✓
  bloom        = max(0, min(1, 0.70))   = 0.70 ✓
  hueShift     = max(-1, min(1, 0.24))  = 0.24 ✓
  noiseShift   = max(0, min(1, 0.02))   = 0.02 ✓
  gradientMix  = max(0, min(1, 0.62))   = 0.62 ✓
  iridescence  = max(0, min(1, 0.0))    = 0.0  ✓

    ↓

UPDATE GPU MATERIAL UNIFORMS
  material.uniforms.uShaderModeId.value = 0
  material.uniforms.uModeIntensity.value = 0.72
  material.uniforms.uModeDistortion.value = 0.02
  material.uniforms.uModeBloom.value = 0.70
  material.uniforms.uModeHueShift.value = 0.24
  material.uniforms.uModeNoiseShift.value = 0.02
  material.uniforms.uModeGradientMix.value = 0.62
  material.uniforms.uModeIridescence.value = 0.0

    ↓

RENDER NEXT FRAME
  GPU uses uniform values for node aura rendering
  Result: SAGE glow with clarity-driven appearance

  │     │  ╱
  │0.8  ├─╱
  └─────┘

  Feels natural and responsive
