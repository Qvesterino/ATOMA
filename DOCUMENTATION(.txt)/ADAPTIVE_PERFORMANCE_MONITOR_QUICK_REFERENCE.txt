WHAT IT DOES
================================================================================

Automatically toggles LowFX quality mode based on real-time frame rate:
  • Monitors FPS continuously each frame
  • Smooths noisy frame times (EMA, configurable alpha)
  • Compares against low/high thresholds (with hysteresis)
  • Uses time windows to confirm sustained changes
  • Calls fxPerformance.setLowFX(true/false) automatically
  • Respects manual F7 overrides (locks to MANUAL_LOCKED)
  • Resets to AUTO on map transitions

KEY BENEFIT: Players get smooth gameplay on any hardware without tweaking.

API REFERENCE
================================================================================

CLASS: AdaptivePerformanceMonitor_v1

CONSTRUCTOR:
  new AdaptivePerformanceMonitor_v1(fxPerformance, options = {})
  
  Options (all optional, all have sensible defaults):
    targetFPS: 60              // Target frame rate
    hysteresisFPS: 5           // Hysteresis band (wider = more stable)
    lowFXDelaySec: 3.0         // Seconds below threshold → enable LowFX
    highFXDelaySec: 5.0        // Seconds above threshold → disable LowFX
    emaAlpha: 0.1              // Smoothing (0-1, higher = faster but jittery)

METHODS:

  update(deltaTime)
    Called each frame. Performs all FPS monitoring and decision logic.
    Usage: monitor.update(0.016);  // frame time in seconds
  
  notifyManualToggle(isLowFX)
    Called when user manually overrides (F7 key).
    Locks auto system to MANUAL_LOCKED mode until map change.
    Usage: monitor.notifyManualToggle(true);
  
  resetToAuto()
    Returns to AUTO mode (automatic control).
    Called on map transitions.
    Usage: monitor.resetToAuto();
  
  getState()
    Returns current state object for debugging.
    Usage: console.log(monitor.getState());
  
  setEnabled(enable)
    Enable/disable monitoring without destroying state.
    Usage: monitor.setEnabled(false);

================================================================================
BEHAVIOR SUMMARY
================================================================================

AUTO MODE (Default):
  • Monitors frame rate continuously
  • Low threshold = target - hysteresis (e.g., 55 FPS)
  • High threshold = target + hysteresis (e.g., 65 FPS)
  • If FPS < low threshold for >3s → LowFX ON
  • If FPS > high threshold for >5s → LowFX OFF
  • Hysteresis prevents oscillation at thresholds

MANUAL_LOCKED MODE (After F7 press):
  • Auto logic disabled, respects user choice
  • Stays locked until map transition (switchMode())
  • Map transition calls resetToAuto() → returns to AUTO

Hysteresis Example:
  • Target: 60 FPS, Hysteresis: 5 FPS
  • Low threshold: 55 FPS
  • High threshold: 65 FPS
  • Dead zone: 55-65 FPS (no toggling, just tracking)

TROUBLESHOOTING
================================================================================

SYMPTOM: Not toggling LowFX
  FIX: Check fxPerformance initialized, check mode (locked?), check FPS range

SYMPTOM: Toggling too frequently (oscillating)
  FIX: Increase hysteresisFPS to 8, increase delay times

SYMPTOM: Not toggling fast enough
  FIX: Decrease hysteresisFPS to 3, decrease delay times

SYMPTOM: F7 toggle not working
  FIX: Ensure setupPerformanceMode() called, check console for errors

SYMPTOM: Performance didn't improve after auto LowFX ON
  FIX: Verify Phase 3c FX enabled, check FXPerformanceScaler running
