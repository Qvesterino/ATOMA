 current crisis je len metric-trigger + timer. Môžme ho spraviť oveľa silnejším.
Čo navrhujem vylepšiť
1. Crisis phases s player agency
Každý crisis má 3 fázy: surge → peak → decay
Player môže počas surge a peak reagovať — link actions, node choices ovplyvňujú outcome
Prežiť = reward, fail = escalated corruption/stability drop
2. Visual identity per crisis
resonance_surge → pulsing screen overlay, nodes glow with synergy burst
integrity_fracture → nodes crack visually, links show fracture patterns  
anchor_collapse → anchor points visually destabilize, gravity drift
pressure_rupture → screen distortion, audio pressure spike
harmony_void → desaturation waves, slow-motion feel
3. Crisis escalation
Prežiť crisis → gain temporary buff alebo unlock
Fail → world mutation unlock (positive, not punishment)
Viac crisis prežitých = harder triggers but better rewards
4. World-specific crisis grammar
Quantum: resonance_surge je burst-oriented, split-window options
Desert: anchor_collapse je slow-burn, hold discipline tested
5. Crisis HUD panel
Ukazuje active crisis, time remaining, intensity meter
Suggested actions based on crisis type
Progress toward crisis mastery
