# /plan-atoma

## Goal
Design a safe architecture plan for the requested change.

## Steps
1. Switch to skill: `atoma-architect`
2. Load Focus Chain memory from `/audit-atoma`.
3. Ask the user for the desired outcome (if not clear).
4. Define:
   - Intent
   - Touch map
   - Risk table
   - Integration strategy
5. Store the plan in Focus Chain.
6. Output the full architecture plan.
