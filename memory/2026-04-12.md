# Session 2026-04-12

## Runtime Test Discipline

- A/B validation must only start after confirming the browser is in a stable gameplay state.
- Menu/boot overlay screenshots are not valid evidence for simulation-layer isolation.
- If `window.game` disappears after a toggle, or the page returns to menu, treat the run as invalid and restart from a clean gameplay boot.
- Use `render_game_to_text` or direct state probes to verify the active mode before concluding that a simulation system is the culprit.
- Link semantic pictogram cleanup now has a stable ordering requirement: remove the link from live arrays first, then dispose/clear glyphs, otherwise the pictogram cache can respawn them.
