## Bug Fixes (same session)

### LinkSparkSystem multi-link freeze fix
**File**: `LinkSparkSystem.js`
**Root cause**: `onBeforeRender` was set on the shared material singleton. When multiple Points objects shared the material, the callback only fired for one object, causing other links' sparks to freeze.
**Fix**: Moved `onBeforeRender` from the shared material to each Points object individually. Each object now injects its own per-instance uniforms before its draw call.
**Follow-up**: The spark material is now cloned per `LinkSparkSystem` instance so uniforms are no longer shared across links at all. This removes the remaining cross-link coupling path and keeps each link's spark state fully isolated.
**Follow-up 2**: Spark particles now self-retire on the CPU once their lifetime expires, and the shader uses a hard offscreen sentinel for dead particles. Lifetime was also shortened to keep sparks visibly brief.

### CascadeParticleSystem spawn fix
**File**: `CascadeParticleSystem_Session120.js`
**Root cause**: `_spawnParticles()` at line 1652 gated on `linkState.isRelevant`, which required `relevantIntensity >= minimumVisibleIntensity (0.05)`. Normal links without cascade-specific data had intensity 0, so they were never relevant and never spawned particles.
**Fix**: Removed the `isRelevant` gate in `_spawnParticles`, added synergy-based fallback intensity for links without cascade data. Matches the intent of the already-disabled gate in `_emitFromLinkState`.

## LinkPulseDustEmitter Epic Polish

**File**: `LinkPulseDustEmitter.js`
**Scope**: MEDIUM — shader + config + spawn logic upgrade, zero architecture change

### Fragment shader (DUST_FS v2)
- Replaced flat radial fog with **multi-lobe glow**: hot core + soft membrane + ethereal halo
- Hot center shifts toward luminous white (`core * 0.38/0.30/0.18`)
- Added subtle shimmer via `sin(lifeProgress * 12.56 + dist * 20.0) * 0.035`

### Vertex shader (DUST_VS v2)
- **Bell curve size**: `sin(lifeProgress * PI) * 0.82 + 0.18` — small birth → peak ~35% → gentle shrink (was linear growth)
- **Breathing pulse**: `sin(age * 7.5 + birthTime * 6.28) * 0.055` — each particle has unique phase
- **Drift deceleration**: `age * (1.0 - lifeProgress * 0.25)` — particles slow down gracefully
- **Color evolution**: shifts toward warmer luminous tones as particle ages (`vec3(0.14, 0.09, 0.03)` warm shift)
- **Richer fade**: quick bright birth (smoothstep 0→0.055) → sustained glow → graceful death (smoothstep 1.0→0.6)
- Alpha max: 0.68 → 0.88

### Config changes
- Max particles: 128 → 192
- Emission rate: 52–132 → 64–155
- Segment angles: 4 → 8 (richer ring distribution)
- `customProgramCacheKey: 'ATOMA_DUST_v2'`

### Spawn logic changes
- **Hero particles**: 12% chance, 1.45× speed, 1.5× size, 1.5× lifetime — creates visual hierarchy
- **Color jitter**: per-particle hue ±0.02, saturation ±0.03, lightness +0–0.06
- **Velocity variety**: wider backward (0.14–0.30), outward (0.05–0.17), swirl (±0.04) ranges
- **Lifetime**: 1.1–1.55s → 1.2–1.8s (hero: 1.8–2.7s)
- **Base size**: 6.8–12.0 → 7.2–14.0 (hero: 10.8–21.0)

### Performance impact: negligible
Same draw call count, same GPU pipeline. Shader adds ~3 ALU ops per particle. 50% more particles but still well under 1K draw budget.
