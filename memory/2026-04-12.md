## Bug Fixes (same session)

### LinkSparkSystem multi-link freeze fix
**File**: `LinkSparkSystem.js`
**Root cause**: `onBeforeRender` was set on the shared material singleton. When multiple Points objects shared the material, the callback only fired for one object, causing other links' sparks to freeze.
**Fix**: Moved `onBeforeRender` from the shared material to each Points object individually. Each object now injects its own per-instance uniforms before its draw call.
**Follow-up**: The spark material is now cloned per `LinkSparkSystem` instance so uniforms are no longer shared across links at all. This removes the remaining cross-link coupling path and keeps each link's spark state fully isolated.
**Follow-up 2**: Spark particles now self-retire on the CPU once their lifetime expires, and the shader uses a hard offscreen sentinel for dead particles. Lifetime was also shortened to keep sparks visibly brief.

### CascadeParticleSystem spawn fix
**File**: `CascadeParticleSystem_Session120.js`
**Root cause**: `_spawnParticles()` at line 1652 gated on `linkState.isRelevant`, which required `relevantIntensity >= minimumVisibleIntensity (0.05)`. Normal links without cascade-specific data had intensity 0, so they were never relevant and never spawned particles.
**Fix**: Removed the `isRelevant` gate in `_spawnParticles`, added synergy-based fallback intensity for links without cascade data. Matches the intent of the already-disabled gate in `_emitFromLinkState`.

## T2_CorruptionVisualIntegration_v1 — Creative Redesign

**File**: `T2_CorruptionVisualIntegration_v1.js`
**Scope**: MEDIUM — geometry + material redesign, zero logic change

### Design concept: Corruption Void Shards
Instead of flat red tetrahedrons, corruption particles are now **irregular crystal shards** with **Fresnel rim glow** — dark core with corruption energy leaking from the edges, like fragments of corrupted reality.

### Geometry: Custom Irregular Shard
- Replaced `THREE.TetrahedronGeometry(0.1, 0)` with `createCorruptionShardGeometry(0.1)`
- Based on `OctahedronGeometry` (8 faces, diamond silhouette) with deterministic hash-based vertex displacement
- Each vertex is displaced by `hash(position) * 0.35 + 0.82` creating an asymmetric broken-crystal shape
- More facets = more interesting silhouette from all viewing angles

### Material: Fresnel Rim Glow Shader
- Replaced `MeshLambertMaterial` (flat red) with custom `ShaderMaterial`
- **Fresnel effect**: `pow(1.0 - abs(dot(viewDir, normal)), 2.5)` — bright edges, dark center
- **Corruption energy pulse**: `0.65 + 0.35 * sin(time * 4.0)` — energy fluctuates
- **Per-instance color**: Uses `instanceColor` attribute for corruption-level-based coloring
- **Additive blending**: Corruption energy glows additively
- **Double-sided**: Visible from all angles
- Uniforms: `uTime`, `uPulseSpeed(4.0)`, `uFresnelPower(2.5)`, `uEmissiveIntensity(1.8)`

### Aura: Corruption Energy Field
- Color: cyan `0x00ffff` → dark crimson `0xff0033`
- Opacity: 0.25 → 0.15 (subtler, lets the Fresnel shader do the work)
- Uses same shard geometry for visual consistency
