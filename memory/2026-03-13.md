## Architecture Overview

### Three-Layer Metrics Model

```
┌─────────────────────────────────────────────┐
│        LAYER 1: CANONICAL METRICS           │
│                                             │
│  node.userData.metrics.*                    │
│  link.userData.synergy.*                    │
│  link.userData.corruptionLevel              │
│                                             │
│  READ-WRITE (Authorized Writers Only)       │
└─────────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────────┐
│     LAYER 2: RUNTIME VISUAL STATE           │
│                                             │
│  node.userData.runtime.*                    │
│  link.userData.runtime.*                    │
│                                             │
│  READ-WRITE (Visual Systems)                │
└─────────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────────┐
│        LAYER 3: VISUAL SYSTEMS              │
│                                             │
│  Aura Systems, Link Glow Systems,           │
│  Shader Packs, FX Layers, Particle Systems  │
│                                             │
│  READ-ONLY (No Metric Mutation)             │
└─────────────────────────────────────────────┘
```

### Canonical Metrics Structure

**Nodes:**
```javascript
node.userData.metrics = {
  synergy: 0..1,
  harmony: 0..1,
  stability: 0..1,
  corruption: 0..1,
  loadPressure: 0..1
}
```

**Links:**
```javascript
link.userData.synergy = {
  score: 0..1,
  synergyNorm: 0..1
}
link.userData.corruptionLevel = 0..1
```

### Runtime Visual State Structure

**Nodes:**
```javascript
node.userData.runtime = {
  visualState: { ready, applied, restoredAt },
  effectsState: {
    synergyPulse: { active, score, lastPulseTime },
    harmonyStabilized: { active, dampingFactor },
    corruptionVisual: { colorTint, intensity },
    harmonyVisual: { auraTint, intensity }
  },
  animationState: { bobPhase, destabilization, tearPhase },
  metadata: { visualRoot, visualType, visualLocked, ... }
}
```

**Links:**
```javascript
link.userData.runtime = {
  visualState: { intensity, corruptionLevel },
  effectsState: {
    synergyCollapse: { active, cascadeTime },
    corruptionVisual: { colorTint, wavePhase, waveIntensity },
    glow: { glowIntensity, qualityNorm, corruptionPulse }
  },
  animationState: { tearPhase, coherenceLoss, strainIntensity },
  metadata: {}
}
```

**Priority 3: NodeLinkingSystem.js**
- Replace `link['synergyScore']` → `link.userData.synergy.score`
- Replace `link.corruptionLevel` → `link.userData.corruptionLevel`
- Replace scattered visual state → `node.userData.runtime.*`

**Priority 4: NodeVisualStateBinder.js**
- Replace scattered visual state → `node.userData.runtime.effectsState.*`

### Migration Pattern

**Before (Legacy):**
```javascript
// ❌ Legacy pattern
const corruption = node.userData.corruption;
node.userData.synergyPulseActive = true;
node.userData.synergyScore = 0.8;
```

**After (Canonical + Adapter):**
```javascript
// ✅ Canonical pattern with adapter
import { NodeMetricRuntimeAdapter } from './src/metrics/MetricRuntimeAdapter.js';

const corruption = NodeMetricRuntimeAdapter.getMetric(node, 'corruption');
NodeMetricRuntimeAdapter.setRuntimeState(node, 'effectsState.synergyPulse.active', true);
NodeMetricRuntimeAdapter.setRuntimeState(node, 'effectsState.synergyPulse.score', 0.8);
```

**After (Direct Access - Preferred):**
```javascript
// ✅ Direct canonical access (no adapter overhead)
const corruption = node.userData.metrics.corruption;
node.userData.runtime.effectsState.synergyPulse.active = true;
node.userData.runtime.effectsState.synergyPulse.score = 0.8;
```
