## Confirmed Technical Findings

- Real runtime selection authority nie je `selectionCore`.
- Real selection authority je `NodeLinkingSystem.primaryNode` path:
  - `handleSingleClick()` -> `setPrimaryNode()` -> `_fireSelectCallbacks()`
  - `clearPrimaryNode()` -> `_fireDeselectCallbacks()`
- Pasivne audio callback API pre runtime selection je:
  - `NodeLinkingSystem.onNodeSelected(callback)`
  - `NodeLinkingSystem.onNodeDeselected(callback)`
- `NodeLinkingSystem.prototype.setSelectionCore = function() {};` je no-op, preto audio napojene len na `selectionCore` neobsluhuje realny click path.

## Safe State After Fixes

- `main.js`:
  - selection/deselection audio je pasivne napojene na `linkingSystem.onNodeSelected/onNodeDeselected`
  - link/unlink audio je pasivne napojene na `linkingSystem.onLinkCreated/onLinkRemoved`
  - ziadne wrappery nad `createLink/removeLink`
  - ziadne wrappery nad `setPrimaryNode/clearPrimaryNode`
- `NodeLinkingSystem.js`:
  - dnesne deferred post-link experimenty su rollbacknute
  - `createLink()` je vratene na synchronny flow
- `AtomaAudioSystem.js`:
  - `selection` je docasne hlasnejsi pre runtime citatelnost
  - `deselect` je zosilneny a predlzeny na citatelny settle cue
  - `link create` je kratky signalizacny cue, nie pretrvavajuci ton
  - `unlink` je zosilneny a ma citatelnejsi filter sweep

## Lessons

- Audio wiring sa nema tlacit do `main.js` link hot-path wrapperov.
- Pri ATOMA linking pipeline aj male defer/wrapper zasahy vedia rozbit link visual bootstrap alebo vyvolat freeze.
- Pre interaction audio preferovat pasivne callback API na skutocnej authority vrstve.

  - `LinkCorruptionParticleSystem`
  - `TIER4_CorruptionFeedbackVisuals_v1`

  - pictogram cleanup nebol hard-viazany na `onLinkRemoved(sourceNode, targetNode)` pre main instanciu
