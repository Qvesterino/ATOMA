# 2026-04-29

- Node growth spawn authority in `AINodes.js` was tightened around two explicit runtime rules:
  - time spawn every `45s`
  - link spawn only when the active link count reaches the next `3-link` milestone (`3, 6, 9, ...`)
- Growth spawns now resolve a random unused `visualCode` from `NodeVisualRegistry` before queueing, so runtime-spawned nodes do not duplicate an active node's visual identity.
- Runtime spawn placement was hardened to avoid body-to-body placement: larger player/node separation, candidate search around the active play area, and geometry clearance check preserved.
- Live browser verification must use a fresh local server for this workspace. The old canonical `127.0.0.1:5500` route was serving a different project (`Flowra`) during this session, so ATOMA was validated on a workspace-local static server instead.
- `Engine/Debug/FXDebugSandbox.js` now serves as a persistent node-FX debug HUD on `L`, with localStorage-backed enable/disable state and runtime discovery of node-related non-link systems from `window.game`.
- `PHASE5_CascadePropagationVisuals` was hard-disabled in `PHASE5_CascadeVisuals.js` by defaulting the class to an inert state, detaching its ring group from the scene, and short-circuiting trigger/update/bus subscription paths.
- `T2_HarmonyVisualConsumer_v1` and `GlyphLayer4_MultiFusion` were hard-disabled in their modules so they remain importable but do not attach or emit node visuals at runtime.
- `RecursiveGlyphSignalSystem` was hard-disabled in `_RecursiveGlyphSignalSystem.js` so it no longer adds its signal container to the scene or emits attention/residue signals.
