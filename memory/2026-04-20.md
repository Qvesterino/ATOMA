### Selection Resonance Cascade Implementation (Proposal 5 from VFX_EXISTING_SYSTEMS_IMPROVEMENT)
- **File**: `_NodeMicroEvents.js`
- **Concept**: Visual chain reaction on node select — BFS through links (3 hops), shows network REACH
- **Changes**:
  - Added `selectionCascade` config block (maxHops:3, hopDelayMs:300, maxAffectedNodes:20, cooldownMs:2000)
  - Added `_setupSelectionCascadeSubscription()` — subscribes to `node.selection` semantic event
  - Added `_resolveCascadeNode()` — resolves node by ID from registered nodes or global game
  - Added `_getLinkingSystem()` + `_getLinksForNode()` — access to link topology for BFS
  - Added `triggerSelectionCascade(sourceNode)` — main method, BFS traversal with staggered scheduling
  - Added `_createSelectionFlash(node, intensity, duration)` — brief emissive spike on node meshes
  - Added `_createSelectionRing(node, color, opacity, duration)` — expanding ring + echo ring at node position
  - Added `_createLinkPulse(fromNode, toNode, color, opacity)` — glowing sphere traveling along link
  - Added 3 new visual types to `updateVisualByType()`: `selection_flash`, `selection_cascade_ring`, `selection_link_pulse`
  - Added timer cleanup and semantic unsubscription to `dispose()`
- **Visual behavior**:
  - Hop 0 (selected): bright white-cyan flash + ring (opacity 0.8, 1.5s)
  - Hop 1 (300ms delay): cyan flash + ring + link pulse (opacity 0.5, 1.2s)
  - Hop 2 (600ms delay): teal flash + ring + link pulse (opacity 0.3, 1.0s)
  - Hop 3 (900ms delay): dim teal flash + ring (opacity 0.15, 0.8s)
  - Hub nodes → large cascades spreading in all directions
  - Isolated nodes → just a flash on themselves
  - Bridge nodes → cascade flows through to both sides
