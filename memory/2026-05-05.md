# 2026-05-05

- Implemented raw gameplay metric split for the Network Time loop.
- `MetricsRuntime_v1` now maintains a raw canonical network snapshot separate from smoothed public live metrics:
  - preferred source: `NetworkMetricsAggregator.compute()`
  - fallback source: `_aggregateNodeMetrics()`
  - zero-link state resolves to raw zero metrics
- Added `MetricsRuntime_v1.getRawNetworkMetrics()` as the gameplay-safe accessor.
- `VisualNetworkTimeElasticity` in `main.js` now reads raw canonical `networkSynergy` from `metricsRuntime_v1.getRawNetworkMetrics()`, not `getCachedVisualMetrics()` / `__ATOMA_LIVE_METRICS__`.
- `MetricsRuntime_v1` now calls `_emitCanonicalSemanticMetrics()` from the raw snapshot path during update, instead of leaving that semantic tier path inert.
- `window.__ATOMA_LIVE_METRICS__` remains smoothed/public and still serves HUD/VFX consumers by default.
- HUD synergy was shifted behaviorally toward gameplay truth:
  - `CoreMetricsHUD` now prefers the score system's raw `avgSynergy` for the synergy display path
  - `_buildHudMetricsSnapshot()` in `main.js` also prefers raw gameplay synergy for AI/HUD-side reports
- Tests added:
  - raw snapshot prefers aggregator while public live metrics stay smoothed
  - raw snapshot falls back to node aggregation when aggregator is unusable
- Live Playwright smoke after the split confirmed:
  - natural smoke with `createSmokeLinks(6)` produced a clear divergence:
    - raw `networkSynergy ~0.347`
    - smoothed public `networkSynergy ~0.093`
    - score state `avgSynergy ~0.347`
  - this proves score now reads raw gameplay authority, not the lagged public/HUD smoothing layer
- Important remaining blocker:
  - the gameplay loop is still not naturally winnable in smoke
  - raw natural network synergy is still under threshold (`~0.35` with 6 smoke links in live runtime)
  - next likely phase is balance/aggregator sensitivity, not another score-authority refactor
- Headless Playwright still appears to under-represent real-time sustain pace because browser timing in background/headless mode throttles world time progression; use visible foreground browser for final real-time sustain/win verification.
