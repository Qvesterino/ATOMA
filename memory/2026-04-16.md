## P0.5 HUD Consolidation — Command Center ✅ COMPLETED

### Architecture: 3-Layer HUD Model
- `PLAYER_CRITICAL`: CoreMetricsHUD, SelectedHUD — always visible
- `CONTEXTUAL_INSPECT`: CategoryHUD, InspectorHUD — visible on interaction
- `DEBUG_AUTHORING`: AIAutomationHUD, VariantBAdvisorHUD, AtomaDebugHUD — F4 toggle only

### New Files Created:
- `HUDLayerManager.js` — single layout authority, layer visibility rules, developer mode state
- `DeveloperToggle.js` — F4 global developer mode toggle with on-screen indicator

### Files Modified:
- `HUDRegistry.js` — upgraded to v2.0 with layer classification, `getHudElement()` helper
- `CoreMetricsHUD.js` — transformed from developer panel to player command panel:
  - State names (CRITICAL, UNSTABLE, STABLE, OPTIMAL, TRANSCENDENT)
  - Trend arrows (↑ ↓ →) per metric
  - Network health summary as primary readout
  - 2-decimal precision (was 6-decimal)
  - State-colored icons and bars
  - Cleaner layout with header/body separation
- `UIVisibilityConfig.js` — added developerMode flag, reorganized sections
- `HUDLayoutManager.js` — integrated with HUDLayerManager for layer-aware visibility
- `HudCollapseSystem1_0.js` — upgraded to v2.0, wires layer manager + developer toggle
- `AtomaDebugHUD_1_0.js` — removed F4 listener (DeveloperToggle handles it globally)

### Key Design Decisions:
- Developer mode persists in localStorage (`atoma.hud.developerMode`)
- F4 is the single global dev toggle — no per-HUD key listeners
- HUDLayerManager is the visibility authority, HUDLayoutManager handles collapse state
- VariantBAdvisorHUD uses `data-hud-variant` selector (not ID) — registry supports both
- CoreMetricsHUD positioned top-left as primary information hierarchy
- No changes needed in main.js — HudCollapseSystem wires everything internally

### Layout Repositioning (added after P0.5):
- `HUDDragManager.js` — drag-to-reposition with localStorage persistence
  - F3: toggle layout edit mode (locked by default)
  - Drag any HUD header to reposition when unlocked
  - Auto-saves positions on drag end
  - Viewport clamping (HUD stays on screen)
  - Console: `window.resetHudPositions()`, `window.saveHudPositions()`, `window.getHudPositions()`
