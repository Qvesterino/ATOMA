## 🎨 LINK PULSE RING V4 - FRESNEL + HARMONIC + HUE DRIFT + ORGANIC TRAIL

### Transformations
**Before:** MeshBasicMaterial, soft glow, single frequency
**After:** ShaderMaterial with Fresnel, harmonic pulse, hue drift

### V4 Features Implemented
1. **Fresnel ShaderMaterial** (Phase A + Hue Drift)
   - uFresnelPower: 2.5 (širší glow)
   - uFresnelIntensity: 1.8 (ostrý rim)
   - Jemný glow term: finalColor += uColor * 0.2

2. **Hue Drift** (živá farba, nie disco)
   - Drift speed: 0.2 + synergy * 0.8
   - Hue shift: sin(now * 0.001 * driftSpeed) * 0.015 (menší než 0.02)
   - Wrap hue: 0-1

3. **Second Harmonic Pulse** (komplexný pulz)
   - Primary: sin(progress * PI * 6)
   - Harmonic: sin(progress * PI * 12) * 0.4
   - Combined: 1.0 + primary * 0.15 + harmonic * 0.08

4. **Harmonic do Opacity** (jemné bliknutie)
   - OpacityPulse: 1.0 + harmonic * 0.2
   - FinalOpacity: alpha * maxOpacity * opacityPulse

5. **Epic Glow** (nie "soft glow", ale ENERGIA)
   - PulseBreath: 1.0 + sin(progress * PI * 6) * 0.15
   - EpicBoost: 0.6 + synergy * 0.8

6. **Trail Organic V2** (ako LinkBeadTrail, nie len zrkadlené kópie)
   - Position lag: 0.002-0.005 (trail nie je presne na tej istej pozícii)
   - Jitter: 0.05-0.14 * ring scale (náhodné posuny ako LinkBeadTrail)
   - Scale pulse: sin(progress * PI * 6 * freq) * 0.05
   - Opacity pulse: sin(progress * PI * 6 * freq) * 0.1
   - Lifetime variation: 0.8, 0.9, 1.0, 1.1 multiplier
   - Hue variation: 0.01, 0.02, 0.03, 0.04 offset + random * 0.02
   - Scale decay base: 0.75, 0.5, 0.25, 0.0
   - Opacity decay: 0.8, 0.6, 0.4, 0.2 (výraznejšie bez "shades")

### Signature
- Nie "soft glow", ale ENERGIA
- Nie monotónne, ale dvojfrekvenčný pulz
- Nie statické farby, ale živá (hue drift 5-10° HSL)

## ⚡ LINK ARC DISCHARGES AAA UPGRADE

### 6 Phases Implemented (NO API CHANGES)

**Phase 1: Two-Phase Arc System (Snap + Afterglow)**
- SNAP ARC: 0.12s, opacity 1.0, jitter 1.5×, pulse speed 2.5
- AFTERGLOW ARC: 0.35-0.5s, opacity 0.5-0.7, jitter 0.5×, pulse speed 1.5

**Phase 2: Branching Lightning**
- 30-50% šanca spawn 1 short branch
- Perpendicular direction k hlavnému smeru
- 40% dĺžka hlavnej arc

**Phase 3: Improved Electric Shape (Structured Wave)**
- taper = sin(t * PI)
- wave = sin(t * PI * 3)
- jitterMagnitude = taper * wave * config.jitterAmount
- Organické elektrické oscilácie, nie chaos

**Phase 4: Smooth Energy Fade**
- ease = sin(progress * PI)
- arc.material.opacity = ease * arc.maxOpacity
- Subtle pulse: 0.9-1.0 range (reduced intensity)
- Odstránené emissiveIntensity (LineBasicMaterial nepodporuje)

**Phase 5: Subtle Hue Variation**
- HSL conversion + hue shift
- Hue shift: (random - 0.5) * 0.05 (±2.5%)
- Wrap hue: 0-1

**Phase 6: Synergy Modulation**
- Synergy > 0.7: arcCount + 1, arcLength mierne zvýšená
- Synergy < 0.3: arcCount - 1, lifetime mierne znížená

- endPoint: startPoint + normal * dirOffset * arcRadius + binormal * dirLift * arcRadius

- Dlhšie trvanie arcov (0.12s snap + 0.35-0.5s afterglow)
- Clear two-phase electric burst
- Occasional branching lightning (30-50% šanca)
