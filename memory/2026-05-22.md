## 2026-05-22 — UX Polish Pass v1
- Presentation-first UX hardening landed without changing gameplay authority, score rules, camera feel constants, or introducing a hard fail state.

### Files touched
- `MainMenu.js`
- `PauseMenu.js`
- `AtomaLoadingOverlay.js`
- `AtomaBoot.js`
- `HUD/CoreMetricsHUD.js`
- `HUD/GameplayHintLayer.js`

### Menu / pause loop
- `MainMenu` and `PauseMenu` now present settings feedback explicitly with:
  - `APPLIED`
  - `PENDING`
  - `TRANSITIONING`
- Async visual toggles now visibly lock while processing instead of silently flipping.
- Settings descriptions were tightened so players can understand impact faster.
- Pause root copy now clearly explains:
  - simulation is paused, not rebooted
  - `ESC` from root returns to simulation
  - `ESC` inside submenus backs out one level

### Resume / transition cadence
- `AtomaLoadingOverlay` now supports a light non-blocking cue mode for resume/re-entry beats.
- `AtomaBoot.resumeGame()` now triggers a short authored return-to-simulation cue instead of a hard visual cut.
- Boot/loading copy was refreshed so first entry and world entry feel more intentional and less placeholder-like.

### HUD / readability
- `CoreMetricsHUD` priority was tightened so:
  - `Network Time` remains the primary read
  - build state stays above run identity
  - onboarding objective reads more clearly than the meta tag
- Rewind-block and stabilizer helper copy was shortened to be more scannable under pressure.

### Soft-failure UX
- `GameplayHintLayer` now supports repeatable cooldown-gated warning hints.
- Added one consistent soft-failure hint family for:
  - rising pressure / rewind blocked
  - lost hold after rewind drift
  - critical node failure / severed link moments
- `main.js` now routes those hints through the existing hint layer with rate limits so setbacks read as authored warnings instead of spam.

### Victory aftermath polish
- Victory overlay copy now reads more like aftermath than a generic results card.
- CTA labels were updated:
  - `Play Again` -> `Stabilize Again`
  - `Leaderboard` -> `View Chronicle`
