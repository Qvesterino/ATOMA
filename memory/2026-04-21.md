**SafeQuantumIllusionsPack1.js** — spawn/condition throttled to ~10Hz

**EventDramaturgyEngine.js** — idle early-exit

- `update()` returns immediately when `activeSequences.size === 0 && _overlayCleared`
- Eliminates per-frame: aggregation loop, DOM writes, 7× `setDramaturgyModulation` calls to subsystems

**SafeColonyExpansion2.js** — non-visual logic throttled to ~5Hz
- Added `_logicAccumulator` / `_logicInterval = 0.2` (200ms)
- Clustering, centers, energy, moods, merges, splits, events, cleanup → ~5Hz
- `updateVFX()` stays at full 30Hz for smooth animation

**MetricReactiveWorldEvents.js** — guard fix
- Changed `shouldRunSimulation()` → `shouldRunVisual()` to match the visual lane it's registered in
- Was effectively dead code (zombie instance) — now actually runs

### Batching Observations
- SafeQuantumIllusionsPack1: uses shared geometry cache (`_getSharedGeometry`) — already good
- SafeColonyExpansion2: delegates to ColonyVFXManager — no raw THREE.Mesh creation in main class
- MetricReactiveWorldEvents: creates individual meshes (data crystals, halos) — potential instancing candidate for future if colony count grows

### ColonyVFXManager Batching Implementation

**Phase 1: Material Cache** (`_materialCache`)
- `getCachedMaterial(color, opacity, side)` — quantises opacity to 0.05 steps, deduplicates across colonies
- Applied to: orbit rings, edges, accents, halo, sigil, beam (structural per-colony meshes)
- Impact: ~150 unique materials → ~15-25 with 10 colonies

**Phase 2: Geometry Cache** (`_geometryCache`)
- `getCachedGeometry(key, factory)` — deduplicates geometries with similar params
- Applied to: orbit rings, edges, accents, halo, sigil, beam
- Impact: ~120 unique geometries → ~20

**Phase 3: InstancedMesh Atmosphere**
- All colony atmospheres consolidated into one `InstancedMesh` (max 24 instances)
- Canonical TorusGeometry(1, 0.2, 16, 32) scaled per colony via instance matrix
- Per-instance color via `setColorAt()`, opacity encoded into color brightness
- `createAtmosphere()` returns lightweight proxy object (preserves VFX bundle interface)
- `releaseVFXObject()` handles proxy cleanup + instance index recycling
- `updateVFXForColony()` updates instance matrix + color per frame
- `update()` flushes `instanceMatrix.needsUpdate` + `instanceColor.needsUpdate`
- Impact: N atmosphere draw calls → 1 draw call

**Not batched** (intentionally):
- Transition effects (birth, collapse, split, morph, phoenix) — temporary, low count
- Core nucleus — uses custom bioluminescent ShaderMaterial with per-colony uniforms
- Central glow — uses custom ShaderMaterial
- Particles — already THREE.Points (inherently batched)
