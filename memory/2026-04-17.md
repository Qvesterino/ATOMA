- Pause badge: `.atoma-main-menu__pause-badge` with pulsing dot animation

#### 3. Link Lattice Background
- Added `_latticeNodes` and `_latticeEdges` arrays
- Lattice nodes: fixed grid with randomized positions, pulsing glow
- Lattice edges: connections between nearby nodes with traveling pulse dots
- Quality-aware: HIGH=8x5, MEDIUM=6x4, LOW=4x3 grid
- Existing bezier strands and particles preserved but reduced opacity

#### 4. World Cards Rendering
- New `_renderWorldCards()` method replaces simple list for MAP screen

- Each card: name, risk badge, tagline, fantasy, mood tags, risk/prosperity bars
- Map preview panel below cards showing selected world details
- CSS class-based selection (`.is-selected`) instead of inline style manipulation

#### 5. Enhanced Selection State
- `is-selected` class added to buttons during `_renderEntryList()`
- `_updateFocusableVisuals()` handles both buttons and world cards
- World cards: CSS class toggle, no inline style writes
- Buttons: left accent border via CSS, marker glow
