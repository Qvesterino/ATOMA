## Network Time Score Gameplay — COMPLETED

### Architecture Plan: `plans/NETWORK_TIME_SCORE_GAMEPLAY.md`

### Concept
Network Time is now the **gameplay score**:
- Counts FORWARD at 5 units/sec (pressure)
- When `global.synergy >= 0.82` sustained for **7 seconds** → counts DOWN at 3 units/sec (reward)
- If synergy drops → resumes FORWARD
- **Win condition**: Network Time reaches 0 → game won
- No game over — player can try forever

### Phase 4 Additions:

#### Phase 4A: Synergy Quality Multiplier (VisualNetworkTimeElasticity_v1.js)
- Rewind speed scales with HOW FAR above threshold synergy is
- Formula: `effectiveRewindSpeed = baseRewindSpeed × (1 + (avgSynergy - threshold) × qualityScale)`
- Config: `_synergyQualityScale = 5.0` (default)
- At synergy 0.82 → 3.0/sec (base), at 0.90 → 4.2/sec, at 0.95 → 4.95/sec, at 1.0 → 5.7/sec
- Rewards excellence — maintaining higher synergy visibly speeds up rewind

#### Phase 4B: Pressure Escalation (VisualNetworkTimeElasticity_v1.js)
- Forward speed grows with Network Time — organic pressure increase
- Formula: `effectiveForwardSpeed = baseForwardSpeed × (1 + networkTimeCounter / escalationDivisor)`
- Config: `_escalationDivisor = 300` (forward doubles at NT=300)
- At NT=0 → 5/sec, at NT=100 → 6.67/sec, at NT=200 → 8.33/sec, at NT=300 → 10/sec
- Creates urgency — the longer you take, the harder it pushes
