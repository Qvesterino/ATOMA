- End events force transition to payoff phase (graceful early exit)
- All values bounded and clamped to prevent visual/audio glitches

## P6: Spatial Audio Zones for Environment Events — COMPLETED

### Problem
Dramaturgy audio cues played at center pan regardless of event origin position. All dramaturgy sounds felt flat and disconnected from the spatial world — a cascade event happening far to the left sounded identical to one on the right.

### Solution
Added position-aware stereo panning to dramaturgy audio cues. Event synths are temporarily routed through a `Tone.Panner` that computes stereo position from the event origin relative to the camera, with phase-dependent spatial behavior.

### Files Modified:

#### `AtomaAudioSystem.js`
- Added `Tone.Panner` in `createSynths()` (line 388) — connected to `masterReverb`
- Added `_dramaturgySpatialOrigin`, `_dramaturgyCamera`, `_dramaturgyRoutingActive`, `_dramaturgyRoutingTimeout` state fields
- Added `setDramaturgySpatialContext(origin, camera)` — receives event origin + camera from dramaturgy engine
- Added `_computeDramaturgyPan(phase)` — computes stereo pan from event origin relative to camera:
  - Uses camera forward direction + cross product for left/right determination
  - **Telegraph**: pan × 0.8 — directional, audio comes from event direction
  - **Escalation**: pan × 0.12 — center/wide, audio fills full stereo field
  - **Payoff**: pan × 0.5 — fading, audio drifts toward event origin
- Added `_routeDramaturgySpatial(panValue)` — routes `eventLeadSynth`, `eventAccentSynth`, `eventNoiseFilter` through panner with 2.5s auto-restore
- Added `_restoreDramaturgyRouting()` — restores normal synth → masterReverb routing
- Modified `_playDramaturgyCue()` — computes phase, calls `_routeDramaturgySpatial(panValue)`

#### `EventDramaturgyEngine.js`
- Modified `_playAudioCue()` — passes `sequence.origin.position` and `this._camera` to audio system via `setDramaturgySpatialContext()`

### Spatial Audio Flow:
1. Event triggers → `_playAudioCue()` extracts origin from sequence
2. Origin + camera passed to `setDramaturgySpatialContext()`
3. `_playDramaturgyCue()` computes phase → `_computeDramaturgyPan(phase)` → pan value
4. `_routeDramaturgySpatial(pan)` routes 3 event synths through panner
5. After 2.5s, `_restoreDramaturgyRouting()` auto-restores normal routing

### Safety:
- All disconnect/connect wrapped in try/catch (Tone.js can throw on already-disconnected nodes)
- Auto-restore timeout prevents permanent routing changes
- Pan computation returns 0 (center) if origin or camera is missing
