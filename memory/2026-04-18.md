### Proposal 2: Corrupted Lore — Text Distortion — COMPLETED

When corruption rises, the AI's ability to express itself degrades. Text literally falls apart.

**New file: `LoreSystem/CorruptedTextRenderer.js`**
- `corruptText(text, corruption, options)` — Applies Unicode-based text distortion
- 5 corruption levels: clear → hesitation → strain → fracture → breaking → near-silence
- Deterministic per-position hashing (no visual jitter)
- Preserves first word for readability below 70% corruption
- Uses Unicode combining characters for glitch effect

**Corruption levels:**
| Level | Corruption | Effect |
|-------|-----------|--------|
| Clear | 0-25% | Clean text |
| Hesitation | 25-40% | Occasional combining mark |
| Strain | 40-55% | More marks, some doubled |
| Fracture | 55-70% | Characters replaced with fragment symbols |
| Breaking | 70-85% | Most characters damaged |
| Near-silence | 85%+ | Almost unreadable |

**Modified `LoreFragmentEmitter.js`:**
- Constructor now accepts `getCorruption` function as 3rd parameter
- `_emitFragment()` applies `corruptText()` when corruption > 0.20

**Modified `main.js`:**
- `setupLoreFragmentEmitter()` passes corruption getter reading from `coreMetricsOverlay.currentMetrics.corruption`

### Proposal 7: The Living Chronicle — A Procedural Diary — COMPLETED

A procedural diary that builds from the player's actual session. Each playthrough generates a unique, shareable narrative document.

**New file: `LoreSystem/NetworkChronicle.js`** (~310 lines)
- `CHRONICLE_TEMPLATES` — 14 milestone template groups with state-aware variants (highHarmony, highCorruption, default)
- `MILESTONE_DEFINITIONS` — 16 milestone definitions with event bindings and conditions
- `NetworkChronicle` class — subscribes to semantic bus, tracks counters, generates entries

**Milestone events tracked:**
- Session start, first link, 5/10/25 links, first cascade, first collapse, first ritual
- Corruption spike (>0.55), harmony peak (>0.80)
- Game won, world change
- Time milestones: 5min, 10min, 20min, 30min
