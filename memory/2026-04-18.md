### Architecture:

#### Event Families (5 families with dramaturgy):
| Family | Trigger Events | End Events | Telegraph | Escalation | Payoff |
|--------|---------------|------------|-----------|------------|--------|
| cascade | cascade.start | cascade.end | 800ms/0.3 | 2000ms/1.0 | 1500ms/0.4 |
| corruption | network:corruptionSpread, node.corruption.high | topology.healing | 1200ms/0.4 | 3000ms/1.0 | 2000ms/0.3 |
| resonance | event:harmonyResonance, hub.harmony.high | — | 600ms/0.25 | 1500ms/0.8 | 1200ms/0.35 |
| ritual | semantic.ritual.started | semantic.ritual.completed | 1500ms/0.35 | 4000ms/1.0 | 2500ms/0.5 |
| hazard | environment.hazard.active, event:loadCollapse, event:instabilityTrap | — | 1000ms/0.4 | 2500ms/1.0 | 1800ms/0.3 |

#### Per-Phase Outputs:
- **Camera**: micro-shake + drift toward event origin (subtle, bounded)
- **Audio**: distinct synth voicing per family × phase
- **Environment**: desaturation shift + fog shift (additive across sequences)

#### Engine State (aggregated):
```js
{
  cameraShake: 0-0.15,
  cameraDrift: 0-1.0,
  desaturation: -0.15 to 0.3,
  fogShift: -0.1 to 0.2,
  dominantFamily: string|null,
  dominantIntensity: 0-1.0,
  activeCount: number
}
```

#### Debug API:
```
dramaturgy.status()   — Active state + sequences
dramaturgy.trigger(f) — Test sequence (f = cascade|corruption|resonance|ritual|hazard)
dramaturgy.clear()    — Clear all sequences
dramaturgy.enable()   — Enable engine
dramaturgy.disable()  — Disable engine
dramaturgy.help()     — Show help
```

### Key Design Decisions:
- Engine is owned by EnvironmentDomainController (not main.js directly)
- Camera reactions are micro-scale (max shake 0.15) — never jarring
- Environment modulation is additive — multiple sequences stack
- Per-family concurrent limits prevent spam (cascade: 3, corruption: 2, resonance: 2, ritual: 1, hazard: 2)
- 2-second family cooldown between triggers
- End events force transition to payoff phase (graceful early exit)
- All values bounded and clamped to prevent visual/audio glitches
- Environment systems receive modulation via optional `setDramaturgyModulation()` method (opt-in)
